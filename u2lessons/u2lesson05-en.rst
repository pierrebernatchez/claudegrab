A ``______________`` of functions is a set of functions that have the
same characteristics. Polynomial functions with the same
``______________`` are said to belong to the same family. The graphs of
polynomial functions that belong to the same family have the same
:math:`x`-intercepts but have different :math:`y`-intercepts (unless 0 is
one of the :math:`x`-intercepts).

An equation for the family of polynomial functions with zeros
:math:`a_1, a_2, a_3, \ldots, a_n` is:

.. math::

   y = k(x - a_1)(x - a_2)(x - a_3) \ldots (x - a_n), \text{ where } k \in
   \mathbb{R}, k \neq 0
