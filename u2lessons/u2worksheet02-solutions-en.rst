**1\)** Calculate each of the following using synthetic division. Express
your answer using the statement that could be used to check the division.

.. list-table::
   :widths: 50 50
   :header-rows: 0

   * - a\) :math:`x^3 - 7x - 6` divided by :math:`x - 3`

       .. image:: ../images/u2worksheet02-image01.png
          :alt: synthetic division of x^3 - 7x - 6 by x - 3, b = 3, quotient x^2 + 3x + 2 remainder 0

       .. math::

          x^3 - 7x - 6 = (x - 3)(x^2 + 3x + 2)
     - b\) :math:`2x^3 - 7x^2 - 7x + 19` divided by :math:`x - 1`

       .. image:: ../images/u2worksheet02-image02.png
          :alt: synthetic division of 2x^3 - 7x^2 - 7x + 19 by x - 1, b = 1, quotient 2x^2 - 5x - 12 remainder 7

       .. math::

          2x^3 - 7x^2 - 7x + 19 = (x - 1)(2x^2 - 5x - 12) + 7
   * - c\) :math:`6x^4 + 13x^3 - 34x^2 - 47x + 28` divided by :math:`x + 3`

       .. image:: ../images/u2worksheet02-image03.png
          :alt: synthetic division of 6x^4 + 13x^3 - 34x^2 - 47x + 28 by x + 3, b = -3, quotient 6x^3 - 5x^2 - 19x + 10 remainder -2

       .. math::

          6x^4 + 13x^3 - 34x^2 - 47x + 28 = (x + 3)(6x^3 - 5x^2 - 19x + 10) - 2
     - d\) :math:`2x^3 + x^2 - 22x + 20` divided by :math:`2x - 3`

       :math:`2x - 3 = 2\left(x - \dfrac{3}{2}\right) \rightarrow b = \dfrac{3}{2}`

       .. image:: ../images/u2worksheet02-image04.png
          :alt: synthetic division of 2x^3 + x^2 - 22x + 20 by x - 3/2, b = 3/2, before dividing by 2: quotient 2x^2 + 4x - 16 remainder -4

       .. math::

          \frac{2x^2 + 4x - 16}{2} = x^2 + 2x - 8

       .. math::

          2x^3 + x^2 - 22x + 20 = (2x - 3)(x^2 + 2x - 8) - 4
   * - e\) :math:`12x^4 - 56x^3 + 59x^2 + 9x - 18` divided by :math:`2x + 1`

       :math:`2x + 1 = 2\left(x + \dfrac{1}{2}\right) \rightarrow b = -\dfrac{1}{2}`

       .. image:: ../images/u2worksheet02-image05.png
          :alt: synthetic division of 12x^4 - 56x^3 + 59x^2 + 9x - 18 by x + 1/2, b = -1/2, before dividing by 2: quotient 12x^3 - 62x^2 + 90x - 36 remainder 0

       .. math::

          \frac{12x^3 - 62x^2 + 90x - 36}{2} = 6x^3 - 31x^2 + 45x - 18

       .. math::

          12x^4 - 56x^3 + 59x^2 + 9x - 18 = (2x + 1)(6x^3 - 31x^2 + 45x - 18)
     - f\) :math:`6x^3 - 15x^2 - 2x + 5` divided by :math:`2x - 5`

       :math:`2x - 5 = 2\left(x - \dfrac{5}{2}\right) \rightarrow b = \dfrac{5}{2}`

       .. image:: ../images/u2worksheet02-image06.png
          :alt: synthetic division of 6x^3 - 15x^2 - 2x + 5 by x - 5/2, b = 5/2, before dividing by 2: quotient 6x^2 + 0x - 2 remainder 0

       .. math::

          \frac{6x^2 + 0x - 2}{2} = 3x^2 - 1

       .. math::

          6x^3 - 15x^2 - 2x + 5 = (2x - 5)(3x^2 - 1)
   * - g\) :math:`x^3 - 2x + 1` divided by :math:`x - 4`

       .. image:: ../images/u2worksheet02-image07.png
          :alt: synthetic division of x^3 - 2x + 1 by x - 4, b = 4, quotient x^2 + 4x + 14 remainder 57

       .. math::

          x^3 - 2x + 1 = (x - 4)(x^2 + 4x + 14) + 57
     - h\) :math:`x^3 + 2x^2 - 6x + 1` divided by :math:`x + 2`

       .. image:: ../images/u2worksheet02-image08.png
          :alt: synthetic division of x^3 + 2x^2 - 6x + 1 by x + 2, b = -2, quotient x^2 + 0x - 6 remainder 13

       .. math::

          x^3 + 2x^2 - 6x + 1 = (x + 2)(x^2 - 6) + 13

**2\)** Divide :math:`x^4 - 16x^3 + 4x^2 + 10x - 11` by each of the
following binomials...

.. list-table::
   :widths: 50 50
   :header-rows: 0

   * - a\) :math:`x - 2`

       .. image:: ../images/u2worksheet02-image09.png
          :alt: synthetic division of x^4 - 16x^3 + 4x^2 + 10x - 11 by x - 2, b = 2, quotient x^3 - 14x^2 - 24x - 38 remainder -87

       .. math::

          x^4 - 16x^3 + 4x^2 + 10x - 11 = (x - 2)(x^3 - 14x^2 - 24x - 38) - 87
     - b\) :math:`x + 4`

       .. image:: ../images/u2worksheet02-image10.png
          :alt: synthetic division of x^4 - 16x^3 + 4x^2 + 10x - 11 by x + 4, b = -4, quotient x^3 - 20x^2 + 84x - 326 remainder 1293

       .. math::

          x^4 - 16x^3 + 4x^2 + 10x - 11 = (x + 4)(x^3 - 20x^2 + 84x - 326) + 1293

**3\)** Are either of the binomials in question #2 factors of
:math:`x^4 - 16x^3 + 4x^2 + 10x - 11`? Explain.

No, because dividing by each binomial leaves a non-zero remainder
(:math:`-87` and :math:`1293` respectively).
