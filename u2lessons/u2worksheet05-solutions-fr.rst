**1\)** Les zéros d'une fonction quadratique sont -7 et -3.

.. rst-class:: keepwithnext

**a\)** Déterminez une équation pour la famille de fonctions quadratiques
ayant ces zéros.

.. rst-class:: solution

:math:`y = k(x + 7)(x + 3)`

.. rst-class:: keepwithnext

**b\)** Écrivez des équations pour deux fonctions qui appartiennent à
cette famille.

.. rst-class:: solution

:math:`y = 87(x + 7)(x + 3)`

.. rst-class:: solution

:math:`y = 71(x + 7)(x + 3)`

.. rst-class:: keepwithnext

**c\)** Déterminez une équation pour le membre de la famille qui passe
par le point :math:`(2, 18)`.

.. rst-class:: solution

:math:`18 = k(2 + 7)(2 + 3)`

.. rst-class:: solution

:math:`18 = 45k`

.. rst-class:: solution

:math:`k = \dfrac{2}{5}`

.. rst-class:: solution

:math:`y = \dfrac{2}{5}(x + 7)(x + 3)`

.. rst-class:: keepwithnext

**2\)** Examinez les fonctions suivantes. Laquelle n'appartient pas à la
même famille ?

.. rst-class:: keepwithnext

a\) :math:`y = 1.5(x + 4)(x - 5)(x - 2)`

.. rst-class:: keepwithnext

b\) :math:`y = -1.5(x - 2)(x - 5)(x + 4)`

.. rst-class:: keepwithnext

c\) :math:`y = 1.5(x - 2)(x + 4)(x - 2)`

.. rst-class:: keepwithnext

d\) :math:`y = 3(x - 5)(x - 2)(x + 4)`

.. rst-class:: solution

Réponse : **c\)** |---| elle a une racine répétée en :math:`x = 2` au lieu
des zéros partagés :math:`-4`, :math:`2`, et :math:`5`.

**5\)**

.. rst-class:: keepwithnext

**a\)** Déterminez une équation pour la famille de fonctions cubiques
avec les zéros :math:`1 \pm \sqrt{2}` et :math:`-\dfrac{1}{2}`

.. rst-class:: solution

Facteurs :

.. rst-class:: solution

:math:`x = 1 \pm \sqrt{2}`

.. rst-class:: solution

:math:`x - 1 = \pm\sqrt{2}`

.. rst-class:: solution

:math:`(x - 1)^2 = 2`

.. rst-class:: solution

:math:`x^2 - 2x + 1 = 2`

.. rst-class:: solution

:math:`x^2 - 2x - 1 = 0`

.. rst-class:: solution

:math:`x = -\dfrac{1}{2}`

.. rst-class:: solution

:math:`2x = -1`

.. rst-class:: solution

:math:`2x + 1 = 0`

.. rst-class:: solution

:math:`y = k(x^2 - 2x - 1)(2x + 1)`

.. rst-class:: keepwithnext

**b\)** Déterminez une équation pour le membre de la famille dont le
graphique passe par le point :math:`(3, 35)`.

.. rst-class:: solution

:math:`35 = k[(3)^2 - 2(3) - 1][2(3) + 1]`

.. rst-class:: solution

:math:`35 = k(2)(7)`

.. rst-class:: solution

:math:`35 = 14k`

.. rst-class:: solution

:math:`k = \dfrac{35}{14} = \dfrac{5}{2}`

.. rst-class:: solution

:math:`y = \dfrac{5}{2}(x^2 - 2x - 1)(2x + 1)`

.. rst-class:: keepwithnext

**6\)**

.. rst-class:: keepwithnext

**a\)** Déterminez une équation pour la famille de fonctions quartiques
avec les zéros 3 (ordre 2) et :math:`-4 \pm \sqrt{3}`.

.. rst-class:: solution

Facteurs :

.. rst-class:: solution

:math:`x = 3` (ordre 2) :math:`\rightarrow (x - 3)^2`

.. rst-class:: solution

:math:`x = -4 \pm \sqrt{3}`

.. rst-class:: solution

:math:`x + 4 = \pm\sqrt{3}`

.. rst-class:: solution

:math:`(x + 4)^2 = 3`

.. rst-class:: solution

:math:`x^2 + 8x + 16 = 3`

.. rst-class:: solution

:math:`x^2 + 8x + 13 = 0`

.. rst-class:: solution

:math:`y = k(x - 3)^2(x^2 + 8x + 13)`

.. rst-class:: keepwithnext

**b\)** Déterminez une équation pour le membre de la famille dont le
graphique passe par le point :math:`(1, -22)`.

.. rst-class:: solution

:math:`-22 = k(1 - 3)^2[(1)^2 + 8(1) + 13]`

.. rst-class:: solution

:math:`-22 = k(4)(22)`

.. rst-class:: solution

:math:`-22 = 88k`

.. rst-class:: solution

:math:`k = -\dfrac{1}{4}`

.. rst-class:: solution

:math:`y = -\dfrac{1}{4}(x - 3)^2(x^2 + 8x + 13)`
