**1\)** Utilisez le théorème du reste pour déterminer le reste lorsque
:math:`2x^3 + 7x^2 - 8x + 3` est divisé par chaque binôme.

a\) :math:`x + 1`

.. math::
   :nowrap:

   \begin{array}{rcl}
   P(-1) &=& 2(-1)^3 + 7(-1)^2 - 8(-1) + 3 \\
   &=& 16
   \end{array}

b\) :math:`x - 2`

.. math::
   :nowrap:

   \begin{array}{rcl}
   P(2) &=& 2(2)^3 + 7(2)^2 - 8(2) + 3 \\
   &=& 31
   \end{array}

c\) :math:`x + 3`

.. math::
   :nowrap:

   \begin{array}{rcl}
   P(-3) &=& 2(-3)^3 + 7(-3)^2 - 8(-3) + 3 \\
   &=& 36
   \end{array}

**2\)** a\) Divisez :math:`x^3 + 3x^2 - 2x + 5` par :math:`x + 1`. Exprimez le résultat sous forme de quotient.

.. image:: ../images/u2worksheet01-tabimage01.png
   :alt: (x^3 + 3x^2 - 2x + 5) divisé par (x + 1) par division longue, quotient x^2 + 2x - 4 reste 9

Le résultat sous forme de quotient est :

.. math::

   \frac{x^3 + 3x^2 - 2x + 5}{x + 1} = x^2 + 2x - 4 + \frac{9}{x + 1}

b\) Écrivez l'énoncé correspondant qui peut être utilisé pour vérifier la division.

.. math::

   x^3 + 3x^2 - 2x + 5 = (x + 1)(x^2 + 2x - 4) + 9

**3\)** Divisez :math:`3x^4 - 4x^3 - 6x^2 + 17x - 8` par :math:`3x - 4`. Exprimez le résultat sous
forme de quotient.

Remarque : le dividende n'a pas de terme en :math:`x^2` à l'endroit voulu pour cette étape, un terme
de substitution :math:`0x^2` est donc utilisé pour garder les colonnes alignées.

.. image:: ../images/u2worksheet01-tabimage02.png
   :alt: (3x^4 - 4x^3 - 6x^2 + 17x - 8) divisé par (3x - 4) par division longue, quotient x^3 - 2x + 3 reste 4

Le résultat sous forme de quotient est :

.. math::

   \frac{3x^4 - 4x^3 - 6x^2 + 17x - 8}{3x - 4} = x^3 - 2x + 3 + \frac{4}{3x - 4}

b\) Écrivez l'énoncé correspondant qui peut être utilisé pour vérifier la division.

.. math::

   3x^4 - 4x^3 - 6x^2 + 17x - 8 = (3x - 4)(x^3 - 2x + 3) + 4

**4\)** Effectuez chaque division. Exprimez le résultat sous forme de quotient.

a\) :math:`x^3 + 7x^2 - 3x + 4` divisé par :math:`x + 2`

.. image:: ../images/u2worksheet01-tabimage03.png
   :alt: (x^3 + 7x^2 - 3x + 4) divisé par (x + 2) par division longue, quotient x^2 + 5x - 13 reste 30

.. math::

   \frac{x^3 + 7x^2 - 3x + 4}{x + 2} = x^2 + 5x - 13 + \frac{30}{x + 2}

b\) :math:`6x^3 + x^2 - 14x - 6` divisé par :math:`3x + 2`

.. image:: ../images/u2worksheet01-tabimage04.png
   :alt: (6x^3 + x^2 - 14x - 6) divisé par (3x + 2) par division longue, quotient 2x^2 - x - 4 reste 2

.. math::

   \frac{6x^3 + x^2 - 14x - 6}{3x + 2} = 2x^2 - x - 4 + \frac{2}{3x + 2}

c\) :math:`10x^3 + 11 - 9x^2 - 8x` divisé par :math:`5x - 2`

Remarque : le dividende est d'abord réordonné en ordre décroissant standard de degré :
:math:`10x^3 - 9x^2 - 8x + 11`.

.. image:: ../images/u2worksheet01-tabimage05.png
   :alt: (10x^3 - 9x^2 - 8x + 11) divisé par (5x - 2) par division longue, quotient 2x^2 - x - 2 reste 7

.. math::

   \frac{10x^3 - 9x^2 - 8x + 11}{5x - 2} = 2x^2 - x - 2 + \frac{7}{5x - 2}

d\) :math:`11x - 4x^4 - 7` divisé par :math:`x - 3`

Remarque : le dividende est d'abord réordonné en ordre décroissant standard de degré :
:math:`-4x^4 + 0x^3 + 0x^2 + 11x - 7`.

.. image:: ../images/u2worksheet01-tabimage06.png
   :alt: (-4x^4 + 11x - 7) divisé par (x - 3) par division longue, quotient -4x^3 - 12x^2 - 36x - 97 reste -298

.. math::

   \frac{-4x^4 + 11x - 7}{x - 3} = -4x^3 - 12x^2 - 36x - 97 - \frac{298}{x - 3}

e\) :math:`6x^3 + x^2 + 7x + 3` divisé par :math:`3x + 2`

.. image:: ../images/u2worksheet01-tabimage07.png
   :alt: (6x^3 + x^2 + 7x + 3) divisé par (3x + 2) par division longue, quotient 2x^2 - x + 3 reste -3

.. math::

   \frac{6x^3 + x^2 + 7x + 3}{3x + 2} = 2x^2 - x + 3 - \frac{3}{3x + 2}

f\) :math:`8x^3 + 4x^2 - 31` divisé par :math:`2x - 3`

Remarque : le dividende n'a pas de terme en :math:`x`, un terme de substitution :math:`0x` est donc
utilisé pour garder les colonnes alignées.

.. image:: ../images/u2worksheet01-tabimage08.png
   :alt: (8x^3 + 4x^2 - 31) divisé par (2x - 3) par division longue, quotient 4x^2 + 8x + 12 reste 5

.. math::

   \frac{8x^3 + 4x^2 - 31}{2x - 3} = 4x^2 + 8x + 12 + \frac{5}{2x - 3}

g\) :math:`6x^2 - 6 + 8x^3` divisé par :math:`4x - 3`

Remarque : le dividende est d'abord réordonné en ordre décroissant standard de degré :
:math:`8x^3 + 6x^2 + 0x - 6`.

.. math::
   :nowrap:

   \begin{array}{l}
   \hphantom{4x - 3 \; )\; 8x^3 {}+{}} 2x^2 + 3x + \frac{9}{4} \\
   4x - 3 \;\overline{)\; 8x^3 + 6x^2 + 0x - 6} \\
   \hphantom{4x - 3 \; )\;} \underline{8x^3 - 6x^2} \\
   \hphantom{4x - 3 \; )\; 8x^3 {}-{}} 12x^2 + 0x \\
   \hphantom{4x - 3 \; )\; 8x^3 {}-{}} \underline{12x^2 - 9x} \\
   \hphantom{4x - 3 \; )\; 8x^3 {}-{} 12x^2 {}-{}} 9x - 6 \\
   \hphantom{4x - 3 \; )\; 8x^3 {}-{} 12x^2 {}-{}} \underline{9x - \frac{27}{4}} \\
   \hphantom{4x - 3 \; )\; 8x^3 {}-{} 12x^2 {}-{} 9x {}-{}} \frac{3}{4}
   \end{array}

.. math::

   \frac{6x^2 - 6 + 8x^3}{4x - 3} = 2x^2 + 3x + \frac{9}{4} + \frac{3}{4(4x - 3)}

**5\)** Le volume, en cm cubes, d'une boîte rectangulaire peut être modélisé par l'expression
polynomiale :math:`2x^3 + 17x^2 + 38x + 15`. Déterminez les dimensions possibles de la boîte si la
hauteur, en cm, est donnée par :math:`x + 5`.

.. image:: ../images/u2worksheet01-tabimage09.png
   :alt: (2x^3 + 17x^2 + 38x + 15) divisé par (x + 5) par division longue, quotient 2x^2 + 7x + 3 reste 0

.. math::

   2x^3 + 17x^2 + 38x + 15 = (x + 5)(2x^2 + 7x + 3) = (x + 5)(x + 3)(2x + 1)

Les dimensions possibles de la boîte sont :math:`x + 5` (hauteur), :math:`x + 3` (longueur), et
:math:`2x + 1` (largeur).

**6\)** Déterminez la valeur de :math:`k` telle que lorsque :math:`P(x) = kx^3 + 5x^2 - 2x + 3` est
divisé par :math:`x + 1`, le reste est 7.

Le reste est :math:`P(-1)`. Résolvez pour :math:`k` lorsque :math:`P(-1)` est égal à 7.

.. math::
   :nowrap:

   \begin{array}{rcl}
   P(-1) &=& k(-1)^3 + 5(-1)^2 - 2(-1) + 3 \\
   7 &=& -k + 5 + 2 + 3 \\
   7 &=& -k + 10 \\
   -3 &=& -k \\
   3 &=& k
   \end{array}

La valeur de :math:`k` est donc :math:`3`.
