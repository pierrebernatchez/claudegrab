it have line symmetry about the :math:`y`-axis, point symmetry about
the origin, or neither?

a\) :math:`y = x^4 - x^2`

**Even**, line symmetry about the :math:`y`-axis

b\) :math:`y = -2x^3 + 5x`

**Odd**, point symmetry about the origin

c\) :math:`y = -4x^5 + 2x^2`

**Neither**

d\) :math:`y = x(2x+1)^2(x-4)`

**Neither**

.. math::

   x(2x+1)^2(x-4) = 4x^4 - 12x^3 - 15x^2 - 4x

e\) :math:`y = -2x^6 + x^4 + 8`

**Even**, line symmetry about the :math:`y`-axis

**2\)** State whether each function is even or odd. Verify
algebraically.

a\) :math:`f(x) = x^4 - 13x^2 + 36`

**Even**

.. math::

   f(-x) = (-x)^4 - 13(-x)^2 + 36 = x^4 - 13x^2 + 36

So :math:`f(-x) = f(x)`.

b\) :math:`g(x) = 6x^5 - 7x^3 - 3x`

**Odd**

.. math::

   g(-x) = 6(-x)^5 - 7(-x)^3 - 3(-x) = -6x^5 + 7x^3 + 3x

So :math:`g(-x) = -g(x)`.
