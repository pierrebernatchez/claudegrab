**2\)** Indiquez si chaque fonction est paire ou impaire. Vérifiez
algébriquement.

a\) :math:`f(x) = x^4 - 13x^2 + 36`

**Paire**

.. math::

   f(-x) = (-x)^4 - 13(-x)^2 + 36 = x^4 - 13x^2 + 36

Donc :math:`f(-x) = f(x)`.

b\) :math:`g(x) = 6x^5 - 7x^3 - 3x`

**Impaire**

.. math::

   g(-x) = 6(-x)^5 - 7(-x)^3 - 3(-x) = -6x^5 + 7x^3 + 3x

Donc :math:`g(-x) = -g(x)`.
