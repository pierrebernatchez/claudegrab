**5\)** Write the equation of each function

a\)

.. image:: ../images/worksheet03-image17.png
   :alt: cubic through (-3, 0), (2, 0), (5, 0) and the point (1, 8)

Zeros at :math:`-3, 2, 5`, so :math:`f(x) = a(x+3)(x-2)(x-5)`.
Substituting :math:`(1, 8)`: :math:`8 = a(4)(-1)(-4) = 16a \implies
a = 0.5`.

.. math::

   f(x) = 0.5(x+3)(x-2)(x-5)

b\)

.. image:: ../images/worksheet03-image18.png
   :alt: quartic touching at (-1, 0), crossing (2, 0) and (4, 0), and the
         point (1, -12)

The graph touches (doesn't cross) at :math:`x = -1`, so that's an
order-2 zero: :math:`f(x) = a(x+1)^2(x-2)(x-4)`.
Substituting :math:`(1, -12)`: :math:`-12 = a(4)(-1)(-3) = 12a \implies a = -1`.

.. math::

   f(x) = -(x+1)^2(x-2)(x-4)

**6\)** Determine an equation for a quintic function with
zeros :math:`-1` (order 3) and :math:`3` (order 2) that passes through the
point :math:`(-2, 50)`.

.. math::

   f(x) = a(x+1)^3(x-3)^2

Substituting :math:`(-2, 50)`:

.. math::

   50 = a(-1)^3(-5)^2 = a(-1)(25) = -25a \implies a = -2

.. math::

   f(x) = -2(x+1)^3(x-3)^2

**7\)** Determine the zeros
of :math:`f(x) = (2x^2-x-1)(x^2-3x-4)`.

Factor each quadratic: :math:`2x^2-x-1 = (2x+1)(x-1)`
and :math:`x^2-3x-4 = (x-4)(x+1)`.

.. math::

   f(x) = (2x+1)(x-1)(x-4)(x+1)

The zeros are :math:`x =` **4, 1, -1, and -0.5**.
