a\) Démontrez algébriquement si f est paire, impaire ou ni l'une ni
l'autre.

.. math::
   :class: solution

   f(-x) = -3(-x)^4 + 6(-x)^2 - 10 = -3x^4 + 6x^2 - 10 = f(x)

.. rst-class:: solution

Puisque :math:`f(-x) = f(x)`, la fonction est paire.

.. rst-class:: keepwithnext

b\) Pour quelle différence finie f donnera-t-elle une valeur constante,
et quelle sera cette valeur constante ?

.. rst-class:: solution

Elle est de degré 4, donc les quatrièmes différences seront constantes.
Différences finies :math:`= -3(4!) = -72`

.. rst-class:: keepwithnext

c\) Quel est le nombre maximum et minimum de zéros que peut avoir le
polynôme ci-dessus ?

.. rst-class:: solution

Zéros minimum = 0, Zéros maximum = 4. Pour un degré 4, le nombre de
zéros possible est 4, 3, 2, 1 ou 0.
