**1)** Let :math:`f(x) = 3x-5` and :math:`g(x) = 2x+3`.

.. rst-class:: solution

.. rst-class:: solution

:math:`h(2) = 5(2)-2 = 8`

value of :math:`k(2)`.

.. rst-class:: solution

:math:`k(x) = (3x-5)-(2x+3) = 3x-5-2x-3 = x-8`

.. rst-class:: solution

:math:`k(2) = 2-8 = -6`

**3)** Let :math:`f(x) = x-2` and :math:`g(x) = x^2+3x-3`. Determine an
algebraic and graphical model for :math:`h(x) = f(x)+g(x)`.

.. rst-class:: solution

:math:`h(x) = (x-2)+(x^2+3x-3) = x^2+4x-5 = (x+5)(x-1)`

.. rst-class:: solution

:math:`x\text{-int}: x=-5` and :math:`x=1`

.. rst-class:: solution

:math:`x\text{-vertex} = \dfrac{-5+1}{2} = -2`; :math:`h(-2) =
(-2)^2+4(-2)-5 = -9`, so vertex :math:`(-2,-9)`

.. rst-class:: solution

:math:`y\text{-int}: h(0) = 0^2+4(0)-5 = -5`, so :math:`(0,-5)`

.. image:: ../images/u7worksheet04-gpimage03.png
   :scale: 90
   :alt: h(x)=x^2+4x-5, an upward parabola vertex (-2,-9)

**4)** Let :math:`f(x) = x-2` and :math:`g(x) = x^2-4`. Develop an
algebraic and graphical model for each of the following:

.. rst-class:: keepwithnext

a\) :math:`y = f(x)g(x)`

.. rst-class:: solution

:math:`y = (x-2)(x^2-4) = (x-2)(x-2)(x+2) = (x-2)^2(x+2)`

.. rst-class:: solution

:math:`x\text{-int}: (2,0)` order 2, :math:`(-2,0)` order 1

.. rst-class:: solution

:math:`y\text{-int}: y = (0-2)^2(0+2) = 8`, so :math:`(0,8)`

.. image:: ../images/u7worksheet04-gpimage04.png
   :scale: 90
   :alt: y=(x-2)^2(x+2), a cubic with a double root at x=2

.. rst-class:: keepwithnext

b\) :math:`y = \dfrac{f(x)}{g(x)}`

.. rst-class:: solution

:math:`y = \dfrac{x-2}{x^2-4} = \dfrac{x-2}{(x-2)(x+2)} = \dfrac{1}{x+2};
x \neq -2, 2`

.. rst-class:: solution

Hole at :math:`x=2`; :math:`VA: x=-2`; :math:`HA: y=0`

.. image:: ../images/u7worksheet04-gpimage05.png
   :scale: 90
   :alt: y=1/(x+2), a hyperbola with VA x=-2 and a hole at x=2

.. rst-class:: keepwithnext

c\) :math:`y = \dfrac{g(x)}{f(x)}`

.. rst-class:: solution

:math:`y = \dfrac{x^2-4}{x-2} = \dfrac{(x-2)(x+2)}{x-2} = x+2; x \neq 2`

.. rst-class:: solution

Hole at :math:`x=2`

.. image:: ../images/u7worksheet04-gpimage06.png
   :scale: 90
   :alt: y=x+2, a line with a hole at x=2

**5)** Let :math:`f(x) = x^2+2x-4` and :math:`g(x) = \dfrac{1}{x+1}`.

.. rst-class:: keepwithnext

a\) Evaluate :math:`g(f(0))`

.. rst-class:: solution

:math:`f(0) = 0^2+2(0)-4 = -4`

.. rst-class:: solution

:math:`g(f(0)) = g(-4) = \dfrac{1}{-4+1} = -\dfrac{1}{3}`

.. rst-class:: keepwithnext

b\) Evaluate :math:`f(g(-2))`

.. rst-class:: solution

:math:`g(-2) = \dfrac{1}{-2+1} = -1`

.. rst-class:: solution

:math:`f(g(-2)) = f(-1) = (-1)^2+2(-1)-4 = -5`

**6)** Let :math:`f(x) = x^2+3x` and :math:`g(x) = 2x-5`. Determine an
equation for each composite function and graph it.

.. rst-class:: keepwithnext

a\) :math:`y = f(g(x))`

.. rst-class:: solution

:math:`f(g(x)) = (2x-5)^2+3(2x-5) = 4x^2-20x+25+6x-15 = 4x^2-14x+10 =
2(2x^2-7x+5) = 2[x(2x-5)-1(2x-5)] = 2(2x-5)(x-1)`

.. rst-class:: solution

:math:`x\text{-int}: x=1` and :math:`x=2.5`; :math:`y\text{-int}:
(0,10)`

.. rst-class:: solution

:math:`x\text{-vertex} = \dfrac{1+2.5}{2} = 1.75`; :math:`y\text{-vertex}
= -2.25`

.. rst-class:: solution

.. rst-class:: keepwithnext

d\) :math:`y = g^{-1}(g(x))`

.. rst-class:: solution

To find :math:`g^{-1}(x)`: let :math:`y=2x-5`, swap to get
:math:`x=2y-5`, solve: :math:`\dfrac{x+5}{2}=y`, so :math:`g^{-1}(x) =
\dfrac{x+5}{2}`

.. rst-class:: solution

:math:`g^{-1}(g(x)) = \dfrac{(2x-5)+5}{2} = \dfrac{2x}{2} = x`

.. rst-class:: solution

:math:`m=1`, :math:`b=0` — this is the identity line, since applying a
function's inverse right after the function itself always returns the
original input.
