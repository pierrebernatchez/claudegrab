plus de renseignements caractéristiques possible sur le graphique (p. ex.

d'autres points déterminants, etc.).

.. rst-class:: solution

\dfrac{8}{2(2)} = 2`. Discriminant :math:`b^2-4ac = (-8)^2-4(2)(9) = -8`,
