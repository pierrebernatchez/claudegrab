**2)** Trace le graphique de chacune des fonctions suivantes. Assure-toi
d'indiquer les caractéristiques clés des fonctions, y compris les
abscisses/ordonnées à l'origine et les asymptotes.

.. rst-class:: keepwithnext

a\) :math:`f(x) = \dfrac{x}{x-5}`

.. rst-class:: solution

:math:`AV: x = 5`, :math:`AH: y = 1`. Abscisse à l'origine : :math:`0 =
\dfrac{x}{x-5} \Rightarrow x = 0`, donc :math:`(0,0)`; ordonnée à
l'origine : :math:`f(0) = \dfrac{0}{-5} = 0`, donc aussi :math:`(0,0)`

.. rst-class:: solution

Autres points : :math:`f(2) = \dfrac{2}{-3} = -0.67`, donc
:math:`(2,-0.67)`; :math:`f(4) = \dfrac{4}{-1} = -4`, donc :math:`(4,-4)`

   :scale: 90
   :alt: f(x)=x/(x-5), une hyperbole avec AV x=5 et AH y=1

.. rst-class:: keepwithnext

b\) :math:`c(x) = \dfrac{4x}{x+8}`

.. rst-class:: solution

:math:`AV: x = -8`, :math:`AH: y = 4`. Abscisse à l'origine : :math:`0 =
\dfrac{4x}{x+8} \Rightarrow x = 0`, donc :math:`(0,0)`, ce qui est aussi
l'ordonnée à l'origine

.. rst-class:: solution

Autres points : :math:`c(-6) = \dfrac{4(-6)}{-6+8} = \dfrac{-24}{2} =
-12`, donc :math:`(-6,-12)`; :math:`c(-4) = \dfrac{4(-4)}{-4+8} =
\dfrac{-16}{4} = -4`, donc :math:`(-4,-4)`

.. image:: ../images/u7worksheet02-gpimage02.png
   :scale: 90
   :alt: c(x)=4x/(x+8), une hyperbole avec AV x=-8 et AH y=4

.. rst-class:: keepwithnext

c\) :math:`k(x) = \dfrac{x+1}{4-x}`

.. rst-class:: solution

:math:`AV: x = 4`, :math:`AH: y = -1`. Abscisse à l'origine : :math:`0 =
x+1 \Rightarrow x = -1`, donc :math:`(-1,0)`; ordonnée à l'origine :
:math:`k(0) = \dfrac{1}{4} = 0.25`, donc :math:`(0,0.25)`

.. rst-class:: solution

Autre point : :math:`k(3) = \dfrac{3+1}{4-3} = 4`, donc :math:`(3,4)`

.. image:: ../images/u7worksheet02-gpimage03.png
   :scale: 90
   :alt: k(x)=(x+1)/(4-x), une hyperbole avec AV x=4 et AH y=-1

.. rst-class:: keepwithnext

d\) :math:`w(x) = \dfrac{x+2}{4x-5}`

.. rst-class:: solution

:math:`AV: x = 1.25`, :math:`AH: y = 0.25`. Abscisse à l'origine :
:math:`0 = x+2 \Rightarrow x = -2`, donc :math:`(-2,0)`; ordonnée à
l'origine : :math:`w(0) = \dfrac{2}{-5} = -0.4`, donc :math:`(0,-0.4)`

.. rst-class:: solution

Autre point : :math:`w(1) = \dfrac{1+2}{4-5} = -3`, donc :math:`(1,-3)`

.. image:: ../images/u7worksheet02-gpimage04.png
   :scale: 90
   :alt: w(x)=(x+2)/(4x-5), une hyperbole avec AV x=1.25 et AH y=0.25

.. rst-class:: keepwithnext

e\) :math:`d(x) = \dfrac{-2x-3}{x+5}`

.. rst-class:: solution

:math:`AV: x = -5`, :math:`AH: y = -2`. Abscisse à l'origine : :math:`0 =
-2x-3 \Rightarrow x = -1.5`, donc :math:`(-1.5,0)`; ordonnée à l'origine :
:math:`d(0) = \dfrac{-3}{5} = -0.6`, donc :math:`(0,-0.6)`

.. rst-class:: solution

Autre point : :math:`d(-4) = \dfrac{-2(-4)-3}{-4+5} = \dfrac{5}{1} = 5`,
donc :math:`(-4,5)`

.. image:: ../images/u7worksheet02-gpimage05.png
   :scale: 90
   :alt: d(x)=(-2x-3)/(x+5), une hyperbole avec AV x=-5 et AH y=-2

.. rst-class:: keepwithnext

f\) :math:`m(x) = \dfrac{3x+1}{2x+1}`

.. rst-class:: solution

:math:`AV: x = -0.5`, :math:`AH: y = 1.5`. Abscisse à l'origine :
:math:`0 = 3x+1 \Rightarrow x = -0.33`, donc :math:`(-0.33,0)`; ordonnée
à l'origine : :math:`m(0) = \dfrac{1}{1} = 1`, donc :math:`(0,1)`

.. rst-class:: solution

Autre point : :math:`m(1) = \dfrac{3(1)+1}{2(1)+1} = \dfrac{4}{3} =
1.33`, donc :math:`(1,1.33)`

.. image:: ../images/u7worksheet02-gpimage06.png
   :scale: 90
   :alt: m(x)=(3x+1)/(2x+1), une hyperbole avec AV x=-0.5 et AH y=1.5

.. rst-class:: keepwithnext

g\) :math:`g(x) = \dfrac{x-2}{x^2+3x+2}`

.. rst-class:: solution

*(utilise une calculatrice graphique ou Desmos)*

.. rst-class:: solution

:math:`g(x) = \dfrac{x-2}{x^2+3x+2} = \dfrac{x-2}{(x+2)(x+1)}`

.. rst-class:: solution

:math:`AH: y = 0`, :math:`AV: x = -2` et :math:`x = -1`

.. rst-class:: solution

Abscisse à l'origine : :math:`0 = x-2 \Rightarrow x = 2`, donc
:math:`(2,0)`; ordonnée à l'origine : :math:`g(0) = \dfrac{0-2}{(0+2)(0+1)}
= -1`, donc :math:`(0,-1)`
