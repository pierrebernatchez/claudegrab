**6)** The cosecant function is the reciprocal of the sine function. For
:math:`\sin^{-1}`, the -1 is NOT an exponent but instead a notation
meaning the opposite operation of sine. The sine function takes an angle
for an input and gives a ratio as an output. :math:`\sin^{-1}` takes a
ratio for an input and gives the angle as an output.
