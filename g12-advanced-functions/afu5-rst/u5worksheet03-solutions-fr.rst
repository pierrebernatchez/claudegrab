**4)** Déterminer les valeurs de :math:`\sin2\theta`, :math:`\cos2\theta`,
et :math:`\tan2\theta`, sachant que :math:`\cos\theta = \dfrac{3}{5}` et
:math:`0 \leq \theta \leq \dfrac{\pi}{2}`

.. list-table::
   :widths: 40 60
   :width: 100%

   * - .. image:: ../images/u5worksheet03-gpimage01.png
          :scale: 90
          :alt: angle theta au quadrant I, cos theta = 3/5, côtés du triangle 3, 4, 5
     - .. rst-class:: solution

       :math:`\sin(2\theta) = 2\sin\theta\cos\theta = 2\left(\dfrac45\right)\left(\dfrac35\right) = \dfrac{24}{25}`

       .. rst-class:: solution

       :math:`\cos(2\theta) = \cos^2\theta-\sin^2\theta = \left(\dfrac35\right)^2-\left(\dfrac45\right)^2 = -\dfrac{7}{25}`

       .. rst-class:: solution

       :math:`\tan(2\theta) = \dfrac{2\tan\theta}{1-\tan^2\theta} = \dfrac{2\left(\frac43\right)}{1-\left(\frac43\right)^2} = -\dfrac{24}{7}`

**5)** Déterminer les valeurs de :math:`\sin2\theta`, :math:`\cos2\theta`,
et :math:`\tan2\theta`, sachant que :math:`\tan\theta = -\dfrac{7}{24}` et
:math:`\dfrac{\pi}{2} \leq \theta \leq \pi`

.. list-table::
   :widths: 40 60
   :width: 100%

   * - .. image:: ../images/u5worksheet03-gpimage02.png
          :scale: 90
          :alt: angle theta au quadrant II, tan theta = -7/24, côtés du triangle 7, 24, 25
     - .. rst-class:: solution

       :math:`\sin(2\theta) = 2\sin\theta\cos\theta = 2\left(\dfrac{7}{25}\right)\left(-\dfrac{24}{25}\right) = -\dfrac{336}{625}`

       .. rst-class:: solution

       :math:`\cos(2\theta) = \cos^2\theta-\sin^2\theta = \left(-\dfrac{24}{25}\right)^2-\left(\dfrac{7}{25}\right)^2 = \dfrac{527}{625}`

       .. rst-class:: solution

       :math:`\tan(2\theta) = \dfrac{\sin(2\theta)}{\cos(2\theta)} = \dfrac{-336/625}{527/625} = -\dfrac{336}{527}`

**6)** Déterminer les valeurs de :math:`\sin2\theta`, :math:`\cos2\theta`,
et :math:`\tan2\theta`, sachant que :math:`\sin\theta = -\dfrac{12}{13}` et
:math:`\dfrac{3\pi}{2} \leq \theta \leq 2\pi`

.. list-table::
   :widths: 40 60
   :width: 100%

   * - .. image:: ../images/u5worksheet03-gpimage03.png
          :scale: 90
          :alt: angle theta au quadrant IV, sin theta = -12/13, côtés du triangle 5, 12, 13
     - .. rst-class:: solution

       :math:`\sin(2\theta) = 2\sin\theta\cos\theta = 2\left(-\dfrac{12}{13}\right)\left(\dfrac{5}{13}\right) = -\dfrac{120}{169}`

       .. rst-class:: solution

       :math:`\cos(2\theta) = \cos^2\theta-\sin^2\theta = \left(\dfrac{5}{13}\right)^2-\left(-\dfrac{12}{13}\right)^2 = -\dfrac{119}{169}`

       .. rst-class:: solution

       :math:`\tan(2\theta) = \dfrac{\sin(2\theta)}{\cos(2\theta)} = \dfrac{-120/169}{-119/169} = \dfrac{120}{119}`

**8)** Déterminer la valeur de :math:`a` dans l'équation
:math:`2\tan x - \tan(2x) + 2a = 1 - \tan(2x)\tan^2 x`

.. rst-class:: solution

:math:`2\tan x + 2a - 1 = \tan(2x) - \tan(2x)\tan^2 x`

.. rst-class:: solution

:math:`2\tan x + 2a - 1 = \tan(2x)\left(1-\tan^2 x\right)`

.. rst-class:: solution

:math:`2\tan x + 2a - 1 = \dfrac{2\tan x}{1-\tan^2 x}\left(1-\tan^2 x\right)`

.. rst-class:: solution

:math:`2\tan x + 2a - 1 = 2\tan x`

.. rst-class:: solution

:math:`2a - 1 = 0`

.. rst-class:: solution

:math:`a = \dfrac{1}{2}`
