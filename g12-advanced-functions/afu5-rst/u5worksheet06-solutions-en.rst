Determine solutions for each equation in the interval
:math:`0 \leq x \leq 2\pi`, to the nearest hundredth of a radian. Give
exact answers where possible.

.. rst-class:: keepwithnext

a\) :math:`\sin(2x) - 0.8 = 0`

.. rst-class:: solution

Let :math:`\theta = 2x`. :math:`\sin\theta = 0.8`

.. image:: ../images/u5worksheet06-gpimage01.png
   :scale: 90
   :alt: unit circle with two solution angles approximately 0.93 and 2.21 radians for theta

.. rst-class:: solution

:math:`\theta_1 = \sin^{-1}(0.8) \approx 0.93`

.. rst-class:: solution

:math:`\theta_2 = \pi - 0.93 \approx 2.21`

.. rst-class:: solution

:math:`2x = \theta \rightarrow 2x = 0.93 \rightarrow x_1 \approx 0.46`,
and :math:`2x = 2.21 \rightarrow x_2 \approx 1.11`

Add the period of :math:`\pi` to find other solutions:

.. rst-class:: solution

:math:`x_3 = x_1 + \pi \approx 3.61`

.. rst-class:: solution

:math:`x_4 = x_2 + \pi \approx 4.25`

.. rst-class:: keepwithnext

d\) :math:`\sin(2x) = \dfrac{1}{\sqrt2}`

.. rst-class:: solution

Let :math:`\theta = 2x`. :math:`\sin\theta = \dfrac{1}{\sqrt2}`. From
special triangle: :math:`\sin\dfrac{\pi}{4} = \dfrac{1}{\sqrt2}`. Place
in Q1 and Q2.

.. image:: ../images/u5worksheet06-gpimage04.png
   :scale: 90
   :alt: unit circle with two exact solution angles pi/4 and 3 pi/4 for theta

.. rst-class:: solution

:math:`\theta_1 = \dfrac{\pi}{4}`, :math:`\theta_2 = \pi - \dfrac{\pi}{4} = \dfrac{3\pi}{4}`

.. rst-class:: solution

:math:`2x = \theta \rightarrow 2x = \dfrac{\pi}{4} \rightarrow x_1 = \dfrac{\pi}{8}`,
and :math:`2x = \dfrac{3\pi}{4} \rightarrow x_2 = \dfrac{3\pi}{8}`

Add the period of :math:`\pi` to find other solutions:

.. rst-class:: solution

:math:`x_3 = x_1 + \pi = \dfrac{\pi}{8} + \pi = \dfrac{9\pi}{8}`

.. rst-class:: solution

:math:`x_4 = x_2 + \pi = \dfrac{3\pi}{8} + \pi = \dfrac{11\pi}{8}`
