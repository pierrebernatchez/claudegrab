**Example 1:** Prove :math:`\dfrac{\sin(2x)}{1+\cos(2x)} = \tan x`

.. list-table::
   :widths: 50 50
   :width: 100%
   :header-rows: 1

   * - LS
     - RS
   * - .. rst-class:: solution

       :math:`= \dfrac{\sin(2x)}{1+\cos(2x)}`

       .. rst-class:: solution

       :math:`= \dfrac{\sin(2x)}{1+2\cos^2 x - 1}`

       .. rst-class:: solution

       :math:`= \dfrac{2\sin x \cos x}{2\cos^2 x}`

       .. rst-class:: solution

       :math:`= \dfrac{\sin x}{\cos x}`
     - .. rst-class:: solution

       :math:`= \tan x`

       .. rst-class:: solution

       :math:`= \dfrac{\sin x}{\cos x}`

.. rst-class:: solution

**LS = RS**

**Example 2:** Prove :math:`\cos\left(\dfrac{\pi}{2}+x\right) = -\sin x`

.. list-table::
   :widths: 50 50
   :width: 100%
   :header-rows: 1

   * - LS
     - RS
   * - .. rst-class:: solution

       :math:`= \cos\left(\dfrac{\pi}{2}+x\right)`

       .. rst-class:: solution

       :math:`= \cos\dfrac{\pi}{2}\cos x - \sin\dfrac{\pi}{2}\sin x`

       .. rst-class:: solution

       :math:`= 0(\cos x) - 1\sin x`

       .. rst-class:: solution

       :math:`= -\sin x`
     - .. rst-class:: solution

       :math:`= -\sin x`

.. rst-class:: solution

**LS = RS**

**Example 3:** Prove :math:`\csc(2x) = \dfrac{\csc x}{2\cos x}`

.. list-table::
   :widths: 50 50
   :width: 100%
   :header-rows: 1

   * - LS
     - RS
   * - .. rst-class:: solution

       :math:`= \csc(2x)`

       .. rst-class:: solution

       :math:`= \dfrac{1}{\sin(2x)}`

       .. rst-class:: solution

       :math:`= \dfrac{1}{2\sin x \cos x}`
     - .. rst-class:: solution

       :math:`= \dfrac{\csc x}{2\cos x}`

       .. rst-class:: solution

       :math:`= \csc x \cdot \dfrac{1}{2\cos x}`

       .. rst-class:: solution

       :math:`= \dfrac{1}{\sin x} \cdot \dfrac{1}{2\cos x}`

       .. rst-class:: solution

       :math:`= \dfrac{1}{2\sin x \cos x}`

.. rst-class:: solution

**LS = RS**

**Example 4:** Prove :math:`\cos x = \dfrac{1}{\cos x} - \sin x \tan x`

.. list-table::
   :widths: 50 50
   :width: 100%
   :header-rows: 1

   * - LS
     - RS
   * - .. rst-class:: solution

       :math:`= \cos x`
     - .. rst-class:: solution

       :math:`= \dfrac{1}{\cos x} - \sin x \tan x`

       .. rst-class:: solution

       :math:`= \dfrac{1}{\cos x} - \sin x \left(\dfrac{\sin x}{\cos x}\right)`

       .. rst-class:: solution

       :math:`= \dfrac{1}{\cos x} - \dfrac{\sin^2 x}{\cos x}`

       .. rst-class:: solution

       :math:`= \dfrac{\cos^2 x}{\cos x}`

       .. rst-class:: solution

       :math:`= \cos x`

.. rst-class:: solution

**LS = RS**

**Example 5:** Prove :math:`\tan(2x) - 2\tan(2x)\sin^2 x = \sin 2x`

.. list-table::
   :widths: 50 50
   :width: 100%
   :header-rows: 1

   * - LS
     - RS
   * - .. rst-class:: solution

       :math:`= \tan(2x) - 2\tan(2x)\sin^2 x`

       .. rst-class:: solution

       :math:`= \tan(2x)\left[1-2\sin^2 x\right]`

       .. rst-class:: solution

       :math:`= \tan(2x)\cos(2x)`

       .. rst-class:: solution

       :math:`= \dfrac{\sin(2x)}{\cos(2x)} \cdot \cos(2x)`

       .. rst-class:: solution

       :math:`= \sin(2x)`
     - .. rst-class:: solution

       :math:`= \sin(2x)`

.. rst-class:: solution

**LS = RS**

**Example 6:** Prove :math:`\dfrac{\cos(x-y)}{\cos(x+y)} = \dfrac{1+\tan x \tan y}{1-\tan x \tan y}`

.. list-table::
   :widths: 50 50
   :width: 100%
   :header-rows: 1

   * - LS
     - RS
   * - .. rst-class:: solution

       :math:`= \dfrac{\cos(x-y)}{\cos(x+y)}`

       .. rst-class:: solution

       :math:`= \dfrac{\cos x \cos y + \sin x \sin y}{\cos x \cos y - \sin x \sin y}`
     - .. rst-class:: solution

       :math:`= \dfrac{1+\left(\frac{\sin x}{\cos x}\right)\left(\frac{\sin y}{\cos y}\right)}{1-\left(\frac{\sin x}{\cos x}\right)\left(\frac{\sin y}{\cos y}\right)} \times \dfrac{\cos x \cos y}{\cos x \cos y}`

       .. rst-class:: solution

       :math:`= \dfrac{\cos x \cos y + \sin x \sin y}{\cos x \cos y - \sin x \sin y}`

.. rst-class:: solution

**LS = RS**
