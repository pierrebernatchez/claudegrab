Part 1: Investigation
================================================================================

.. image:: ../images/u5lesson06-gpimage01.png
   :scale: 90
   :alt: y = sin x with 2 marked solutions, next to y = sin(2x) with 4 marked solutions

.. rst-class:: keepwithnext

a\) What is the period of both of the functions above? How many cycles
between 0 and :math:`2\pi` radians?

.. rst-class:: solution

For :math:`y = \sin x \rightarrow period = 2\pi`

.. rst-class:: solution

For :math:`y = \sin(2x) \rightarrow period = \dfrac{2\pi}{2} = \pi`

.. rst-class:: keepwithnext

b\) Looking at the graph of :math:`y = \sin x`, how many solutions are
there for :math:`\sin x = \dfrac{1}{\sqrt2} \approx 0.71` ?

.. rst-class:: solution

2 solutions

.. rst-class:: solution

:math:`\sin\dfrac{\pi}{4} = \sin\dfrac{3\pi}{4} = \dfrac{1}{\sqrt2}`

.. rst-class:: keepwithnext

c\) Looking at the graph of :math:`y = \sin(2x)`, how many solutions are
there for :math:`\sin(2x) = \dfrac{1}{\sqrt2} \approx 0.71` ?

.. rst-class:: solution

4 solutions

.. rst-class:: solution

:math:`\sin\left[2\left(\dfrac{\pi}{8}\right)\right] = \sin\left[2\left(\dfrac{3\pi}{8}\right)\right] = \sin\left[2\left(\dfrac{9\pi}{8}\right)\right] = \sin\left[2\left(\dfrac{11\pi}{8}\right)\right] = \dfrac{1}{\sqrt2}`

.. rst-class:: keepwithnext

d\) When the period of a function is cut in half, what does that do to
the number of solutions between 0 and :math:`2\pi` radians?

.. rst-class:: solution

Doubles the number of solutions

Part 2: Solve Linear Trigonometric Equations that Involve Double Angles
================================================================================

.. rst-class:: keepwithnext

**Example 1:** :math:`\sin(2\theta) = \dfrac{\sqrt3}{2}` where
:math:`0 \leq \theta \leq 2\pi`

.. rst-class:: solution

Let :math:`2\theta = x`. :math:`\sin x = \dfrac{\sqrt3}{2} \rightarrow`
Graph? No :math:`\rightarrow` Triangle? Yes

.. image:: ../images/u5lesson06-gpimage02.png
   :scale: 55
   :alt: 30-60-90 special triangle, sides 1, root 3, and 2

.. rst-class:: solution

:math:`\sin\dfrac{\pi}{3} = \dfrac{\sqrt3}{2}`. Put the reference angle
in Q1 and Q2, where sine is positive.

.. image:: ../images/u5lesson06-gpimage03.png
   :scale: 90
   :alt: unit circle with two solution angles pi/3 and 2 pi/3 for x

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{3}`

.. rst-class:: solution

:math:`x_2 = \pi - \dfrac{\pi}{3} = \dfrac{2\pi}{3}`

.. rst-class:: solution

:math:`2\theta = x \rightarrow 2\theta = \dfrac{\pi}{3} \rightarrow \theta_1 = \dfrac{\pi}{6}`,
and :math:`2\theta = \dfrac{2\pi}{3} \rightarrow \theta_2 = \dfrac{\pi}{3}`

:math:`y = \sin(2\theta)` has a period of :math:`\pi`; add :math:`\pi`
to :math:`\theta_1` and :math:`\theta_2` to find other angles
:math:`0 \leq \theta \leq 2\pi` that have equivalent ratios.

.. rst-class:: solution

:math:`\theta_3 = \theta_1 + \pi = \dfrac{\pi}{6} + \pi = \dfrac{7\pi}{6}`

.. rst-class:: solution

:math:`\theta_4 = \theta_2 + \pi = \dfrac{\pi}{3} + \pi = \dfrac{4\pi}{3}`

.. rst-class:: solution

:math:`\sin\left[2\left(\dfrac{\pi}{6}\right)\right] = \sin\left[2\left(\dfrac{\pi}{3}\right)\right] = \sin\left[2\left(\dfrac{7\pi}{6}\right)\right] = \sin\left[2\left(\dfrac{4\pi}{3}\right)\right] = \dfrac{\sqrt3}{2}`

.. rst-class:: keepwithnext

**Example 2:** :math:`\cos(2\theta) = -\dfrac{1}{2}` where
:math:`0 \leq \theta \leq 2\pi`

.. rst-class:: solution

Let :math:`2\theta = x`. :math:`\cos x = -\dfrac{1}{2} \rightarrow`
Graph? No :math:`\rightarrow` Triangle? Yes

.. image:: ../images/u5lesson06-gpimage04.png
   :scale: 55
   :alt: 30-60-90 special triangle, sides 1, root 3, and 2

.. rst-class:: solution

:math:`\cos\dfrac{\pi}{3} = \dfrac{1}{2}`. Put the reference angle in
Q2 and Q3, where cosine is negative.

.. image:: ../images/u5lesson06-gpimage05.png
   :scale: 90
   :alt: unit circle with two solution angles 2 pi/3 and 4 pi/3 for x

.. rst-class:: solution

:math:`x_1 = \pi - \dfrac{\pi}{3} = \dfrac{2\pi}{3}`

.. rst-class:: solution

:math:`x_2 = \pi + \dfrac{\pi}{3} = \dfrac{4\pi}{3}`

.. rst-class:: solution

:math:`2\theta = x \rightarrow 2\theta = \dfrac{2\pi}{3} \rightarrow \theta_1 = \dfrac{\pi}{3}`,
and :math:`2\theta = \dfrac{4\pi}{3} \rightarrow \theta_2 = \dfrac{2\pi}{3}`

Remember that :math:`\cos(2\theta)` has a period of :math:`\pi`; add
:math:`\pi` to :math:`\theta_1` and :math:`\theta_2` to find other
solutions :math:`0 \leq \theta \leq 2\pi`.

.. rst-class:: solution

:math:`\theta_3 = \theta_1 + \pi = \dfrac{\pi}{3} + \pi = \dfrac{4\pi}{3}`

.. rst-class:: solution

:math:`\theta_4 = \theta_2 + \pi = \dfrac{2\pi}{3} + \pi = \dfrac{5\pi}{3}`

.. rst-class:: solution

:math:`\cos\left[2\left(\dfrac{\pi}{3}\right)\right] = \cos\left[2\left(\dfrac{2\pi}{3}\right)\right] = \cos\left[2\left(\dfrac{4\pi}{3}\right)\right] = \cos\left[2\left(\dfrac{5\pi}{3}\right)\right] = -\dfrac{1}{2}`

.. rst-class:: keepwithnext

**Example 3:** :math:`\tan(2\theta) = 1` where :math:`0 \leq \theta \leq 2\pi`

.. rst-class:: solution

Let :math:`2\theta = x`. :math:`\tan x = 1 \rightarrow` Graph? No
:math:`\rightarrow` Triangle? Yes

.. image:: ../images/u5lesson06-gpimage06.png
   :scale: 55
   :alt: 45-45-90 special triangle, legs 1 and 1, hypotenuse root 2

.. rst-class:: solution

:math:`\tan\dfrac{\pi}{4} = 1`. Put the reference angle in Q1 and Q3,
where tangent is positive.

.. image:: ../images/u5lesson06-gpimage07.png
   :scale: 90
   :alt: unit circle with two solution angles pi/4 and 5 pi/4 for x

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{4}`

.. rst-class:: solution

:math:`x_2 = \pi + \dfrac{\pi}{4} = \dfrac{5\pi}{4}`

.. rst-class:: solution

:math:`2\theta = x \rightarrow 2\theta = \dfrac{\pi}{4} \rightarrow \theta_1 = \dfrac{\pi}{8}`,
and :math:`2\theta = \dfrac{5\pi}{4} \rightarrow \theta_2 = \dfrac{5\pi}{8}`

Remember that :math:`\tan(2\theta)` has a period of :math:`\dfrac{\pi}{2}`;
add :math:`\dfrac{\pi}{2}` to :math:`\theta_1` and :math:`\theta_2` to
find other solutions :math:`0 \leq \theta \leq 2\pi`.

.. rst-class:: solution

:math:`\theta_3 = \theta_2 + \dfrac{\pi}{2} = \dfrac{5\pi}{8} + \dfrac{4\pi}{8} = \dfrac{9\pi}{8}`

.. rst-class:: solution

:math:`\theta_4 = \theta_3 + \dfrac{\pi}{2} = \dfrac{9\pi}{8} + \dfrac{4\pi}{8} = \dfrac{13\pi}{8}`

.. rst-class:: solution

:math:`\tan\left[2\left(\dfrac{\pi}{8}\right)\right] = \tan\left[2\left(\dfrac{5\pi}{8}\right)\right] = \tan\left[2\left(\dfrac{9\pi}{8}\right)\right] = \tan\left[2\left(\dfrac{13\pi}{8}\right)\right] = 1`
