**1)** Solve :math:`\sin^2 x - 2\sin x - 3 = 0` on the interval
:math:`0 \leq x \leq 2\pi`

.. rst-class:: solution

:math:`(\sin x - 3)(\sin x + 1) = 0`

.. rst-class:: solution

:math:`\sin x - 3 = 0 \rightarrow \sin x = 3 \rightarrow` No solution

.. rst-class:: solution

:math:`\sin x + 1 = 0 \rightarrow \sin x = -1`

.. image:: ../images/u5worksheet07-gpimage01.png
   :scale: 90
   :alt: unit circle with the point (0,-1) marked, solution 3 pi/2

.. rst-class:: solution

:math:`x = \dfrac{3\pi}{2}`

.. rst-class:: keepwithnext

**2)** Solve :math:`\csc^2 x - \csc x - 2 = 0` on the interval
:math:`0 \leq x \leq 2\pi`

.. rst-class:: solution

:math:`(\csc x - 2)(\csc x + 1) = 0`

.. rst-class:: solution

:math:`\csc x - 2 = 0 \rightarrow \csc x = 2 \rightarrow \sin x = \dfrac{1}{2}`

.. image:: ../images/u5worksheet07-gpimage02.png
   :scale: 90
   :alt: unit circle with two solution angles pi/6 and 5 pi/6

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{6}`, :math:`x_2 = \pi - \dfrac{\pi}{6} = \dfrac{5\pi}{6}`

.. rst-class:: solution

:math:`\csc x + 1 = 0 \rightarrow \csc x = -1 \rightarrow \sin x = -1`

.. image:: ../images/u5worksheet07-gpimage01.png
   :scale: 90
   :alt: unit circle with the point (0,-1) marked, solution 3 pi/2

.. rst-class:: solution

:math:`x_3 = \dfrac{3\pi}{2}`

.. rst-class:: solution

Answer: :math:`x = \dfrac{\pi}{6}, \dfrac{5\pi}{6}, \dfrac{3\pi}{2}`

.. rst-class:: keepwithnext

**3)** Solve :math:`2\sec^2 x - \sec x - 1 = 0` on the interval
:math:`0 \leq x \leq 2\pi`

.. rst-class:: solution

:math:`2\sec^2 x - 2\sec x + \sec x - 1 = 0`

.. rst-class:: solution

:math:`2\sec x(\sec x - 1) + 1(\sec x - 1) = 0`

.. rst-class:: solution

:math:`(\sec x - 1)(2\sec x + 1) = 0`

.. rst-class:: solution

:math:`\sec x - 1 = 0 \rightarrow \sec x = 1 \rightarrow \cos x = 1`

.. image:: ../images/u5worksheet07-gpimage03.png
   :scale: 90
   :alt: unit circle with the point (1,0) marked, solutions 0 and 2 pi

.. rst-class:: solution

:math:`x_1 = 0`, :math:`x_2 = 2\pi`

.. rst-class:: solution

:math:`2\sec x + 1 = 0 \rightarrow \sec x = -\dfrac{1}{2} \rightarrow \cos x = -2 \rightarrow`
No solution

.. rst-class:: solution

Answer: :math:`x = 0, 2\pi`

**5)** Solve :math:`6\cos^2 x + 5\cos x - 6 = 0` on the interval
:math:`0 \leq x \leq 2\pi`

.. rst-class:: solution

:math:`6\cos^2 x + 9\cos x - 4\cos x - 6 = 0`

   :alt: unit circle with two solution angles approximately 0.84 and 5.44 radians

.. rst-class:: solution

Answer: :math:`x \approx 0.84, 5.44`

**8)** Solve :math:`\cot x \csc^2 x = 2\cot x` on the interval
:math:`0 \leq x \leq 2\pi`

.. rst-class:: solution

:math:`0 = 2\cot x - \cot x \csc^2 x`

.. rst-class:: solution

:math:`0 = \cot x (2 - \csc^2 x)`

.. rst-class:: solution

:math:`\cot x = 0 \rightarrow \tan x` undefined

.. image:: ../images/u5worksheet07-gpimage09.png
   :scale: 90
   :alt: unit circle with the points (0,1) and (0,-1) marked, solutions pi/2 and 3 pi/2

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{2}`, :math:`x_2 = \dfrac{3\pi}{2}`

.. rst-class:: solution

:math:`2 - \csc^2 x = 0 \rightarrow \csc^2 x = 2 \rightarrow \sin^2 x = \dfrac{1}{2} \rightarrow \sin x = \pm\dfrac{1}{\sqrt2}`

.. image:: ../images/u5worksheet07-gpimage08.png
   :scale: 90
   :alt: unit circle with four solution angles pi/4, 3 pi/4, 5 pi/4, 7 pi/4

:math:`x_5 = \dfrac{5\pi}{4}`, :math:`x_6 = \dfrac{7\pi}{4}`

.. rst-class:: solution

**9)** Solve for :math:`\theta` to the nearest hundredth, where
:math:`0 \leq \theta \leq 2\pi`

.. rst-class:: keepwithnext

a\) :math:`3\tan^2\theta - 2\tan\theta = 1`

.. rst-class:: solution

:math:`3\tan^2\theta - 2\tan\theta - 1 = 0`

.. rst-class:: solution

:math:`3\tan^2\theta - 3\tan\theta + 1\tan\theta - 1 = 0`

.. rst-class:: solution

:math:`3\tan\theta(\tan\theta - 1) + 1(\tan\theta - 1) = 0`

.. rst-class:: solution

:math:`(\tan\theta - 1)(3\tan\theta + 1) = 0`

.. rst-class:: solution

:math:`\tan\theta = 1`

.. image:: ../images/u5worksheet07-gpimage10.png
   :scale: 90
   :alt: unit circle with two exact solution angles pi/4 and 5 pi/4

.. rst-class:: solution

:math:`\theta_1 = \dfrac{\pi}{4}`, :math:`\theta_2 = \pi + \dfrac{\pi}{4} = \dfrac{5\pi}{4}`

.. rst-class:: solution

:math:`\tan\theta = -\dfrac{1}{3} \rightarrow \theta_3 = \tan^{-1}\left(-\dfrac{1}{3}\right) \approx -0.32 + 2\pi \approx 5.96`

.. image:: ../images/u5worksheet07-gpimage11.png
   :scale: 90
   :alt: unit circle with two solution angles approximately 2.82 and 5.96 radians

.. rst-class:: solution

:math:`\theta_3 \approx 5.96`, :math:`\theta_4 = \pi - 0.32 \approx 2.82`

.. rst-class:: solution

Answer: :math:`\theta = \dfrac{\pi}{4}, \dfrac{5\pi}{4}, 2.82, 5.96`
