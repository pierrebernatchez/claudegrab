Dans la leçon précédente, nous avons travaillé avec des identités. Les
identités sont des équations vraies pour TOUTE valeur de :math:`x`.
Dans cette leçon, nous travaillerons avec des équations qui ne sont pas
des identités. Nous devrons résoudre pour la ou les valeurs qui rendent
l'équation vraie.

Rappelons que 2 solutions sont possibles pour un angle entre 0 et
:math:`2\pi` avec un rapport donné. Utiliser l'angle de référence et la
règle CAST pour déterminer les angles.

Pour résoudre une équation trigonométrique, considérer les 3 outils
suivants :

1. Triangles spéciaux
2. Graphiques des fonctions trigonométriques
3. Calculatrice

.. rst-class:: keepwithnext

**Exemple 1 :** Trouver toutes les solutions de :math:`\cos\theta = -\dfrac{\sqrt3}{2}`
dans l'intervalle :math:`0 \leq \theta \leq 2\pi`

.. rst-class:: solution

:math:`-\dfrac{\sqrt3}{2} \rightarrow` Graphique? Non :math:`\rightarrow` Triangle? Oui

.. image:: ../images/u5lesson05-gpimage01.png
   :scale: 55
   :alt: triangle spécial 30-60-90, côtés 1, racine de 3, et 2

.. rst-class:: solution

:math:`\cos\dfrac{\pi}{6} = \dfrac{\sqrt3}{2}`, donc l'angle de référence
est :math:`\dfrac{\pi}{6}`. Placer l'angle de référence dans les
quadrants 2 et 3 pour rendre le rapport négatif.

.. image:: ../images/u5lesson05-gpimage02.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions 5 pi/6 et 7 pi/6

.. rst-class:: solution

:math:`\theta_1 = \pi - \dfrac{\pi}{6} = \dfrac{5\pi}{6}`

.. rst-class:: solution

:math:`\theta_2 = \pi + \dfrac{\pi}{6} = \dfrac{7\pi}{6}`

.. rst-class:: solution

:math:`\cos\dfrac{5\pi}{6} = \cos\dfrac{7\pi}{6} = -\dfrac{\sqrt3}{2}`

.. rst-class:: keepwithnext

**Exemple 2 :** Trouver toutes les solutions de :math:`\tan\theta = 5`
dans l'intervalle :math:`0 \leq \theta \leq 2\pi`

.. rst-class:: solution

:math:`\tan\theta = 5 \rightarrow` Graphique? Non :math:`\rightarrow` Triangle?
Non :math:`\rightarrow` Calculatrice

**Remarque :** Tan est positif aux quadrants I et III.

.. image:: ../images/u5lesson05-gpimage03.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions environ 1,37 et 4,51 radians

.. rst-class:: solution

:math:`\tan\theta = 5`

.. rst-class:: solution

:math:`\theta_1 = \tan^{-1}(5)`

.. rst-class:: solution

:math:`\theta_1 \approx 1.37` radians

.. rst-class:: solution

:math:`\theta_2 = \pi + 1.37`

.. rst-class:: solution

:math:`\theta_2 \approx 4.51` radians

.. rst-class:: solution

:math:`\tan(1.37) = \tan(4.51) = 5`

.. rst-class:: keepwithnext

**Exemple 3 :** Trouver toutes les solutions de :math:`2\sin x + 1 = 0`
dans l'intervalle :math:`0 \leq x \leq 2\pi`

.. rst-class:: solution

:math:`2\sin x + 1 = 0`

.. rst-class:: solution

:math:`2\sin x = -1`

.. rst-class:: solution

:math:`\sin x = -\dfrac{1}{2}` :math:`\rightarrow` Graphique? Non :math:`\rightarrow`
Triangle? Oui

.. image:: ../images/u5lesson05-gpimage01.png
   :scale: 55
   :alt: triangle spécial 30-60-90, côtés 1, racine de 3, et 2

.. rst-class:: solution

:math:`\sin\dfrac{\pi}{6} = \dfrac{1}{2}`, utiliser comme angle de
référence aux quadrants 3 et 4 pour rendre le rapport négatif.

.. image:: ../images/u5lesson05-gpimage04.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions 7 pi/6 et 11 pi/6

.. rst-class:: solution

:math:`\theta_1 = \pi + \dfrac{\pi}{6} = \dfrac{7\pi}{6}`

.. rst-class:: solution

:math:`\theta_2 = 2\pi - \dfrac{\pi}{6} = \dfrac{11\pi}{6}`

.. rst-class:: solution

:math:`\sin\dfrac{7\pi}{6} = \sin\dfrac{11\pi}{6} = -\dfrac{1}{2}`

.. rst-class:: keepwithnext

**Exemple 4 :** Résoudre :math:`3(\tan x + 1) = 2`, où
:math:`0 \leq x \leq 2\pi`

.. rst-class:: solution

:math:`3(\tan x + 1) = 2`

.. rst-class:: solution

:math:`\tan x + 1 = \dfrac{2}{3}`

.. rst-class:: solution

:math:`\tan x = \dfrac{2}{3} - 1`

.. rst-class:: solution

:math:`\tan x = -\dfrac{1}{3}` :math:`\rightarrow` Graphique? Non :math:`\rightarrow`
Triangle? Non :math:`\rightarrow` Calculatrice

**Remarque :** Tan est négatif aux quadrants II et IV.

.. image:: ../images/u5lesson05-gpimage05.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions environ 2,82 et 5,96 radians

.. rst-class:: solution

:math:`\tan x = -\dfrac{1}{3}`

.. rst-class:: solution

:math:`x_1 = \tan^{-1}\left(-\dfrac{1}{3}\right)`

.. rst-class:: solution

:math:`x_1 = -0.32175`

.. rst-class:: solution

:math:`x_1 = 2\pi - 0.32175`

.. rst-class:: solution

:math:`x_1 \approx 5.96` radians

.. rst-class:: solution

:math:`x_2 = \pi - 0.32`

.. rst-class:: solution

:math:`x_2 \approx 2.82` radians

.. rst-class:: solution

:math:`\tan(5.96) = \tan(2.82) = -\dfrac{1}{3}`
