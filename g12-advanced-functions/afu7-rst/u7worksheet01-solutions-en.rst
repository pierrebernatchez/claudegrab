h\) :math:`p(x) = \dfrac{4}{2x^2-8x+9}`

.. rst-class:: solution

:math:`y = 2x^2 - 8x + 9`, vertex at :math:`x = -\dfrac{b}{2a} =
\dfrac{8}{2(2)} = 2`. Discriminant :math:`b^2-4ac = (-8)^2-4(2)(9) = -8`,
so :math:`VA:` none. :math:`HA: y = 0`
