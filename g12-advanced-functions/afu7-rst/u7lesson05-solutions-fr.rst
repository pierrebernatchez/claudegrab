Partie 1 : Expressions rationnelles
================================================================================

**Expression rationnelle :** le quotient de deux polynômes,
:math:`\dfrac{p(x)}{q(x)}`, où :math:`q(x) \neq 0`

.. rst-class:: keepwithnext

**Exemple 1 :** Simplifie et indique les restrictions de chaque
expression rationnelle

.. rst-class:: keepwithnext

a\) :math:`\dfrac{2x^2-8}{x^2+3x+2}`

.. rst-class:: solution

:math:`= \dfrac{2(x^2-4)}{(x+2)(x+1)} = \dfrac{2(x-2)(x+2)}{(x+2)(x+1)} =
\dfrac{2(x-2)}{x+1}; x \neq -2,-1`

.. rst-class:: keepwithnext

b\) :math:`\dfrac{x^3-x^2-x+1}{3x^3-3}`

.. rst-class:: solution

:math:`= \dfrac{(x^3-x^2)+(-x+1)}{3(x^3-1)} = \dfrac{x^2(x-1)-1(x-1)}{3(x-1)(x^2+x+1)}
= \dfrac{(x-1)(x^2-1)}{3(x-1)(x^2+x+1)} = \dfrac{(x-1)(x+1)}{3(x^2+x+1)};
x \neq 1`

Partie 2 : Résoudre des équations rationnelles
================================================================================

.. list-table::
   :width: 100%

   * - Étapes pour résoudre une équation rationnelle :

       1. Factorise complètement les deux côtés de l'équation
       2. Multiplie les deux côtés par un dénominateur commun (multiplie
          en croix si approprié)
       3. Continue à résoudre comme tu le ferais pour une équation
          polynomiale normale
       4. Indique les restrictions tout au long (valeurs de :math:`x`
          qui rendraient le dénominateur égal à zéro)

.. rst-class:: keepwithnext

**Exemple 2 :** Résous chaque équation

.. rst-class:: keepwithnext

a\) :math:`\dfrac{4}{3x-5} = 4`

.. rst-class:: solution

:math:`(3x-5)\left(\dfrac{4}{3x-5}\right) = 4(3x-5); x \neq \dfrac{5}{3}`

.. rst-class:: solution

:math:`4 = 4(3x-5)`

.. rst-class:: solution

:math:`4 = 12x-20`

.. rst-class:: solution

:math:`24 = 12x`

.. rst-class:: solution

:math:`x = 2`

.. rst-class:: keepwithnext

b\) :math:`\dfrac{6}{x-2} = x-1`

.. rst-class:: solution

:math:`(x-2)\left(\dfrac{6}{x-2}\right) = (x-2)(x-1); x \neq 2`

.. rst-class:: solution

:math:`6 = x^2-x-2x+2`

.. rst-class:: solution

:math:`0 = x^2-3x-4`

.. rst-class:: solution

:math:`0 = (x-4)(x+1)`

.. rst-class:: solution

:math:`x-4=0 \Rightarrow x_1=4`; :math:`x+1=0 \Rightarrow x_2=-1`

.. rst-class:: keepwithnext

c\) :math:`\dfrac{x-5}{x^2-3x-4} = \dfrac{3x+2}{x^2-1}`

.. rst-class:: solution

:math:`\dfrac{x-5}{(x-4)(x+1)} = \dfrac{3x+2}{(x-1)(x+1)}; x \neq -1,1,4`

.. rst-class:: solution

:math:`(x-1)(x+1)(x-4)(x-5) = (x-4)(x+1)(x-1)(3x+2)` — annule le facteur
commun :math:`(x+1)` des deux côtés :

.. rst-class:: solution

:math:`(x-1)(x-5) = (x-4)(3x+2)`

.. rst-class:: solution

:math:`x^2-6x+5 = 3x^2-10x-8`

.. rst-class:: solution

:math:`0 = 2x^2-4x-13` — non factorisable, utilise la formule quadratique

.. rst-class:: solution

:math:`x = \dfrac{4 \pm \sqrt{(-4)^2-4(2)(-13)}}{2(2)} = \dfrac{4 \pm
\sqrt{120}}{4} = \dfrac{4 \pm 2\sqrt{30}}{4} = \dfrac{2(2 \pm
\sqrt{30})}{4} = \dfrac{2 \pm \sqrt{30}}{2}`

Partie 3 : Résoudre des inéquations rationnelles
================================================================================

**RAPPEL :** Résoudre des inégalités est la même chose que résoudre des
équations. Cependant, lorsque les deux côtés d'une inégalité sont
multipliés ou divisés par un nombre négatif, le signe de l'inégalité doit
être inversé.

.. list-table::
   :width: 100%

   * - Étapes pour résoudre une inéquation rationnelle algébriquement :

       1. Utilise des opérations inverses pour déplacer tous les termes
          d'un côté de l'inégalité
       2. Combine les expressions à l'aide d'un dénominateur commun
       3. Factorise le polynôme
       4. Détermine le ou les intervalles où la fonction est positive ou
          négative en construisant un tableau de signes

.. list-table::
   :width: 100%

   * - Pour construire un tableau de signes :

       - Utilise les abscisses à l'origine et les asymptotes verticales
         pour diviser en intervalles
       - Utilise un point d'essai dans chaque intervalle pour déterminer
         le signe de chaque facteur
       - Détermine le signe global du produit en multipliant les signes
         de chaque facteur dans chaque intervalle.

.. rst-class:: keepwithnext
