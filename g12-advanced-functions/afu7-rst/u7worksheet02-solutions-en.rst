.. rst-class:: keepwithnext

a\) :math:`f(x) = \dfrac{x}{x-5}`

.. rst-class:: solution

:math:`VA: x = 5`, :math:`HA: y = 1`. :math:`x\text{-int}: 0 =
\dfrac{x}{x-5} \Rightarrow x = 0`, so :math:`(0,0)`;
:math:`y\text{-int}: f(0) = \dfrac{0}{-5} = 0`, so also :math:`(0,0)`

.. rst-class:: solution

Other points: :math:`f(2) = \dfrac{2}{-3} = -0.67`, so :math:`(2,-0.67)`;
:math:`f(4) = \dfrac{4}{-1} = -4`, so :math:`(4,-4)`

   :scale: 90
   :alt: f(x)=x/(x-5), a hyperbola with VA x=5 and HA y=1

.. rst-class:: keepwithnext

b\) :math:`c(x) = \dfrac{4x}{x+8}`

.. rst-class:: solution

:math:`VA: x = -8`, :math:`HA: y = 4`. :math:`x\text{-int}: 0 =
\dfrac{4x}{x+8} \Rightarrow x = 0`, so :math:`(0,0)`, which is also the
:math:`y`-int

.. rst-class:: solution

Other points: :math:`c(-6) = \dfrac{4(-6)}{-6+8} = \dfrac{-24}{2} = -12`,
so :math:`(-6,-12)`; :math:`c(-4) = \dfrac{4(-4)}{-4+8} =
\dfrac{-16}{4} = -4`, so :math:`(-4,-4)`

.. image:: ../images/u7worksheet02-gpimage02.png
   :scale: 90
   :alt: c(x)=4x/(x+8), a hyperbola with VA x=-8 and HA y=4

.. rst-class:: keepwithnext

c\) :math:`k(x) = \dfrac{x+1}{4-x}`

.. rst-class:: solution

:math:`VA: x = 4`, :math:`HA: y = -1`. :math:`x\text{-int}: 0 = x+1
\Rightarrow x = -1`, so :math:`(-1,0)`; :math:`y\text{-int}: k(0) =
\dfrac{1}{4} = 0.25`, so :math:`(0,0.25)`

.. rst-class:: solution

Other point: :math:`k(3) = \dfrac{3+1}{4-3} = 4`, so :math:`(3,4)`

.. image:: ../images/u7worksheet02-gpimage03.png
   :scale: 90
   :alt: k(x)=(x+1)/(4-x), a hyperbola with VA x=4 and HA y=-1

.. rst-class:: keepwithnext

d\) :math:`w(x) = \dfrac{x+2}{4x-5}`

.. rst-class:: solution

:math:`VA: x = 1.25`, :math:`HA: y = 0.25`. :math:`x\text{-int}: 0 = x+2
\Rightarrow x = -2`, so :math:`(-2,0)`; :math:`y\text{-int}: w(0) =
\dfrac{2}{-5} = -0.4`, so :math:`(0,-0.4)`

.. rst-class:: solution

Other point: :math:`w(1) = \dfrac{1+2}{4-5} = -3`, so :math:`(1,-3)`

.. image:: ../images/u7worksheet02-gpimage04.png
   :scale: 90
   :alt: w(x)=(x+2)/(4x-5), a hyperbola with VA x=1.25 and HA y=0.25

.. rst-class:: keepwithnext

e\) :math:`d(x) = \dfrac{-2x-3}{x+5}`

.. rst-class:: solution

:math:`VA: x = -5`, :math:`HA: y = -2`. :math:`x\text{-int}: 0 = -2x-3
\Rightarrow x = -1.5`, so :math:`(-1.5,0)`; :math:`y\text{-int}: d(0) =
\dfrac{-3}{5} = -0.6`, so :math:`(0,-0.6)`

.. rst-class:: solution

Other point: :math:`d(-4) = \dfrac{-2(-4)-3}{-4+5} = \dfrac{5}{1} = 5`,
so :math:`(-4,5)`

.. image:: ../images/u7worksheet02-gpimage05.png
   :scale: 90
   :alt: d(x)=(-2x-3)/(x+5), a hyperbola with VA x=-5 and HA y=-2

.. rst-class:: keepwithnext

f\) :math:`m(x) = \dfrac{3x+1}{2x+1}`

.. rst-class:: solution

:math:`VA: x = -0.5`, :math:`HA: y = 1.5`. :math:`x\text{-int}: 0 = 3x+1
\Rightarrow x = -0.33`, so :math:`(-0.33,0)`; :math:`y\text{-int}: m(0) =
\dfrac{1}{1} = 1`, so :math:`(0,1)`

.. rst-class:: solution

Other point: :math:`m(1) = \dfrac{3(1)+1}{2(1)+1} = \dfrac{4}{3} = 1.33`,
so :math:`(1,1.33)`

.. image:: ../images/u7worksheet02-gpimage06.png
   :scale: 90
   :alt: m(x)=(3x+1)/(2x+1), a hyperbola with VA x=-0.5 and HA y=1.5

g\) :math:`g(x) = \dfrac{x-2}{x^2+3x+2}`

.. rst-class:: solution

*(use a graphing calculator/Desmos)*

.. rst-class:: solution

:math:`g(x) = \dfrac{x-2}{x^2+3x+2} = \dfrac{x-2}{(x+2)(x+1)}`

.. rst-class:: solution

:math:`HA: y = 0`, :math:`VA: x = -2` and :math:`x = -1`

.. rst-class:: solution

:math:`x\text{-int}: 0 = x-2 \Rightarrow x = 2`, so :math:`(2,0)`;
:math:`y\text{-int}: g(0) = \dfrac{0-2}{(0+2)(0+1)} = -1`, so
:math:`(0,-1)`
