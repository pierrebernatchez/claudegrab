**1)** Déterminer les solutions approximatives de chaque équation dans
l'intervalle :math:`0 \leq x \leq 2\pi`, au centième de radian près.

.. rst-class:: keepwithnext

a\) :math:`\sin x - \dfrac{1}{4} = 0`

.. rst-class:: solution

:math:`\sin x = \dfrac{1}{4}`

.. image:: ../images/u5worksheet05-gpimage01.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions environ 0,25 et 2,89 radians

.. rst-class:: solution

:math:`x_1 = \sin^{-1}\left(\dfrac{1}{4}\right) \approx 0.25`

.. rst-class:: solution

:math:`x_2 = \pi - 0.25 \approx 2.89`

.. rst-class:: keepwithnext

b\) :math:`\cos x + 0.75 = 0`

.. rst-class:: solution

:math:`\cos x = -0.75`

.. image:: ../images/u5worksheet05-gpimage02.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions environ 2,42 et 3,86 radians

.. rst-class:: solution

:math:`x_1 = \cos^{-1}(-0.75) \approx 2.42`

.. rst-class:: solution

:math:`\beta = \pi - 2.42 = 0.72`

.. rst-class:: solution

:math:`x_2 = \pi + \beta = \pi + 0.72 \approx 3.86`

.. rst-class:: keepwithnext

c\) :math:`\tan x - 5 = 0`

.. rst-class:: solution

:math:`\tan x = 5`

.. image:: ../images/u5worksheet05-gpimage03.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions environ 1,37 et 4,51 radians

.. rst-class:: solution

:math:`x_1 = \tan^{-1}(5) \approx 1.37`

.. rst-class:: solution

:math:`x_2 = \pi + 1.37 \approx 4.51`

.. rst-class:: keepwithnext

d\) :math:`\sec x - 4 = 0`

.. rst-class:: solution

:math:`\sec x = 4 \rightarrow \cos x = \dfrac{1}{4}`

.. image:: ../images/u5worksheet05-gpimage04.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions environ 1,32 et 4,96 radians

.. rst-class:: solution

:math:`x_1 = \cos^{-1}\left(\dfrac{1}{4}\right) \approx 1.32`

.. rst-class:: solution

:math:`x_2 = 2\pi - 1.32 \approx 4.96`

.. rst-class:: keepwithnext

e\) :math:`3\cot x + 2 = 0`

.. rst-class:: solution

:math:`\cot x = -\dfrac{2}{3} \rightarrow \tan x = -\dfrac{3}{2}`

   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions environ 2,16 et 5,3 radians

.. rst-class:: solution

:math:`x_2 = \pi - 0.98 \approx 2.16`

.. rst-class:: keepwithnext

.. rst-class:: solution

**2)** Déterminer les solutions exactes de chaque équation dans
l'intervalle :math:`0 \leq x \leq 2\pi`.

.. rst-class:: keepwithnext

a\) :math:`\sin x + \dfrac{\sqrt3}{2} = 0`

.. rst-class:: solution

:math:`\sin x = -\dfrac{\sqrt3}{2}`. Du triangle spécial :
:math:`\sin\dfrac{\pi}{3} = \dfrac{\sqrt3}{2}`. Placer :math:`\dfrac{\pi}{3}`
aux quadrants 3 et 4.

.. image:: ../images/u5worksheet05-gpimage07.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions exacts 4 pi/3 et 5 pi/3

.. rst-class:: solution

:math:`x_1 = 2\pi - \dfrac{\pi}{3} = \dfrac{5\pi}{3}`

.. rst-class:: solution

:math:`x_2 = \pi + \dfrac{\pi}{3} = \dfrac{4\pi}{3}`

.. rst-class:: keepwithnext

b\) :math:`\cos x - 0.5 = 0`

.. rst-class:: solution

:math:`\cos x = \dfrac{1}{2}`. Du triangle spécial :
:math:`\cos\dfrac{\pi}{3} = \dfrac{1}{2}`. Placer :math:`\dfrac{\pi}{3}`
aux quadrants 1 et 4.

.. image:: ../images/u5worksheet05-gpimage08.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions exacts pi/3 et 5 pi/3

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{3}`

.. rst-class:: solution

:math:`x_2 = 2\pi - \dfrac{\pi}{3} = \dfrac{5\pi}{3}`

.. rst-class:: keepwithnext

c\) :math:`\tan x - 1 = 0`

.. rst-class:: solution

:math:`\tan x = 1`. Du triangle spécial : :math:`\tan\dfrac{\pi}{4} = 1`.
Placer :math:`\dfrac{\pi}{4}` aux quadrants 1 et 3.

.. image:: ../images/u5worksheet05-gpimage09.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions exacts pi/4 et 5 pi/4

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{4}`

.. rst-class:: solution

:math:`x_2 = \pi + \dfrac{\pi}{4} = \dfrac{5\pi}{4}`

.. rst-class:: keepwithnext

d\) :math:`\cot x + 1 = 0`

.. rst-class:: solution

:math:`\cot x = -1 \rightarrow \tan x = -1`. Du triangle spécial :
:math:`\tan\dfrac{\pi}{4} = 1`. Placer :math:`\dfrac{\pi}{4}` aux
quadrants 2 et 4.

.. image:: ../images/u5worksheet05-gpimage10.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions exacts 3 pi/4 et 7 pi/4

.. rst-class:: solution

:math:`x_1 = \pi - \dfrac{\pi}{4} = \dfrac{3\pi}{4}`

.. rst-class:: solution

:math:`x_2 = 2\pi - \dfrac{\pi}{4} = \dfrac{7\pi}{4}`

**3)** Déterminer les solutions approximatives de chaque équation dans
l'intervalle :math:`0 \leq x \leq 2\pi`, au centième de radian près.

.. rst-class:: keepwithnext

a\) :math:`\sin^2 x - 0.64 = 0`

.. rst-class:: solution

:math:`\sin^2 x = 0.64`

.. rst-class:: solution

:math:`\sin x = \pm\sqrt{0.64} = \pm0.8`

.. image:: ../images/u5worksheet05-gpimage11.png
   :scale: 90
   :alt: cercle trigonométrique avec quatre angles solutions 0,93, 2,21, 4,07, et 5,36 radians

.. rst-class:: solution

:math:`\sin x = 0.8 \rightarrow x_1 = \sin^{-1}(0.8) \approx 0.93`,
:math:`x_2 = \pi - 0.93 \approx 2.21`

.. rst-class:: solution

:math:`\sin x = -0.8 \rightarrow x_3 = \sin^{-1}(-0.8) = -0.93 + 2\pi \approx 5.36`,
:math:`x_4 = \pi + 0.93 \approx 4.07`

.. rst-class:: keepwithnext

b\) :math:`\cos^2 x - \dfrac{4}{9} = 0`

.. rst-class:: solution

:math:`\cos^2 x = \dfrac{4}{9}`

.. rst-class:: solution

:math:`\cos x = \pm\sqrt{\dfrac{4}{9}} = \pm\dfrac{2}{3}`

.. image:: ../images/u5worksheet05-gpimage12.png
   :scale: 90
   :alt: cercle trigonométrique avec quatre angles solutions 0,84, 2,30, 3,98, et 5,44 radians

.. rst-class:: solution

:math:`\cos x = \dfrac{2}{3} \rightarrow x_1 = \cos^{-1}\left(\dfrac{2}{3}\right) \approx 0.84`,
:math:`x_2 = 2\pi - 0.84 \approx 5.44`

.. rst-class:: solution

:math:`\cos x = -\dfrac{2}{3} \rightarrow x_3 = \cos^{-1}\left(-\dfrac{2}{3}\right) \approx 2.30`,
:math:`x_4 = \pi + 0.84 \approx 3.98`

.. rst-class:: keepwithnext

c\) :math:`\tan^2 x - 1.44 = 0`

.. rst-class:: solution

:math:`\tan^2 x = 1.44`

.. rst-class:: solution

:math:`\tan x = \pm\sqrt{1.44} = \pm1.2`

.. image:: ../images/u5worksheet05-gpimage13.png
   :scale: 90
   :alt: cercle trigonométrique avec quatre angles solutions 0,88, 2,27, 4,02, et 5,41 radians

.. rst-class:: solution

:math:`\tan x = 1.2 \rightarrow x_1 = \tan^{-1}(1.2) \approx 0.88`,
:math:`x_2 = \pi + 0.88 \approx 4.02`

.. rst-class:: solution

:math:`\tan x = -1.2 \rightarrow x_3 = \pi - 0.88 \approx 2.27`,
:math:`x_4 = 2\pi - 0.88 \approx 5.41`

.. rst-class:: keepwithnext

d\) :math:`\sec^2 x - 2.5 = 0`

.. rst-class:: solution

:math:`\sec^2 x = 2.5 \rightarrow \cos^2 x = \dfrac{1}{2.5}`

.. rst-class:: solution

:math:`\cos x = \pm\sqrt{\dfrac{1}{2.5}} \approx \pm0.63`

.. image:: ../images/u5worksheet05-gpimage14.png

:math:`x_2 = 2\pi - 0.89 \approx 5.4`

.. rst-class:: solution

:math:`\cos x = -0.63 \rightarrow x_3 = \cos^{-1}(-0.63) \approx 2.26`,
:math:`x_4 = \pi + 0.89 \approx 4.03`

**4)** Déterminer les solutions exactes de chaque équation dans
l'intervalle :math:`0 \leq x \leq 2\pi`.

.. rst-class:: keepwithnext

a\) :math:`\sin^2 x - \dfrac{1}{4} = 0`

.. rst-class:: solution

:math:`\sin^2 x = \dfrac{1}{4} \rightarrow \sin x = \pm\dfrac{1}{2}`.
Du triangle spécial : :math:`\sin\dfrac{\pi}{6} = \dfrac{1}{2}`. Placer
:math:`\dfrac{\pi}{6}` aux quadrants 1 et 2 pour :math:`\sin x = \dfrac{1}{2}`,
et aux quadrants 3 et 4 pour :math:`\sin x = -\dfrac{1}{2}`.

.. image:: ../images/u5worksheet05-gpimage15.png
   :scale: 90
   :alt: cercle trigonométrique avec quatre angles solutions exacts pi/6, 5 pi/6, 7 pi/6, 11 pi/6

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{6}`, :math:`x_2 = \dfrac{5\pi}{6}`,
:math:`x_3 = \pi + \dfrac{\pi}{6} = \dfrac{7\pi}{6}`,
:math:`x_4 = 2\pi - \dfrac{\pi}{6} = \dfrac{11\pi}{6}`

.. rst-class:: keepwithnext

b\) :math:`\cos^2 x - \dfrac{3}{4} = 0`

.. rst-class:: solution

:math:`\cos^2 x = \dfrac{3}{4} \rightarrow \cos x = \pm\dfrac{\sqrt3}{2}`.
Du triangle spécial : :math:`\cos\dfrac{\pi}{6} = \dfrac{\sqrt3}{2}`.
Placer :math:`\dfrac{\pi}{6}` aux quadrants 1 et 4 pour
:math:`\cos x = \dfrac{\sqrt3}{2}`, et aux quadrants 2 et 3 pour
:math:`\cos x = -\dfrac{\sqrt3}{2}`.

.. image:: ../images/u5worksheet05-gpimage16.png
   :scale: 90
   :alt: cercle trigonométrique avec quatre angles solutions exacts pi/6, 5 pi/6, 7 pi/6, 11 pi/6

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{6}`, :math:`x_2 = \pi - \dfrac{\pi}{6} = \dfrac{5\pi}{6}`,
:math:`x_3 = \pi + \dfrac{\pi}{6} = \dfrac{7\pi}{6}`,
:math:`x_4 = 2\pi - \dfrac{\pi}{6} = \dfrac{11\pi}{6}`

.. rst-class:: keepwithnext

c\) :math:`\tan^2 x - 3 = 0`

.. rst-class:: solution

:math:`\tan^2 x = 3 \rightarrow \tan x = \pm\sqrt3`. Du triangle
spécial : :math:`\tan\dfrac{\pi}{3} = \sqrt3`. Placer :math:`\dfrac{\pi}{3}`
aux quadrants 1 et 3 pour :math:`\tan x = \sqrt3`, et aux quadrants 2 et
4 pour :math:`\tan x = -\sqrt3`.

.. image:: ../images/u5worksheet05-gpimage17.png
   :scale: 90
   :alt: cercle trigonométrique avec quatre angles solutions exacts pi/3, 2 pi/3, 4 pi/3, 5 pi/3

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{3}`, :math:`x_2 = \pi - \dfrac{\pi}{3} = \dfrac{2\pi}{3}`,
:math:`x_3 = \pi + \dfrac{\pi}{3} = \dfrac{4\pi}{3}`,
:math:`x_4 = 2\pi - \dfrac{\pi}{3} = \dfrac{5\pi}{3}`

.. rst-class:: keepwithnext

d\) :math:`3\csc^2 x - 4 = 0`

.. rst-class:: solution

:math:`\csc^2 x = \dfrac{4}{3} \rightarrow \sin^2 x = \dfrac{3}{4}
\rightarrow \sin x = \pm\dfrac{\sqrt3}{2}`. Du triangle spécial :
:math:`\sin\dfrac{\pi}{3} = \dfrac{\sqrt3}{2}`. Placer :math:`\dfrac{\pi}{3}`
aux quadrants 1 et 2 pour :math:`\sin x = \dfrac{\sqrt3}{2}`, et aux
quadrants 3 et 4 pour :math:`\sin x = -\dfrac{\sqrt3}{2}`.

.. image:: ../images/u5worksheet05-gpimage18.png
   :scale: 90
   :alt: cercle trigonométrique avec quatre angles solutions exacts pi/3, 2 pi/3, 4 pi/3, 5 pi/3

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{3}`, :math:`x_2 = \pi - \dfrac{\pi}{3} = \dfrac{2\pi}{3}`,
:math:`x_3 = \pi + \dfrac{\pi}{3} = \dfrac{4\pi}{3}`,
:math:`x_4 = 2\pi - \dfrac{\pi}{3} = \dfrac{5\pi}{3}`

.. rst-class:: keepwithnext

**5)** Déterminer les solutions de chaque équation dans l'intervalle
:math:`0 \leq x \leq 2\pi`.

.. rst-class:: keepwithnext

a\) :math:`3\sin x = \sin x + 1`

.. rst-class:: solution

:math:`2\sin x = 1 \rightarrow \sin x = \dfrac{1}{2}`. Du triangle
spécial : :math:`\sin\dfrac{\pi}{6} = \dfrac{1}{2}`. Placer aux
quadrants 1 et 2.

.. image:: ../images/u5worksheet05-gpimage19.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions exacts pi/6 et 5 pi/6

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{6}`, :math:`x_2 = \pi - \dfrac{\pi}{6} = \dfrac{5\pi}{6}`

.. rst-class:: keepwithnext

b\) :math:`5\cos x - \sqrt3 = 3\cos x`

.. rst-class:: solution

:math:`2\cos x = \sqrt3 \rightarrow \cos x = \dfrac{\sqrt3}{2}`. Du
triangle spécial : :math:`\cos\dfrac{\pi}{6} = \dfrac{\sqrt3}{2}`.
Placer aux quadrants 1 et 4.

.. image:: ../images/u5worksheet05-gpimage20.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions exacts pi/6 et 11 pi/6

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{6}`, :math:`x_2 = 2\pi - \dfrac{\pi}{6} = \dfrac{11\pi}{6}`

.. rst-class:: keepwithnext

c\) :math:`7\sec x = 7`

.. rst-class:: solution

:math:`\sec x = 1 \rightarrow \cos x = 1`. Utiliser le cercle
trigonométrique, où chaque point est :math:`(\cos x, \sin x)`.

.. image:: ../images/u5worksheet05-gpimage21.png
   :scale: 90
   :alt: cercle trigonométrique montrant le point (1,0)

.. rst-class:: solution

:math:`x_1 = 0`, :math:`x_2 = 2\pi`

.. rst-class:: keepwithnext

d\) :math:`2\csc x + 17 = 15 + \csc x`

.. rst-class:: solution

:math:`\csc x = -2 \rightarrow \sin x = -\dfrac{1}{2}`. Du triangle
spécial : :math:`\sin\dfrac{\pi}{6} = \dfrac{1}{2}`. Placer
:math:`\dfrac{\pi}{6}` aux quadrants 3 et 4.

.. image:: ../images/u5worksheet05-gpimage22.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions exacts 7 pi/6 et 11 pi/6

.. rst-class:: solution

:math:`x_1 = \pi + \dfrac{\pi}{6} = \dfrac{7\pi}{6}`,
:math:`x_2 = 2\pi - \dfrac{\pi}{6} = \dfrac{11\pi}{6}`
