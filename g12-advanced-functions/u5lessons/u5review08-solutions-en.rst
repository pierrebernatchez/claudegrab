.. rst-class:: solution

:math:`= \sin\left(\dfrac{\pi}{2} - \dfrac{3\pi}{14}\right)`

**5)** Use an appropriate compound angle formula to determine an exact
value for each.

.. rst-class:: keepwithnext

a\) :math:`\sin\dfrac{11\pi}{12}`

.. rst-class:: solution

:math:`= \sin\left(\dfrac{8\pi}{12} + \dfrac{3\pi}{12}\right) = \sin\left(\dfrac{2\pi}{3} + \dfrac{\pi}{4}\right)`

.. rst-class:: solution

:math:`= \sin\dfrac{2\pi}{3}\cos\dfrac{\pi}{4} + \cos\dfrac{2\pi}{3}\sin\dfrac{\pi}{4}`

.. rst-class:: solution

:math:`= \left(\dfrac{\sqrt3}{2}\right)\left(\dfrac{\sqrt2}{2}\right) + \left(-\dfrac{1}{2}\right)\left(\dfrac{\sqrt2}{2}\right)`

.. rst-class:: solution

:math:`= \dfrac{\sqrt6}{4} - \dfrac{\sqrt2}{4} = \dfrac{\sqrt6-\sqrt2}{4}`

.. rst-class:: keepwithnext

b\) :math:`\cos\dfrac{25\pi}{12}`

.. rst-class:: solution

:math:`= \cos\left(\dfrac{25\pi}{12} - 2\pi\right) = \cos\dfrac{\pi}{12}`

.. rst-class:: solution

:math:`= \cos\left(\dfrac{3\pi}{12} - \dfrac{2\pi}{12}\right) = \cos\left(\dfrac{\pi}{4} - \dfrac{\pi}{6}\right)`

.. rst-class:: solution

:math:`= \cos\dfrac{\pi}{4}\cos\dfrac{\pi}{6} + \sin\dfrac{\pi}{4}\sin\dfrac{\pi}{6}`

.. rst-class:: solution

:math:`= \left(\dfrac{\sqrt2}{2}\right)\left(\dfrac{\sqrt3}{2}\right) + \left(\dfrac{\sqrt2}{2}\right)\left(\dfrac{1}{2}\right)`

.. rst-class:: solution

:math:`= \dfrac{\sqrt6}{4} + \dfrac{\sqrt2}{4} = \dfrac{\sqrt6+\sqrt2}{4}`

.. rst-class:: keepwithnext

c\) :math:`\tan\dfrac{7\pi}{12}`

.. rst-class:: solution

:math:`= \tan\left(\dfrac{3\pi}{12} + \dfrac{4\pi}{12}\right) = \tan\left(\dfrac{\pi}{4} + \dfrac{\pi}{3}\right)`

.. rst-class:: solution

:math:`= \dfrac{\tan\frac{\pi}{4} + \tan\frac{\pi}{3}}{1 - \tan\frac{\pi}{4}\tan\frac{\pi}{3}} = \dfrac{1+\sqrt3}{1-1(\sqrt3)}`

.. rst-class:: solution

:math:`= \dfrac{1+\sqrt3}{1-\sqrt3} \times \dfrac{1+\sqrt3}{1+\sqrt3} = \dfrac{1+2\sqrt3+3}{1-3}`

.. rst-class:: solution

:math:`= \dfrac{4+2\sqrt3}{-2} = -2-\sqrt3`
