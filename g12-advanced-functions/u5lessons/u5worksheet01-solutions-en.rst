**6)** Given that :math:`\sin\dfrac{\pi}{6} = \dfrac{1}{2}`, use an
equivalent trigonometric expression to show that
:math:`\cos\dfrac{\pi}{3} = \dfrac{1}{2}`

.. rst-class:: solution

:math:`\cos\dfrac{\pi}{3} = \sin\left(\dfrac{\pi}{2} - \dfrac{\pi}{3}\right)`

.. rst-class:: solution

:math:`= \sin\left(\dfrac{\pi}{6}\right)`

.. rst-class:: solution

:math:`= \dfrac{1}{2}`

.. rst-class:: keepwithnext

**7)** Given that :math:`\sin\dfrac{\pi}{6} = \dfrac{1}{2}`, use an
equivalent trigonometric expression to show that
:math:`\cos\dfrac{2\pi}{3} = -\dfrac{1}{2}`

.. rst-class:: solution

:math:`\cos\dfrac{2\pi}{3} = \sin\left(\dfrac{\pi}{2} - \dfrac{2\pi}{3}\right)`

.. rst-class:: solution

:math:`= -\sin\dfrac{\pi}{6}`

.. rst-class:: solution

:math:`= -\dfrac{1}{2}`

.. rst-class:: keepwithnext

**8)** Given that :math:`\csc\dfrac{\pi}{4} = \sqrt{2}`, use an
equivalent trigonometric expression to show that
:math:`\sec\dfrac{3\pi}{4} = -\sqrt{2}`

.. rst-class:: solution

:math:`\sec\dfrac{3\pi}{4} = \dfrac{1}{\cos\frac{3\pi}{4}}`

.. rst-class:: solution

:math:`= \dfrac{1}{\sin\left(\frac{\pi}{2} - \frac{3\pi}{4}\right)}`

.. rst-class:: solution

:math:`= \dfrac{1}{\sin\left(-\frac{\pi}{4}\right)}`

.. rst-class:: solution

:math:`= \dfrac{1}{-\sin\frac{\pi}{4}}`

.. rst-class:: solution

:math:`= -\csc\dfrac{\pi}{4}`

.. rst-class:: solution

:math:`= -\sqrt{2}`
