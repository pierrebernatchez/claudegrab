.. rst-class:: keepwithnext

.. rst-class:: keepwithnext

b\) :math:`1 - \cos^2 x = \tan x \cos x \sin x`

.. rst-class:: keepwithnext

c\) :math:`\dfrac{\cos^2 x - \sin^2 x}{\cos^2 x + \sin x \cos x} = 1 - \tan x`

.. rst-class:: keepwithnext

d\) :math:`\dfrac{1}{1+\cos x} + \dfrac{1}{1-\cos x} = 2\csc^2 x`

.. rst-class:: keepwithnext

e\) :math:`\sin(2\pi - x) = -\sin x`

.. rst-class:: keepwithnext

f\) :math:`[\sin(2x)](\tan x + \cot x) = 2`

.. rst-class:: keepwithnext

g\) :math:`2\sin x \cos y = \sin(x+y) + \sin(x-y)`

.. rst-class:: keepwithnext

h\) :math:`(\cos x - \sin x)^2 = 1 - \sin(2x)`

.. rst-class:: keepwithnext

i\) :math:`\dfrac{1-\sin^2 x}{\cot^2 x} = 1 - \cos^2 x`

.. rst-class:: keepwithnext

j\) :math:`(\csc x - \cot x)^2 = \dfrac{1-\cos x}{1+\cos x}`

.. rst-class:: keepwithnext

k\) :math:`\dfrac{1-2\sin^2 x}{\cos x + \sin x} + 2\sin\dfrac{x}{2}\cos\dfrac{x}{2} = \cos x`
