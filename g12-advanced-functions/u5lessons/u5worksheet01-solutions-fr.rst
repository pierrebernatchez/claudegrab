**5)** Écrire une expression équivalente à chacune des expressions
suivantes, en utilisant l'angle aigu associé.

.. rst-class:: keepwithnext

a\) :math:`\sin\dfrac{7\pi}{8}`

:math:`\dfrac{7\pi}{8}` se trouve au quadrant II, où le sinus est
positif, avec un angle de référence de :math:`\dfrac{\pi}{8}`.

.. rst-class:: solution

:math:`\sin\dfrac{7\pi}{8} = \sin\dfrac{\pi}{8}`

.. rst-class:: keepwithnext

.. rst-class:: solution

:math:`\cos\dfrac{13\pi}{12} = -\cos\dfrac{\pi}{12}`

.. rst-class:: keepwithnext

.. rst-class:: solution

**6)** Sachant que :math:`\sin\dfrac{\pi}{6} = \dfrac{1}{2}`, utiliser
une expression trigonométrique équivalente pour montrer que
:math:`\cos\dfrac{\pi}{3} = \dfrac{1}{2}`

.. rst-class:: solution

:math:`\cos\dfrac{\pi}{3} = \sin\left(\dfrac{\pi}{2} - \dfrac{\pi}{3}\right)`

.. rst-class:: solution

:math:`= \sin\left(\dfrac{\pi}{6}\right)`

.. rst-class:: solution

:math:`= \dfrac{1}{2}`

.. rst-class:: keepwithnext

**7)** Sachant que :math:`\sin\dfrac{\pi}{6} = \dfrac{1}{2}`, utiliser
une expression trigonométrique équivalente pour montrer que
:math:`\cos\dfrac{2\pi}{3} = -\dfrac{1}{2}`

.. rst-class:: solution

:math:`\cos\dfrac{2\pi}{3} = \sin\left(\dfrac{\pi}{2} - \dfrac{2\pi}{3}\right)`

.. rst-class:: solution

:math:`= \sin\left(\dfrac{3\pi}{6} - \dfrac{4\pi}{6}\right)`

.. rst-class:: solution

:math:`= \sin\left(-\dfrac{\pi}{6}\right)`

.. rst-class:: solution

:math:`= -\sin\dfrac{\pi}{6}`

.. rst-class:: solution

:math:`= -\dfrac{1}{2}`

.. rst-class:: keepwithnext

**8)** Sachant que :math:`\csc\dfrac{\pi}{4} = \sqrt{2}`, utiliser une
expression trigonométrique équivalente pour montrer que
:math:`\sec\dfrac{3\pi}{4} = -\sqrt{2}`

.. rst-class:: solution

:math:`\sec\dfrac{3\pi}{4} = \dfrac{1}{\cos\frac{3\pi}{4}}`

.. rst-class:: solution

:math:`= \dfrac{1}{\sin\left(\frac{\pi}{2} - \frac{3\pi}{4}\right)}`

.. rst-class:: solution

:math:`= \dfrac{1}{\sin\left(-\frac{\pi}{4}\right)}`

.. rst-class:: solution

:math:`= \dfrac{1}{-\sin\frac{\pi}{4}}`

.. rst-class:: solution

:math:`= -\csc\dfrac{\pi}{4}`

.. rst-class:: solution

:math:`= -\sqrt{2}`
