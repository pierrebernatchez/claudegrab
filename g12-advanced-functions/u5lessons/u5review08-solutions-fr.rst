.. rst-class:: keepwithnext

**1)** Sachant que :math:`\sin\left(\dfrac{2\pi}{7}\right) \cong 0.7818`,
utiliser des expressions trigonométriques équivalentes pour évaluer ce
qui suit,

.. rst-class:: keepwithnext

a\) :math:`\cos\dfrac{3\pi}{14}`

.. rst-class:: solution

:math:`= \sin\left(\dfrac{\pi}{2} - \dfrac{3\pi}{14}\right)`

.. rst-class:: solution

:math:`= \sin\left(\dfrac{7\pi}{14} - \dfrac{3\pi}{14}\right)`

.. rst-class:: solution

:math:`= \sin\left(\dfrac{4\pi}{14}\right) = \sin\left(\dfrac{2\pi}{7}\right)`

.. rst-class:: solution

**5)** Utiliser une formule des angles composés appropriée pour
déterminer une valeur exacte pour chacune.

.. rst-class:: keepwithnext

a\) :math:`\sin\dfrac{11\pi}{12}`

.. rst-class:: solution

:math:`= \sin\left(\dfrac{8\pi}{12} + \dfrac{3\pi}{12}\right) = \sin\left(\dfrac{2\pi}{3} + \dfrac{\pi}{4}\right)`

.. rst-class:: solution

:math:`= \sin\dfrac{2\pi}{3}\cos\dfrac{\pi}{4} + \cos\dfrac{2\pi}{3}\sin\dfrac{\pi}{4}`

.. rst-class:: solution

:math:`= \left(\dfrac{\sqrt3}{2}\right)\left(\dfrac{\sqrt2}{2}\right) + \left(-\dfrac{1}{2}\right)\left(\dfrac{\sqrt2}{2}\right)`

.. rst-class:: solution

:math:`= \dfrac{\sqrt6}{4} - \dfrac{\sqrt2}{4} = \dfrac{\sqrt6-\sqrt2}{4}`

.. rst-class:: keepwithnext

b\) :math:`\cos\dfrac{25\pi}{12}`

.. rst-class:: solution

:math:`= \cos\left(\dfrac{25\pi}{12} - 2\pi\right) = \cos\dfrac{\pi}{12}`

.. rst-class:: solution

:math:`= \cos\left(\dfrac{3\pi}{12} - \dfrac{2\pi}{12}\right) = \cos\left(\dfrac{\pi}{4} - \dfrac{\pi}{6}\right)`

.. rst-class:: solution

:math:`= \cos\dfrac{\pi}{4}\cos\dfrac{\pi}{6} + \sin\dfrac{\pi}{4}\sin\dfrac{\pi}{6}`

.. rst-class:: solution

:math:`= \left(\dfrac{\sqrt2}{2}\right)\left(\dfrac{\sqrt3}{2}\right) + \left(\dfrac{\sqrt2}{2}\right)\left(\dfrac{1}{2}\right)`

.. rst-class:: solution

:math:`= \dfrac{\sqrt6}{4} + \dfrac{\sqrt2}{4} = \dfrac{\sqrt6+\sqrt2}{4}`

.. rst-class:: keepwithnext

c\) :math:`\tan\dfrac{7\pi}{12}`

.. rst-class:: solution

:math:`= \tan\left(\dfrac{3\pi}{12} + \dfrac{4\pi}{12}\right) = \tan\left(\dfrac{\pi}{4} + \dfrac{\pi}{3}\right)`

.. rst-class:: solution

:math:`= \dfrac{\tan\frac{\pi}{4} + \tan\frac{\pi}{3}}{1 - \tan\frac{\pi}{4}\tan\frac{\pi}{3}} = \dfrac{1+\sqrt3}{1-1(\sqrt3)}`

.. rst-class:: solution

:math:`= \dfrac{1+\sqrt3}{1-\sqrt3} \times \dfrac{1+\sqrt3}{1+\sqrt3} = \dfrac{1+2\sqrt3+3}{1-3}`

.. rst-class:: solution

:math:`= \dfrac{4+2\sqrt3}{-2} = -2-\sqrt3`

**6)** Une échelle de 15 m appuyée contre un mur est en position
dangereuse si elle fait un angle de moins de :math:`\dfrac{\pi}{12}`
radians avec le mur. Utiliser une formule des angles composés pour
déterminer une expression exacte de la distance minimale à laquelle le
pied de l'échelle peut être placé du mur pour que l'échelle soit stable
en toute sécurité.

.. image:: ../images/u5review08-gpimage03.png
   :scale: 90
   :alt: échelle de 15 m contre un mur, angle pi/12 avec le mur

.. rst-class:: solution

:math:`\sin\dfrac{\pi}{12} = \dfrac{x}{15}`

.. rst-class:: solution

:math:`\sin\left(\dfrac{4\pi}{12} - \dfrac{3\pi}{12}\right) = \dfrac{x}{15} \rightarrow \sin\left(\dfrac{\pi}{3} - \dfrac{\pi}{4}\right) = \dfrac{x}{15}`

.. rst-class:: solution

:math:`\sin\dfrac{\pi}{3}\cos\dfrac{\pi}{4} - \cos\dfrac{\pi}{3}\sin\dfrac{\pi}{4} = \dfrac{x}{15}`

.. rst-class:: solution

:math:`\left(\dfrac{\sqrt3}{2}\right)\left(\dfrac{\sqrt2}{2}\right) - \left(\dfrac{1}{2}\right)\left(\dfrac{\sqrt2}{2}\right) = \dfrac{x}{15}`

.. rst-class:: solution

:math:`\dfrac{\sqrt6-\sqrt2}{4} = \dfrac{x}{15}`

.. rst-class:: solution

:math:`x = \dfrac{15(\sqrt6-\sqrt2)}{4}` m
