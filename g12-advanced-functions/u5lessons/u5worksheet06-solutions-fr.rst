Déterminer les solutions de chaque équation dans l'intervalle
:math:`0 \leq x \leq 2\pi`, au centième de radian près. Donner des
réponses exactes lorsque c'est possible.

.. rst-class:: keepwithnext

a\) :math:`\sin(2x) - 0.8 = 0`

.. rst-class:: solution

Soit :math:`\theta = 2x`. :math:`\sin\theta = 0.8`

.. image:: ../images/u5worksheet06-gpimage01.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions environ 0,93 et 2,21 radians pour theta

.. rst-class:: solution

:math:`\theta_1 = \sin^{-1}(0.8) \approx 0.93`

.. rst-class:: solution

:math:`\theta_2 = \pi - 0.93 \approx 2.21`

.. rst-class:: solution

:math:`2x = \theta \rightarrow 2x = 0.93 \rightarrow x_1 \approx 0.46`,
et :math:`2x = 2.21 \rightarrow x_2 \approx 1.11`

Ajouter la période :math:`\pi` pour trouver d'autres solutions :

.. rst-class:: solution

:math:`x_3 = x_1 + \pi \approx 3.61`

.. rst-class:: solution

:math:`x_4 = x_2 + \pi \approx 4.25`

.. rst-class:: keepwithnext

b\) :math:`5\sin(2x) - 3 = 0`

.. rst-class:: solution

Soit :math:`\theta = 2x`. :math:`\sin\theta = \dfrac{3}{5}`

.. image:: ../images/u5worksheet06-gpimage02.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions environ 0,64 et 2,5 radians pour theta

.. rst-class:: solution

:math:`\theta_1 = \sin^{-1}\left(\dfrac{3}{5}\right) \approx 0.64`

.. rst-class:: solution

:math:`\theta_2 = \pi - 0.64 \approx 2.5`

.. rst-class:: solution

:math:`2x = \theta \rightarrow 2x = 0.64 \rightarrow x_1 \approx 0.32`,
et :math:`2x = 2.5 \rightarrow x_2 \approx 1.25`

Ajouter la période :math:`\pi` pour trouver d'autres solutions :

.. rst-class:: solution

:math:`x_3 = x_1 + \pi \approx 3.46`

.. rst-class:: solution

:math:`x_4 = x_2 + \pi \approx 4.39`

d\) :math:`\sin(2x) = \dfrac{1}{\sqrt2}`

.. rst-class:: solution

Soit :math:`\theta = 2x`. :math:`\sin\theta = \dfrac{1}{\sqrt2}`. Du
triangle spécial : :math:`\sin\dfrac{\pi}{4} = \dfrac{1}{\sqrt2}`.
Placer aux quadrants 1 et 2.

.. image:: ../images/u5worksheet06-gpimage04.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions exacts pi/4 et 3 pi/4 pour theta

.. rst-class:: solution

:math:`\theta_1 = \dfrac{\pi}{4}`, :math:`\theta_2 = \pi - \dfrac{\pi}{4} = \dfrac{3\pi}{4}`

.. rst-class:: solution

:math:`2x = \theta \rightarrow 2x = \dfrac{\pi}{4} \rightarrow x_1 = \dfrac{\pi}{8}`,
et :math:`2x = \dfrac{3\pi}{4} \rightarrow x_2 = \dfrac{3\pi}{8}`

Ajouter la période :math:`\pi` pour trouver d'autres solutions :

.. rst-class:: solution

:math:`x_3 = x_1 + \pi = \dfrac{\pi}{8} + \pi = \dfrac{9\pi}{8}`

.. rst-class:: solution

:math:`x_4 = x_2 + \pi = \dfrac{3\pi}{8} + \pi = \dfrac{11\pi}{8}`
