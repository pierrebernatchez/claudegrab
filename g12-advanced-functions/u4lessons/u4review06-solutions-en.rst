**18)** A cosine function has a maximum value of 7, a minimum value of
1, a period of :math:`\dfrac{\pi}{2}`, and a phase shift of
:math:`\dfrac{3\pi}{4}` radians to the right.

.. rst-class:: keepwithnext

a\) Write an equation for the function.

:solmath:`a = \dfrac{7-1}{2} = 3`

:solmath:`k = \dfrac{2\pi}{\left(\frac{\pi}{2}\right)} = 4`

:solmath:`d_{\cos} = \dfrac{3\pi}{4}`

:solmath:`c = 7-3 = 4`

:solmath:`y = 3\cos\left[4\left(x-\dfrac{3\pi}{4}\right)\right]+4`

.. rst-class:: keepwithnext

b\) Write an equivalent sine equation for the function.

:solmath:`d_{\sin} = d_{\cos}-\dfrac{\pi}{2k} = \dfrac{3\pi}{4}-\dfrac{\pi}{2(4)} = \dfrac{6\pi}{8}-\dfrac{\pi}{8} = \dfrac{5\pi}{8}`

:solmath:`y = 3\sin\left[4\left(x-\dfrac{5\pi}{8}\right)\right]+4`

**21)** A person who was listening to a siren reported that the

:solmath:`c = 1000-250 = 750`
