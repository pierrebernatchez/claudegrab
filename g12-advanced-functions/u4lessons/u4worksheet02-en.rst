**2)** a) -0.9587 b) 0.2198 c) -0.7975 d) 1.0470 e) 0.1844 f) 1.7953

**3)** a) 0.2282 b) -2.0000 c) 1.0103

**4)** a) :math:`\dfrac{\sqrt3}{2}` b) :math:`\dfrac{1}{\sqrt3}` c)
:math:`-\dfrac{1}{\sqrt2}` d) :math:`-1`

**5)** a) :math:`\sin\frac{2\pi}{3}=\frac{\sqrt3}{2}` ;
:math:`\cos\frac{2\pi}{3}=-\frac12` ; :math:`\tan\frac{2\pi}{3}=-\sqrt3`

b) :math:`\sin\frac{5\pi}{6}=\frac12` ;
:math:`\cos\frac{5\pi}{6}=-\frac{\sqrt3}{2}` ;
:math:`\tan\frac{5\pi}{6}=-\frac{1}{\sqrt3}`

c) :math:`\sin\frac{3\pi}{2}=-1` ; :math:`\cos\frac{3\pi}{2}=0` ;
:math:`\tan\frac{3\pi}{2}=` undefined

d) :math:`\sin\frac{7\pi}{4}=-\frac{1}{\sqrt2}` ;
:math:`\cos\frac{7\pi}{4}=\frac{1}{\sqrt2}` ;
:math:`\tan\frac{7\pi}{4}=-1`

**6)** :math:`\sin\frac{11\pi}{6}=-\frac12` ;
:math:`\cos\frac{11\pi}{6}=\frac{\sqrt3}{2}` ;
:math:`\tan\frac{11\pi}{6}=-\frac{1}{\sqrt3}` ;
:math:`\csc\frac{11\pi}{6}=-2` ; :math:`\sec\frac{11\pi}{6}=\frac{2}{\sqrt3}`
; :math:`\cot\frac{11\pi}{6}=-\sqrt3`

**7)** a) :math:`20(\sqrt2-1)` meters b) :math:`20(\sqrt3-\sqrt2)` meters

**8)** a) :math:`\dfrac{\sqrt2}{2}` b) 2
