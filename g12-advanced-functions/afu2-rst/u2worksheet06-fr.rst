**4\)** Le prix, :math:`p`, en dollars, d'une action :math:`t` années
après 1999 peut être modélisé par la fonction :math:`p(t) = 0.5t^3 -
5.5t^2 + 14t`. Quand l'action sera-t-elle supérieure à 90 $ ? Vous pouvez
utiliser la technologie pour vous aider à déterminer la solution.

Corrigé
================================================================================

**1)** a) :math:`x \leq 2` b) :math:`x < 1`

**2)** a) :math:`x < -3` ou :math:`x > 2` b) :math:`-2 < x < -1` ou
:math:`x > 3`

**3)** a) :math:`x \leq 2` ou :math:`x \geq 5` b) :math:`-8 < x < 0`
ou :math:`x > 2` c) :math:`-6 \leq x \leq 6` d) :math:`x < -5` ou
:math:`-1 < x < 1` ou :math:`x > 5` e) :math:`-5 \leq x \leq 3` ou
:math:`x \geq 5` f) :math:`x \leq -4` ou :math:`-2 \leq x \leq 6` g)
:math:`x < -2` ou :math:`1 < x < 3` h) :math:`x \leq -1` ou
:math:`\dfrac{2}{5} \leq x \leq 3`

**4)** :math:`t > 10` (c'est-à-dire, après l'année 2009)
