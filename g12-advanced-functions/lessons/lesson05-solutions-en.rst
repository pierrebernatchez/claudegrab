Symmetry in Polynomial Functions
================================================================================

:sol:`Line Symmetry` -- there is a vertical line over which the polynomial
remains unchanged when reflected.

:sol:`Point symmetry / Rotational Symmetry` -- there is a point about
which the polynomial remains unchanged when rotated 180°

Section 1: Properties of Even and Odd Functions
================================================================================

A polynomial function of even or odd degree is NOT necessarily an even
or odd function. The following are properties of all even and odd
functions:

.. list-table::
   :widths: 50 50
   :header-rows: 0

   * - **Even Functions**
     - **Odd Functions**
   * - An even degree polynomial function is an EVEN FUNCTION if:

       - Line symmetry over the :solmath:`y`:sol:`-axis`
       - The exponent of each term is :sol:`even`
       - May have a constant term
     - An odd degree polynomial function is an ODD FUNCTION if:

       - Point symmetry about the :sol:`origin (0, 0)`
       - The exponent of each term is :sol:`odd`
       - No constant term
   * - **Rule:**

       :solmath:`f(-x) = f(x)`
     - **Rule:**

       :solmath:`-f(x) = f(-x)`
   * - **Example:**

       .. image:: ../images/lesson05-image03.png
          :scale: 50
          :alt: f(x) = 2x^4 + 3x^2 - 2 with f(1) and f(-1) marked

       :math:`f(x) = 2x^4 + 3x^2 - 2`

       Notice:

       :math:`f(1) =` :sol:`3`

       :math:`f(-1) =` :sol:`3`

       :solmath:`\therefore f(1) = f(-1)`
     - **Example:**

       .. image:: ../images/lesson05-image04.png
          :scale: 50
          :alt: f(x) = 2x^3 + 3x with f(1) and f(-1) marked

       :math:`f(x) = 2x^3 + 3x`

       Notice:

       :math:`f(1) =` :sol:`5`

       :math:`f(-1) =` :sol:`-5`

       :solmath:`\therefore -f(1) = f(-1)`

**Example 1:** Identify each function as an even function, odd
function, or neither. Explain how you can tell.

a\) :math:`y = x^3 - 4x`

.. image:: ../images/lesson05-image05.png
   :scale: 50
   :alt: y = x^3 - 4x, point (0,0) marked

.. rst-class:: solution

This is an **odd function** because:

- .. rst-class:: solution

  It has point symmetry about the origin
- .. rst-class:: solution

  All terms in the equation have an odd exponent and there is no
  constant term

b\) :math:`y = x^3 - 4x + 2`

.. image:: ../images/lesson05-image06.png
   :scale: 50
   :alt: y = x^3 - 4x + 2, point (0,2) marked

.. rst-class:: solution

**Neither**

.. rst-class:: solution

This function has point symmetry. However, the origin is not the point
about which the function is symmetrical. Therefore, it is not an odd
or even function.

.. rst-class:: solution

From the equation we can tell it is NOT an odd function because there
is a constant term.

.. image:: ../images/lesson05-image07.png
   :scale: 50
   :alt: y = x^4 - 4x^2 + 2

.. rst-class:: solution

This is an **even function** because:

- .. rst-class:: solution

  It has line symmetry about the :math:`y`-axis
- .. rst-class:: solution

  All terms in the equation have an even exponent. Even functions are
  allowed to have a constant term.

.. rst-class:: solution

**Neither**

.. rst-class:: solution

This function has line symmetry. However, the :math:`y`-axis is not the
line about which the function is symmetrical. Therefore, it is not an
odd or even function.

.. rst-class:: solution

From the equation we can tell it is NOT an even or odd function because
there is a mixture of even and odd exponents.

**Example 3:** Without graphing, determine if each polynomial function
has line symmetry about the y-axis, point symmetry about the origin, or
neither. Verify your response algebraically.

a\) :math:`f(x) = 2x^4 - 5x^2 + 4`

.. rst-class:: solution

The function is even since the exponent of each term is even. The
function has line symmetry about the :math:`y`-axis.

Verify :math:`f(x) = f(-x)`

.. math::
   :class: solution

   f(-x) = 2(-x)^4 - 5(-x)^2 + 4

.. math::
   :class: solution

   f(-x) = 2x^4 - 5x^2 + 4

.. rst-class:: solution

So :math:`f(-x) = f(x)`.

b\) :math:`f(x) = -3x^5 + 9x^3 + 2x`

.. rst-class:: solution

The function is odd since the exponent of each term is odd. The
function has point symmetry about the origin.

Verify :math:`-f(x) = f(-x)`

.. math::
   :class: solution

   -f(x) = -(-3x^5 + 9x^3 + 2x) = 3x^5 - 9x^3 - 2x

.. math::
   :class: solution

   f(-x) = -3(-x)^5 + 9(-x)^3 + 2(-x) = 3x^5 - 9x^3 - 2x

.. rst-class:: solution

So :math:`-f(x) = f(-x)`.

c\) :math:`x^6 - 4x^3 + 6x^2 - 4`

.. rst-class:: solution

Some exponents are even and some are odd, so the function is neither
even nor odd. It does not have line symmetry about the :math:`y`-axis
or point symmetry about the origin.
