.. rst-class:: keepwithnext

**1\)** Déterminez les solutions des polynômes suivants.

.. rst-class:: keepwithnext

**a\)** :math:`(3x + 2)(x + 9)(x - 2) = 0`

.. rst-class:: solution

:math:`3x + 2 = 0 \rightarrow x_1 = -\dfrac{2}{3}`

.. rst-class:: solution

:math:`x + 9 = 0 \rightarrow x_2 = -9`

.. rst-class:: solution

:math:`x - 2 = 0 \rightarrow x_3 = 2`

.. rst-class:: solution

Solutions : :math:`\left(-\dfrac{2}{3}, 0\right)`, :math:`(-9, 0)`, et
:math:`(2, 0)`

.. rst-class:: keepwithnext

**b\)** :math:`(x^2 + 1)(x - 4) = 0`

.. rst-class:: solution

:math:`x^2 + 1 = 0 \rightarrow x^2 = -1` |---| aucune solution réelle

.. rst-class:: solution

:math:`x - 4 = 0 \rightarrow x = 4`

.. rst-class:: solution

Solution : :math:`(4, 0)`

.. rst-class:: keepwithnext

**2\)** Déterminez les solutions des polynômes suivants par
factorisation. Utilisez les outils appris dans cette unité pour vous
aider. (théorème du reste, théorème du zéro entier, division, etc.)

.. rst-class:: keepwithnext

**a\)** :math:`x^3 - 4x^2 - 3x + 18 = 0`

.. rst-class:: solution

Zéros possibles : :math:`\pm 1, \pm 2, \pm 3, \pm 6, \pm 9, \pm 18`

.. rst-class:: solution

:math:`f(-2) = 0` ; :math:`\therefore x + 2` est un facteur

.. image:: ../images/u2worksheet04-tabimage01.png
   :alt: division synthétique de x^3 - 4x^2 - 3x + 18 par x + 2, b = -2, quotient x^2 - 6x + 9 reste 0

.. rst-class:: solution

:math:`(x + 2)(x^2 - 6x + 9) = 0`

.. rst-class:: solution

:math:`(x + 2)(x - 3)^2 = 0`

.. rst-class:: solution

:math:`x_1 = -2`, :math:`x_2 = 3`

.. rst-class:: solution

Solutions : :math:`(-2, 0)` et :math:`(3, 0)`

.. rst-class:: keepwithnext

**b\)** :math:`x^3 - 3x^2 - 4x + 12 = 0`

.. rst-class:: solution

Zéros possibles : :math:`\pm 1, \pm 2, \pm 3, \pm 4, \pm 6, \pm 12`

.. rst-class:: solution

:math:`f(2) = 0` ; :math:`\therefore x - 2` est un facteur

.. image:: ../images/u2worksheet04-tabimage02.png
   :alt: division synthétique de x^3 - 3x^2 - 4x + 12 par x - 2, b = 2, quotient x^2 - x - 6 reste 0

.. rst-class:: solution

:math:`(x - 2)(x^2 - x - 6) = 0`

.. rst-class:: solution

:math:`(x - 2)(x - 3)(x + 2) = 0`

.. rst-class:: solution

:math:`x_1 = 2`, :math:`x_2 = 3`, :math:`x_3 = -2`

.. rst-class:: solution

Solutions : :math:`(2, 0)`, :math:`(3, 0)`, et :math:`(-2, 0)`

.. rst-class:: keepwithnext

**c\)** :math:`x^4 - x^3 - 11x^2 + 9x + 18 = 0`

.. rst-class:: solution

Zéros possibles : :math:`\pm 1, \pm 2, \pm 3, \pm 6, \pm 9, \pm 18`

.. rst-class:: solution

:math:`f(-1) = 0` ; :math:`\therefore x + 1` est un facteur

.. image:: ../images/u2worksheet04-tabimage03.png
   :alt: division synthétique de x^4 - x^3 - 11x^2 + 9x + 18 par x + 1, b = -1, quotient x^3 - 2x^2 - 9x + 18 reste 0

.. rst-class:: solution

:math:`(x + 1)(x^3 - 2x^2 - 9x + 18) = 0`

.. rst-class:: solution

:math:`(x + 1)[x^2(x - 2) - 9(x - 2)] = 0`

.. rst-class:: solution

:math:`(x + 1)(x - 2)(x^2 - 9) = 0`

.. rst-class:: solution

:math:`(x + 1)(x - 2)(x - 3)(x + 3) = 0`

.. rst-class:: solution

:math:`x_1 = -1`, :math:`x_2 = 2`, :math:`x_3 = 3`, :math:`x_4 = -3`

.. rst-class:: solution

Solutions : :math:`(-1, 0)`, :math:`(2, 0)`, :math:`(3, 0)`, et
:math:`(-3, 0)`

.. rst-class:: keepwithnext

**d\)** :math:`x^3 - 64 = 0`

:math:`a^3 + b^3 = (a + b)(a^2 - ab + b^2)`, :math:`a^3 - b^3 = (a -
b)(a^2 + ab + b^2)`

.. rst-class:: solution

:math:`(x - 4)(x^2 + 4x + 16) = 0`

.. rst-class:: solution

:math:`x = 4`

.. rst-class:: solution

Vérification : :math:`b^2 - 4ac = (4)^2 - 4(1)(16) = -48` |---| aucune
solution réelle

.. rst-class:: solution

Solution : :math:`(4, 0)`

.. rst-class:: keepwithnext

**e\)** :math:`2x^3 - 7x^2 + 10x - 5 = 0`

.. rst-class:: solution

Zéros possibles : :math:`\pm 1, \pm \dfrac{1}{2}, \pm 5, \pm \dfrac{5}{2}`

.. rst-class:: solution

:math:`f(1) = 0` ; :math:`\therefore x - 1` est un facteur

.. image:: ../images/u2worksheet04-tabimage04.png
   :alt: division synthétique de 2x^3 - 7x^2 + 10x - 5 par x - 1, b = 1, quotient 2x^2 - 5x + 5 reste 0

.. rst-class:: solution

:math:`(x - 1)(2x^2 - 5x + 5) = 0`

.. rst-class:: solution

:math:`x - 1 = 0 \rightarrow x = 1`

.. rst-class:: solution

Vérification : :math:`b^2 - 4ac = (-5)^2 - 4(2)(5) = -15` |---| aucune
solution réelle

.. rst-class:: solution

Solution : :math:`(1, 0)`

**4\)** Résolvez par factorisation

.. rst-class:: keepwithnext

**a\)** :math:`x^3 - 4x^2 - 7x + 10 = 0`

.. rst-class:: solution

Zéros possibles : :math:`\pm 1, \pm 2, \pm 5, \pm 10`

.. rst-class:: solution

:math:`f(1) = 0` ; :math:`\therefore x - 1` est un facteur

.. image:: ../images/u2worksheet04-tabimage05.png
   :alt: division synthétique de x^3 - 4x^2 - 7x + 10 par x - 1, b = 1, quotient x^2 - 3x - 10 reste 0

.. rst-class:: solution

.. rst-class:: keepwithnext

**b\)** :math:`2x^3 - 11x^2 + 12x + 9 = 0`

.. rst-class:: solution

Zéros possibles : :math:`\pm 1, \pm \dfrac{1}{2}, \pm 3, \pm \dfrac{3}{2},
\pm 9, \pm \dfrac{9}{2}`

.. rst-class:: solution

:math:`f(3) = 0` ; :math:`\therefore x - 3` est un facteur

.. image:: ../images/u2worksheet04-tabimage06.png
   :alt: division synthétique de 2x^3 - 11x^2 + 12x + 9 par x - 3, b = 3, quotient 2x^2 - 5x - 3 reste 0

.. rst-class:: solution

:math:`(x - 3)(2x^2 - 5x - 3) = 0`

.. rst-class:: solution

:math:`(x - 3)(x - 3)(2x + 1) = 0`

.. rst-class:: solution

:math:`(x - 3)^2(2x + 1) = 0`

.. rst-class:: solution

:math:`x_1 = 3`, :math:`x_2 = -\dfrac{1}{2}`

.. rst-class:: solution

Solutions : :math:`(3, 0)` et :math:`\left(-\dfrac{1}{2}, 0\right)`
