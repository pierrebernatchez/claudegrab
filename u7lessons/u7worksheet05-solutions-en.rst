.. rst-class:: keepwithnext

**1)** Solve each equation algebraically.

.. rst-class:: keepwithnext

a\) :math:`\dfrac{6}{2x-1} = 5`

.. rst-class:: solution

:math:`(2x-1)\left(\dfrac{6}{2x-1}\right) = 5(2x-1)`

.. rst-class:: solution

:math:`6 = 10x-5 \Rightarrow 11 = 10x \Rightarrow x = \dfrac{11}{10} =
1.1`

.. rst-class:: keepwithnext

b\) :math:`\dfrac{6}{x} = x-5`

.. rst-class:: solution

:math:`x\left(\dfrac{6}{x}\right) = x(x-5) \Rightarrow 6 = x^2-5x
\Rightarrow 0 = x^2-5x-6 \Rightarrow 0 = (x-6)(x+1)`

.. rst-class:: solution

:math:`x-6=0 \Rightarrow x_1=6`; :math:`x+1=0 \Rightarrow x_2=-1`

.. rst-class:: keepwithnext

c\) :math:`1 = \dfrac{5}{3x^2-8x+2}`

.. rst-class:: solution

:math:`(3x^2-8x+2)(1) = 5 \Rightarrow 3x^2-8x-3 = 0`

.. rst-class:: solution

:math:`3x^2-9x+1x-3=0 \Rightarrow 3x(x-3)+1(x-3)=0 \Rightarrow
(x-3)(3x+1)=0`

.. rst-class:: solution

:math:`x-3=0 \Rightarrow x_1=3`; :math:`3x+1=0 \Rightarrow x_2=-\dfrac{1}{3}`

.. rst-class:: keepwithnext

d\) :math:`\dfrac{x+5}{x-1} = \dfrac{x+1}{x-3}`

.. rst-class:: solution

:math:`(x-3)(x+5) = (x+1)(x-1) \Rightarrow x^2+2x-15 = x^2-1`

.. rst-class:: solution

:math:`2x = 14 \Rightarrow x = 7`

.. rst-class:: keepwithnext

e\) :math:`\dfrac{3}{x+5} + \dfrac{4}{x} = 0`

.. rst-class:: solution

:math:`\dfrac{3}{x+5} = \dfrac{-4}{x} \Rightarrow 3x = -4(x+5)
\Rightarrow 3x = -4x-20`

.. rst-class:: solution

:math:`7x = -20 \Rightarrow x = -\dfrac{20}{7}`

.. rst-class:: keepwithnext

f\) :math:`2x = 5 - \dfrac{3}{x}`

.. rst-class:: solution

:math:`x(2x) = x\left(5-\dfrac{3}{x}\right) \Rightarrow 2x^2 = 5x-3
\Rightarrow 2x^2-5x+3=0`

.. rst-class:: solution

:math:`2x^2-2x-3x+3=0 \Rightarrow 2x(x-1)-3(x-1)=0 \Rightarrow
(x-1)(2x-3)=0`

.. rst-class:: solution

:math:`x-1=0 \Rightarrow x_1=1`; :math:`2x-3=0 \Rightarrow
x_2=\dfrac{3}{2}`

.. rst-class:: keepwithnext

g\) :math:`\dfrac{2}{1-x} + \dfrac{3}{x+1} = \dfrac{1}{x}`

.. rst-class:: solution

:math:`\dfrac{2(x+1)+3(1-x)}{(1-x)(x+1)} = \dfrac{1}{x} \Rightarrow
\dfrac{2x+2+3-3x}{1-x^2} = \dfrac{1}{x} \Rightarrow \dfrac{-x+5}{1-x^2} =
\dfrac{1}{x}`

.. rst-class:: solution

:math:`x(-x+5) = 1(1-x^2) \Rightarrow -x^2+5x = 1-x^2 \Rightarrow 5x=1
\Rightarrow x = \dfrac{1}{5}`

.. rst-class:: keepwithnext

h\) :math:`\dfrac{3}{x-1} + 5 + \dfrac{2}{x} = 0`

.. rst-class:: solution

:math:`x(x-1)\left[\dfrac{3}{x-1}+5+\dfrac{2}{x}\right] = 0(x)(x-1)
\Rightarrow 3x+5x(x-1)+2(x-1) = 0`

.. rst-class:: solution

:math:`3x+5x^2-5x+2x-2=0 \Rightarrow 5x^2=2 \Rightarrow x^2=\dfrac{2}{5}
\Rightarrow x = \pm\sqrt{0.4}`
