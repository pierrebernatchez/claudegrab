Part 1: Analyze the Reciprocal of a Linear Function
================================================================================

.. rst-class:: keepwithnext

**Example 1:**

.. image:: ../images/u7lesson01-gpimage01.png
   :scale: 90
   :alt: y=2x+4 and its reciprocal y=1/(2x+4), with VA x=-2 and HA y=0

.. rst-class:: keepwithnext

a\) Draw the horizontal and vertical asymptotes for the reciprocal function
and state what they are

.. rst-class:: solution

:math:`HA: y = 0`

.. rst-class:: solution

:math:`VA: x = -2`

.. rst-class:: keepwithnext

b\) What graphical characteristic in the reciprocal function does the zero
(:math:`x`-int) of the original function correspond to?

.. rst-class:: solution

The vertical asymptote of the reciprocal function passes through the
:math:`x`-intercept of the linear function.

.. rst-class:: keepwithnext

c\) When the original function is increasing, what is happening to the
reciprocal function?

.. rst-class:: solution

It is DECREASING.

.. rst-class:: keepwithnext

d\) What are the :math:`y`-coordinates of the points of intersection?

.. rst-class:: solution

:math:`1` and :math:`-1`. This is because the reciprocal of each of those
does not change their value.

.. rst-class:: keepwithnext

e\) Label a point on the graph of both functions at :math:`x = 2`. What do
you notice about the :math:`y` values of each point?

.. rst-class:: solution

The :math:`y`-value of the reciprocal function is the reciprocal of the
:math:`y`-value of the linear function.

Part 2: Analyze the Reciprocal of a Quadratic Function
================================================================================

.. rst-class:: keepwithnext

**Example 2:**

.. image:: ../images/u7lesson01-gpimage02.png
   :scale: 90
   :alt: y=x^2-4 and its reciprocal y=1/(x^2-4), with VA x=-2,2 and HA y=0

.. rst-class:: keepwithnext

a\) Draw the horizontal and vertical asymptotes for the reciprocal function
and state what they are

.. rst-class:: solution

:math:`VA: x = 2` and :math:`x = -2`

.. rst-class:: solution

:math:`HA: y = 0`

.. rst-class:: keepwithnext

b\) What graphical characteristic in the reciprocal function do the zeros
(:math:`x`-int) of the original function correspond to?

.. rst-class:: solution

The vertical asymptotes of the reciprocal function pass through the
:math:`x`-intercepts of the quadratic.

.. rst-class:: keepwithnext

c\) When the original function is decreasing, what is happening to the
reciprocal function?

.. rst-class:: solution

It is INCREASING.

.. rst-class:: keepwithnext

d\) What are the :math:`y`-coordinates of the points of intersection?

.. rst-class:: solution

:math:`1` and :math:`-1`

.. rst-class:: keepwithnext

f\) Label the local min or max point on each function. What do you notice
about them?

.. rst-class:: solution

They have the same :math:`x`-coordinate, which is exactly half way between
the vertical asymptotes.

.. rst-class:: solution

The quadratic has a local min but the reciprocal has a local max.

.. list-table::
   :width: 100%

   * - Properties of Reciprocal Functions

       - All the :math:`y`-coordinates of the reciprocal function are the
         reciprocals of the :math:`y`-coordinates of the original function
       - The graph of the reciprocal function has a vertical asymptote at
         the :math:`x`-intercepts (zeros) of the original

         - This is because it makes the denominator of the reciprocal
           :math:`= 0`
       - :math:`y = 0` will always be a horizontal asymptote
       - The reciprocal function has the same positive/negative intervals
         as the original function
       - Intervals of increase on the original function are intervals of
         decrease on the reciprocal
       - Intervals of decrease on the original function are intervals of
         increase on the reciprocal
       - If :math:`1` is in the range of the original function, this is
         where the functions will intersect
       - If the original function has a local min point, the reciprocal
         will have a local max at the same :math:`x`-value (and vice versa)

Part 3: Graphing Reciprocal Functions
================================================================================

.. list-table::
   :width: 100%

   * - Process:

       - Find key features of the function in the denominator and graph
         it using a table of values
       - Create a table of values for the reciprocal function by keeping
         the same :math:`x` values but using the reciprocal of all
         :math:`y` values
       - Draw vertical asymptotes at any point that is a zero of the
         original linear/quadratic function

         - Reciprocal of :math:`0` is undefined
       - If the numerator is something other than :math:`1`, multiply the
         :math:`y`-values by this stretch factor
