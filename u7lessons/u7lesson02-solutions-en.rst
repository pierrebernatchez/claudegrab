Part 1: Key Features of the Quotient of Linear Functions
================================================================================

.. list-table::
   :width: 100%

   * - Features of :math:`f(x) = \dfrac{ax+b}{cx+d}`

       - If an :math:`x` value is a zero of the denominator ONLY, this
         results in a vertical asymptote

         - Equation of vertical asymptote is :math:`x = \dfrac{-d}{c}`
       - If an :math:`x` value is a zero of the numerator AND
         denominator, this results in a **hole** in the graph NOT a
         vertical asymptote
       - There is a horizontal asymptote at the ratio of the leading
         coefficients

         - Equation of horizontal asymptote is :math:`y = \dfrac{a}{c}`
       - Forms a **Hyperbola**: the two branches of the graph of the
         function are equidistant from the point of intersection of the
         vertical and horizontal asymptotes

         - Once you know the shape of one branch, you can translate the
           points to graph the other branch
       - You can find the :math:`x`-intercept by setting :math:`y = 0`
         and solving for :math:`x`

         - This results in :math:`\left(\dfrac{-b}{a}, 0\right)`
       - You can find the :math:`y`-intercept by setting :math:`x = 0`
         and solving for :math:`y`

         - This results in :math:`\left(0, \dfrac{b}{d}\right)`

Part 2: Graphing a Quotient of Linear Functions
================================================================================

.. rst-class:: keepwithnext

**Example 1:** Graph each of the following functions

.. rst-class:: keepwithnext

a\) :math:`f(x) = \dfrac{x-3}{x+2}`

.. rst-class:: solution

:math:`VA: x+2 = 0 \Rightarrow x = -2`

.. rst-class:: solution

:math:`HA: \dfrac{1}{1} = 1 \Rightarrow y = 1`

.. rst-class:: solution

:math:`x\text{-int}: 0 = \dfrac{x-3}{x+2} \Rightarrow 0 = x-3 \Rightarrow
x = 3`, so :math:`(3,0)`

.. rst-class:: solution

:math:`y\text{-int}: f(0) = \dfrac{0-3}{0+2} = -\dfrac{3}{2}`, so
:math:`(0,-1.5)`

.. rst-class:: solution

Another point: :math:`f(-1.5) = \dfrac{-1.5-3}{-1.5+2} =
\dfrac{-4.5}{0.5} = -9`, so :math:`(-1.5,-9)`

.. rst-class:: keepwithnext

b\) :math:`g(x) = \dfrac{2x-3}{x-1}`

.. rst-class:: solution

:math:`VA: x-1 = 0 \Rightarrow x = 1`

.. rst-class:: solution

:math:`HA: \dfrac{2}{1} = 2 \Rightarrow y = 2`

.. rst-class:: solution

:math:`x\text{-int}: 0 = \dfrac{2x-3}{x-1} \Rightarrow 0 = 2x-3
\Rightarrow x = \dfrac{3}{2}`, so :math:`(1.5,0)`

.. rst-class:: solution

:math:`y\text{-int}: g(0) = \dfrac{2(0)-3}{0-1} = 3`, so :math:`(0,3)`

.. rst-class:: solution

Other points: :math:`g(2) = \dfrac{2(2)-3}{2-1} = \dfrac{1}{1} = 1`, so
:math:`(2,1)`; :math:`g(3) = \dfrac{2(3)-3}{3-1} = \dfrac{3}{2}`, so
:math:`(3,1.5)`
