**1)** Soit :math:`f(x) = 3x-5` et :math:`g(x) = 2x+3`.

.. rst-class:: keepwithnext

a\) Écris l'équation de :math:`h(x) = f(x)+g(x)` et détermine la valeur de
:math:`h(2)`.

.. rst-class:: solution

:math:`h(x) = (3x-5)+(2x+3) = 3x-5+2x+3 = 5x-2`

.. rst-class:: solution

:math:`h(2) = 5(2)-2 = 8`

.. rst-class:: keepwithnext

b\) Écris l'équation de :math:`k(x) = f(x)-g(x)` et détermine la valeur de
:math:`k(2)`.

.. rst-class:: solution

:math:`k(x) = (3x-5)-(2x+3) = 3x-5-2x-3 = x-8`

.. rst-class:: solution

:math:`k(2) = 2-8 = -6`

**3)** Soit :math:`f(x) = x-2` et :math:`g(x) = x^2+3x-3`. Détermine un
modèle algébrique et graphique pour :math:`h(x) = f(x)+g(x)`.

.. rst-class:: solution

:math:`h(x) = (x-2)+(x^2+3x-3) = x^2+4x-5 = (x+5)(x-1)`

.. rst-class:: solution

Abscisses à l'origine : :math:`x=-5` et :math:`x=1`

.. rst-class:: solution

:math:`x\text{-sommet} = \dfrac{-5+1}{2} = -2`; :math:`h(-2) =
(-2)^2+4(-2)-5 = -9`, donc sommet :math:`(-2,-9)`

.. rst-class:: solution

Ordonnée à l'origine : :math:`h(0) = 0^2+4(0)-5 = -5`, donc :math:`(0,-5)`

.. image:: ../images/u7worksheet03-gpimage03.png
   :scale: 90
   :alt: h(x)=x^2+4x-5, parabole vers le haut sommet (-2,-9)

**4)** Soit :math:`f(x) = x-2` et :math:`g(x) = x^2-4`. Élabore un modèle
algébrique et graphique pour chacune des fonctions suivantes :

.. rst-class:: keepwithnext

a\) :math:`y = f(x)g(x)`

.. rst-class:: solution

:math:`y = (x-2)(x^2-4) = (x-2)(x-2)(x+2) = (x-2)^2(x+2)`

.. rst-class:: solution

Abscisses à l'origine : :math:`(2,0)` d'ordre 2, :math:`(-2,0)` d'ordre 1

.. rst-class:: solution

Ordonnée à l'origine : :math:`y = (0-2)^2(0+2) = 8`, donc :math:`(0,8)`

.. image:: ../images/u7worksheet03-gpimage04.png
   :scale: 90
   :alt: y=(x-2)^2(x+2), cubique avec une racine double à x=2

.. rst-class:: keepwithnext

b\) :math:`y = \dfrac{f(x)}{g(x)}`

.. rst-class:: solution

:math:`y = \dfrac{x-2}{x^2-4} = \dfrac{x-2}{(x-2)(x+2)} = \dfrac{1}{x+2};
x \neq -2, 2`

.. rst-class:: solution

Trou à :math:`x=2`; :math:`AV: x=-2`; :math:`AH: y=0`

.. image:: ../images/u7worksheet03-gpimage05.png
   :scale: 90
   :alt: y=1/(x+2), une hyperbole avec AV x=-2 et un trou à x=2

.. rst-class:: keepwithnext

c\) :math:`y = \dfrac{g(x)}{f(x)}`

.. rst-class:: solution

:math:`y = \dfrac{x^2-4}{x-2} = \dfrac{(x-2)(x+2)}{x-2} = x+2; x \neq 2`

.. rst-class:: solution

Trou à :math:`x=2`

   :scale: 90
   :alt: y=x+2, une droite avec un trou à x=2

**5)** Soit :math:`f(x) = x^2+2x-4` et :math:`g(x) = \dfrac{1}{x+1}`.

.. rst-class:: keepwithnext

a\) Évalue :math:`g(f(0))`

.. rst-class:: solution

:math:`f(0) = 0^2+2(0)-4 = -4`

.. rst-class:: solution

:math:`g(f(0)) = g(-4) = \dfrac{1}{-4+1} = -\dfrac{1}{3}`

.. rst-class:: keepwithnext

b\) Évalue :math:`f(g(-2))`

.. rst-class:: solution

:math:`g(-2) = \dfrac{1}{-2+1} = -1`

.. rst-class:: solution

:math:`f(g(-2)) = f(-1) = (-1)^2+2(-1)-4 = -5`

**6)** Soit :math:`f(x) = x^2+3x` et :math:`g(x) = 2x-5`. Détermine une
équation pour chaque fonction composée et trace son graphique.

.. rst-class:: keepwithnext

a\) :math:`y = f(g(x))`

.. rst-class:: solution

:math:`f(g(x)) = (2x-5)^2+3(2x-5) = 4x^2-20x+25+6x-15 = 4x^2-14x+10 =
2(2x^2-7x+5) = 2[x(2x-5)-1(2x-5)] = 2(2x-5)(x-1)`

.. rst-class:: solution

Abscisses à l'origine : :math:`x=1` et :math:`x=2.5`; ordonnée à
l'origine : :math:`(0,10)`

.. rst-class:: solution

:math:`x\text{-sommet} = \dfrac{1+2.5}{2} = 1.75`;
:math:`y\text{-sommet} = -2.25`

.. image:: ../images/u7worksheet03-gpimage07.png
   :scale: 90
   :alt: y=f(g(x))=2(2x-5)(x-1), parabole vers le haut sommet (1.75,-2.25)

.. rst-class:: keepwithnext

b\) :math:`y = g(f(x))`

.. rst-class:: solution

:math:`g(f(x)) = 2(x^2+3x)-5 = 2x^2+6x-5`

.. rst-class:: solution

:math:`x\text{-sommet} = -\dfrac{b}{2a} = -\dfrac{6}{2(2)} = -1.5`;
:math:`y\text{-sommet} = -9.5`

.. image:: ../images/u7worksheet03-gpimage08.png
   :scale: 90
   :alt: y=g(f(x))=2x^2+6x-5, parabole vers le haut sommet (-1.5,-9.5)

.. rst-class:: keepwithnext

c\) :math:`y = g(g(x))`

.. rst-class:: solution

:math:`g(g(x)) = 2(2x-5)-5 = 4x-10-5 = 4x-15`

.. rst-class:: solution

:math:`m=4`, :math:`b=-15`

.. image:: ../images/u7worksheet03-gpimage09.png

.. rst-class:: keepwithnext

d\) :math:`y = g^{-1}(g(x))`

.. rst-class:: solution

Pour trouver :math:`g^{-1}(x)` : soit :math:`y=2x-5`, échange pour
obtenir :math:`x=2y-5`, résous : :math:`\dfrac{x+5}{2}=y`, donc
:math:`g^{-1}(x) = \dfrac{x+5}{2}`

.. rst-class:: solution

:math:`g^{-1}(g(x)) = \dfrac{(2x-5)+5}{2} = \dfrac{2x}{2} = x`

.. rst-class:: solution

:math:`m=1`, :math:`b=0` — c'est la droite identité, puisque
l'application de la réciproque d'une fonction immédiatement après la
fonction elle-même redonne toujours l'entrée originale.
