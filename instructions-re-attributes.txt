We have an extra requirement for our process.

Each of our .rst files must include some extra attributes which the downstream process
needs.

This must be inserted below the main header underline as illustrated in the files
example-en.rst and example-fr.rst.  With an empty line before and after the inserted block.

The lang value corresponds to the language. (en,fr,es)
The slug value must be the .rst filename but without the -en.rst trailing string.
The date value is generated by "date -u --rfc-3339=seconds" as and when we generate the file.
The summary value should match the header text

The rest of the lines just duplicate from the corresponding example-en.rst or example-fr.rst files.
