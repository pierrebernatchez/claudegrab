a\) :math:`y = 5\sin(3x)`

.. list-table::
   :widths: 50 50

   * - Amplitude: :solmath:`|a| = 5`
     - Period: :solmath:`\dfrac{2\pi}{|k|} = \dfrac{2\pi}{3}`
   * - Phase shift: :sol:`none`
     - Vertical shift: :sol:`none`
   * - Max: :solmath:`c+|a| = 0+5 = 5`
     - Min: :solmath:`c-|a| = 0-5 = -5`

**3)** A sine function has a maximum value of 7, a minimum value of -1, a
phase shift of :math:`\dfrac{3\pi}{4}` radians to the left, and a period
of :math:`\dfrac{\pi}{2}`.

.. rst-class:: keepwithnext

a\) Write an equation for this function.

:solmath:`a = \dfrac{\max-\min}{2} = \dfrac{7-(-1)}{2} = 4`

:solmath:`k = \dfrac{2\pi}{\text{period}} = \dfrac{2\pi}{\frac{\pi}{2}} = 4`

:solmath:`d = -\dfrac{3\pi}{4}`

:solmath:`c = \max-|a| = 7-4 = 3`

:solmath:`y = 4\sin\left[4\left(x+\dfrac{3\pi}{4}\right)\right]+3`

.. rst-class:: keepwithnext

b\) Write an equivalent cosine equation for this function.

:solmath:`d_{\cos} = d_{\sin} + \dfrac{\pi}{2k} = -\dfrac{3\pi}{4} +
\dfrac{\pi}{8} = -\dfrac{6\pi}{8} + \dfrac{\pi}{8} = -\dfrac{5\pi}{8}`

:solmath:`y = 4\cos\left[4\left(x+\dfrac{5\pi}{8}\right)\right]+3`

.. rst-class:: keepwithnext

**4)** A cosine function has a maximum value of 1, a minimum value of -5,
a phase shift of 2 radians to the right, and a period of 3.

.. rst-class:: keepwithnext

a\) Write an equation for this function.

:solmath:`a = \dfrac{\max-\min}{2} = \dfrac{1-(-5)}{2} = 3`

:solmath:`k = \dfrac{2\pi}{\text{period}} = \dfrac{2\pi}{3}`

:solmath:`d = 2`

:solmath:`c = \max-|a| = 1-3 = -2`

:solmath:`y = 3\cos\left[\dfrac{2\pi}{3}(x-2)\right]-2`

.. rst-class:: keepwithnext

b\) Write an equivalent sine equation for this function.

:solmath:`d_{\sin} = d_{\cos} - \dfrac{\pi}{2k} = 2 -
\dfrac{\pi}{\frac{4\pi}{3}} = 2 - \dfrac34 = \dfrac54`

:solmath:`y = 3\sin\left[\dfrac{2\pi}{3}\left(x-\dfrac54\right)\right]-2`
