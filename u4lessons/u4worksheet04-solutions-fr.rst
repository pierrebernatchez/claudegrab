**1)** Pour chaque fonction, remplis le tableau de renseignements, puis
représente graphiquement deux cycles de la fonction transformée en
utilisant les transformations de la fonction mère. Choisis une échelle
appropriée.

.. rst-class:: keepwithnext

a\) :math:`y = 5\sin(3x)`

.. list-table::
   :widths: 50 50

   * - Amplitude : :solmath:`|a| = 5`
     - Période : :solmath:`\dfrac{2\pi}{|k|} = \dfrac{2\pi}{3}`
   * - Déphasage : :sol:`aucun`
     - Déplacement vertical : :sol:`aucun`
   * - Max : :solmath:`c+|a| = 0+5 = 5`
     - Min : :solmath:`c-|a| = 0-5 = -5`

b\) :math:`y = -3\cos\left(\dfrac34 x\right)`

.. list-table::
   :widths: 50 50

   * - Amplitude : :solmath:`|a| = 3`
     - Période : :solmath:`\dfrac{2\pi}{|k|} = \dfrac{2\pi}{\frac34} =
       \dfrac{8\pi}{3}`
   * - Déphasage : :sol:`aucun`
     - Déplacement vertical : :sol:`aucun`
   * - Max : :solmath:`c+|a| = 0+3 = 3`
     - Min : :solmath:`c-|a| = 0-3 = -3`

.. image:: ../images/u4worksheet04-gpimage02.png
   :scale: 76
   :alt: graphique de y = -3 cos(3x/4) sur deux cycles, de 0 à 16 pi/3, avec points clés marqués

c\) :math:`y = 4\sin\left[3\left(x-\dfrac{\pi}{3}\right)\right] - 2`

.. list-table::
   :widths: 50 50

   * - Amplitude : :solmath:`|a| = 4`
     - Période : :solmath:`\dfrac{2\pi}{|k|} = \dfrac{2\pi}{3}`
   * - Déphasage : :solmath:`\dfrac{\pi}{3}` :sol:`vers la droite`
     - Déplacement vertical : :sol:`2 vers le bas`
   * - Max : :solmath:`c+|a| = -2+4 = 2`
     - Min : :solmath:`c-|a| = -2-4 = -6`

d\) :math:`y = 2\sin\left[\dfrac12\left(x+\dfrac{5\pi}{6}\right)\right] + 4`

.. list-table::
   :widths: 50 50

   * - Amplitude : :solmath:`|a| = 2`
     - Période : :solmath:`\dfrac{2\pi}{|k|} = \dfrac{2\pi}{\frac12} = 4\pi`
   * - Déphasage : :solmath:`\dfrac{5\pi}{6}` :sol:`vers la gauche`
     - Déplacement vertical : :sol:`4 vers le haut`
   * - Max : :solmath:`c+|a| = 4+2 = 6`
     - Min : :solmath:`c-|a| = 4-2 = 2`

**2)** Modélise chaque graphique montré sous forme de fonction sinus et
cosinus.

.. rst-class:: keepwithnext

a\)

.. image:: ../images/u4worksheet04-gpimage05.png
   :scale: 65
   :alt: graphique donné oscillant entre un maximum de 4 et un minimum de -2

:solmath:`a = \dfrac{\max-\min}{2} = \dfrac{4-(-2)}{2} = 3`

:solmath:`k = \dfrac{2\pi}{\text{période}} = \dfrac{2\pi}{4} = \dfrac{\pi}{2}`

:solmath:`c = \max-|a| = 4-3 = 1`

:solmath:`d_{\sin} = 1`, :solmath:`d_{\cos} = 2`

:solmath:`y = 3\sin\left[\dfrac{\pi}{2}(x-1)\right]+1`

:solmath:`y = 3\cos\left[\dfrac{\pi}{2}(x-2)\right]+1`

.. rst-class:: keepwithnext

b\)

.. image:: ../images/u4worksheet04-gpimage06.png
   :scale: 65
   :alt: graphique donné oscillant entre un maximum de 3 et un minimum de -1

:solmath:`a = \dfrac{\max-\min}{2} = \dfrac{3-(-1)}{2} = 2`

:solmath:`k = \dfrac{2\pi}{\text{période}} = \dfrac{2\pi}{12} = \dfrac{\pi}{6}`

:solmath:`c = \max-|a| = 3-2 = 1`

:solmath:`d_{\cos} = 4`

:solmath:`d_{\sin} = d_{\cos} - \dfrac{\pi}{2k} = 4 - \dfrac{\pi}{\frac{\pi}{3}}
= 4-3 = 1`

:solmath:`y = 2\sin\left[\dfrac{\pi}{6}(x-1)\right]+1`

:solmath:`y = 2\cos\left[\dfrac{\pi}{6}(x-4)\right]+1`

.. rst-class:: keepwithnext

c\)

.. image:: ../images/u4worksheet04-gpimage07.png
   :scale: 65
   :alt: graphique donné oscillant entre un maximum de 2 et un minimum de -4

:solmath:`a = \dfrac{\max-\min}{2} = \dfrac{2-(-4)}{2} = 3`

:solmath:`k = \dfrac{2\pi}{\text{période}} = \dfrac{2\pi}{\pi} = 2`

:solmath:`c = \max-|a| = 2-3 = -1`

:solmath:`d_{\cos} = \dfrac{\pi}{2}`, :solmath:`d_{\sin} = \dfrac{\pi}{4}`

:solmath:`y = 3\sin\left[2\left(x-\dfrac{\pi}{4}\right)\right]-1`

:solmath:`y = 3\cos\left[2\left(x-\dfrac{\pi}{2}\right)\right]-1`

.. rst-class:: keepwithnext

**3)** Une fonction sinus a une valeur maximale de 7, une valeur
minimale de -1, un déphasage de :math:`\dfrac{3\pi}{4}` radians vers la
gauche, et une période de :math:`\dfrac{\pi}{2}`.

.. rst-class:: keepwithnext

a\) Écris une équation pour cette fonction.

:solmath:`a = \dfrac{\max-\min}{2} = \dfrac{7-(-1)}{2} = 4`

:solmath:`k = \dfrac{2\pi}{\text{période}} = \dfrac{2\pi}{\frac{\pi}{2}} = 4`

:solmath:`d = -\dfrac{3\pi}{4}`

:solmath:`c = \max-|a| = 7-4 = 3`

:solmath:`y = 4\sin\left[4\left(x+\dfrac{3\pi}{4}\right)\right]+3`

.. rst-class:: keepwithnext

b\) Écris une équation cosinus équivalente pour cette fonction.

:solmath:`d_{\cos} = d_{\sin} + \dfrac{\pi}{2k} = -\dfrac{3\pi}{4} +
\dfrac{\pi}{8} = -\dfrac{6\pi}{8} + \dfrac{\pi}{8} = -\dfrac{5\pi}{8}`

:solmath:`y = 4\cos\left[4\left(x+\dfrac{5\pi}{8}\right)\right]+3`

.. rst-class:: keepwithnext

**4)** Une fonction cosinus a une valeur maximale de 1, une valeur
minimale de -5, un déphasage de 2 radians vers la droite, et une
période de 3.

.. rst-class:: keepwithnext

a\) Écris une équation pour cette fonction.

:solmath:`a = \dfrac{\max-\min}{2} = \dfrac{1-(-5)}{2} = 3`

:solmath:`k = \dfrac{2\pi}{\text{période}} = \dfrac{2\pi}{3}`

:solmath:`d = 2`

:solmath:`c = \max-|a| = 1-3 = -2`

:solmath:`y = 3\cos\left[\dfrac{2\pi}{3}(x-2)\right]-2`

.. rst-class:: keepwithnext

b\) Écris une équation sinus équivalente pour cette fonction.

:solmath:`d_{\sin} = d_{\cos} - \dfrac{\pi}{2k} = 2 -
\dfrac{\pi}{\frac{4\pi}{3}} = 2 - \dfrac34 = \dfrac54`

:solmath:`y = 3\sin\left[\dfrac{2\pi}{3}\left(x-\dfrac54\right)\right]-2`
