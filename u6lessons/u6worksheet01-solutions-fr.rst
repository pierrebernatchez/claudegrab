**3)** Quel est le taux de variation moyen des valeurs de la fonction
:math:`f(x) = 4x` de :math:`x = 2` à :math:`x = 6`? Qu'en est-il de
:math:`x = 2` à :math:`x = 26`? Que révèlent vos résultats à propos de
:math:`f(x)`?

.. rst-class:: solution

:math:`2 \leq x \leq 6` : :math:`m = \dfrac{f(6)-f(2)}{6-2} = \dfrac{24-8}{4} = 4`

.. rst-class:: solution

:math:`2 \leq x \leq 26` : :math:`m = \dfrac{f(26)-f(2)}{26-2} = \dfrac{104-8}{24} = 4`

.. rst-class:: solution

Le taux de variation moyen sera toujours 4 parce que c'est une fonction
linéaire avec une pente de 4.

**5)** Une entreprise qui vend des chandails à capuchon constate que le
profit peut être modélisé par
:math:`P(s) = -0.30s^2 + 3.5s + 11.15`, où :math:`P(s)` est le profit,
en milliers de dollars, et :math:`s` est le nombre de chandails vendus
(exprimé en milliers).

.. rst-class:: keepwithnext

a\) Calculer le taux de variation moyen du profit pour les intervalles
suivants.

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       i\) :math:`1 \leq s \leq 2`

       .. rst-class:: solution

       :math:`m = \dfrac{P(2)-P(1)}{2-1}`

       .. rst-class:: solution

       :math:`= \dfrac{16.95-14.35}{1}`

       .. rst-class:: solution

       :math:`= 2.60\$/\text{chandail}`
     - .. rst-class:: keepwithnext

       ii\) :math:`2 \leq s \leq 3`

       .. rst-class:: solution

       :math:`m = \dfrac{P(3)-P(2)}{3-2}`

       .. rst-class:: solution

       :math:`= \dfrac{18.95-16.95}{1}`

       .. rst-class:: solution

       :math:`= 2.00\$/\text{chandail}`
   * - .. rst-class:: keepwithnext

       iii\) :math:`3 \leq s \leq 4`

       .. rst-class:: solution

       :math:`m = \dfrac{P(4)-P(3)}{4-3}`

       .. rst-class:: solution

       :math:`= \dfrac{20.35-18.95}{1}`

       .. rst-class:: solution

       :math:`= 1.40\$/\text{chandail}`
     - .. rst-class:: keepwithnext

       iv\) :math:`4 \leq s \leq 5`

       .. rst-class:: solution

       :math:`m = \dfrac{P(5)-P(4)}{5-4}`

       .. rst-class:: solution

       :math:`= \dfrac{21.15-20.35}{1}`

       .. rst-class:: solution

       :math:`= 0.80\$/\text{chandail}`

.. rst-class:: keepwithnext

b\) À mesure que le nombre de chandails vendus augmente, que
remarquez-vous à propos du taux de variation moyen du profit par
chandail? Que signifie ce résultat?

.. rst-class:: solution

Le taux de variation est positif mais décroissant. Les profits
continuent d'augmenter, mais à un rythme décroissant.

.. rst-class:: keepwithnext

c\) Prédire si le taux de variation du profit restera positif.
Expliquer ce que cela signifie.

.. rst-class:: solution

:math:`x_{sommet} = \dfrac{-b}{2a} = \dfrac{-3.5}{2(-0.3)} \approx 5.83`

.. rst-class:: solution

Non; autour de 6000 chandails vendus, les profits commenceront à
diminuer.
