**3)** What is the average rate of change in the values of the function
:math:`f(x) = 4x` from :math:`x = 2` to :math:`x = 6`? What about from
:math:`x = 2` to :math:`x = 26`? What do your results indicate about
:math:`f(x)`?

.. rst-class:: solution

:math:`2 \leq x \leq 6`: :math:`m = \dfrac{f(6)-f(2)}{6-2} = \dfrac{24-8}{4} = 4`

.. rst-class:: solution

:math:`2 \leq x \leq 26`: :math:`m = \dfrac{f(26)-f(2)}{26-2} = \dfrac{104-8}{24} = 4`

.. rst-class:: solution

The average rate of change will always be 4 because it is a linear
function with a slope of 4.

**5)** A company that sells sweatshirts finds that the profit can be
modelled by :math:`P(s) = -0.30s^2 + 3.5s + 11.15`, where :math:`P(s)` is
the profit, in thousands of dollars, and :math:`s` is the number of
sweatshirts sold (expressed in thousands).

.. rst-class:: keepwithnext

a\) Calculate the average rate of change in the profit for the following
intervals.

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       i\) :math:`1 \leq s \leq 2`

       .. rst-class:: solution

       :math:`m = \dfrac{P(2)-P(1)}{2-1}`

       .. rst-class:: solution

       :math:`= \dfrac{16.95-14.35}{1}`

       .. rst-class:: solution

       :math:`= \$2.60/\text{sweatshirt}`
     - .. rst-class:: keepwithnext

       ii\) :math:`2 \leq s \leq 3`

       .. rst-class:: solution

       :math:`m = \dfrac{P(3)-P(2)}{3-2}`

       .. rst-class:: solution

       :math:`= \dfrac{18.95-16.95}{1}`

       .. rst-class:: solution

       :math:`= \$2.00/\text{sweatshirt}`
   * - .. rst-class:: keepwithnext

       iii\) :math:`3 \leq s \leq 4`

       .. rst-class:: solution

       :math:`m = \dfrac{P(4)-P(3)}{4-3}`

       .. rst-class:: solution

       :math:`= \dfrac{20.35-18.95}{1}`

       .. rst-class:: solution

       :math:`= \$1.40/\text{sweatshirt}`
     - .. rst-class:: keepwithnext

       iv\) :math:`4 \leq s \leq 5`

       .. rst-class:: solution

       :math:`m = \dfrac{P(5)-P(4)}{5-4}`

       .. rst-class:: solution

       :math:`= \dfrac{21.15-20.35}{1}`

       .. rst-class:: solution

       :math:`= \$0.80/\text{sweatshirt}`

.. rst-class:: keepwithnext

b\) As the number of sweatshirts sold increases, what do you notice about
the average rate of change in profit on each sweatshirt? What does this
mean?

.. rst-class:: solution

The rate of change is positive but decreasing. Profits are going up but at
a decreasing rate.

.. rst-class:: keepwithnext

c\) Predict if the rate of change in profit will stay positive. Explain
what this means.

.. rst-class:: solution

:math:`x_{vertex} = \dfrac{-b}{2a} = \dfrac{-3.5}{2(-0.3)} \approx 5.83`

.. rst-class:: solution

No; at around 6000 sweatshirts sold, profits will start to decrease.
