About file/directory naming:
============================

A course's identifiers:
    The main subdirectory for the course:            g12-calculus-and-vectors
    The two character unique prefix for that course: cv
    Units within a course:                       u1,u2,u3,..., fc

Directories under the main course directory by type of content
(type directory name suffix: -rst, -gp, -media, -pdfs, -tableaux)
 
So when you are setting up a new course:

   Supply the directory name: g12-something-else
   Supply its prefix:         se
   Tell claude those details.
   Create an upstream sudirectory within it, and add .pdf s  to that for claude to start from.
   Work one unit at a time,  supplying clause with  all the pdfs for a given unit.
   Try to name you upstream files sensibly: s3u1lesson01.pdf, s3u1lesson01-solutions.pdf, ...
   to make it easy to correlate to the generated files.
