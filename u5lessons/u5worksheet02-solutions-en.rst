**3)** Apply a compound angle formula, and then determine an exact value
for each.

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       a\) :math:`\sin\left(\dfrac{\pi}{3}+\dfrac{\pi}{4}\right)`

       .. rst-class:: solution

       :math:`= \sin\dfrac{\pi}{3}\cos\dfrac{\pi}{4} + \cos\dfrac{\pi}{3}\sin\dfrac{\pi}{4}`

       .. rst-class:: solution

       :math:`= \left(\dfrac{\sqrt3}{2}\right)\left(\dfrac{\sqrt2}{2}\right) + \left(\dfrac{1}{2}\right)\left(\dfrac{\sqrt2}{2}\right)`

       .. rst-class:: solution

       :math:`= \dfrac{\sqrt6}{4} + \dfrac{\sqrt2}{4}`

       .. rst-class:: solution

       :math:`= \dfrac{\sqrt6+\sqrt2}{4}`
     - .. rst-class:: keepwithnext

       b\) :math:`\cos\left(\dfrac{\pi}{3}+\dfrac{\pi}{4}\right)`

       .. rst-class:: solution

       :math:`= \cos\dfrac{\pi}{3}\cos\dfrac{\pi}{4} - \sin\dfrac{\pi}{3}\sin\dfrac{\pi}{4}`

       .. rst-class:: solution

       :math:`= \left(\dfrac{1}{2}\right)\left(\dfrac{\sqrt2}{2}\right) - \left(\dfrac{\sqrt3}{2}\right)\left(\dfrac{\sqrt2}{2}\right)`

       .. rst-class:: solution

       :math:`= \dfrac{\sqrt2}{4} - \dfrac{\sqrt6}{4}`

       .. rst-class:: solution

       :math:`= \dfrac{\sqrt2-\sqrt6}{4}`
   * - .. rst-class:: keepwithnext

       c\) :math:`\cos\left(\dfrac{2\pi}{3}-\dfrac{\pi}{4}\right)`

       .. rst-class:: solution

       :math:`= \cos\dfrac{2\pi}{3}\cos\dfrac{\pi}{4} + \sin\dfrac{2\pi}{3}\sin\dfrac{\pi}{4}`

       .. rst-class:: solution

       :math:`= \left(-\dfrac{1}{2}\right)\left(\dfrac{\sqrt2}{2}\right) + \left(\dfrac{\sqrt3}{2}\right)\left(\dfrac{\sqrt2}{2}\right)`

       .. rst-class:: solution

       :math:`= -\dfrac{\sqrt2}{4} + \dfrac{\sqrt6}{4}`

       .. rst-class:: solution

       :math:`= \dfrac{\sqrt6-\sqrt2}{4}`
     - .. rst-class:: keepwithnext

       d\) :math:`\sin\left(\dfrac{2\pi}{3}-\dfrac{\pi}{4}\right)`

       .. rst-class:: solution

       :math:`= \sin\dfrac{2\pi}{3}\cos\dfrac{\pi}{4} - \cos\dfrac{2\pi}{3}\sin\dfrac{\pi}{4}`

       .. rst-class:: solution

       :math:`= \left(\dfrac{\sqrt3}{2}\right)\left(\dfrac{\sqrt2}{2}\right) - \left(-\dfrac{1}{2}\right)\left(\dfrac{\sqrt2}{2}\right)`

       .. rst-class:: solution

       :math:`= \dfrac{\sqrt6}{4} + \dfrac{\sqrt2}{4}`

       .. rst-class:: solution

       :math:`= \dfrac{\sqrt6+\sqrt2}{4}`
   * - .. rst-class:: keepwithnext

       e\) :math:`\tan\left(\dfrac{\pi}{4}+\pi\right)`

       .. rst-class:: solution

       :math:`= \dfrac{\tan\frac{\pi}{4} + \tan\pi}{1 - \tan\frac{\pi}{4}\tan\pi}`

       .. rst-class:: solution

       :math:`= \dfrac{1+0}{1-1(0)}`

       .. rst-class:: solution

       :math:`= 1`
     - .. rst-class:: keepwithnext

       f\) :math:`\tan\left(\dfrac{\pi}{3}-\dfrac{\pi}{6}\right)`

       .. rst-class:: solution

       :math:`= \dfrac{\tan\frac{\pi}{3} - \tan\frac{\pi}{6}}{1 + \tan\frac{\pi}{3}\tan\frac{\pi}{6}}`

       .. rst-class:: solution

       :math:`= \dfrac{\sqrt3 - \frac{1}{\sqrt3}}{1 + \sqrt3\left(\frac{1}{\sqrt3}\right)}`

       .. rst-class:: solution

       :math:`= \dfrac{\frac{3}{\sqrt3} - \frac{1}{\sqrt3}}{2}`

       .. rst-class:: solution

       :math:`= \dfrac{1}{\sqrt3} = \dfrac{\sqrt3}{3}`
