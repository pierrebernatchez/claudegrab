:math:`0 \leq x \leq 2\pi`, to the nearest hundredth of a radian.

.. rst-class:: keepwithnext

a\) :math:`\sin x - \dfrac{1}{4} = 0`

.. rst-class:: solution

:math:`\sin x = \dfrac{1}{4}`

.. rst-class:: solution

:math:`\beta = \pi - 2.42 = 0.72`

.. rst-class:: keepwithnext

a\) :math:`\sin^2 x - 0.64 = 0`

.. rst-class:: solution

:math:`\sin^2 x = 0.64`

.. rst-class:: solution

:math:`\sin x = \pm\sqrt{0.64} = \pm0.8`

.. image:: ../images/u5worksheet05-gpimage11.png
   :scale: 90
   :alt: unit circle with four solution angles 0.93, 2.21, 4.07, and 5.36 radians

.. rst-class:: solution

:math:`\sin x = 0.8 \rightarrow x_1 = \sin^{-1}(0.8) \approx 0.93`,
:math:`x_2 = \pi - 0.93 \approx 2.21`

.. rst-class:: solution

:math:`\sin x = -0.8 \rightarrow x_3 = \sin^{-1}(-0.8) = -0.93 + 2\pi \approx 5.36`,
:math:`x_4 = \pi + 0.93 \approx 4.07`

.. rst-class:: keepwithnext

b\) :math:`\cos^2 x - \dfrac{4}{9} = 0`

.. rst-class:: solution

:math:`\cos^2 x = \dfrac{4}{9}`

.. rst-class:: solution

:math:`\cos x = \pm\sqrt{\dfrac{4}{9}} = \pm\dfrac{2}{3}`

   :scale: 90
   :alt: unit circle with four solution angles 0.84, 2.30, 3.98, and 5.44 radians

:math:`\cos x = \dfrac{2}{3} \rightarrow x_1 = \cos^{-1}\left(\dfrac{2}{3}\right) \approx 0.84`,
:math:`x_2 = 2\pi - 0.84 \approx 5.44`

.. rst-class:: solution

:math:`\cos x = -\dfrac{2}{3} \rightarrow x_3 = \cos^{-1}\left(-\dfrac{2}{3}\right) \approx 2.30`,
:math:`x_4 = \pi + 0.84 \approx 3.98`

.. rst-class:: keepwithnext

.. rst-class:: solution

:math:`\tan^2 x = 1.44`

**4)** Determine exact solutions for each equation in the interval
:math:`0 \leq x \leq 2\pi`.

.. rst-class:: keepwithnext

a\) :math:`\sin^2 x - \dfrac{1}{4} = 0`

.. rst-class:: solution

:math:`\sin^2 x = \dfrac{1}{4} \rightarrow \sin x = \pm\dfrac{1}{2}`.
From special triangle: :math:`\sin\dfrac{\pi}{6} = \dfrac{1}{2}`. Place
:math:`\dfrac{\pi}{6}` in Q1 and Q2 for :math:`\sin x = \dfrac{1}{2}`,
and in Q3 and Q4 for :math:`\sin x = -\dfrac{1}{2}`.

.. image:: ../images/u5worksheet05-gpimage15.png
   :scale: 90
   :alt: unit circle with four exact solution angles pi/6, 5 pi/6, 7 pi/6, 11 pi/6

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{6}`, :math:`x_2 = \dfrac{5\pi}{6}`,
:math:`x_3 = \pi + \dfrac{\pi}{6} = \dfrac{7\pi}{6}`,
:math:`x_4 = 2\pi - \dfrac{\pi}{6} = \dfrac{11\pi}{6}`

.. rst-class:: keepwithnext

b\) :math:`\cos^2 x - \dfrac{3}{4} = 0`

.. rst-class:: solution

:math:`\cos^2 x = \dfrac{3}{4} \rightarrow \cos x = \pm\dfrac{\sqrt3}{2}`.
From special triangle: :math:`\cos\dfrac{\pi}{6} = \dfrac{\sqrt3}{2}`.
Place :math:`\dfrac{\pi}{6}` in Q1 and Q4 for :math:`\cos x = \dfrac{\sqrt3}{2}`,
and in Q2 and Q3 for :math:`\cos x = -\dfrac{\sqrt3}{2}`.

.. image:: ../images/u5worksheet05-gpimage16.png
   :scale: 90
   :alt: unit circle with four exact solution angles pi/6, 5 pi/6, 7 pi/6, 11 pi/6

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{6}`, :math:`x_2 = \pi - \dfrac{\pi}{6} = \dfrac{5\pi}{6}`,
:math:`x_3 = \pi + \dfrac{\pi}{6} = \dfrac{7\pi}{6}`,
:math:`x_4 = 2\pi - \dfrac{\pi}{6} = \dfrac{11\pi}{6}`

.. rst-class:: keepwithnext

c\) :math:`\tan^2 x - 3 = 0`

.. rst-class:: solution

:math:`\tan^2 x = 3 \rightarrow \tan x = \pm\sqrt3`. From special
triangle: :math:`\tan\dfrac{\pi}{3} = \sqrt3`. Place :math:`\dfrac{\pi}{3}`
in Q1 and Q3 for :math:`\tan x = \sqrt3`, and in Q2 and Q4 for
:math:`\tan x = -\sqrt3`.

.. image:: ../images/u5worksheet05-gpimage17.png
   :scale: 90
   :alt: unit circle with four exact solution angles pi/3, 2 pi/3, 4 pi/3, 5 pi/3

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{3}`, :math:`x_2 = \pi - \dfrac{\pi}{3} = \dfrac{2\pi}{3}`,
:math:`x_3 = \pi + \dfrac{\pi}{3} = \dfrac{4\pi}{3}`,
:math:`x_4 = 2\pi - \dfrac{\pi}{3} = \dfrac{5\pi}{3}`

.. rst-class:: keepwithnext

d\) :math:`3\csc^2 x - 4 = 0`

.. rst-class:: solution

:math:`\csc^2 x = \dfrac{4}{3} \rightarrow \sin^2 x = \dfrac{3}{4}
\rightarrow \sin x = \pm\dfrac{\sqrt3}{2}`. From special triangle:
:math:`\sin\dfrac{\pi}{3} = \dfrac{\sqrt3}{2}`. Place :math:`\dfrac{\pi}{3}`
in Q1 and Q2 for :math:`\sin x = \dfrac{\sqrt3}{2}`, and in Q3 and Q4 for
:math:`\sin x = -\dfrac{\sqrt3}{2}`.

.. image:: ../images/u5worksheet05-gpimage18.png
   :scale: 90
   :alt: unit circle with four exact solution angles pi/3, 2 pi/3, 4 pi/3, 5 pi/3

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{3}`, :math:`x_2 = \pi - \dfrac{\pi}{3} = \dfrac{2\pi}{3}`,
:math:`x_3 = \pi + \dfrac{\pi}{3} = \dfrac{4\pi}{3}`,
:math:`x_4 = 2\pi - \dfrac{\pi}{3} = \dfrac{5\pi}{3}`

**5)** Determine solutions for each equation in the interval
:math:`0 \leq x \leq 2\pi`.

.. rst-class:: keepwithnext

a\) :math:`3\sin x = \sin x + 1`

.. rst-class:: solution

:math:`2\sin x = 1 \rightarrow \sin x = \dfrac{1}{2}`. From special
triangle: :math:`\sin\dfrac{\pi}{6} = \dfrac{1}{2}`. Place in Q1 and Q2.

.. image:: ../images/u5worksheet05-gpimage19.png
   :scale: 90
   :alt: unit circle with two exact solution angles pi/6 and 5 pi/6

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{6}`, :math:`x_2 = \pi - \dfrac{\pi}{6} = \dfrac{5\pi}{6}`

.. rst-class:: keepwithnext

b\) :math:`5\cos x - \sqrt3 = 3\cos x`

.. rst-class:: solution

:math:`2\cos x = \sqrt3 \rightarrow \cos x = \dfrac{\sqrt3}{2}`. From
special triangle: :math:`\cos\dfrac{\pi}{6} = \dfrac{\sqrt3}{2}`. Place
in Q1 and Q4.

.. image:: ../images/u5worksheet05-gpimage20.png
   :scale: 90
   :alt: unit circle with two exact solution angles pi/6 and 11 pi/6

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{6}`, :math:`x_2 = 2\pi - \dfrac{\pi}{6} = \dfrac{11\pi}{6}`

.. rst-class:: keepwithnext

c\) :math:`7\sec x = 7`

.. rst-class:: solution

:math:`\sec x = 1 \rightarrow \cos x = 1`. Use the unit circle, where
each point is :math:`(\cos x, \sin x)`.

.. image:: ../images/u5worksheet05-gpimage21.png
   :scale: 90
   :alt: unit circle showing the point (1,0)

.. rst-class:: solution

:math:`x_1 = 0`, :math:`x_2 = 2\pi`

.. rst-class:: keepwithnext

d\) :math:`2\csc x + 17 = 15 + \csc x`

.. rst-class:: solution

:math:`\csc x = -2 \rightarrow \sin x = -\dfrac{1}{2}`. From special
triangle: :math:`\sin\dfrac{\pi}{6} = \dfrac{1}{2}`. Place
:math:`\dfrac{\pi}{6}` in Q3 and Q4.

.. image:: ../images/u5worksheet05-gpimage22.png
   :scale: 90
   :alt: unit circle with two exact solution angles 7 pi/6 and 11 pi/6

.. rst-class:: solution

:math:`x_1 = \pi + \dfrac{\pi}{6} = \dfrac{7\pi}{6}`,
:math:`x_2 = 2\pi - \dfrac{\pi}{6} = \dfrac{11\pi}{6}`
