In the previous lesson we have been working with identities. Identities
are equations that are true for ANY value of :math:`x`. In this lesson,
we will be working with equations that are not identities. We will have
to solve for the value(s) that make the equation true.

Remember that 2 solutions are possible for an angle between 0 and
:math:`2\pi` with a given ratio. Use the reference angle and CAST rule
to determine the angles.

When solving a trigonometric equation, consider all 3 tools that can be
useful:

1. Special Triangles
2. Graphs of Trig Functions
3. Calculator

.. rst-class:: keepwithnext

**Example 1:** Find all solutions for :math:`\cos\theta = -\dfrac{\sqrt3}{2}`
in the interval :math:`0 \leq \theta \leq 2\pi`

.. rst-class:: solution

:math:`-\dfrac{\sqrt3}{2} \rightarrow` Graph? No :math:`\rightarrow` Triangle? Yes

.. image:: ../images/u5lesson05-gpimage01.png
   :scale: 55
   :alt: 30-60-90 special triangle, sides 1, root 3, and 2

.. rst-class:: solution

:math:`\cos\dfrac{\pi}{6} = \dfrac{\sqrt3}{2}`, so the reference angle is
:math:`\dfrac{\pi}{6}`. Put the reference angle into quadrants 2 and 3
to make the ratio negative.

.. image:: ../images/u5lesson05-gpimage02.png
   :scale: 90
   :alt: unit circle with two solution angles 5 pi/6 and 7 pi/6

.. rst-class:: solution

:math:`\theta_1 = \pi - \dfrac{\pi}{6} = \dfrac{5\pi}{6}`

.. rst-class:: solution

:math:`\theta_2 = \pi + \dfrac{\pi}{6} = \dfrac{7\pi}{6}`

.. rst-class:: solution

:math:`\cos\dfrac{5\pi}{6} = \cos\dfrac{7\pi}{6} = -\dfrac{\sqrt3}{2}`

.. rst-class:: keepwithnext

**Example 2:** Find all solutions for :math:`\tan\theta = 5` in the
interval :math:`0 \leq \theta \leq 2\pi`

.. rst-class:: solution

:math:`\tan\theta = 5 \rightarrow` Graph? No :math:`\rightarrow` Triangle?
No :math:`\rightarrow` Calculator

**Note:** Tan is positive in Q1 and Q3.

.. image:: ../images/u5lesson05-gpimage03.png
   :scale: 90
   :alt: unit circle with two solution angles approximately 1.37 and 4.51 radians

.. rst-class:: solution

:math:`\tan\theta = 5`

.. rst-class:: solution

:math:`\theta_1 = \tan^{-1}(5)`

.. rst-class:: solution

:math:`\theta_1 \approx 1.37` radians

.. rst-class:: solution

:math:`\theta_2 = \pi + 1.37`

.. rst-class:: solution

:math:`\theta_2 \approx 4.51` radians

.. rst-class:: solution

:math:`\tan(1.37) = \tan(4.51) = 5`

.. rst-class:: keepwithnext

**Example 3:** Find all solutions for :math:`2\sin x + 1 = 0` in the
interval :math:`0 \leq x \leq 2\pi`

.. rst-class:: solution

:math:`2\sin x + 1 = 0`

.. rst-class:: solution

:math:`2\sin x = -1`

.. rst-class:: solution

:math:`\sin x = -\dfrac{1}{2}` :math:`\rightarrow` Graph? No :math:`\rightarrow`
Triangle? Yes

.. image:: ../images/u5lesson05-gpimage01.png
   :scale: 55
   :alt: 30-60-90 special triangle, sides 1, root 3, and 2

.. rst-class:: solution

:math:`\sin\dfrac{\pi}{6} = \dfrac{1}{2}`, use as reference angle in Q3
and Q4 to make the ratio negative.

.. image:: ../images/u5lesson05-gpimage04.png
   :scale: 90
   :alt: unit circle with two solution angles 7 pi/6 and 11 pi/6

.. rst-class:: solution

:math:`\theta_1 = \pi + \dfrac{\pi}{6} = \dfrac{7\pi}{6}`

.. rst-class:: solution

:math:`\theta_2 = 2\pi - \dfrac{\pi}{6} = \dfrac{11\pi}{6}`

.. rst-class:: solution

:math:`\sin\dfrac{7\pi}{6} = \sin\dfrac{11\pi}{6} = -\dfrac{1}{2}`

.. rst-class:: keepwithnext

**Example 4:** Solve :math:`3(\tan x + 1) = 2`, where
:math:`0 \leq x \leq 2\pi`

.. rst-class:: solution

:math:`3(\tan x + 1) = 2`

.. rst-class:: solution

:math:`\tan x + 1 = \dfrac{2}{3}`

.. rst-class:: solution

:math:`\tan x = \dfrac{2}{3} - 1`

.. rst-class:: solution

:math:`\tan x = -\dfrac{1}{3}` :math:`\rightarrow` Graph? No :math:`\rightarrow`
Triangle? No :math:`\rightarrow` Calculator

**Note:** Tan is negative in Q2 and Q4.

.. image:: ../images/u5lesson05-gpimage05.png
   :scale: 90
   :alt: unit circle with two solution angles approximately 2.82 and 5.96 radians

.. rst-class:: solution

:math:`\tan x = -\dfrac{1}{3}`

.. rst-class:: solution

:math:`x_1 = \tan^{-1}\left(-\dfrac{1}{3}\right)`

.. rst-class:: solution

:math:`x_1 = -0.32175`

.. rst-class:: solution

:math:`x_1 = 2\pi - 0.32175`

.. rst-class:: solution

:math:`x_1 \approx 5.96` radians

.. rst-class:: solution

:math:`x_2 = \pi - 0.32`

.. rst-class:: solution

:math:`x_2 \approx 2.82` radians

.. rst-class:: solution

:math:`\tan(5.96) = \tan(2.82) = -\dfrac{1}{3}`
