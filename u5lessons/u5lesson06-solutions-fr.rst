Partie 1 : Investigation
================================================================================

.. image:: ../images/u5lesson06-gpimage01.png
   :scale: 90
   :alt: y = sin x avec 2 solutions marquées, à côté de y = sin(2x) avec 4 solutions marquées

.. rst-class:: keepwithnext

a\) Quelle est la période des deux fonctions ci-dessus? Combien de
cycles entre 0 et :math:`2\pi` radians?

.. rst-class:: solution

Pour :math:`y = \sin x \rightarrow période = 2\pi`

.. rst-class:: solution

Pour :math:`y = \sin(2x) \rightarrow période = \dfrac{2\pi}{2} = \pi`

.. rst-class:: keepwithnext

b\) En regardant le graphique de :math:`y = \sin x`, combien de
solutions y a-t-il pour :math:`\sin x = \dfrac{1}{\sqrt2} \approx 0.71` ?

.. rst-class:: solution

2 solutions

.. rst-class:: solution

:math:`\sin\dfrac{\pi}{4} = \sin\dfrac{3\pi}{4} = \dfrac{1}{\sqrt2}`

.. rst-class:: keepwithnext

c\) En regardant le graphique de :math:`y = \sin(2x)`, combien de
solutions y a-t-il pour :math:`\sin(2x) = \dfrac{1}{\sqrt2} \approx 0.71` ?

.. rst-class:: solution

4 solutions

.. rst-class:: solution

:math:`\sin\left[2\left(\dfrac{\pi}{8}\right)\right] = \sin\left[2\left(\dfrac{3\pi}{8}\right)\right] = \sin\left[2\left(\dfrac{9\pi}{8}\right)\right] = \sin\left[2\left(\dfrac{11\pi}{8}\right)\right] = \dfrac{1}{\sqrt2}`

.. rst-class:: keepwithnext

d\) Lorsque la période d'une fonction est réduite de moitié, quel est
l'effet sur le nombre de solutions entre 0 et :math:`2\pi` radians?

.. rst-class:: solution

Double le nombre de solutions

Partie 2 : Résoudre des équations trigonométriques linéaires impliquant des angles doubles
================================================================================================

.. rst-class:: keepwithnext

**Exemple 1 :** :math:`\sin(2\theta) = \dfrac{\sqrt3}{2}` où
:math:`0 \leq \theta \leq 2\pi`

.. rst-class:: solution

Soit :math:`2\theta = x`. :math:`\sin x = \dfrac{\sqrt3}{2} \rightarrow`
Graphique? Non :math:`\rightarrow` Triangle? Oui

.. image:: ../images/u5lesson06-gpimage02.png
   :scale: 55
   :alt: triangle spécial 30-60-90, côtés 1, racine de 3, et 2

.. rst-class:: solution

:math:`\sin\dfrac{\pi}{3} = \dfrac{\sqrt3}{2}`. Placer l'angle de
référence aux quadrants 1 et 2, où le sinus est positif.

.. image:: ../images/u5lesson06-gpimage03.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions pi/3 et 2 pi/3 pour x

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{3}`

.. rst-class:: solution

:math:`x_2 = \pi - \dfrac{\pi}{3} = \dfrac{2\pi}{3}`

.. rst-class:: solution

:math:`2\theta = x \rightarrow 2\theta = \dfrac{\pi}{3} \rightarrow \theta_1 = \dfrac{\pi}{6}`,
et :math:`2\theta = \dfrac{2\pi}{3} \rightarrow \theta_2 = \dfrac{\pi}{3}`

:math:`y = \sin(2\theta)` a une période de :math:`\pi`; ajouter :math:`\pi`
à :math:`\theta_1` et :math:`\theta_2` pour trouver d'autres angles
:math:`0 \leq \theta \leq 2\pi` ayant des rapports équivalents.

.. rst-class:: solution

:math:`\theta_3 = \theta_1 + \pi = \dfrac{\pi}{6} + \pi = \dfrac{7\pi}{6}`

.. rst-class:: solution

:math:`\theta_4 = \theta_2 + \pi = \dfrac{\pi}{3} + \pi = \dfrac{4\pi}{3}`

.. rst-class:: solution

:math:`\sin\left[2\left(\dfrac{\pi}{6}\right)\right] = \sin\left[2\left(\dfrac{\pi}{3}\right)\right] = \sin\left[2\left(\dfrac{7\pi}{6}\right)\right] = \sin\left[2\left(\dfrac{4\pi}{3}\right)\right] = \dfrac{\sqrt3}{2}`

.. rst-class:: keepwithnext

**Exemple 2 :** :math:`\cos(2\theta) = -\dfrac{1}{2}` où
:math:`0 \leq \theta \leq 2\pi`

.. rst-class:: solution

Soit :math:`2\theta = x`. :math:`\cos x = -\dfrac{1}{2} \rightarrow`
Graphique? Non :math:`\rightarrow` Triangle? Oui

.. image:: ../images/u5lesson06-gpimage04.png
   :scale: 55
   :alt: triangle spécial 30-60-90, côtés 1, racine de 3, et 2

.. rst-class:: solution

:math:`\cos\dfrac{\pi}{3} = \dfrac{1}{2}`. Placer l'angle de référence
aux quadrants 2 et 3, où le cosinus est négatif.

.. image:: ../images/u5lesson06-gpimage05.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions 2 pi/3 et 4 pi/3 pour x

.. rst-class:: solution

:math:`x_1 = \pi - \dfrac{\pi}{3} = \dfrac{2\pi}{3}`

.. rst-class:: solution

:math:`x_2 = \pi + \dfrac{\pi}{3} = \dfrac{4\pi}{3}`

.. rst-class:: solution

:math:`2\theta = x \rightarrow 2\theta = \dfrac{2\pi}{3} \rightarrow \theta_1 = \dfrac{\pi}{3}`,
et :math:`2\theta = \dfrac{4\pi}{3} \rightarrow \theta_2 = \dfrac{2\pi}{3}`

Rappelons que :math:`\cos(2\theta)` a une période de :math:`\pi`;
ajouter :math:`\pi` à :math:`\theta_1` et :math:`\theta_2` pour trouver
d'autres solutions :math:`0 \leq \theta \leq 2\pi`.

.. rst-class:: solution

:math:`\theta_3 = \theta_1 + \pi = \dfrac{\pi}{3} + \pi = \dfrac{4\pi}{3}`

.. rst-class:: solution

:math:`\theta_4 = \theta_2 + \pi = \dfrac{2\pi}{3} + \pi = \dfrac{5\pi}{3}`

.. rst-class:: solution

:math:`\cos\left[2\left(\dfrac{\pi}{3}\right)\right] = \cos\left[2\left(\dfrac{2\pi}{3}\right)\right] = \cos\left[2\left(\dfrac{4\pi}{3}\right)\right] = \cos\left[2\left(\dfrac{5\pi}{3}\right)\right] = -\dfrac{1}{2}`

.. rst-class:: keepwithnext

**Exemple 3 :** :math:`\tan(2\theta) = 1` où :math:`0 \leq \theta \leq 2\pi`

.. rst-class:: solution

Soit :math:`2\theta = x`. :math:`\tan x = 1 \rightarrow` Graphique? Non
:math:`\rightarrow` Triangle? Oui

.. image:: ../images/u5lesson06-gpimage06.png
   :scale: 55
   :alt: triangle spécial 45-45-90, côtés 1 et 1, hypoténuse racine de 2

.. rst-class:: solution

:math:`\tan\dfrac{\pi}{4} = 1`. Placer l'angle de référence aux
quadrants 1 et 3, où la tangente est positive.

.. image:: ../images/u5lesson06-gpimage07.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions pi/4 et 5 pi/4 pour x

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{4}`

.. rst-class:: solution

:math:`x_2 = \pi + \dfrac{\pi}{4} = \dfrac{5\pi}{4}`

.. rst-class:: solution

:math:`2\theta = x \rightarrow 2\theta = \dfrac{\pi}{4} \rightarrow \theta_1 = \dfrac{\pi}{8}`,
et :math:`2\theta = \dfrac{5\pi}{4} \rightarrow \theta_2 = \dfrac{5\pi}{8}`

Rappelons que :math:`\tan(2\theta)` a une période de :math:`\dfrac{\pi}{2}`;
ajouter :math:`\dfrac{\pi}{2}` à :math:`\theta_1` et :math:`\theta_2`
pour trouver d'autres solutions :math:`0 \leq \theta \leq 2\pi`.

.. rst-class:: solution

:math:`\theta_3 = \theta_2 + \dfrac{\pi}{2} = \dfrac{5\pi}{8} + \dfrac{4\pi}{8} = \dfrac{9\pi}{8}`

.. rst-class:: solution

:math:`\theta_4 = \theta_3 + \dfrac{\pi}{2} = \dfrac{9\pi}{8} + \dfrac{4\pi}{8} = \dfrac{13\pi}{8}`

.. rst-class:: solution

:math:`\tan\left[2\left(\dfrac{\pi}{8}\right)\right] = \tan\left[2\left(\dfrac{5\pi}{8}\right)\right] = \tan\left[2\left(\dfrac{9\pi}{8}\right)\right] = \tan\left[2\left(\dfrac{13\pi}{8}\right)\right] = 1`
