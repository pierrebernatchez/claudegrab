**1)** Résoudre :math:`\sin^2 x - 2\sin x - 3 = 0` dans l'intervalle
:math:`0 \leq x \leq 2\pi`

.. rst-class:: solution

:math:`(\sin x - 3)(\sin x + 1) = 0`

.. rst-class:: solution

:math:`\sin x - 3 = 0 \rightarrow \sin x = 3 \rightarrow` Aucune solution

.. rst-class:: solution

:math:`\sin x + 1 = 0 \rightarrow \sin x = -1`

.. image:: ../images/u5worksheet07-gpimage01.png
   :scale: 90
   :alt: cercle trigonométrique avec le point (0,-1) marqué, solution 3 pi/2

.. rst-class:: solution

:math:`x = \dfrac{3\pi}{2}`

.. rst-class:: keepwithnext

**2)** Résoudre :math:`\csc^2 x - \csc x - 2 = 0` dans l'intervalle
:math:`0 \leq x \leq 2\pi`

.. rst-class:: solution

:math:`(\csc x - 2)(\csc x + 1) = 0`

.. rst-class:: solution

:math:`\csc x - 2 = 0 \rightarrow \csc x = 2 \rightarrow \sin x = \dfrac{1}{2}`

.. image:: ../images/u5worksheet07-gpimage02.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions pi/6 et 5 pi/6

.. rst-class:: solution

:math:`x_1 = \dfrac{\pi}{6}`, :math:`x_2 = \pi - \dfrac{\pi}{6} = \dfrac{5\pi}{6}`

.. rst-class:: solution

:math:`\csc x + 1 = 0 \rightarrow \csc x = -1 \rightarrow \sin x = -1`

.. image:: ../images/u5worksheet07-gpimage01.png
   :scale: 90
   :alt: cercle trigonométrique avec le point (0,-1) marqué, solution 3 pi/2

.. rst-class:: solution

:math:`x_3 = \dfrac{3\pi}{2}`

.. rst-class:: solution

Réponse : :math:`x = \dfrac{\pi}{6}, \dfrac{5\pi}{6}, \dfrac{3\pi}{2}`

.. rst-class:: keepwithnext

**3)** Résoudre :math:`2\sec^2 x - \sec x - 1 = 0` dans l'intervalle
:math:`0 \leq x \leq 2\pi`

.. rst-class:: solution

:math:`2\sec^2 x - 2\sec x + \sec x - 1 = 0`

.. rst-class:: solution

:math:`2\sec x(\sec x - 1) + 1(\sec x - 1) = 0`

.. rst-class:: solution

:math:`(\sec x - 1)(2\sec x + 1) = 0`

.. rst-class:: solution

:math:`\sec x - 1 = 0 \rightarrow \sec x = 1 \rightarrow \cos x = 1`

.. image:: ../images/u5worksheet07-gpimage03.png
   :scale: 90
   :alt: cercle trigonométrique avec le point (1,0) marqué, solutions 0 et 2 pi

.. rst-class:: solution

:math:`x_1 = 0`, :math:`x_2 = 2\pi`

.. rst-class:: solution

:math:`2\sec x + 1 = 0 \rightarrow \sec x = -\dfrac{1}{2} \rightarrow \cos x = -2 \rightarrow`
Aucune solution

.. rst-class:: solution

Réponse : :math:`x = 0, 2\pi`

.. rst-class:: keepwithnext

**4)** Résoudre :math:`\tan^2 x - \tan x - 6 = 0` dans l'intervalle

près.

.. rst-class:: solution

:math:`(\tan x - 3)(\tan x + 2) = 0`

**8)** Résoudre :math:`\cot x \csc^2 x = 2\cot x` dans l'intervalle
:math:`0 \leq x \leq 2\pi`

.. rst-class:: solution

:math:`0 = 2\cot x - \cot x \csc^2 x`

.. rst-class:: solution

:math:`0 = \cot x (2 - \csc^2 x)`

.. rst-class:: solution

:math:`\cot x = 0 \rightarrow \tan x` non défini

.. image:: ../images/u5worksheet07-gpimage09.png
   :scale: 90
   :alt: cercle trigonométrique avec les points (0,1) et (0,-1) marqués, solutions pi/2 et 3 pi/2

**9)** Résoudre pour :math:`\theta` au centième près, où
:math:`0 \leq \theta \leq 2\pi`

.. rst-class:: keepwithnext

a\) :math:`3\tan^2\theta - 2\tan\theta = 1`

.. rst-class:: solution

:math:`3\tan^2\theta - 2\tan\theta - 1 = 0`

.. rst-class:: solution

:math:`3\tan^2\theta - 3\tan\theta + 1\tan\theta - 1 = 0`

.. rst-class:: solution

:math:`3\tan\theta(\tan\theta - 1) + 1(\tan\theta - 1) = 0`

.. rst-class:: solution

:math:`(\tan\theta - 1)(3\tan\theta + 1) = 0`

.. rst-class:: solution

:math:`\tan\theta = 1`

.. image:: ../images/u5worksheet07-gpimage10.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions exacts pi/4 et 5 pi/4

.. rst-class:: solution

:math:`\theta_1 = \dfrac{\pi}{4}`, :math:`\theta_2 = \pi + \dfrac{\pi}{4} = \dfrac{5\pi}{4}`

.. rst-class:: solution

:math:`\tan\theta = -\dfrac{1}{3} \rightarrow \theta_3 = \tan^{-1}\left(-\dfrac{1}{3}\right) \approx -0.32 + 2\pi \approx 5.96`

.. image:: ../images/u5worksheet07-gpimage11.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions environ 2,82 et 5,96 radians

.. rst-class:: solution

:math:`\theta_3 \approx 5.96`, :math:`\theta_4 = \pi - 0.32 \approx 2.82`

.. rst-class:: solution

Réponse : :math:`\theta = \dfrac{\pi}{4}, \dfrac{5\pi}{4}, 2.82, 5.96`

.. rst-class:: keepwithnext

b\) :math:`12\sin^2\theta + \sin\theta - 6 = 0`

.. rst-class:: solution

:math:`12\sin^2\theta + 9\sin\theta - 8\sin\theta - 6 = 0`

.. rst-class:: solution

:math:`3\sin\theta(4\sin\theta + 3) - 2(4\sin\theta + 3) = 0`

.. rst-class:: solution

:math:`(4\sin\theta + 3)(3\sin\theta - 2) = 0`

.. rst-class:: solution

:math:`\sin\theta = -\dfrac{3}{4} \rightarrow \theta_1 = \sin^{-1}\left(-\dfrac{3}{4}\right) \approx -0.85 + 2\pi \approx 5.44`

.. image:: ../images/u5worksheet07-gpimage12.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions environ 3,99 et 5,44 radians

.. rst-class:: solution

:math:`\theta_1 \approx 5.44`, :math:`\theta_2 = \pi + 0.85 \approx 3.99`

.. rst-class:: solution

:math:`\sin\theta = \dfrac{2}{3} \rightarrow \theta_3 = \sin^{-1}\left(\dfrac{2}{3}\right) \approx 0.73`

.. image:: ../images/u5worksheet07-gpimage13.png
   :scale: 90
   :alt: cercle trigonométrique avec deux angles solutions environ 0,73 et 2,41 radians
