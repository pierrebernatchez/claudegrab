f\) :math:`[\sin(2x)](\tan x + \cot x) = 2`

.. rst-class:: keepwithnext

g\) :math:`2\sin x \cos y = \sin(x+y) + \sin(x-y)`

.. rst-class:: keepwithnext

h\) :math:`(\cos x - \sin x)^2 = 1 - \sin(2x)`

.. rst-class:: keepwithnext

i\) :math:`\dfrac{1-\sin^2 x}{\cot^2 x} = 1 - \cos^2 x`

.. rst-class:: keepwithnext
