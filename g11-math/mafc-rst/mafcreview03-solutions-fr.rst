Section 2 : Réciproque d'une fonction
================================================================================

.. rst-class:: keepwithnext

**9)** Pour chaque fonction ci-dessous, détermine l'équation de la
réciproque, :math:`f^{-1}(x)`.

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       a\) :math:`f(x) = 3x+9`

       .. rst-class:: solution

       :math:`x = 3y+9`

       .. rst-class:: solution

       :math:`f^{-1}(x) = \dfrac{x-9}{3}`
     - .. rst-class:: keepwithnext

       b\) :math:`f(x) = \dfrac{1}{3}x^2-4`

       .. rst-class:: solution

       :math:`x = \dfrac{1}{3}y^2-4`

       .. rst-class:: solution

       :math:`f^{-1}(x) = \pm\sqrt{3(x+4)}`

.. rst-class:: keepwithnext

**10)** Détermine l'équation de la réciproque de :math:`f(x) =
2x^2+16x+30` en complétant d'abord le carré.

.. rst-class:: solution

:math:`f(x) = 2(x^2+8x)+30`

.. rst-class:: solution

:math:`f(x) = 2(x^2+8x+16-16)+30 = 2(x^2+8x+16)-32+30`

.. rst-class:: solution

:math:`f(x) = 2(x+4)^2-2`

.. rst-class:: solution

:math:`x = 2(y+4)^2-2`

.. rst-class:: solution

:math:`\dfrac{x+2}{2} = (y+4)^2 \implies \pm\sqrt{\dfrac{x+2}{2}} = y+4`

.. rst-class:: solution

:math:`f^{-1}(x) = -4\pm\sqrt{\dfrac{x+2}{2}}`

.. rst-class:: keepwithnext

**11)** Calcule la réciproque de :math:`f(x) = 2(x-1)^2+2`.

.. rst-class:: solution

:math:`x = 2(y-1)^2+2`

.. rst-class:: solution

:math:`\dfrac{x-2}{2} = (y-1)^2 \implies \pm\sqrt{\dfrac{x-2}{2}} = y-1`

.. rst-class:: solution

:math:`f^{-1}(x) = 1\pm\sqrt{\dfrac{x-2}{2}}`

.. rst-class:: keepwithnext
