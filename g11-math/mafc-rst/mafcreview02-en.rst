Answers
================================================================================

1\) a\) :math:`\dfrac{1}{x+3};\ x \neq -3,7` b\) :math:`\dfrac{x+5}{x+3};\
x \neq -3,\dfrac{3}{2}`

2\) a\) :math:`48x^4;\ x \neq 0` b\) :math:`\dfrac{1}{3x};\ x \neq 0, y
\neq 0`

3\) a\) :math:`4;\ x \neq 6` b\) :math:`\dfrac{x-8}{x-6};\ x \neq -2,6`
c\) :math:`\dfrac{4x}{x+6};\ x \neq -6,0,5` d\) :math:`\dfrac{1}{x-4};\
x \neq -2,-1,1,4`

4\) a\) :math:`2;\ x \neq -1,0` b\) :math:`\dfrac{x-5}{x+10};\ x \neq
-12,-10,5` c\) :math:`\dfrac{1}{6};\ x \neq 0,9` d\) :math:`\dfrac{3}
{x+1};\ x \neq -2,-1,2,5`

5\) a\) :math:`-\dfrac{1}{28x};\ x \neq 0` b\) :math:`\dfrac{8+9a}{2ab};\
a \neq 0, b \neq 0` c\) :math:`\dfrac{-3(x-7)}{(x-3)(x+3)};\ x \neq -3,3`
d\) :math:`\dfrac{9(2x+1)}{(x+4)(x-5)};\ x \neq -4,5`

6\) a\) :math:`\dfrac{2x^2-3x+3}{(x-6)(x-3)};\ x \neq 3,6` b\)
:math:`\dfrac{2x^2+4x-3}{(x-2)(x+2)};\ x \neq -2,2` c\) :math:`\dfrac{1}
{x+2};\ x \neq -3,-2,1` d\) :math:`\dfrac{4x^2-37x+21}{(x+7)(x-10)};\ x
\neq -7,2,5,10`

7\) a\) :math:`\dfrac{2}{x-5};\ x \neq 5` b\) :math:`\dfrac{-x-1}
{4x-3};\ x \neq \dfrac{3}{4}` OR :math:`\dfrac{x+1}{3-4x}`
