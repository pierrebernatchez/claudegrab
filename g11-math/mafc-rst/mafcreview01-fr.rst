Corrigé
================================================================================

1\) a\) B et C sont des fonctions, A n'est pas une fonction b\) test de
la droite verticale : chaque valeur de :math:`x` n'a qu'une seule valeur
de :math:`y` c\) :math:`f(3)=1`

2\) a\) D : :math:`\{x=-6,-5,-4,-3\}`; I : :math:`\{y=2\}`; est une
fonction b\) D : :math:`\{x=5\}`; I : :math:`\{y=-4,-2,0,2,4\}`; n'est
pas une fonction

3\) a\) D : :math:`\{x \in \mathbb{R}\}`; I : :math:`\{y \in
\mathbb{R}\}`; est une fonction b\) D : :math:`\{x \in \mathbb{R}\}`;
I : :math:`\{y \in \mathbb{R} \mid y \geq -1\}`, est une fonction

c\) D : :math:`\{x \in \mathbb{R} \mid x \leq 3\}`; I : :math:`\{y \in
\mathbb{R}\}`; n'est pas une fonction d\) D : :math:`\{x \in \mathbb{R}
\mid x \neq -4\}`; I : :math:`\{y \in \mathbb{R} \mid y \neq 0\}`; est
une fonction

e\) D : :math:`\{x \in \mathbb{R}\}`; I : :math:`\{y \in \mathbb{R} \mid
-3 \leq y \leq 7\}`; est une fonction

4\) a\) -44 b\) 6 c\) :math:`\dfrac{39}{8}`

5\) a\) :math:`\dfrac{16}{5},\dfrac{7}{5},\dfrac{17}{10}` b\)
