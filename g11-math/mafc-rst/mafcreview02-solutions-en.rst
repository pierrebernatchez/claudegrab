Section 1: Simplifying Rational Expressions
================================================================================

.. rst-class:: keepwithnext

**1)** Simplify each expression. State all restrictions on :math:`x`.

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       a\) :math:`\dfrac{x-7}{x^2-4x-21}`

       .. rst-class:: solution

       :math:`= \dfrac{x-7}{(x-7)(x+3)}`

       .. rst-class:: solution

       :math:`= \dfrac{1}{x+3};\ x \neq 7,-3`
     - .. rst-class:: keepwithnext

       b\) :math:`\dfrac{2x^2+7x-15}{2x^2+3x-9}`

       .. rst-class:: solution

       :math:`= \dfrac{(2x-3)(x+5)}{(2x-3)(x+3)}`

       .. rst-class:: solution

       :math:`= \dfrac{x+5}{x+3};\ x \neq -3,\dfrac{3}{2}`

   * - .. rst-class:: keepwithnext

       a\) :math:`\dfrac{36x^4}{5x^2} \times \dfrac{80x^3}{12x}`

       .. rst-class:: solution

       :math:`= \dfrac{48x^7}{x^3}`

       .. rst-class:: solution

       :math:`= 48x^4;\ x \neq 0`
     - .. rst-class:: keepwithnext

       b\) :math:`\dfrac{3x}{32y} \div \dfrac{27x^2}{96y}`

       .. rst-class:: solution

       :math:`= \dfrac{3x}{32y} \times \dfrac{96y}{27x^2} =
       \dfrac{3xy}{9x^2y}`

       .. rst-class:: solution

       :math:`= \dfrac{1}{3x};\ x \neq 0, y \neq 0`

**3)** Simplify and state any restrictions

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       a\) :math:`\dfrac{12}{x-6} \times \dfrac{x-6}{3}`

       .. rst-class:: solution

       :math:`= 4;\ x \neq 6`
     - .. rst-class:: keepwithnext

       b\) :math:`\dfrac{x-8}{x+2} \times \dfrac{x+2}{x-6}`

       .. rst-class:: solution

       :math:`= \dfrac{x-8}{x-6};\ x \neq -2,6`

   * - .. rst-class:: keepwithnext

       c\) :math:`\dfrac{4x-20}{x^2+6x} \times \dfrac{3x^2}{3x-15}`

       .. rst-class:: solution

       :math:`= \dfrac{4(x-5)(3x^2)}{x(x+6)(3)(x-5)}`

       .. rst-class:: solution

       :math:`= \dfrac{4x^2}{x(x+6)} = \dfrac{4x}{x+6};\ x \neq -6,0,5`
     - .. rst-class:: keepwithnext

       d\) :math:`\dfrac{x^2+3x+2}{x^2-1} \times \dfrac{x-1}{x^2-2x-8}`

       .. rst-class:: solution

       :math:`= \dfrac{(x+2)(x+1)}{(x-1)(x+1)} \times
       \dfrac{x-1}{(x-4)(x+2)}`

       .. rst-class:: solution

       :math:`= \dfrac{1}{x-4};\ x \neq -2,-1,1,4`

**4)** Simplify and state any restrictions

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       a\) :math:`\dfrac{x+1}{x} \div \dfrac{x+1}{2x}`

       .. rst-class:: solution

       :math:`= \dfrac{x+1}{x} \times \dfrac{2x}{x+1}`

       .. rst-class:: solution

       :math:`= 2;\ x \neq -1,0`
     - .. rst-class:: keepwithnext

       b\) :math:`\dfrac{x+12}{x+10} \div \dfrac{x+12}{x-5}`

       .. rst-class:: solution

       :math:`= \dfrac{x+12}{x+10} \times \dfrac{x-5}{x+12}`

       .. rst-class:: solution

       :math:`= \dfrac{x-5}{x+10};\ x \neq -12,-10,5`

   * - .. rst-class:: keepwithnext

       c\) :math:`\dfrac{6x}{8x-72} \div \dfrac{9x}{2x-18}`

       .. rst-class:: solution

       :math:`= \dfrac{6x}{8(x-9)} \times \dfrac{2(x-9)}{9x}`

       .. rst-class:: solution

       :math:`= \dfrac{12x}{72x} = \dfrac{1}{6};\ x \neq 0,9`
     - .. rst-class:: keepwithnext

       d\) :math:`\dfrac{x^2-7x+10}{x^2-4} \div \dfrac{x^2-4x-5}{3x+6}`

       .. rst-class:: solution

       :math:`= \dfrac{(x-2)(x-5)}{(x-2)(x+2)} \times
       \dfrac{3(x+2)}{(x-5)(x+1)}`

       .. rst-class:: solution

       :math:`= \dfrac{3}{x+1};\ x \neq -2,-1,2,5`

   * - .. rst-class:: keepwithnext

       a\) :math:`\dfrac{5}{7x}-\dfrac{3}{4x}`

       .. rst-class:: solution

       :math:`= \dfrac{20}{28x}-\dfrac{21}{28x}`

       .. rst-class:: solution

       :math:`= -\dfrac{1}{28x};\ x \neq 0`
     - .. rst-class:: keepwithnext

       b\) :math:`\dfrac{4}{ab}+\dfrac{9}{2b}`

       .. rst-class:: solution

       :math:`= \dfrac{8}{2ab}+\dfrac{9a}{2ab}`

       .. rst-class:: solution

       :math:`= \dfrac{8+9a}{2ab};\ a \neq 0, b \neq 0`

   * - .. rst-class:: keepwithnext

       c\) :math:`\dfrac{2}{x-3}-\dfrac{5}{x+3}`

       .. rst-class:: solution

       :math:`= \dfrac{2(x+3)-5(x-3)}{(x-3)(x+3)}`

       .. rst-class:: solution

       :math:`= \dfrac{2x+6-5x+15}{(x-3)(x+3)}`

       .. rst-class:: solution

       :math:`= \dfrac{-3(x-7)}{(x-3)(x+3)};\ x \neq -3,3`
     - .. rst-class:: keepwithnext

       d\) :math:`\dfrac{7}{x+4}+\dfrac{11}{x-5}`

       .. rst-class:: solution

       :math:`= \dfrac{7(x-5)+11(x+4)}{(x+4)(x-5)}`

       .. rst-class:: solution

       :math:`= \dfrac{7x-35+11x+44}{(x+4)(x-5)}`

       .. rst-class:: solution

       :math:`= \dfrac{9(2x+1)}{(x+4)(x-5)};\ x \neq -4,5`

**6)** Simplify and state any restrictions

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       a\) :math:`\dfrac{4x}{x^2-9x+18}+\dfrac{2x-1}{x-6}`

       .. rst-class:: solution

       :math:`= \dfrac{4x}{(x-3)(x-6)}+\dfrac{(2x-1)(x-3)}{(x-6)(x-3)}`

       .. rst-class:: solution

       :math:`= \dfrac{4x+2x^2-7x+3}{(x-3)(x-6)}`

       .. rst-class:: solution

       :math:`= \dfrac{2x^2-3x+3}{(x-3)(x-6)};\ x \neq 3,6`
     - .. rst-class:: keepwithnext

       b\) :math:`\dfrac{2x}{x-2}-\dfrac{3}{x^2-4}`

       .. rst-class:: solution

       :math:`= \dfrac{2x(x+2)}{(x-2)(x+2)}-\dfrac{3}{(x-2)(x+2)}`

       .. rst-class:: solution

       :math:`= \dfrac{2x^2+4x-3}{(x-2)(x+2)};\ x \neq -2,2`

   * - .. rst-class:: keepwithnext

       c\) :math:`\dfrac{3x+9}{x^2+5x+6}-\dfrac{2x-2}{x^2+x-2}`

       .. rst-class:: solution

       :math:`= \dfrac{3(x+3)}{(x+2)(x+3)}-\dfrac{2(x-1)}{(x+2)(x-1)}`

       .. rst-class:: solution

       :math:`= \dfrac{3}{x+2}-\dfrac{2}{x+2}`

       .. rst-class:: solution

       :math:`= \dfrac{1}{x+2};\ x \neq -3,-2,1`
     - .. rst-class:: keepwithnext

       d\) :math:`\dfrac{4x^2-20x}{x^2+2x-35}+\dfrac{3x-6}{x^2-12x+20}`

       .. rst-class:: solution

       :math:`= \dfrac{4x(x-5)}{(x+7)(x-5)}+\dfrac{3(x-2)}{(x-10)(x-2)}`

       .. rst-class:: solution

       :math:`= \dfrac{4x}{x+7}+\dfrac{3}{x-10}`

       .. rst-class:: solution

       :math:`= \dfrac{4x(x-10)+3(x+7)}{(x+7)(x-10)}`

       .. rst-class:: solution

       :math:`= \dfrac{4x^2-37x+21}{(x+7)(x-10)};\ x \neq -7,2,5,10`
