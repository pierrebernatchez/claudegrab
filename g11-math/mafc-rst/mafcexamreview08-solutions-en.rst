**7)** The student council is organizing a trip to a rock concert. All
proceeds from ticket sales will be donated to charity. Tickets to the
concert cost $31.25 per person if a minimum of 104 people attend. For
every 8 extra people that attend, the price will decrease by $1.25 per
person.

.. rst-class:: keepwithnext

a\) How many tickets need to be sold to maximize the donation to charity?

.. rst-class:: solution

Revenue :math:`= (\text{cost})(\#\text{sold})`:
:math:`R = (31.25-1.25x)(104+8x)`

.. rst-class:: solution

Find the :math:`x`-vertex by averaging the :math:`x`-intercepts:
:math:`0 = (31.25-1.25x)(104+8x) \implies x_1=25,\ x_2=-13`

.. rst-class:: solution

:math:`x\text{-vertex} = \dfrac{25+(-13)}{2} = 6`

.. rst-class:: solution

Number sold :math:`= 104+8(6) = 152` tickets

.. rst-class:: keepwithnext

b\) What is the price of each ticket that maximizes the donation?

.. rst-class:: solution

:math:`\text{cost} = 31.25-1.25(6) = 23.75`; $23.75 per ticket

.. rst-class:: keepwithnext

c\) What is the maximum donation?

.. rst-class:: solution

:math:`R = (23.75)(152) = \$3610`

**12)** Given the equation of a parabola and the slope of a line that is
tangent to the parabola, determine the y-intercept of the tangent line.

:math:`f(x) = -3x^2+x-4`, tangent line has slope 13: :math:`y = 13x+k`

.. rst-class:: solution

:math:`13x+k = -3x^2+x-4 \implies 0 = -3x^2-12x-4-k`

.. rst-class:: solution

Tangent has 1 point of intersection, so :math:`b^2-4ac=0`:

.. rst-class:: solution

:math:`0 = (-12)^2-4(-3)(-4-k) = 144+12(-4-k) = 144-48-12k = 96-12k`

.. rst-class:: solution

:math:`12k = 96 \implies k = 8`

.. rst-class:: solution

The equation of the tangent line is :math:`y=13x+8`. The y-intercept is at
8.

   * - .. rst-class:: keepwithnext

       .. rst-class:: solution

       :math:`= \dfrac{48x^7}{x^3}`

       .. rst-class:: solution

       :math:`= 48x^4;\ x \neq 0`
     - .. rst-class:: keepwithnext

       d\) :math:`\dfrac{3x}{32y} \div \dfrac{27x^2}{96y}`

       .. rst-class:: solution

       :math:`= \dfrac{3x}{32y} \times \dfrac{96y}{27x^2} =
       \dfrac{3xy}{9x^2y}`

       .. rst-class:: solution

       :math:`= \dfrac{1}{3x};\ x \neq 0, y \neq 0`

   * - .. rst-class:: keepwithnext

       e\) :math:`\dfrac{x-8}{x+2} \times \dfrac{x+2}{x-6}`

       .. rst-class:: solution

       :math:`= \dfrac{x-8}{x-6};\ x \neq -2,6`
     - .. rst-class:: keepwithnext

       f\) :math:`\dfrac{4x-20}{x^2+6x} \times \dfrac{3x^2}{3x-15}`

       .. rst-class:: solution

       :math:`= \dfrac{4(x-5)(3x^2)}{x(x+6)(3)(x-5)}`

       .. rst-class:: solution

       :math:`= \dfrac{4x^2}{x(x+6)} = \dfrac{4x}{x+6};\ x \neq -6,0,5`

   * - .. rst-class:: keepwithnext

       g\) :math:`\dfrac{x+1}{x} \div \dfrac{x+1}{2x}`

       .. rst-class:: solution

       :math:`= \dfrac{x+1}{x} \times \dfrac{2x}{x+1}`

       .. rst-class:: solution

       :math:`= 2;\ x \neq -1,0`
     - .. rst-class:: keepwithnext

       h\) :math:`\dfrac{x^2-7x+10}{x^2-4} \div \dfrac{x^2-4x-5}{3x+6}`

       .. rst-class:: solution

       :math:`= \dfrac{(x-2)(x-5)}{(x-2)(x+2)} \times
       \dfrac{3(x+2)}{(x-5)(x+1)}`

       .. rst-class:: solution

       :math:`= \dfrac{3}{x+1};\ x \neq -2,-1,2,5`

   * - .. rst-class:: keepwithnext

       i\) :math:`\dfrac{2x}{x-2}-\dfrac{3}{x^2-4}`

       .. rst-class:: solution

       :math:`= \dfrac{2x(x+2)}{(x-2)(x+2)}-\dfrac{3}{(x-2)(x+2)}`

       .. rst-class:: solution

       :math:`= \dfrac{2x^2+4x-3}{(x-2)(x+2)};\ x \neq -2,2`
     - .. rst-class:: keepwithnext

       j\) :math:`\dfrac{x-2}{x+2}+\dfrac{x+10}{x^2+6x+8}`

       .. rst-class:: solution

       :math:`= \dfrac{(x-2)(x+4)}{(x+2)(x+4)}+\dfrac{x+10}{(x+2)(x+4)}`

       .. rst-class:: solution

       :math:`= \dfrac{x^2+3x+2}{(x+2)(x+4)} = \dfrac{(x+2)(x+1)}
       {(x+2)(x+4)} = \dfrac{x+1}{x+4};\ x \neq -4,-2`

   * - .. rst-class:: keepwithnext

       k\) :math:`\dfrac{4x^2-20x}{x^2+2x-35}+\dfrac{3x-6}{x^2-12x+20}`

       .. rst-class:: solution

       :math:`= \dfrac{4x(x-5)}{(x+7)(x-5)}+\dfrac{3(x-2)}{(x-10)(x-2)}`

       .. rst-class:: solution

       :math:`= \dfrac{4x}{x+7}+\dfrac{3}{x-10} =

       .. rst-class:: solution
