**7)** Le conseil des élèves organise une sortie à un concert rock. Tous
les profits de la vente des billets seront versés à un organisme de
bienfaisance. Les billets du concert coûtent 31,25 $ par personne si au
moins 104 personnes y assistent. Pour chaque 8 personnes supplémentaires,
le prix diminue de 1,25 $ par personne.

.. rst-class:: keepwithnext

a\) Combien de billets doivent être vendus pour maximiser le don à
l'organisme de bienfaisance?

.. rst-class:: solution

Don :math:`= (\text{prix})(\#\text{ vendus})`:
:math:`D = (31.25-1.25x)(104+8x)`

.. rst-class:: solution

Trouve le :math:`x`-sommet en faisant la moyenne des abscisses à
l'origine : :math:`0 = (31.25-1.25x)(104+8x) \implies x_1=25,\ x_2=-13`

.. rst-class:: solution

:math:`x\text{-sommet} = \dfrac{25+(-13)}{2} = 6`

.. rst-class:: solution

Nombre vendu :math:`= 104+8(6) = 152` billets

.. rst-class:: keepwithnext

b\) Quel est le prix de chaque billet qui maximise le don?

.. rst-class:: solution

:math:`\text{prix} = 31.25-1.25(6) = 23.75`; 23,75 $ par billet

.. rst-class:: keepwithnext

c\) Quel est le don maximal?

.. rst-class:: solution

:math:`D = (23.75)(152) = 3610` $

**12)** Étant donné l'équation d'une parabole et la pente d'une droite
tangente à la parabole, détermine l'ordonnée à l'origine de la droite
tangente.

:math:`f(x) = -3x^2+x-4`, la droite tangente a une pente de 13 :
:math:`y = 13x+k`

.. rst-class:: solution

:math:`13x+k = -3x^2+x-4 \implies 0 = -3x^2-12x-4-k`

.. rst-class:: solution

La tangente a 1 point d'intersection, donc :math:`b^2-4ac=0` :

.. rst-class:: solution

:math:`0 = (-12)^2-4(-3)(-4-k) = 144+12(-4-k) = 144-48-12k = 96-12k`

.. rst-class:: solution

:math:`12k = 96 \implies k = 8`

.. rst-class:: solution

L'équation de la droite tangente est :math:`y=13x+8`. L'ordonnée à
l'origine est 8.

       .. rst-class:: solution

       :math:`= \dfrac{x+5}{x+3};\ x \neq -3,\dfrac{3}{2}`

   * - .. rst-class:: keepwithnext

       c\) :math:`\dfrac{36x^4}{5x^2} \times \dfrac{80x^3}{12x}`

       .. rst-class:: solution

       :math:`= \dfrac{48x^7}{x^3}`

       .. rst-class:: solution

       :math:`= 48x^4;\ x \neq 0`
     - .. rst-class:: keepwithnext

       d\) :math:`\dfrac{3x}{32y} \div \dfrac{27x^2}{96y}`

       .. rst-class:: solution

       :math:`= \dfrac{3x}{32y} \times \dfrac{96y}{27x^2} =
       \dfrac{3xy}{9x^2y}`

       .. rst-class:: solution

       :math:`= \dfrac{1}{3x};\ x \neq 0, y \neq 0`

   * - .. rst-class:: keepwithnext

       e\) :math:`\dfrac{x-8}{x+2} \times \dfrac{x+2}{x-6}`

       .. rst-class:: solution

       :math:`= \dfrac{x-8}{x-6};\ x \neq -2,6`
     - .. rst-class:: keepwithnext

       f\) :math:`\dfrac{4x-20}{x^2+6x} \times \dfrac{3x^2}{3x-15}`

       .. rst-class:: solution

       :math:`= \dfrac{4(x-5)(3x^2)}{x(x+6)(3)(x-5)}`

       .. rst-class:: solution

       :math:`= \dfrac{4x^2}{x(x+6)} = \dfrac{4x}{x+6};\ x \neq -6,0,5`

   * - .. rst-class:: keepwithnext

       g\) :math:`\dfrac{x+1}{x} \div \dfrac{x+1}{2x}`

       .. rst-class:: solution

       :math:`= \dfrac{x+1}{x} \times \dfrac{2x}{x+1}`

       .. rst-class:: solution

       :math:`= 2;\ x \neq -1,0`
     - .. rst-class:: keepwithnext

       h\) :math:`\dfrac{x^2-7x+10}{x^2-4} \div \dfrac{x^2-4x-5}{3x+6}`

       .. rst-class:: solution

       :math:`= \dfrac{(x-2)(x-5)}{(x-2)(x+2)} \times
       \dfrac{3(x+2)}{(x-5)(x+1)}`

       .. rst-class:: solution

       :math:`= \dfrac{3}{x+1};\ x \neq -2,-1,2,5`

   * - .. rst-class:: keepwithnext

       i\) :math:`\dfrac{2x}{x-2}-\dfrac{3}{x^2-4}`

       .. rst-class:: solution

       :math:`= \dfrac{2x(x+2)}{(x-2)(x+2)}-\dfrac{3}{(x-2)(x+2)}`

       .. rst-class:: solution

       :math:`= \dfrac{2x^2+4x-3}{(x-2)(x+2)};\ x \neq -2,2`
     - .. rst-class:: keepwithnext

       j\) :math:`\dfrac{x-2}{x+2}+\dfrac{x+10}{x^2+6x+8}`

       .. rst-class:: solution

       :math:`= \dfrac{(x-2)(x+4)}{(x+2)(x+4)}+\dfrac{x+10}{(x+2)(x+4)}`

       .. rst-class:: solution

       :math:`= \dfrac{x^2+3x+2}{(x+2)(x+4)} = \dfrac{(x+2)(x+1)}
       {(x+2)(x+4)} = \dfrac{x+1}{x+4};\ x \neq -4,-2`

   * - .. rst-class:: keepwithnext

       k\) :math:`\dfrac{4x^2-20x}{x^2+2x-35}+\dfrac{3x-6}{x^2-12x+20}`

       .. rst-class:: solution

       :math:`= \dfrac{4x(x-5)}{(x+7)(x-5)}+\dfrac{3(x-2)}{(x-10)(x-2)}`

       .. rst-class:: solution

       :math:`= \dfrac{4x}{x+7}+\dfrac{3}{x-10} =
