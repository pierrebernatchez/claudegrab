**13)** Dave is in a hot air balloon 400m in the air exactly halfway
between two houses on the ground. His wife, Rhonda, is at her friend's
house which is 4.6km from the first house and 3.4km from the second
house. The angle of the two houses, from Rhonda's point of view, is 64°.
Find the angle of elevation if Rhonda looks up at Dave.

.. image:: ../images/mafcreview05-gpimage22.png
   :align: center

.. rst-class:: solution

Distance between the two houses: :math:`b^2 = 4.6^2 + 3.4^2 - 2(4.6)(3.4)
\cos 64^\circ \implies b = 4.36` km, so each half is 2.18 km.

.. rst-class:: solution

Angle between Rhonda-House2 and Rhonda-House1 is 64°, so the angle at
House2 (between House2-House1 and House2-Rhonda) comes from
:math:`\dfrac{4.36}{\sin 64^\circ} = \dfrac{4.6}{\sin A} \implies \angle A =
71.5^\circ` (this is also the angle between House2-D and House2-Rhonda,
since D lies on House1-House2).

.. rst-class:: solution

:math:`BD^2 = 3.4^2 + 2.18^2 - 2(3.4)(2.18)\cos 71.5^\circ \implies BD =
3.41` km

.. rst-class:: solution

:math:`\tan\theta = \dfrac{0.4}{3.41} \implies \theta = \tan^{-1}
\left(\dfrac{0.4}{3.41}\right) = 6.7^\circ`

**14)** Prove the following trigonometric identities.

.. rst-class:: keepwithnext

a\) :math:`\sec\theta\cos\theta + \sec\theta\sin\theta = 1 + \tan\theta`

.. rst-class:: solution

LS :math:`= \dfrac{1}{\cos\theta}(\cos\theta) + \dfrac{1}{\cos\theta}
(\sin\theta) = 1 + \dfrac{\sin\theta}{\cos\theta} = 1 + \tan\theta` = RS

.. rst-class:: keepwithnext

b\) :math:`\tan^2 x + \cos^2 x + \sin^2 x = \dfrac{1}{\cos^2 x}`

.. rst-class:: solution

LS :math:`= \tan^2 x + 1 = \dfrac{\sin^2 x}{\cos^2 x} + \dfrac{\cos^2 x}
{\cos^2 x} = \dfrac{1}{\cos^2 x}` = RS

.. rst-class:: keepwithnext

c\) :math:`\csc^4 x + \cot^4 x = 1 + 2\csc^2 x\cot^2 x`

.. rst-class:: solution

LS :math:`= \dfrac{1}{\sin^4 x} + \dfrac{\cos^4 x}{\sin^4 x} = \dfrac{1 +
\cos^2 x(\cos^2 x)}{\sin^4 x} = \dfrac{1 + (1-\sin^2 x)(\cos^2 x)}{\sin^4 x}
= \dfrac{\sin^2 x(1-\cos^2 x) + 2\cos^2 x}{\sin^4 x} = \dfrac{\sin^4 x +
2\cos^2 x}{\sin^4 x}`

.. rst-class:: solution

RS :math:`= 1 + 2\left(\dfrac{1}{\sin^2 x}\right)\left(\dfrac{\cos^2 x}
{\sin^2 x}\right) = \dfrac{\sin^4 x}{\sin^4 x} + \dfrac{2\cos^2 x}{\sin^4 x}
= \dfrac{\sin^4 x + 2\cos^2 x}{\sin^4 x}` = LS

.. rst-class:: keepwithnext

d\) :math:`\dfrac{\cot x - \tan x}{\csc^2 x - \sec^2 x} = \dfrac{1}
{\csc x\sec x}`

.. rst-class:: solution

LS :math:`= \dfrac{\frac{\cos x}{\sin x} - \frac{\sin x}{\cos x}}
{\frac{1}{\sin^2 x} - \frac{1}{\cos^2 x}} = \dfrac{\frac{\cos^2 x -
\sin^2 x}{\sin x\cos x}}{\frac{\cos^2 x - \sin^2 x}{\sin^2 x\cos^2 x}} =
\dfrac{\cos^2 x - \sin^2 x}{\sin x\cos x}\cdot\dfrac{\sin^2 x\cos^2 x}
{\cos^2 x - \sin^2 x} = \sin x\cos x`

.. rst-class:: solution

RS :math:`= \dfrac{1}{\left(\frac{1}{\sin x}\right)\left(\frac{1}
{\cos x}\right)} = \sin x\cos x` = LS

.. rst-class:: keepwithnext

e\) :math:`\dfrac{\cot x - \tan x}{\sin x\cos x} = \csc^2 x - \sec^2 x`

.. rst-class:: solution

LS :math:`= \dfrac{\frac{\cos x}{\sin x} - \frac{\sin x}{\cos x}}
{\sin x\cos x} = \dfrac{\cos^2 x - \sin^2 x}{\sin x\cos x}\cdot
\dfrac{1}{\sin x\cos x} = \dfrac{\cos^2 x - \sin^2 x}{\sin^2 x\cos^2 x}`

.. rst-class:: solution

RS :math:`= \dfrac{1}{\sin^2 x} - \dfrac{1}{\cos^2 x} = \dfrac{\cos^2 x -
\sin^2 x}{\sin^2 x\cos^2 x}` = LS
