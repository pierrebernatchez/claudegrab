**9)** A farmer has 5000 meters of fencing to enclose a rectangular field
and subdivide it into three equal plots. The enclosed area is to be a
maximum. Determine the dimensions of one plot of land, to the nearest
meter.

.. rst-class:: solution

Let :math:`x` be the width. :math:`2(\text{length})+4x = 5000 \Rightarrow
\text{length} = 2500-2x`. Total area :math:`A = x(2500-2x)`.

.. rst-class:: solution

:math:`0 = x(2500-2x) \Rightarrow x=0` or :math:`x=1250`;
:math:`x\text{-vertex} = \dfrac{0+1250}{2} = 625`

.. rst-class:: solution

For 1 plot: length :math:`= \dfrac{2500-2(625)}{3} \approx 417`; width
:math:`= 625`

.. rst-class:: solution

Area :math:`= 417 \times 625 = 260\,625\ \text{m}^2`

**10)** The student council is organizing a trip to a rock concert. All
proceeds from ticket sales will be donated to charity. Tickets to the
concert cost $31.25 per person if a minimum of 104 people attend. For
every 8 extra people that attend, the price will decrease by $1.25 per
person.

.. rst-class:: keepwithnext

a\) How many tickets need to be sold to maximize the donation to charity?

.. rst-class:: solution

Donation :math:`= (\text{cost})(\#\text{ sold}) =
(31.25-1.25x)(104+8x)`

.. rst-class:: solution

:math:`0 = (31.25-1.25x)(104+8x) \Rightarrow x=25` or :math:`x=-13`;
:math:`x\text{-vertex} = \dfrac{25+(-13)}{2} = 6`

.. rst-class:: solution

:math:`\#\text{ sold} = 104+8(6) = 152`

.. rst-class:: keepwithnext

b\) What is the price of each ticket that maximizes the donation?

.. rst-class:: solution

Price :math:`= 31.25-1.25(6) = \$23.75`

.. rst-class:: keepwithnext

c\) What is the maximum donation?

.. rst-class:: solution

Donation :math:`= (23.75)(152) = \$3610`

.. rst-class:: keepwithnext

:math:`0.8` seconds.

a\) :math:`y = x^2+4x+3` and :math:`y = 5x+9`

.. rst-class:: solution

:math:`5x+9 = x^2+4x+3 \Rightarrow 0 = x^2-x-6 = (x-3)(x+2)`

:math:`x=3`: :math:`y = 5(3)+9 = 24 \Rightarrow (3,24)`

.. rst-class:: solution

.. rst-class:: solution

:math:`x-8 = -x^2-4x+6 \Rightarrow 0 = x^2+5x-14 = (x+7)(x-2)`

.. rst-class:: solution

:math:`x=-7`: :math:`y = -7-8 = -15 \Rightarrow (-7,-15)`

.. rst-class:: solution

:math:`x=2`: :math:`y = 2-8 = -6 \Rightarrow (2,-6)`

**20)** Given the equation of a parabola and the slope of a line that is
tangent to the parabola, determine the y-intercept of the tangent line.

:math:`f(x) = -3x^2+x-4`, tangent line has slope 13: :math:`y = 13x+k`

.. rst-class:: solution

:math:`13x+k = -3x^2+x-4 \Rightarrow 0 = -3x^2-12x-4-k`

.. rst-class:: solution

Tangent has 1 point of intersection, so :math:`b^2-4ac=0`:

.. rst-class:: solution

:math:`0 = (-12)^2-4(-3)(-4-k) = 144+12(-4-k) = 144-48-12k = 96-12k`

.. rst-class:: solution

:math:`12k = 96 \Rightarrow k = 8`

.. rst-class:: solution

The y-intercept is at 8.
