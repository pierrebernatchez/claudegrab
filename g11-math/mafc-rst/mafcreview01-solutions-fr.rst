**8)** Convertis la parabole :math:`y = 3x^2+15x-5` en forme canonique en
utilisant n'importe quelle méthode. Indique si le sommet est un point
minimum ou maximum.

.. rst-class:: solution

:math:`x\text{-sommet} = \dfrac{-b}{2a} = \dfrac{-15}{2(3)} =
-\dfrac{15}{6} = -\dfrac{5}{2}`

.. rst-class:: solution

:math:`y\text{-sommet} = 3\left(-\frac{5}{2}\right)^2+15\left(-
\frac{5}{2}\right)-5 = \dfrac{75}{4}-\dfrac{150}{4}-\dfrac{20}{4} =
-\dfrac{95}{4}`

.. rst-class:: solution

Le sommet :math:`\left(-\dfrac{5}{2},-\dfrac{95}{4}\right)` est un
minimum.

**9)** Un fermier dispose de 5000 mètres de clôture pour enclore un champ
rectangulaire et le subdiviser en trois parcelles égales. L'aire enclose
doit être maximale. Détermine les dimensions d'une parcelle de terrain,
au mètre près.

.. rst-class:: solution

Soit :math:`x` la largeur. :math:`2(\text{longueur})+4x = 5000
\Rightarrow \text{longueur} = 2500-2x`. Aire totale :math:`A =
x(2500-2x)`.

.. rst-class:: solution

:math:`0 = x(2500-2x) \Rightarrow x=0` ou :math:`x=1250`;
:math:`x\text{-sommet} = \dfrac{0+1250}{2} = 625`

.. rst-class:: solution

Pour 1 parcelle : longueur :math:`= \dfrac{2500-2(625)}{3} \approx 417`;
largeur :math:`= 625`

.. rst-class:: solution

Aire :math:`= 417 \times 625 = 260\,625\ \text{m}^2`

**10)** Le conseil des élèves organise une sortie à un concert rock. Tous
les profits de la vente des billets seront versés à un organisme de
bienfaisance. Les billets du concert coûtent 31,25 $ par personne si au
moins 104 personnes y assistent. Pour chaque 8 personnes supplémentaires,
le prix diminue de 1,25 $ par personne.

.. rst-class:: keepwithnext

a\) Combien de billets doivent être vendus pour maximiser le don à
l'organisme de bienfaisance?

.. rst-class:: solution

Don :math:`= (\text{prix})(\#\text{ vendus}) =
(31.25-1.25x)(104+8x)`

.. rst-class:: solution

:math:`0 = (31.25-1.25x)(104+8x) \Rightarrow x=25` ou :math:`x=-13`;
:math:`x\text{-sommet} = \dfrac{25+(-13)}{2} = 6`

.. rst-class:: solution

:math:`\#\text{ vendus} = 104+8(6) = 152`

.. rst-class:: keepwithnext

b\) Quel est le prix de chaque billet qui maximise le don?

.. rst-class:: solution

Prix :math:`= 31.25-1.25(6) =` 23,75 $

.. rst-class:: keepwithnext

c\) Quel est le don maximal?

.. rst-class:: solution

Don :math:`= (23.75)(152) =` 3610 $

.. rst-class:: keepwithnext

**11)** Un ballon est botté dans les airs. Sa trajectoire est donnée par
:math:`h(t) = -4.9t^2+8t+0.4`, où :math:`t` est le temps, en secondes,
et :math:`h(t)` est la hauteur, en mètres.

.. rst-class:: keepwithnext

a\) Détermine la hauteur maximale du ballon au dixième de mètre près.

.. rst-class:: solution

:math:`t\text{-sommet} = \dfrac{-b}{2a} = \dfrac{-8}{2(-4.9)} =
\dfrac{40}{49} \approx 0.8`

.. rst-class:: solution

:math:`h(0.8) = -4.9(0.8)^2+8(0.8)+0.4 \approx 3.7` m

.. rst-class:: keepwithnext

b\) À quel moment le ballon atteint-il sa hauteur maximale?

.. rst-class:: solution

:math:`0.8` seconde.

**20)** Étant donné l'équation d'une parabole et la pente d'une droite
tangente à la parabole, détermine l'ordonnée à l'origine de la droite
tangente.

:math:`f(x) = -3x^2+x-4`, la droite tangente a une pente de 13 :
:math:`y = 13x+k`

.. rst-class:: solution

:math:`13x+k = -3x^2+x-4 \Rightarrow 0 = -3x^2-12x-4-k`

.. rst-class:: solution

La tangente a 1 point d'intersection, donc :math:`b^2-4ac=0` :

.. rst-class:: solution

:math:`0 = (-12)^2-4(-3)(-4-k) = 144+12(-4-k) = 144-48-12k = 96-12k`

.. rst-class:: solution

:math:`12k = 96 \Rightarrow k = 8`

.. rst-class:: solution

L'ordonnée à l'origine est 8.
