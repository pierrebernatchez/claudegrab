**4)** The curve :math:`y = 3x^2-4x+8` and the line :math:`y = 3x+5`
intersect at

a\) No point b\) One point c\) 2 points d\) An infinite number of points

.. rst-class:: solution

Setting them equal: :math:`3x^2-4x+8=3x+5 \Rightarrow 3x^2-7x+3=0`.
Discriminant :math:`=(-7)^2-4(3)(3)=49-36=13>0`, so there are two real
solutions — **c) 2 points**

**5)** For the function :math:`f(x) = 2x^2-5x+1`, if :math:`f(a) = 4`,
what is the value of :math:`a`?

a\) 4 b\) 3 c\) :math:`-3` d\) :math:`-4`

.. rst-class:: solution

:math:`2a^2-5a+1=4 \Rightarrow 2a^2-5a-3=0`. Discriminant
:math:`=25+24=49`, :math:`\sqrt{49}=7`, so
:math:`a=\dfrac{5\pm7}{4}=3\text{ or }-\dfrac{1}{2}`. Only 3 is listed —
**b) 3**

**6)** The restrictions on the expression
:math:`\dfrac{2x^2+5x+3}{4x^2-9}` is (are)

a\) :math:`x\neq0` b\) :math:`x\neq\dfrac{3}{2}` c\) :math:`x\neq
\dfrac{3}{2}, x\neq-\dfrac{3}{2}` d\) :math:`x\neq\dfrac{3}{2},
x\neq-\dfrac{3}{2}, x\neq-1`

.. rst-class:: solution

Restrictions come only from the denominator: :math:`4x^2-9=(2x-3)(2x+3)=0
\Rightarrow x=\dfrac{3}{2},-\dfrac{3}{2}`. (The numerator factors as
:math:`(x+1)(2x+3)`, so :math:`2x+3` cancels, but :math:`x=-1` was never
a restriction of the *original* expression, since :math:`x+1` never
appears in the denominator.) — **c)**

**34)** Prove the trig identity
:math:`\dfrac{\cos\theta}{\sec\theta} - \dfrac{\sin\theta}{\cot\theta} =
\dfrac{\cot\theta\cos\theta-\tan\theta}{\csc\theta}`

.. rst-class:: solution

LHS :math:`=\cos\theta\cdot\cos\theta - \sin\theta\cdot\tan\theta
=\cos^2\theta-\dfrac{\sin^2\theta}{\cos\theta}
=\dfrac{\cos^3\theta-\sin^2\theta}{\cos\theta}`

.. rst-class:: solution

RHS numerator :math:`=\dfrac{\cos\theta}{\sin\theta}\cos\theta -
\dfrac{\sin\theta}{\cos\theta}
=\dfrac{\cos^3\theta-\sin^2\theta}{\sin\theta\cos\theta}`; dividing by
:math:`\csc\theta` (multiplying by :math:`\sin\theta`) gives
:math:`\dfrac{\cos^3\theta-\sin^2\theta}{\cos\theta}`

.. rst-class:: solution

LHS = RHS :math:`\blacksquare`
