Answers
================================================================================

1\) a\) B&C are functions, A is not a function b\) vertical line test:
each value of :math:`x` has only 1 value of :math:`y` c\) :math:`f(3)=1`

2\) a\) D: :math:`\{x=-6,-5,-4,-3\}`; R: :math:`\{y=2\}`; is a function
b\) D: :math:`\{x=5\}`; R: :math:`\{y=-4,-2,0,2,4\}`; not a function

3\) a\) D: :math:`\{x \in \mathbb{R}\}`; R: :math:`\{y \in \mathbb{R}\}`;
is a function b\) D: :math:`\{x \in \mathbb{R}\}`; R: :math:`\{y \in
\mathbb{R} \mid y \geq -1\}`, is a function

c\) D: :math:`\{x \in \mathbb{R} \mid x \leq 3\}`; R: :math:`\{y \in
\mathbb{R}\}`; not a function d\) D: :math:`\{x \in \mathbb{R} \mid x
\neq -4\}`; R: :math:`\{y \in \mathbb{R} \mid y \neq 0\}`; is a function

e\) D: :math:`\{x \in \mathbb{R}\}`; R: :math:`\{y \in \mathbb{R} \mid -3
\leq y \leq 7\}`; is a function

4\) a\) -44 b\) 6 c\) :math:`\dfrac{39}{8}`

5\) a\) :math:`\dfrac{16}{5},\dfrac{7}{5},\dfrac{17}{10}` b\)
:math:`\sqrt{7},1,\sqrt{2}`
