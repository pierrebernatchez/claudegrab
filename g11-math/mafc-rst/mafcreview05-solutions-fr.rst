**13)** Dave est dans une montgolfière à 400 m dans les airs, exactement
à mi-chemin entre deux maisons au sol. Sa femme, Rhonda, est chez une
amie qui se trouve à 4,6 km de la première maison et à 3,4 km de la
deuxième maison. L'angle entre les deux maisons, du point de vue de
Rhonda, est de 64°. Trouve l'angle d'élévation si Rhonda regarde vers le
haut en direction de Dave.

.. image:: ../images/mafcreview05-gpimage22-fr.png
   :align: center

.. rst-class:: solution

Distance entre les deux maisons : :math:`b^2 = 4.6^2 + 3.4^2 - 2(4.6)(3.4)
\cos 64^\circ \implies b = 4.36` km, donc chaque moitié est de 2,18 km.

.. rst-class:: solution

L'angle entre Rhonda-Maison2 et Rhonda-Maison1 est de 64°, donc l'angle à
Maison2 (entre Maison2-Maison1 et Maison2-Rhonda) vient de
:math:`\dfrac{4.36}{\sin 64^\circ} = \dfrac{4.6}{\sin A} \implies \angle A =
71.5^\circ` (c'est aussi l'angle entre Maison2-D et Maison2-Rhonda,
puisque D se trouve sur Maison1-Maison2).

.. rst-class:: solution

:math:`BD^2 = 3.4^2 + 2.18^2 - 2(3.4)(2.18)\cos 71.5^\circ \implies BD =
3.41` km

.. rst-class:: solution

:math:`\tan\theta = \dfrac{0.4}{3.41} \implies \theta = \tan^{-1}
\left(\dfrac{0.4}{3.41}\right) = 6.7^\circ`

**14)** Démontre les identités trigonométriques suivantes.

.. rst-class:: keepwithnext

a\) :math:`\sec\theta\cos\theta + \sec\theta\sin\theta = 1 + \tan\theta`

.. rst-class:: solution

MG :math:`= \dfrac{1}{\cos\theta}(\cos\theta) + \dfrac{1}{\cos\theta}
(\sin\theta) = 1 + \dfrac{\sin\theta}{\cos\theta} = 1 + \tan\theta` = MD

.. rst-class:: keepwithnext

b\) :math:`\tan^2 x + \cos^2 x + \sin^2 x = \dfrac{1}{\cos^2 x}`

.. rst-class:: solution

MG :math:`= \tan^2 x + 1 = \dfrac{\sin^2 x}{\cos^2 x} + \dfrac{\cos^2 x}
{\cos^2 x} = \dfrac{1}{\cos^2 x}` = MD

.. rst-class:: keepwithnext

c\) :math:`\csc^4 x + \cot^4 x = 1 + 2\csc^2 x\cot^2 x`

.. rst-class:: solution

MG :math:`= \dfrac{1}{\sin^4 x} + \dfrac{\cos^4 x}{\sin^4 x} = \dfrac{1 +
\cos^2 x(\cos^2 x)}{\sin^4 x} = \dfrac{1 + (1-\sin^2 x)(\cos^2 x)}{\sin^4 x}
= \dfrac{\sin^2 x(1-\cos^2 x) + 2\cos^2 x}{\sin^4 x} = \dfrac{\sin^4 x +
2\cos^2 x}{\sin^4 x}`

.. rst-class:: solution

MD :math:`= 1 + 2\left(\dfrac{1}{\sin^2 x}\right)\left(\dfrac{\cos^2 x}
{\sin^2 x}\right) = \dfrac{\sin^4 x}{\sin^4 x} + \dfrac{2\cos^2 x}{\sin^4 x}
= \dfrac{\sin^4 x + 2\cos^2 x}{\sin^4 x}` = MG

.. rst-class:: keepwithnext

d\) :math:`\dfrac{\cot x - \tan x}{\csc^2 x - \sec^2 x} = \dfrac{1}
{\csc x\sec x}`

.. rst-class:: solution

MG :math:`= \dfrac{\frac{\cos x}{\sin x} - \frac{\sin x}{\cos x}}
{\frac{1}{\sin^2 x} - \frac{1}{\cos^2 x}} = \dfrac{\frac{\cos^2 x -
\sin^2 x}{\sin x\cos x}}{\frac{\cos^2 x - \sin^2 x}{\sin^2 x\cos^2 x}} =
\dfrac{\cos^2 x - \sin^2 x}{\sin x\cos x}\cdot\dfrac{\sin^2 x\cos^2 x}
{\cos^2 x - \sin^2 x} = \sin x\cos x`

.. rst-class:: solution

MD :math:`= \dfrac{1}{\left(\frac{1}{\sin x}\right)\left(\frac{1}
{\cos x}\right)} = \sin x\cos x` = MG

.. rst-class:: keepwithnext

e\) :math:`\dfrac{\cot x - \tan x}{\sin x\cos x} = \csc^2 x - \sec^2 x`

.. rst-class:: solution

MG :math:`= \dfrac{\frac{\cos x}{\sin x} - \frac{\sin x}{\cos x}}
{\sin x\cos x} = \dfrac{\cos^2 x - \sin^2 x}{\sin x\cos x}\cdot
\dfrac{1}{\sin x\cos x} = \dfrac{\cos^2 x - \sin^2 x}{\sin^2 x\cos^2 x}`

.. rst-class:: solution

MD :math:`= \dfrac{1}{\sin^2 x} - \dfrac{1}{\cos^2 x} = \dfrac{\cos^2 x -
\sin^2 x}{\sin^2 x\cos^2 x}` = MG
