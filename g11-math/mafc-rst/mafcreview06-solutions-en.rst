**5)** Write sentences to explain the steps you would take to transform
:math:`y=\sin x` into the graph of :math:`y=-3\sin 4(x+30)+1`.

.. rst-class:: solution

Vertical reflection; vertical stretch by a factor of 3; horizontal
compression by a factor of :math:`\tfrac{1}{4}`; shift left 30°; shift up
1 unit.

**6)** For the transformed function :math:`y = 4\cos[3(x-20^\circ)]+5`
state the amplitude, the period, the phase shift and the vertical shift of
the function with respect to the parent function, also state the maximum
and minimum values of the function.

Amplitude :solmath:`= 4` :math:`\quad` Period :solmath:`= \dfrac{360}{3} =
120^\circ` :math:`\quad` Phase shift :sol:`= right 20°`

Vertical Shift :sol:`= up 5` :math:`\quad` Maximum Value :solmath:`= 5+4 =
9` :math:`\quad` Minimum Value :solmath:`= 5-4 = 1`

**8)** Determine two equations for a sinusoidal wave that has a maximum at
:math:`(0, 2/3)`, vertical shift of 1/3 up, and a period of 120.

.. rst-class:: solution

:math:`a = \max - c = \dfrac{2}{3}-\dfrac{1}{3} = \dfrac{1}{3}` :math:`\quad`
:math:`k = \dfrac{360}{\text{period}} = \dfrac{360}{120} = 3` :math:`\quad`
:math:`c = \dfrac{1}{3}`

.. rst-class:: solution

:math:`d=0` (cos, max at the origin) :math:`\quad` :math:`d=-30` (sin, the
rising midline is :math:`90/k=30` to the left of the max)

.. rst-class:: solution

:math:`y = \dfrac{1}{3}\cos(3x) + \dfrac{1}{3}` :math:`\quad` :math:`y =
\dfrac{1}{3}\sin[3(x+30)] + \dfrac{1}{3}`
