**1)** Find the formula for the general term :math:`t_n` and then use it to
calculate :math:`t_{12}` for each of the following sequences:

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       a\) :math:`9, 15, 21, \ldots`

       .. rst-class:: solution

       :math:`a=9,\ d=6` :math:`\quad` :math:`t_n = 9+(n-1)(6)`

       .. rst-class:: solution

       :math:`t_{12} = 9+(12-1)(6) = 75`
     - .. rst-class:: keepwithnext

       b\) :math:`-1, 2, -4, 8, \ldots`

       .. rst-class:: solution

       :math:`a=-1,\ r=-2` :math:`\quad` :math:`t_n = -1(-2)^{n-1}`

       .. rst-class:: solution

       :math:`t_{12} = -1(-2)^{12-1} = 2048`

**4)** In an arithmetic series of 50 terms, the 17th term is 53 and the
28th term is 86. Determine, a, d and :math:`S_{50}`.

.. rst-class:: solution

:math:`t_{17}=53 \implies a+16d=53` :math:`\quad` :math:`t_{28}=86 \implies
a+27d=86`

.. rst-class:: solution

Subtracting: :math:`11d=33 \implies d=3`, and :math:`a+16(3)=53 \implies
a=5`

.. rst-class:: solution

:math:`S_{50} = \dfrac{50}{2}\left[2(5)+(50-1)(3)\right] = 25(157) = 3925`

.. rst-class:: keepwithnext

**5)** In an arithmetic series, the 12th term is 15 and the sum of the
first 15 terms is 105. Determine the sum of the first three terms in the
series.

.. rst-class:: solution

:math:`t_{12}=15 \implies a+11d=15` :math:`\quad` :math:`S_{15}=105
\implies \dfrac{15}{2}\left[2a+14d\right]=105 \implies a+7d=7`

.. rst-class:: solution

Subtracting: :math:`4d=8 \implies d=2`, and :math:`a+7(2)=7 \implies a=-7`

.. rst-class:: solution

:math:`S_3 = \dfrac{3}{2}\left[2(-7)+(3-1)(2)\right] = -15`

.. rst-class:: keepwithnext

**6)** The fifth term of a geometric series is 405 and the sixth term is
1215. Find the sum of the first nine terms.

.. rst-class:: solution

:math:`t_5=405=ar^4` :math:`\quad` :math:`t_6=1215=ar^5` :math:`\quad`
:math:`\dfrac{t_6}{t_5} = r = \dfrac{1215}{405} = 3`

.. rst-class:: solution

:math:`a = \dfrac{405}{3^4} = 5`

.. rst-class:: solution

:math:`S_9 = \dfrac{5\left[(3)^9-1\right]}{3-1} = 49\,205`

.. rst-class:: keepwithnext

**7)** Find the sum of each of the following series:

.. list-table::

   * - .. rst-class:: keepwithnext

       :math:`a=251,\ d=-8` :math:`\quad` :math:`-205=251+(n-1)(-8)

     - .. rst-class:: keepwithnext

       2187=3^{n-1} \implies n=8`

       .. rst-class:: solution

       :math:`S_8 = \dfrac{-4\left[3^8-1\right]}{3-1} = -13\,120`
   * - .. rst-class:: keepwithnext

       c\) :math:`21 + 23 + 25 + \ldots + 43`

       .. rst-class:: solution

       :math:`a=21,\ d=2` :math:`\quad` :math:`43=21+(n-1)(2) \implies
       n=12`

       .. rst-class:: solution

       :math:`S_{12} = \dfrac{12}{2}(21+43) = 384`
     - .. rst-class:: keepwithnext

       d\) :math:`1280 - 640 + 320 - \ldots + 5`

       .. rst-class:: solution

       :math:`a=1280,\ r=-\dfrac{1}{2}` :math:`\quad` :math:`5=1280
       \left(-\dfrac{1}{2}\right)^{n-1} \implies n=9`

       .. rst-class:: solution

       :math:`S_9 = \dfrac{1280\left[\left(-\tfrac{1}{2}\right)^9-1
       \right]}{-\tfrac{1}{2}-1} = 855`

**10)** In an arithmetic sequence, the 3rd term is 25 and the 9th term is
43. How many terms are less than 100?

.. rst-class:: solution

:math:`t_3=25 \implies a+2d=25` :math:`\quad` :math:`t_9=43 \implies
a+8d=43`

.. rst-class:: solution

Subtracting: :math:`6d=18 \implies d=3`, and :math:`a+2(3)=25 \implies
a=19`

.. rst-class:: solution

:math:`t_n = 19+(n-1)(3) < 100 \implies (n-1)(3) < 81 \implies n < 28`

.. rst-class:: solution

So 27 terms are less than 100.

**11)** The sum of the first 6 terms is 297 and the sum of the first 8
terms is 500. Determine the 5th term if the sequence is arithmetic.

.. rst-class:: solution

:math:`S_6=297 \implies 3(2a+5d)=297 \implies 2a+5d=99` :math:`\quad`
:math:`S_8=500 \implies 4(2a+7d)=500 \implies 2a+7d=125`

.. rst-class:: solution

Subtracting: :math:`2d=26 \implies d=13`, and :math:`2a+5(13)=99 \implies
a=17`

.. rst-class:: solution

:math:`t_5 = 17+(5-1)(13) = 69`
