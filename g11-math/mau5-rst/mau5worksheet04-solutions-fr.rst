       .. rst-class:: solution

       :math:`\sin G = -\dfrac{3}{4}`

       Aucun angle du premier quadrant n'a un rapport sinus négatif,
       donc il n'y a pas de solution.
     - .. rst-class:: keepwithnext

       .. rst-class:: solution

       :math:`\cos H = \dfrac{5}{2}`

       .. rst-class:: solution

       Les rapports cosinus sont toujours compris entre :math:`-1` et
       :math:`1`, car l'hypoténuse doit être plus longue que le côté
       adjacent, donc il n'y a pas de solution.

Réponses
================================================================================

**1)** a) :math:`A = 8\degree` b) :math:`B = 65\degree`
c) :math:`C = 47\degree`

**2)** :math:`\sin 315\degree = -\dfrac{1}{\sqrt{2}}`
:math:`\cos 315\degree = \dfrac{1}{\sqrt{2}}`
:math:`\tan 315\degree = -1`
:math:`\csc 315\degree = -\sqrt{2}`
:math:`\sec 315\degree = \sqrt{2}`
:math:`\cot 315\degree = -1`

**3)** a) :math:`42\degree` b) :math:`53\degree` c) :math:`63\degree`
d) :math:`41\degree` e) pas de solution f) pas de solution

**4)** a) :math:`135\degree` et :math:`225\degree`
b) :math:`135\degree` et :math:`315\degree`
c) :math:`19\degree` et :math:`161\degree`

**5)** a) :math:`\sin\theta = \dfrac{12}{13}`,
:math:`\cos\theta = -\dfrac{5}{13}`, :math:`\tan\theta = -\dfrac{12}{5}`,
:math:`\csc\theta = \dfrac{13}{12}`, :math:`\sec\theta = -\dfrac{13}{5}`,
:math:`\cot\theta = -\dfrac{5}{12}`
