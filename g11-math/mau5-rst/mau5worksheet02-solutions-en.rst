**2)** State the value of each ratio **exactly**.

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       a\) sin 225°

       .. image:: ../images/mau5worksheet02-gpimage13.png
          :scale: 75

       .. rst-class:: solution

       :math:`\sin 225\degree = -\sin 45\degree`

       .. rst-class:: solution

       :math:`= -\dfrac{1}{\sqrt{2}}`
     - .. rst-class:: keepwithnext

       c\) sin 270°

       .. image:: ../images/mau5worksheet02-gpimage15.png
          :scale: 75

       .. rst-class:: solution

       Use the unit circle: :math:`\sin\theta = \dfrac{y}{r}`

       .. rst-class:: solution

       :math:`\sin 270\degree = \dfrac{-1}{1} = -1`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       b\) cos 240°

       .. image:: ../images/mau5worksheet02-gpimage14.png
          :scale: 75

       .. rst-class:: solution

       :math:`\cos 240\degree = -\cos 60\degree`

       .. rst-class:: solution

       :math:`= -\dfrac{1}{2}`
     - .. rst-class:: keepwithnext

       d\) tan 300°

       .. image:: ../images/mau5worksheet02-gpimage16.png
          :scale: 75

       .. rst-class:: solution

       :math:`\tan 300\degree = -\tan 60\degree`

       .. rst-class:: solution

       :math:`= -\dfrac{\sqrt{3}}{1} = -\sqrt{3}`

.. rst-class:: keepwithnext

e\) cos 180°

.. image:: ../images/mau5worksheet02-gpimage17.png
   :scale: 75

.. rst-class:: solution

Use the unit circle: :math:`\cos\theta = \dfrac{x}{r}`

.. rst-class:: solution

:math:`\cos 180\degree = \dfrac{-1}{1} = -1`

**3)** Point P(-9, 4) is on the terminal arm of an angle in standard
position.

.. rst-class:: keepwithnext

a\) Sketch the principal angle, θ.

.. image:: ../images/mau5worksheet02-gpimage18.png
   :scale: 75

.. rst-class:: keepwithnext

b\) What is the measure of β, the related acute angle to the nearest
degree?

.. rst-class:: solution

:math:`\tan\theta = \dfrac{y}{x}`

.. rst-class:: solution

:math:`\tan\theta = \dfrac{4}{9}`

.. rst-class:: solution

:math:`\theta = \tan^{-1}\left(\dfrac{4}{9}\right)`

.. rst-class:: solution

:math:`\theta \approx 24\degree`

.. rst-class:: keepwithnext

c\) What is the measure of θ to the nearest degree?

.. rst-class:: solution

:math:`\theta = 180\degree - 24\degree`

.. rst-class:: solution

:math:`= 156\degree`

**4)** Point P(7, -24) is on the terminal arm of an angle in standard
position.

.. rst-class:: keepwithnext

a\) Sketch the principal angle, θ.

.. image:: ../images/mau5worksheet02-gpimage19.png
   :scale: 75

.. rst-class:: keepwithnext

b\) What is the measure of β, the related acute angle to the nearest
degree?

.. rst-class:: solution

:math:`\tan\theta = \dfrac{y}{x}`

.. rst-class:: solution

:math:`\tan\theta = \dfrac{24}{7}`

.. rst-class:: solution

:math:`\theta = \tan^{-1}\left(\dfrac{24}{7}\right)`

.. rst-class:: solution

:math:`\theta \approx 74\degree`

.. rst-class:: keepwithnext

c\) What is the measure of θ to the nearest degree?

.. rst-class:: solution

:math:`\theta = 360\degree - 74\degree`

.. rst-class:: solution

:math:`= 286\degree`
