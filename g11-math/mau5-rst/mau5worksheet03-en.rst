Answers
================================================================================

**1)** a) :math:`\sin\theta = \dfrac{3}{\sqrt{10}}`,
:math:`\cos\theta = \dfrac{1}{\sqrt{10}}`, :math:`\tan\theta = 3`
b) :math:`\sin\theta = \dfrac{4}{5}`, :math:`\cos\theta = -\dfrac{3}{5}`,
:math:`\tan\theta = -\dfrac{4}{3}`
c) :math:`\sin\theta = -\dfrac{5}{\sqrt{61}}`,
:math:`\cos\theta = -\dfrac{6}{\sqrt{61}}`, :math:`\tan\theta = \dfrac{5}{6}`
d) :math:`\sin\theta = -\dfrac{5}{\sqrt{34}}`,
:math:`\cos\theta = \dfrac{3}{\sqrt{34}}`, :math:`\tan\theta = -\dfrac{5}{3}`

**2)** a) :math:`\cos A = \dfrac{\sqrt{7}}{4}`, :math:`\tan A = \dfrac{3}{\sqrt{7}}`
b) :math:`\sin B = \dfrac{\sqrt{5}}{3}`, :math:`\tan B = -\dfrac{\sqrt{5}}{2}`

**3)** Answers may vary. Sample answer: :math:`510\degree, 870\degree`

**4)** a) :math:`30\degree, 150\degree` b) :math:`150\degree, 210\degree`
c) :math:`7\degree, 187\degree` d) :math:`127\degree, 233\degree`

**5)** a) the first and fourth quadrants
b) first quadrant: :math:`(12,35)`; fourth quadrant: :math:`(12,-35)`
c) fourth quadrant
d) :math:`\sin F = -\dfrac{35}{37}`, :math:`\tan F = -\dfrac{35}{12}`
