Answers
================================================================================

**1)** a) :math:`A = 8\degree` b) :math:`B = 65\degree`
c) :math:`C = 47\degree`

**2)** :math:`\sin 315\degree = -\dfrac{1}{\sqrt{2}}`
:math:`\cos 315\degree = \dfrac{1}{\sqrt{2}}`
:math:`\tan 315\degree = -1`
:math:`\csc 315\degree = -\sqrt{2}`
:math:`\sec 315\degree = \sqrt{2}`
:math:`\cot 315\degree = -1`

**3)** a) :math:`42\degree` b) :math:`53\degree` c) :math:`63\degree`
d) :math:`41\degree` e) no solution f) no solution

**4)** a) :math:`135\degree` and :math:`225\degree`
b) :math:`135\degree` and :math:`315\degree`
c) :math:`19\degree` and :math:`161\degree`

**5)** a) :math:`\sin\theta = \dfrac{12}{13}`,
:math:`\cos\theta = -\dfrac{5}{13}`, :math:`\tan\theta = -\dfrac{12}{5}`,
:math:`\csc\theta = \dfrac{13}{12}`, :math:`\sec\theta = -\dfrac{13}{5}`,
:math:`\cot\theta = -\dfrac{5}{12}`

b) :math:`\sin\theta = \dfrac{40}{41}`, :math:`\cos\theta = \dfrac{9}{41}`,
:math:`\tan\theta = \dfrac{40}{9}`, :math:`\csc\theta = \dfrac{41}{40}`,
:math:`\sec\theta = \dfrac{41}{9}`, :math:`\cot\theta = \dfrac{9}{40}`

c) :math:`\sin\theta = -\dfrac{3}{\sqrt{34}}`,
:math:`\cos\theta = \dfrac{5}{\sqrt{34}}`,
:math:`\tan\theta = -\dfrac{3}{5}`,
:math:`\csc\theta = -\dfrac{\sqrt{34}}{3}`,
:math:`\sec\theta = \dfrac{\sqrt{34}}{5}`,
:math:`\cot\theta = -\dfrac{5}{3}`
