In this section, you will learn how to identify different angles that have
the same trigonometric ratio, as well as learn how they are related.

To do this you will have to visualize the terminal arm rotating around a
circle centred at the origin of a grid with a radius of :math:`r`. This is
done so that we can extend our understanding of trig functions for a
broader class of angles and see how different angles are related.

`www.mathsisfun.com/geometry/unit-circle.html <https://www.mathsisfun.com/geometry/unit-circle.html>`_

Some helpful reminders:

.. list-table::
   :widths: 40 60
   :width: 100%

   * - For any point :math:`P(x,y)` in the Cartesian plane, the
       trigonometric ratios for angles in standard position can be
       expressed in terms of :math:`x`, :math:`y`, and :math:`r`.

       :math:`\sin\theta =` :solmath:`\dfrac{y}{r}`

       :math:`\cos\theta =` :solmath:`\dfrac{x}{r}`

       :math:`\tan\theta =` :solmath:`\dfrac{y}{x}`
     - .. image:: ../images/mau5lesson03-gpimage01.png
          :scale: 75

.. image:: ../images/mau5lesson03-gpimage02.png
   :scale: 75

.. list-table::
   :widths: 40 60
   :width: 100%

   * - For any point :math:`P(x,y)` in the Cartesian plane that
       intersects the **unit circle**, the trigonometric ratios for
       angles can be expressed in terms of :math:`x`, :math:`y`, and
       :math:`r`.

       :math:`\sin\theta =` :solmath:`\dfrac{y}{1} = y`

       :math:`\cos\theta =` :solmath:`\dfrac{x}{1} = x`

       :math:`\tan\theta =` :solmath:`\dfrac{y}{x}`
     - .. image:: ../images/mau5lesson03-gpimage03.png
          :scale: 75

We know the :math:`x`-coordinate of where the terminal arm intersects the
unit circle is equivalent to the cosine ratio and the :math:`y`-coordinate
is equivalent to the sine ratio.

Notice that both :math:`45\degree` and :math:`135\degree` have the same
:sol:`reference angle`. Since the angles fall in quadrants :sol:`1` and
:sol:`2` respectively, they will have the exact same :math:`y`-coordinate
but the :math:`x`-coordinates will have the same absolute value but will
be opposite signs.

.. image:: ../images/mau5lesson03-gpimage04.png
   :scale: 80

:math:`\sin 135\degree =`
:solmath:`\sin 45\degree = \dfrac{1}{\sqrt{2}} = \dfrac{\sqrt{2}}{2}`

The important takeaway from this is that there are :sol:`2 angles` between
:math:`0\degree` and :math:`360\degree` that have the exact same ratio.
Using reference angles and the CAST rule, we can make sure to always find
both possible angles between :math:`0\degree` and :math:`360\degree` that
have the same trigonometric ratio.

**Example 2:** The point :math:`(-7,19)` lies on the terminal arm. Find
the angle to the terminal arm (principal angle, :math:`\theta`) and find
the related acute angle (reference angle, :math:`\beta`).

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: solution

       :math:`\beta = \tan^{-1}\left(\dfrac{19}{7}\right)`

       .. rst-class:: solution

       :math:`\beta \approx 70\degree`

       .. rst-class:: solution

       :math:`\theta = 180\degree - 70\degree`

       .. rst-class:: solution

       :math:`\theta \approx 110\degree`

**Example 3:** The point :math:`P(5,11)` lies on the terminal arm of
angle :math:`\theta`, in standard position. Draw a sketch of angle
:math:`\theta`, determine the exact value of :math:`r`, determine the
primary trig ratios for angle :math:`\theta`, then calculate
:math:`\theta` to the nearest tenth of a degree.

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: solution

       :math:`5^2 + 11^2 = r^2`

       .. rst-class:: solution

       :math:`r^2 = 146`

       .. rst-class:: solution

       :math:`r = \sqrt{146}`

       .. rst-class:: solution

       :math:`\sin\theta = \dfrac{11}{\sqrt{146}}`

       .. rst-class:: solution

       :math:`\cos\theta = \dfrac{5}{\sqrt{146}}`

       .. rst-class:: solution

       :math:`\tan\theta = \dfrac{11}{5}`

       .. rst-class:: solution

       :math:`\theta = \tan^{-1}\left(\dfrac{11}{5}\right)`

       .. rst-class:: solution

       :math:`\theta \approx 65.6\degree`
     - .. image:: ../images/mau5lesson03-gpimage08.png
          :scale: 75

**Example 4:** Solve the following equation for
:math:`0\degree \leq \theta \leq 360\degree`.

:math:`3\cos\theta + 1 = 0`

.. rst-class:: solution

:math:`\cos\theta = -\dfrac{1}{3}`

.. rst-class:: solution

:math:`\theta_1 = \cos^{-1}\left(-\dfrac{1}{3}\right)`

.. rst-class:: solution

:math:`\theta_1 \approx 109.5\degree`

.. rst-class:: solution

:math:`\theta_2 = 360\degree - 109.5\degree`

.. rst-class:: solution

:math:`\theta_2 \approx 250.5\degree`
