Partie 1 : Révision de la trigonométrie
================================================================================

Le principal concept à retenir de la trigonométrie de 10e année devrait être :

Si l'on sait qu'un triangle rectangle a un angle de :math:`\theta`, tous les
autres triangles rectangles ayant un angle de :math:`\theta` sont

.. rst-class:: solution

**SEMBLABLES**

et ont donc des rapports

.. rst-class:: solution

**ÉQUIVALENTS**

des côtés correspondants.

Il existe trois rapports trigonométriques primaires pour les triangles
rectangles.

.. rst-class:: solution

**Sinus, Cosinus,** et **Tangente**.

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. image:: ../images/mau5lesson01-gpimage01-fr.png
          :scale: 85
     - .. rst-class:: solution

       :math:`\sin\theta = \dfrac{opposé}{hypoténuse}`

       .. rst-class:: solution

       :math:`\cos\theta = \dfrac{adjacent}{hypoténuse}`

       .. rst-class:: solution

       :math:`\tan\theta = \dfrac{opposé}{adjacent}`

**Acronyme :** SOHCAHTOA — **S** O/H, **C** A/H, **T** O/A

Partie 2 : Angles particuliers
================================================================================

Il existe 2 triangles particuliers :

i\) isocèle : 45° - 45° - 90°

ii\) demi-équilatéral : 30° - 60° - 90°

.. list-table::
   :widths: 40 60
   :width: 100%

   * - .. image:: ../images/mau5lesson01-gpimage04.png
          :scale: 80
     - .. rst-class:: solution

       :math:`\sin 45\degree = \dfrac{1}{\sqrt{2}}`

       .. rst-class:: solution

       :math:`\cos 45\degree = \dfrac{1}{\sqrt{2}}`

       .. rst-class:: solution

       :math:`\tan 45\degree = \dfrac{1}{1} = 1`

.. list-table::
   :widths: 40 30 30
   :width: 100%

   * - .. image:: ../images/mau5lesson01-gpimage05.png
          :scale: 80
     - .. rst-class:: solution

       :math:`\sin 30\degree = \dfrac{1}{2}`

       .. rst-class:: solution

       :math:`\cos 30\degree = \dfrac{\sqrt{3}}{2}`

       .. rst-class:: solution

       :math:`\tan 30\degree = \dfrac{1}{\sqrt{3}}`
     - .. rst-class:: solution

       :math:`\sin 60\degree = \dfrac{\sqrt{3}}{2}`

       .. rst-class:: solution

       :math:`\cos 60\degree = \dfrac{1}{2}`

       .. rst-class:: solution

       :math:`\tan 60\degree = \dfrac{\sqrt{3}}{1} = \sqrt{3}`

Tous les triangles rectangles de ces angles, quelle que soit leur taille,
sont semblables et auront donc les mêmes rapports des côtés correspondants.
Nous pouvons donc utiliser ces 2 triangles particuliers pour obtenir des
valeurs

.. rst-class:: solution

**EXACTES**

pour les rapports trigonométriques impliquant un angle de référence de 30°,
45° ou 60° ET nous n'avons pas besoin de calculatrice!

.. rst-class:: keepwithnext

**Exemple 2 :** Utilise les triangles particuliers pour déterminer les
valeurs EXACTES de tous les côtés et angles

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       a\)

       .. image:: ../images/mau5lesson01-gpimage06.png
          :scale: 85

       .. rst-class:: solution

       :math:`\tan 45\degree = \dfrac{y}{4} \Rightarrow 1 = \dfrac{y}{4}
       \Rightarrow y = 4`

       .. rst-class:: solution

       :math:`\cos 45\degree = \dfrac{4}{r} \Rightarrow \dfrac{1}{\sqrt{2}}
       = \dfrac{4}{r} \Rightarrow r = 4\sqrt{2}`
     - .. rst-class:: keepwithnext

       b\)

       .. image:: ../images/mau5lesson01-gpimage07.png
          :scale: 85

       .. rst-class:: solution

       :math:`\tan 60\degree = \dfrac{3\sqrt{3}}{y} \Rightarrow \sqrt{3} =
       \dfrac{3\sqrt{3}}{y} \Rightarrow y = \dfrac{3\sqrt{3}}{\sqrt{3}}
       \Rightarrow y = 3`

       .. rst-class:: solution

       :math:`\sin 60\degree = \dfrac{3\sqrt{3}}{r} \Rightarrow
       \dfrac{\sqrt{3}}{2} = \dfrac{3\sqrt{3}}{r} \Rightarrow r\sqrt{3} =
       6\sqrt{3} \Rightarrow r = 6`

**Exemple 3 :** Détermine la valeur exacte de...

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       a\) :math:`(\sin 45\degree)(\cos 45\degree) + (\sin 30\degree)(\sin
       60\degree)`

       .. rst-class:: solution

       :math:`= \left(\dfrac{1}{\sqrt{2}}\right)\left(\dfrac{1}{\sqrt{2}}
       \right) + \left(\dfrac{1}{2}\right)\left(\dfrac{\sqrt{3}}{2}\right)`

       .. rst-class:: solution

       :math:`= \dfrac{1}{2} + \dfrac{\sqrt{3}}{4}`

       .. rst-class:: solution

       :math:`= \dfrac{2}{4} + \dfrac{\sqrt{3}}{4}`

       .. rst-class:: solution

       :math:`= \dfrac{2+\sqrt{3}}{4}`
     - .. rst-class:: keepwithnext

       b\) :math:`\dfrac{\sin^2 30\degree}{1-\cos 30\degree}`

       .. rst-class:: solution

       :math:`= \dfrac{(\sin 30\degree)(\sin 30\degree)}{1-\cos 30\degree}`

       .. rst-class:: solution

       :math:`= \dfrac{\left(\frac{1}{2}\right)\left(\frac{1}{2}\right)}
       {1-\frac{\sqrt{3}}{2}}`

       .. rst-class:: solution

       :math:`= \dfrac{\frac{1}{4}}{\frac{2-\sqrt{3}}{2}} = \dfrac{1}{4}
       \times \dfrac{2}{2-\sqrt{3}}`

       .. rst-class:: solution

       :math:`= \dfrac{1}{2(2-\sqrt{3})} = \dfrac{1}{4-2\sqrt{3}}`

Partie 3 : Rationalisation du dénominateur
================================================================================

*Les fractions doivent être simplifiées de façon à ce que le dénominateur ne
contienne que des nombres rationnels.*

.. rst-class:: keepwithnext

**Exemple 4 :** Rationalise le dénominateur de chacune des expressions
suivantes

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       a\) :math:`\dfrac{1}{\sqrt{2}} \times \dfrac{\sqrt{2}}{\sqrt{2}}`

       .. rst-class:: solution

       :math:`= \dfrac{\sqrt{2}}{\sqrt{4}}`

       .. rst-class:: solution

       :math:`= \dfrac{\sqrt{2}}{2}`
     - .. rst-class:: keepwithnext

       b\) :math:`\dfrac{3}{1+\sqrt{5}} \times \dfrac{1-\sqrt{5}}
       {1-\sqrt{5}}` (en multipliant par le « conjugué »)

       .. rst-class:: solution

       :math:`= \dfrac{3(1-\sqrt{5})}{(1)^2-(\sqrt{5})^2}`

       .. rst-class:: solution

       :math:`= \dfrac{3-3\sqrt{5}}{1-5}`

       .. rst-class:: solution

       :math:`= \dfrac{3-3\sqrt{5}}{-4} = \dfrac{-3+3\sqrt{5}}{4}`
