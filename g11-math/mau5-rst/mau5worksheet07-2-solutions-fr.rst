**14)** :math:`\dfrac{\sec\theta+1}{\sec\theta-1} + \dfrac{\cos\theta+1}{\cos\theta-1} = 0`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - MG

       .. rst-class:: solution

       :math:`= \dfrac{\sec\theta+1}{\sec\theta-1} + \dfrac{\cos\theta+1}{\cos\theta-1}`

       .. rst-class:: solution

       :math:`= \dfrac{\left(\dfrac{1}{\cos\theta}+1\right)}{\left(\dfrac{1}{\cos\theta}-1\right)} +
       \dfrac{\cos\theta+1}{\cos\theta-1}`

       .. rst-class:: solution

       :math:`= \dfrac{1+\cos\theta}{1-\cos\theta} + \dfrac{\cos\theta+1}{\cos\theta-1}`

       .. rst-class:: solution

       :math:`= \dfrac{1+\cos\theta}{1-\cos\theta} + \dfrac{(-1)(\cos\theta+1)}{(-1)(\cos\theta-1)}`

       .. rst-class:: solution

       :math:`= \dfrac{1+\cos\theta}{1-\cos\theta} - \dfrac{\cos\theta+1}{1-\cos\theta}`

       .. rst-class:: solution

       :math:`= \dfrac{1+\cos\theta-\cos\theta-1}{1-\cos\theta}`

       .. rst-class:: solution

       :math:`= \dfrac{0}{1-\cos\theta}`

       .. rst-class:: solution

       :math:`= 0`
     - MD

       .. rst-class:: solution

       :math:`= 0`

:sol:`MG = MD`

**15)** :math:`\dfrac{\csc\theta}{\csc\theta-1} + \dfrac{\csc\theta}{\csc\theta+1} = 2\sec^2\theta`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - MG

       .. rst-class:: solution

       :math:`= \dfrac{\csc\theta}{\csc\theta-1} + \dfrac{\csc\theta}{\csc\theta+1}`

       .. rst-class:: solution

       :math:`= \dfrac{\left(\dfrac{1}{\sin\theta}\right)}{\left(\dfrac{1}{\sin\theta}-\sin\theta\right)}
       + \dfrac{\left(\dfrac{1}{\sin\theta}\right)}{\left(\dfrac{1}{\sin\theta}+\sin\theta\right)}`

       .. rst-class:: solution

       :math:`= \dfrac{\left(\dfrac{1}{\sin\theta}\right)}{\left(\dfrac{1-\sin\theta}{\sin\theta}\right)}
       + \dfrac{\left(\dfrac{1}{\sin\theta}\right)}{\left(\dfrac{1+\sin\theta}{\sin\theta}\right)}`

       .. rst-class:: solution

       :math:`= \left(\dfrac{1}{\sin\theta}\right)\left(\dfrac{\sin\theta}{1-\sin\theta}\right)
       + \left(\dfrac{1}{\sin\theta}\right)\left(\dfrac{\sin\theta}{1+\sin\theta}\right)`

       .. rst-class:: solution

       :math:`= \dfrac{1}{1-\sin\theta} + \dfrac{1}{1+\sin\theta}`

       .. rst-class:: solution

       :math:`= \dfrac{(1+\sin\theta)+(1-\sin\theta)}{(1-\sin\theta)(1+\sin\theta)}`

       .. rst-class:: solution

       :math:`= \dfrac{2}{1-\sin^2\theta}`

       .. rst-class:: solution

       :math:`= \dfrac{2}{\cos^2\theta}`
     - MD

       .. rst-class:: solution

       :math:`= 2\sec^2\theta`

       .. rst-class:: solution

       :math:`= 2\left(\dfrac{1}{\cos^2\theta}\right)`

       .. rst-class:: solution

       :math:`= \dfrac{2}{\cos^2\theta}`

:sol:`MG = MD`
