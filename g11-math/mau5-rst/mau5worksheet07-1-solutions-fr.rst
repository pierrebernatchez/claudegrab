**1)** Prouve chaque identité

.. rst-class:: keepwithnext

a\) :math:`\sin\theta = \cos\theta\tan\theta`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - MG

       .. rst-class:: solution

       :math:`= \sin\theta`
     - MD

       .. rst-class:: solution

       :math:`= \cos\theta\tan\theta`

       .. rst-class:: solution

       :math:`= \cos\theta\left(\dfrac{\sin\theta}{\cos\theta}\right)`

       .. rst-class:: solution

       :math:`= \sin\theta`

:sol:`MG = MD`

.. rst-class:: keepwithnext

b\) :math:`\csc\theta = \sec\theta\cot\theta`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - MG

       .. rst-class:: solution

       :math:`= \csc\theta`

       .. rst-class:: solution

       :math:`= \dfrac{1}{\sin\theta}`
     - MD

       .. rst-class:: solution

       :math:`= \sec\theta\cot\theta`

       .. rst-class:: solution

       :math:`= \dfrac{1}{\cos\theta}\left(\dfrac{1}{\tan\theta}\right)`

       .. rst-class:: solution

       :math:`= \dfrac{1}{\cos\theta}\left(\dfrac{\sin\theta}{\cos\theta}\right)`

       .. rst-class:: solution

       :math:`= \dfrac{1}{\cos\theta}\left(\dfrac{\cos\theta}{\sin\theta}\right)`

       .. rst-class:: solution

       :math:`= \dfrac{1}{\sin\theta}`

:sol:`MG = MD`

**2)** Prouve chaque identité

.. rst-class:: keepwithnext

a\) :math:`1+\csc\theta = \csc\theta(1+\sin\theta)`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - MG

       .. rst-class:: solution

       :math:`= 1+\csc\theta`
     - MD

       .. rst-class:: solution

       :math:`= \csc\theta(1+\sin\theta)`

       .. rst-class:: solution

       :math:`= \csc\theta + \csc\theta\sin\theta`

       .. rst-class:: solution

       :math:`= \csc\theta + \left(\dfrac{1}{\sin\theta}\right)\sin\theta`

       .. rst-class:: solution

       :math:`= \csc\theta + 1`

:sol:`MG = MD`

.. rst-class:: keepwithnext

b\) :math:`\cot\theta\sin\theta\sec\theta = 1`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - MG

       .. rst-class:: solution

       :math:`= \cot\theta\sin\theta\sec\theta`

       .. rst-class:: solution

       :math:`= \left(\dfrac{\cos\theta}{\sin\theta}\right)\sin\theta\left(\dfrac{1}{\cos\theta}\right)`

       .. rst-class:: solution

       :math:`= \dfrac{\cos\theta}{\cos\theta}`

       .. rst-class:: solution

       :math:`= 1`
     - MD

       .. rst-class:: solution

       :math:`= 1`

:sol:`MG = MD`

.. rst-class:: keepwithnext

c\) :math:`\cos\theta(\sec\theta-1) = 1-\cos\theta`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - MG

       .. rst-class:: solution

       :math:`= \cos\theta(\sec\theta-1)`

       .. rst-class:: solution

       :math:`= \cos\theta\sec\theta - \cos\theta`

       .. rst-class:: solution

       :math:`= \cos\theta\left(\dfrac{1}{\cos\theta}\right) - \cos\theta`

       .. rst-class:: solution

       :math:`= 1-\cos\theta`
     - MD

       .. rst-class:: solution

       :math:`= 1-\cos\theta`

:sol:`MG = MD`

.. rst-class:: keepwithnext

d\) :math:`1+\sin\theta = \sin\theta(1+\csc\theta)`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - MG

       .. rst-class:: solution

       :math:`= 1+\sin\theta`
     - MD

       .. rst-class:: solution

       :math:`= \sin\theta(1+\csc\theta)`

       .. rst-class:: solution

       :math:`= \sin\theta + \sin\theta\csc\theta`

       .. rst-class:: solution

       :math:`= \sin\theta + \sin\theta\left(\dfrac{1}{\sin\theta}\right)`

       .. rst-class:: solution

       :math:`= \sin\theta + 1`

:sol:`MG = MD`

**3)** Prouve que :math:`1-\sin^2\theta = \sin\theta\cos\theta\cot\theta`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - MG

       .. rst-class:: solution

       :math:`= 1-\sin^2\theta`

       .. rst-class:: solution

       :math:`= \sin^2\theta+\cos^2\theta-\sin^2\theta`

       .. rst-class:: solution

       :math:`= \cos^2\theta`
     - MD

       .. rst-class:: solution

       :math:`= \sin\theta\cos\theta\cot\theta`

       .. rst-class:: solution

       :math:`= \sin\theta\cos\theta\left(\dfrac{\cos\theta}{\sin\theta}\right)`

       .. rst-class:: solution

       :math:`= \cos^2\theta`

:sol:`MG = MD`

.. rst-class:: keepwithnext

**4)** Prouve que :math:`\csc^2\theta = \cot^2\theta+1`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - MG

       .. rst-class:: solution

       :math:`= \csc^2\theta`

       .. rst-class:: solution

       :math:`= \dfrac{1}{\sin^2\theta}`
     - MD

       .. rst-class:: solution

       :math:`= \cot^2\theta+1`

       .. rst-class:: solution

       :math:`= \dfrac{\cos^2\theta}{\sin^2\theta} + \dfrac{\sin^2\theta}{\sin^2\theta}`

       .. rst-class:: solution

       :math:`= \dfrac{\cos^2\theta+\sin^2\theta}{\sin^2\theta}`

       .. rst-class:: solution

       :math:`= \dfrac{1}{\sin^2\theta}`

:sol:`MG = MD`

.. rst-class:: keepwithnext

**5)** Prouve que :math:`\dfrac{\cos\theta}{1+\sin\theta} = \dfrac{1-\sin\theta}{\cos\theta}`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - MG

       .. rst-class:: solution

       :math:`= \dfrac{\cos\theta}{1+\sin\theta}`

       .. rst-class:: solution

       :math:`= \dfrac{\cos\theta}{1+\sin\theta}\times\dfrac{1-\sin\theta}{1-\sin\theta}`

       .. rst-class:: solution

       :math:`= \dfrac{\cos\theta(1-\sin\theta)}{1-\sin^2\theta}`

       .. rst-class:: solution

       :math:`= \dfrac{\cos\theta(1-\sin\theta)}{\cos^2\theta}`

       .. rst-class:: solution

       :math:`= \dfrac{1-\sin\theta}{\cos\theta}`
     - MD

       .. rst-class:: solution

       :math:`= \dfrac{1-\sin\theta}{\cos\theta}`

:sol:`MG = MD`

.. rst-class:: keepwithnext

**6)** Prouve que :math:`\dfrac{\cos\theta}{1-\sin\theta} + \dfrac{\cos\theta}{1+\sin\theta} = \dfrac{2}{\cos\theta}`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - MG

       .. rst-class:: solution

       :math:`= \dfrac{\cos\theta}{1-\sin\theta} + \dfrac{\cos\theta}{1+\sin\theta}`

       .. rst-class:: solution

       :math:`= \dfrac{\cos\theta(1+\sin\theta)+\cos\theta(1-\sin\theta)}{(1-\sin\theta)(1+\sin\theta)}`

       .. rst-class:: solution

       :math:`= \dfrac{\cos\theta+\cos\theta\sin\theta+\cos\theta-\cos\theta\sin\theta}{1-\sin^2\theta}`

       .. rst-class:: solution

       :math:`= \dfrac{2\cos\theta}{\cos^2\theta}`

       .. rst-class:: solution

       :math:`= \dfrac{2}{\cos\theta}`
     - MD

       .. rst-class:: solution

       :math:`= \dfrac{2}{\cos\theta}`

:sol:`MG = MD`

**7)** Prouve que :math:`\csc^2\theta\cos^2\theta = \csc^2\theta - 1`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - MG

       .. rst-class:: solution

       :math:`= \csc^2\theta\cos^2\theta`

       .. rst-class:: solution

       :math:`= \dfrac{1}{\sin^2\theta}\left(\cos^2\theta\right)`

       .. rst-class:: solution

       :math:`= \dfrac{\cos^2\theta}{\sin^2\theta}`
     - MD

       .. rst-class:: solution

       :math:`= \csc^2\theta-1`

       .. rst-class:: solution

       :math:`= \dfrac{1}{\sin^2\theta} - \dfrac{\sin^2\theta}{\sin^2\theta}`

       .. rst-class:: solution

       :math:`= \dfrac{1-\sin^2\theta}{\sin^2\theta}`

       .. rst-class:: solution

       :math:`= \dfrac{\cos^2\theta}{\sin^2\theta}`

:sol:`MG = MD`

**8)** Prouve que :math:`\tan^2\theta - \sin^2\theta = \sin^2\theta\tan^2\theta`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - MG

       .. rst-class:: solution

       :math:`= \tan^2\theta - \sin^2\theta`

       .. rst-class:: solution

       :math:`= \dfrac{\sin^2\theta}{\cos^2\theta} - \dfrac{\sin^2\theta\cos^2\theta}{\cos^2\theta}`

       .. rst-class:: solution

       :math:`= \dfrac{\sin^2\theta(1-\cos^2\theta)}{\cos^2\theta}`

       .. rst-class:: solution

       :math:`= \tan^2\theta(1-\cos^2\theta)`

       .. rst-class:: solution

       :math:`= \tan^2\theta\sin^2\theta`
     - MD

       .. rst-class:: solution

       :math:`= \sin^2\theta\tan^2\theta`

:sol:`MG = MD`
