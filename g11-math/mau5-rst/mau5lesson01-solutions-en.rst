Part 1: Trig Review
================================================================================

Your main takeaway from grade 10 trigonometry should have been:

If we know a right triangle has an angle of :math:`\theta`, all other right
triangles with an angle of :math:`\theta` are

.. rst-class:: solution

**SIMILAR**

and therefore have

.. rst-class:: solution

**EQUIVALENT**

ratios of corresponding sides.

There are three primary trigonometric ratios for right angled triangles.

.. rst-class:: solution

**Sine, Cosine,** and **Tangent**.

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. image:: ../images/mau5lesson01-gpimage01.png
          :scale: 85
     - .. rst-class:: solution

       :math:`\sin\theta = \dfrac{opposite}{hypotenuse}`

       .. rst-class:: solution

       :math:`\cos\theta = \dfrac{adjacent}{hypotenuse}`

       .. rst-class:: solution

       :math:`\tan\theta = \dfrac{opposite}{adjacent}`

**Acronym:** SOHCAHTOA — **S** O/H, **C** A/H, **T** O/A

Part 2: Special Angles
================================================================================

There are 2 special triangles:

i\) isosceles: 45° - 45° - 90°

ii\) half equilateral: 30° - 60° - 90°

.. list-table::
   :widths: 40 60
   :width: 100%

   * - .. image:: ../images/mau5lesson01-gpimage04.png
          :scale: 80
     - .. rst-class:: solution

       :math:`\sin 45\degree = \dfrac{1}{\sqrt{2}}`

       .. rst-class:: solution

       :math:`\cos 45\degree = \dfrac{1}{\sqrt{2}}`

       .. rst-class:: solution

       :math:`\tan 45\degree = \dfrac{1}{1} = 1`

.. list-table::
   :widths: 40 30 30
   :width: 100%

   * - .. image:: ../images/mau5lesson01-gpimage05.png
          :scale: 80
     - .. rst-class:: solution

       :math:`\sin 30\degree = \dfrac{1}{2}`

       .. rst-class:: solution

       :math:`\cos 30\degree = \dfrac{\sqrt{3}}{2}`

       .. rst-class:: solution

       :math:`\tan 30\degree = \dfrac{1}{\sqrt{3}}`
     - .. rst-class:: solution

       :math:`\sin 60\degree = \dfrac{\sqrt{3}}{2}`

       .. rst-class:: solution

       :math:`\cos 60\degree = \dfrac{1}{2}`

       .. rst-class:: solution

       :math:`\tan 60\degree = \dfrac{\sqrt{3}}{1} = \sqrt{3}`

All sized right triangles with these angles are similar and therefore will
have the same ratios of corresponding sides. Therefore, we can use these 2
special triangles to get

.. rst-class:: solution

**EXACT**

values for trig ratios involving a 30°, 45°, or 60° reference angle AND we
don't need a calculator!

.. rst-class:: keepwithnext

**Example 2:** Use special triangles to find the EXACT values of all sides
and angles

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       a\)

       .. image:: ../images/mau5lesson01-gpimage06.png
          :scale: 85

       .. rst-class:: solution

       :math:`\tan 45\degree = \dfrac{y}{4} \Rightarrow 1 = \dfrac{y}{4}
       \Rightarrow y = 4`

       .. rst-class:: solution

       :math:`\cos 45\degree = \dfrac{4}{r} \Rightarrow \dfrac{1}{\sqrt{2}}
       = \dfrac{4}{r} \Rightarrow r = 4\sqrt{2}`
     - .. rst-class:: keepwithnext

       b\)

       .. image:: ../images/mau5lesson01-gpimage07.png
          :scale: 85

       .. rst-class:: solution

       :math:`\tan 60\degree = \dfrac{3\sqrt{3}}{y} \Rightarrow \sqrt{3} =
       \dfrac{3\sqrt{3}}{y} \Rightarrow y = \dfrac{3\sqrt{3}}{\sqrt{3}}
       \Rightarrow y = 3`

       .. rst-class:: solution

       :math:`\sin 60\degree = \dfrac{3\sqrt{3}}{r} \Rightarrow
       \dfrac{\sqrt{3}}{2} = \dfrac{3\sqrt{3}}{r} \Rightarrow r\sqrt{3} =
       6\sqrt{3} \Rightarrow r = 6`

.. rst-class:: keepwithnext

**Example 3:** Determine the exact value of...

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       a\) :math:`(\sin 45\degree)(\cos 45\degree) + (\sin 30\degree)(\sin
       60\degree)`

       .. rst-class:: solution

       :math:`= \left(\dfrac{1}{\sqrt{2}}\right)\left(\dfrac{1}{\sqrt{2}}
       \right) + \left(\dfrac{1}{2}\right)\left(\dfrac{\sqrt{3}}{2}\right)`

       .. rst-class:: solution

       :math:`= \dfrac{1}{2} + \dfrac{\sqrt{3}}{4}`

       .. rst-class:: solution

       :math:`= \dfrac{2}{4} + \dfrac{\sqrt{3}}{4}`

       .. rst-class:: solution

       :math:`= \dfrac{2+\sqrt{3}}{4}`
     - .. rst-class:: keepwithnext

       b\) :math:`\dfrac{\sin^2 30\degree}{1-\cos 30\degree}`

       .. rst-class:: solution

       :math:`= \dfrac{(\sin 30\degree)(\sin 30\degree)}{1-\cos 30\degree}`

       .. rst-class:: solution

       :math:`= \dfrac{\left(\frac{1}{2}\right)\left(\frac{1}{2}\right)}
       {1-\frac{\sqrt{3}}{2}}`

       .. rst-class:: solution

       :math:`= \dfrac{\frac{1}{4}}{\frac{2-\sqrt{3}}{2}} = \dfrac{1}{4}
       \times \dfrac{2}{2-\sqrt{3}}`

       .. rst-class:: solution

       :math:`= \dfrac{1}{2(2-\sqrt{3})} = \dfrac{1}{4-2\sqrt{3}}`

Part 3: Rationalizing the Denominator
================================================================================

*Fractions should be simplified so that the denominator contains only
rational numbers.*

.. rst-class:: keepwithnext

**Example 4:** Rationalize the denominator for each of the following
expressions

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       a\) :math:`\dfrac{1}{\sqrt{2}} \times \dfrac{\sqrt{2}}{\sqrt{2}}`

       .. rst-class:: solution

       :math:`= \dfrac{\sqrt{2}}{\sqrt{4}}`

       .. rst-class:: solution

       :math:`= \dfrac{\sqrt{2}}{2}`
     - .. rst-class:: keepwithnext

       b\) :math:`\dfrac{3}{1+\sqrt{5}} \times \dfrac{1-\sqrt{5}}
       {1-\sqrt{5}}` (multiplying by the "conjugate")

       .. rst-class:: solution

       :math:`= \dfrac{3(1-\sqrt{5})}{(1)^2-(\sqrt{5})^2}`

       .. rst-class:: solution

       :math:`= \dfrac{3-3\sqrt{5}}{1-5}`

       .. rst-class:: solution

       :math:`= \dfrac{3-3\sqrt{5}}{-4} = \dfrac{-3+3\sqrt{5}}{4}`
