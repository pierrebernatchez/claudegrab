**8)** Le bras d'une grue mesure 20 m de longueur. L'angle
d'inclinaison de la flèche de la grue a une valeur minimale de 45° et
une valeur maximale de 60°.

.. rst-class:: keepwithnext

**a)** Détermine une valeur exacte pour le déplacement vertical de la
flèche de la grue lorsqu'elle passe de son inclinaison minimale à son
inclinaison maximale.

.. image:: ../images/mau5review08-gpimage07.png
   :align: center

.. image:: ../images/mau5review08-gpimage08.png
   :align: center

.. rst-class:: solution

:math:`\sin 45^\circ = \dfrac{y_1}{20} \Rightarrow \dfrac{1}{\sqrt{2}} =
\dfrac{y_1}{20} \Rightarrow y_1 = \dfrac{20}{\sqrt{2}}\left(\dfrac{\sqrt{2}}{\sqrt{2}}\right)
= \dfrac{20\sqrt{2}}{2} = 10\sqrt{2}`

.. rst-class:: solution

:math:`\sin 60^\circ = \dfrac{y_2}{20} \Rightarrow \dfrac{\sqrt{3}}{2} =
\dfrac{y_2}{20} \Rightarrow y_2 = \dfrac{20\sqrt{3}}{2} = 10\sqrt{3}`

.. rst-class:: solution

déplacement vertical :math:`= y_2 - y_1 = 10\sqrt{3} - 10\sqrt{2} =
10(\sqrt{3}-\sqrt{2})` m

.. rst-class:: keepwithnext

**b)** Détermine la valeur de ce déplacement vertical au dixième de
mètre près.

.. rst-class:: solution

déplacement vertical :math:`\approx 3.2` m

**16)** Jeremy a un nouveau viseur laser de golf qui lui donne la
distance en ligne directe jusqu'à tout objet sur lequel il pointe le
viseur. Depuis un tertre de départ surélevé, il utilise le viseur et
détermine que la distance en ligne directe jusqu'au vert est de 378 m.
Il détermine aussi que l'angle de dépression jusqu'au vert est de 52°.
Quelle est la hauteur du tertre de départ surélevé par rapport au
niveau du vert?

.. image:: ../images/mau5review08-gpimage19.png
   :align: center

.. rst-class:: solution

:math:`\cos 38^\circ = \dfrac{x}{378}`

.. rst-class:: solution

:math:`x = 378(\cos 38^\circ)`

.. rst-class:: solution

:math:`x \approx 298` m

.. rst-class:: keepwithnext

**17)** Un carrousel, d'un diamètre de 20 m, a 12 chevaux répartis à
distances égales sur la circonférence. Si les chevaux sont numérotés
dans l'ordre, quelle est la distance directe entre le deuxième cheval
et le quatrième?

.. image:: ../images/mau5review08-gpimage20.png
   :align: center

.. rst-class:: solution

:math:`\dfrac{360^\circ}{12} = 30^\circ`, donc l'angle entre deux
chevaux adjacents est de 30°, et entre le cheval 2 et le cheval 4, il
est de :math:`2 \times 30^\circ = 60^\circ`

.. rst-class:: solution

:math:`x^2 = 10^2 + 10^2 - 2(10)(10)\cos 60^\circ`

.. rst-class:: solution

:math:`x = 10` m

.. rst-class:: keepwithnext

**18)** L'angle entre le manche et la palette d'un bâton de hockey est
de 120°. Le manche mesure 1.5 m de longueur et la palette mesure 25 cm
de longueur. Détermine la distance en ligne directe entre le sommet du
manche et le bout de la palette.

.. image:: ../images/mau5review08-gpimage21.png
   :align: center

.. rst-class:: solution

:math:`x^2 = (1.5)^2 + (0.25)^2 - 2(1.5)(0.25)\cos 120^\circ`

.. rst-class:: solution

:math:`x^2 = 2.6875`

.. rst-class:: solution

:math:`x \approx 1.64` m, ou 164 cm

.. rst-class:: keepwithnext

**19)** Un câble de soutien jusqu'au sommet d'un arbre nouvellement
planté mesure 15 m de longueur. Il forme un angle de 30° avec le sol.
Du même côté de l'arbre, un deuxième câble est aussi attaché au sommet
de l'arbre, mais il forme un angle de 45° avec le sol. Détermine une
expression exacte de la distance entre les points où les deux câbles
de soutien sont attachés au sol.

.. image:: ../images/mau5review08-gpimage22.png
   :align: center

.. rst-class:: solution

Rappel :

.. image:: ../images/mau5review08-gpimage02.png
   :align: center

.. image:: ../images/mau5review08-gpimage01.png
   :align: center

.. rst-class:: solution

:math:`\sin 30^\circ = \dfrac{z}{15} \Rightarrow \dfrac{1}{2} =
\dfrac{z}{15} \Rightarrow \dfrac{15}{2} = z`

.. rst-class:: solution

:math:`\cos 30^\circ = \dfrac{y}{15} \Rightarrow \dfrac{\sqrt{3}}{2} =
\dfrac{y}{15} \Rightarrow \dfrac{15\sqrt{3}}{2} = y`

.. rst-class:: solution

:math:`\tan 45^\circ = \dfrac{(15/2)}{x} \Rightarrow \dfrac{1}{1} =
\dfrac{(15/2)}{x} \Rightarrow x = \dfrac{15}{2}`

.. rst-class:: solution

distance entre les câbles :math:`= y - x = \dfrac{15\sqrt{3}}{2} -
\dfrac{15}{2} = \dfrac{15(\sqrt{3}-1)}{2}` m, ou :math:`7.5(\sqrt{3}-1)`
m

.. rst-class:: keepwithnext

**a)** :math:`\sin^2 x(1+\cot^2 x) = 1`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - MG
     - MD
   * - .. rst-class:: solution

         :math:`= \sin^2 x(1+\cot^2 x)`

         .. rst-class:: solution

         :math:`= \sin^2 x + \sin^2 x\cot^2 x`

         .. rst-class:: solution

         :math:`= \sin^2 x + \sin^2 x\left(\dfrac{\cos^2 x}{\sin^2
         x}\right)`

         .. rst-class:: solution

         :math:`= \sin^2 x + \cos^2 x`

         .. rst-class:: solution

         :math:`= 1`
     - .. rst-class:: solution

         :math:`= 1`

:sol:`MG = MD`

.. rst-class:: keepwithnext

**b)** :math:`1-\cos^2 x = \tan x\cos x\sin x`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - MG
     - MD
   * - .. rst-class:: solution

         :math:`= 1-\cos^2 x`

         .. rst-class:: solution

         :math:`= \sin^2 x`
     - .. rst-class:: solution

         :math:`= \tan x\cos x\sin x`

         .. rst-class:: solution

         :math:`= \left(\dfrac{\sin x}{\cos x}\right)\cos x\sin x`

         .. rst-class:: solution

         :math:`= \sin^2 x`

:sol:`MG = MD`

.. rst-class:: keepwithnext

**c)** :math:`\cos x\tan^3 x = \sin x\tan^2 x`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - MG
     - MD
   * - .. rst-class:: solution

         :math:`= \cos x\tan^3 x`

         .. rst-class:: solution

         :math:`= \cos x\left(\dfrac{\sin^3 x}{\cos^3 x}\right)`

         .. rst-class:: solution

         :math:`= \dfrac{\sin^3 x}{\cos^2 x}`
     - .. rst-class:: solution

         :math:`= \sin x\tan^2 x`

         .. rst-class:: solution

         :math:`= \sin x\left(\dfrac{\sin^2 x}{\cos^2 x}\right)`

         .. rst-class:: solution

         :math:`= \dfrac{\sin^3 x}{\cos^2 x}`

:sol:`MG = MD`

**d)** :math:`1-2\cos^2\theta = \sin^4\theta - \cos^4\theta`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - MG
     - MD
   * - .. rst-class:: solution

         :math:`= 1-2\cos^2\theta`
     - .. rst-class:: solution

         :math:`= \sin^4\theta - \cos^4\theta`

         .. rst-class:: solution

         :math:`= (\sin^2\theta-\cos^2\theta)(\sin^2\theta+\cos^2\theta)`

         .. rst-class:: solution

         :math:`= (\sin^2\theta-\cos^2\theta)(1)`

         .. rst-class:: solution

         :math:`= \sin^2\theta - \cos^2\theta`
