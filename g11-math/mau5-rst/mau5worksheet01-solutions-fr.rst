**4)** Détermine la valeur exacte de chaque expression trigonométrique.

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       a\) :math:`\sin 30\degree \times \tan 60\degree - \cos 30\degree`

       .. rst-class:: solution

       :math:`= \dfrac{1}{2} \times \sqrt{3} - \dfrac{\sqrt{3}}{2}`

       .. rst-class:: solution

       :math:`= \dfrac{\sqrt{3}}{2} - \dfrac{\sqrt{3}}{2}`

       .. rst-class:: solution

       :math:`= 0`
     - .. rst-class:: keepwithnext

       b\) :math:`1 - \dfrac{\sin 45\degree}{\cos 45\degree}`

       .. rst-class:: solution

       :math:`= 1 - \dfrac{\left(\frac{1}{\sqrt{2}}\right)}
       {\left(\frac{1}{\sqrt{2}}\right)}`

       .. rst-class:: solution

       :math:`= 1 - 1`

       .. rst-class:: solution

       :math:`= 0`

**5)** En utilisant les valeurs exactes, démontre que
:math:`\sin^2\theta + \cos^2\theta = 1` pour chaque angle

.. list-table::
   :widths: 33 33 34
   :width: 100%

   * - .. rst-class:: keepwithnext

       a\) :math:`\theta = 30\degree`

       .. rst-class:: solution

       :math:`\sin^2(30) + \cos^2(30) = 1`

       .. rst-class:: solution

       :math:`\left(\dfrac{1}{2}\right)^2 +
       \left(\dfrac{\sqrt{3}}{2}\right)^2 = 1`

       .. rst-class:: solution

       :math:`\dfrac{1}{4} + \dfrac{3}{4} = 1`

       .. rst-class:: solution

       :math:`1 = 1`
     - .. rst-class:: keepwithnext

       b\) :math:`\theta = 45\degree`

       .. rst-class:: solution

       :math:`\sin^2(45) + \cos^2(45) = 1`

       .. rst-class:: solution

       :math:`\left(\dfrac{1}{\sqrt{2}}\right)^2 +
       \left(\dfrac{1}{\sqrt{2}}\right)^2 = 1`

       .. rst-class:: solution

       :math:`\dfrac{1}{2} + \dfrac{1}{2} = 1`

       .. rst-class:: solution

       :math:`1 = 1`
     - .. rst-class:: keepwithnext

       .. rst-class:: solution

**7)** Un escabeau de 5 mètres appuyé contre le mur d'une classe forme un
angle de 30° avec le mur. À quelle distance exacte du sol se trouve le haut
de l'escabeau? Exprime ta réponse sous forme radicale.

.. rst-class:: solution

.. image:: ../images/mau5worksheet01-gpimage05.png
   :scale: 85

.. rst-class:: solution

:math:`\cos 30\degree = \dfrac{x}{5}` — à partir du triangle particulier :
:math:`\cos 30\degree = \dfrac{\sqrt{3}}{2}`

.. rst-class:: solution

:math:`\dfrac{x}{5} = \dfrac{\sqrt{3}}{2} \Rightarrow x =
\dfrac{5\sqrt{3}}{2}` m

**8)** Simplifie les expressions suivantes en rationalisant le dénominateur

.. list-table::
   :widths: 33 33 34
   :width: 100%

   * - .. rst-class:: keepwithnext

       a\) :math:`\dfrac{3\sqrt{2}}{\sqrt{5}}`

       .. rst-class:: solution

       :math:`= \dfrac{3\sqrt{2}}{\sqrt{5}} \cdot
       \dfrac{\sqrt{5}}{\sqrt{5}}`

       .. rst-class:: solution

       :math:`= \dfrac{3\sqrt{10}}{5}`
     - .. rst-class:: keepwithnext

       b\) :math:`\dfrac{6\sqrt{5}}{\sqrt{3}}`

       .. rst-class:: solution

       :math:`= \dfrac{6\sqrt{5}}{\sqrt{3}} \cdot
       \dfrac{\sqrt{3}}{\sqrt{3}}`

       .. rst-class:: solution

       :math:`= \dfrac{6\sqrt{15}}{3} = 2\sqrt{15}`
     - .. rst-class:: keepwithnext

       c\) :math:`\dfrac{4-5\sqrt{3}}{1+\sqrt{2}}`

       .. rst-class:: solution

       :math:`= \dfrac{4-5\sqrt{3}}{1+\sqrt{2}} \cdot
       \dfrac{1-\sqrt{2}}{1-\sqrt{2}}`

       .. rst-class:: solution

       :math:`= \dfrac{4-4\sqrt{2}-5\sqrt{3}+5\sqrt{6}}{1-2}`

       .. rst-class:: solution

       :math:`= -4+4\sqrt{2}+5\sqrt{3}-5\sqrt{6}`
