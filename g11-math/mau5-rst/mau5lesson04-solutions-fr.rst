Les rapports trigonométriques réciproques sont les réciproques des rapports
trigonométriques primaires. Ils sont définis comme 1 divisé par chacun des
rapports trigonométriques primaires :

.. list-table::
   :header-rows: 1
   :width: 100%

   * - Rapports trigonométriques primaires
     - Rapports trigonométriques réciproques
   * - :math:`\sin\theta = \dfrac{oppos\acute{e}}{hypot\acute{e}nuse}`
     - :math:`cos\acute{e}cante = \dfrac{1}{\sin\theta} = \dfrac{hypot\acute{e}nuse}{oppos\acute{e}}`
   * - :math:`\cos\theta = \dfrac{adjacent}{hypot\acute{e}nuse}`
     - :math:`s\acute{e}cante = \dfrac{1}{\cos\theta} = \dfrac{hypot\acute{e}nuse}{adjacent}`
   * - :math:`\tan\theta = \dfrac{oppos\acute{e}}{adjacent}`
     - :math:`cotangente = \dfrac{1}{\tan\theta} = \dfrac{adjacent}{oppos\acute{e}}`

**Exemple 2 :** Le point :math:`(-9,12)` se trouve sur le côté terminal
d'un angle en position standard. Détermine les expressions exactes des
six rapports trigonométriques de l'angle.

.. list-table::
   :widths: 40 60
   :width: 100%

   * - .. image:: ../images/mau5lesson04-gpimage03.png
          :scale: 75
     - .. rst-class:: solution

         :math:`r^2 = 12^2 + 9^2`

       .. rst-class:: solution

         :math:`r^2 = 225`

       .. rst-class:: solution

         :math:`r = 15`

       .. rst-class:: solution

         :math:`\sin\theta = \dfrac{12}{15}` |---| :math:`\csc\theta = \dfrac{15}{12}`

       .. rst-class:: solution

         :math:`\cos\theta = -\dfrac{9}{15}` |---| :math:`\sec\theta = -\dfrac{15}{9}`

       .. rst-class:: solution

         :math:`\tan\theta = -\dfrac{12}{9}` |---| :math:`\cot\theta = -\dfrac{9}{12}`
