   * - .. rst-class:: keepwithnext

       c\) coefficient de :math:`x` dans le développement de
       :math:`(x+3)^5`

       .. rst-class:: solution

       :math:`(3+b)^4`

       .. rst-class:: solution

**2)** Trouve chaque terme décrit.

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       a\) 2e terme du développement de :math:`(y-2x)^4`

       .. rst-class:: solution

       :math:`= 4(y)^3(-2x)^1 = -8y^3x`
     - .. rst-class:: keepwithnext

       b\) 4e terme du développement de :math:`(4y+x)^4`

       .. rst-class:: solution

       :math:`= 4(4y)^1(x)^3 = 16yx^3`
   * - .. rst-class:: keepwithnext

       c\) 1er terme du développement de :math:`(a+b)^5`

       .. rst-class:: solution

       :math:`= 1(a)^5(b)^0 = a^5`
     - .. rst-class:: keepwithnext

       d\) 2e terme du développement de :math:`(y-x)^4`

       .. rst-class:: solution

       :math:`= 4(y)^3(-x)^1 = -4y^3x`

**3)** Développe complètement.

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       a\) :math:`(2m-1)^4`

       .. rst-class:: solution

       :math:`= 1(2m)^4+4(2m)^3(-1)+6(2m)^2(-1)^2+4(2m)(-1)^3+1(-1)^4`

       .. rst-class:: solution

       :math:`= 16m^4-32m^3+24m^2-8m+1`
     - .. rst-class:: keepwithnext

       b\) :math:`(x-y)^3`

       .. rst-class:: solution

       :math:`= 1(x)^3+3(x)^2(-y)+3(x)(-y)^2+1(-y)^3`

       .. rst-class:: solution

       :math:`= x^3-3x^2y+3xy^2-y^3`
   * - .. rst-class:: keepwithnext

       c\) :math:`(x^4-y)^5`

       .. rst-class:: solution

       :math:`= 1(x^4)^5+5(x^4)^4(-y)+10(x^4)^3(-y)^2`

       .. rst-class:: solution

       :math:`+10(x^4)^2(-y)^3+5(x^4)(-y)^4+1(-y)^5`

       .. rst-class:: solution

       :math:`= x^{20}-5x^{16}y+10x^{12}y^2-10x^8y^3+5x^4y^4-y^5`
     - .. rst-class:: keepwithnext

       d\) :math:`(2x^3+1)^5`

       .. rst-class:: solution

       :math:`= 1(2x^3)^5+5(2x^3)^4(1)+10(2x^3)^3(1)^2`

       .. rst-class:: solution

       :math:`+10(2x^3)^2(1)^3+5(2x^3)(1)^4+1(1)^5`

       .. rst-class:: solution

       :math:`= 32x^{15}+80x^{12}+80x^9+40x^6+10x^3+1`
   * - .. rst-class:: keepwithnext

       e\) :math:`(y-x^2)^3`

       .. rst-class:: solution

       :math:`= 1(y)^3+3(y)^2(-x^2)+3(y)(-x^2)^2+1(-x^2)^3`

       .. rst-class:: solution

       :math:`= y^3-3x^2y^2+3x^4y-x^6`

       f\) :math:`(y^3-4x)^3`

       .. rst-class:: solution
