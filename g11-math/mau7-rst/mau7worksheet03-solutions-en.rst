**4)** Which term in the arithmetic sequence :math:`9, 4, -1, \ldots` has the
value -146?

.. rst-class:: solution

:math:`a=9, d=-5`

.. rst-class:: solution

:math:`t_n = a+(n-1)d \Rightarrow -146 = 9+(n-1)(-5) \Rightarrow -155 =
(n-1)(-5) \Rightarrow n=32`

**7)** In a lottery, the owner of the first ticket drawn receives $10 000.
Each successive winner receives $500 less than the previous winner.

.. rst-class:: keepwithnext

a\) How much does the 10th winner receive?

.. rst-class:: solution

:math:`t_n = 10\,000+(n-1)(-500)`

.. rst-class:: solution

:math:`t_{10} = 10\,000+(10-1)(-500) = 5500`, so the 10th winner receives
$5500.

.. rst-class:: keepwithnext

b\) How many winners are there in total?

.. rst-class:: solution

:math:`500 = 10\,000+(n-1)(-500) \Rightarrow -9500 = (n-1)(-500)
\Rightarrow n=20`

.. rst-class:: solution

There are 20 winners.

**8)** At the end of the second week after opening, a new fitness club has
870 members. At the end of the seventh week, there are 1110 members. If the
increase is arithmetic, how many members were there in the first week?

.. rst-class:: solution

:math:`t_2 = a+d = 870 \qquad t_7 = a+6d = 1110`

.. rst-class:: solution

:math:`240 = 5d \Rightarrow d=48 \Rightarrow a=822`

.. rst-class:: solution

There were 822 members in the first week.

**10)** For the geometric sequence :math:`54, 18, 6, \ldots` determine the
formula for the general term and then find :math:`t_9`.

.. rst-class:: solution

:math:`a=54, r=\dfrac{1}{3}`

.. rst-class:: solution

:math:`t_n = 54\left(\dfrac{1}{3}\right)^{n-1}`

.. rst-class:: solution

:math:`t_9 = 54\left(\dfrac{1}{3}\right)^8 = \dfrac{54}{3^8} = \dfrac{2}{243}`

**12)** Determine the number of terms in the geometric sequence
:math:`6, 18, 54, \ldots, 4374`.

.. rst-class:: solution

:math:`a=6, r=3`

.. rst-class:: solution

:math:`4374 = 6(3)^{n-1} \Rightarrow 729 = 3^{n-1} \Rightarrow 3^6 = 3^{n-1}
\Rightarrow n=7`

value of 19 683?

.. rst-class:: solution

:math:`19\,683 = 1(3)^{n-1} \Rightarrow 3^9 = 3^{n-1} \Rightarrow n=10`
