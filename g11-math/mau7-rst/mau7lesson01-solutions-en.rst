Section 1: Definitions
================================================================================

**Formula for general term (explicit formula):**

.. rst-class:: solution

A formula that represents any term in a sequence relative to the term
number (:math:`n`).

**Sequence:**

.. rst-class:: solution

An ordered list of numbers identified by a pattern or rule that may stop
at some number or continue indefinitely.

Ex.

3, 7, 11, 15

2, 6, 18, 54, ... the three dots indicate that it continues forever

**Note:** the terms of a sequence represent the range (:math:`y`-values)
of a function.

.. rst-class:: keepwithnext

**Example 1:** Write the first three terms of each sequence, given the
explicit formula for the :math:`n` th term of the sequence.

.. container:: keeptogether

   a\) :math:`t_n = 3n^2-1`

   .. rst-class:: solution

   :math:`t_1 = 3(1)^2-1 = 2`

   .. rst-class:: solution

   :math:`t_2 = 3(2)^2-1 = 11`

   .. rst-class:: solution

   :math:`t_3 = 3(3)^2-1 = 26`

   .. rst-class:: solution

   The first three terms are 2, 11, 26.

.. container:: keeptogether

   b\) :math:`t_n = \dfrac{n-1}{n}`

   .. rst-class:: solution

   :math:`t_1 = \dfrac{1-1}{1} = 0`

   .. rst-class:: solution

   :math:`t_2 = \dfrac{2-1}{2} = \dfrac{1}{2}`

   .. rst-class:: solution

   :math:`t_3 = \dfrac{3-1}{3} = \dfrac{2}{3}`

   .. rst-class:: solution

   The first three terms are :math:`0, \dfrac{1}{2}, \dfrac{2}{3}`.

Section 2: Arithmetic Sequences
================================================================================

Examples of sequences:

a\) 14, 18, 22, 26, ... (each term is 4 more than the previous term)

b\) 7, 3, -1, -5, ... (each term is 4 less than the previous term)

These are called *arithmetic* sequences because they increase by a
constant difference (+ or -).

Formula for General Term of an Arithmetic Sequence

.. math::

   t_n = a + (n-1)d

:math:`n`: the term number

:math:`a`: the value of the first term

:math:`t_n`: a term in the sequence

:math:`d`: the common difference

.. rst-class:: keepwithnext

**Example 2**

a\) Determine a formula for the general term of the following arithmetic
sequence.

14, 18, 22, 26, ...

.. rst-class:: solution

:math:`a = 14, d = 4`

.. rst-class:: solution

:math:`t_n = a + (n-1)d = 14 + (n-1)(4)`

.. rst-class:: keepwithnext

b\) What is the value of :math:`t_{30}`?

.. rst-class:: solution

:math:`t_{30} = 14 + (30-1)(4) = 14 + 116 = 130`

.. rst-class:: keepwithnext

**Example 3:**

a\) Determine a formula for the general term of the following arithmetic
sequence.

7, 3, -1, -5, ...

.. rst-class:: solution

:math:`a = 7, d = -4`

.. rst-class:: solution

:math:`t_n = a + (n-1)d = 7 + (n-1)(-4)`

.. rst-class:: keepwithnext

b\) What is the value of :math:`t_{41}`?

.. rst-class:: solution

:math:`t_{41} = 7 + (41-1)(-4) = 7 - 160 = -153`

Section 3: Geometric Sequences
================================================================================

Examples of sequences:

a\) 2, 6, 18, 54, ... (each term is 3 times the previous term)

b\) 80, 40, 20, 10, ... (each term is :math:`\dfrac{1}{2}` times the
previous term — note: no division is used)

These are called *geometric* sequences because the ratio of consecutive
terms is constant. Increase/decrease by a constant multiple.

Formula for the General Term of a Geometric Sequence

.. math::

   t_n = a \cdot r^{n-1}

:math:`n`: the term number

:math:`a`: the first term

:math:`t_n`: a term in the sequence

:math:`r`: the constant multiple

**Note:** no division is used — :math:`\div 2 = \times \dfrac{1}{2}`

.. rst-class:: keepwithnext

**Example 4:** Determine a formula for the general term of the following
geometric sequence.

2, 6, 18, 54, 162, ...

.. rst-class:: solution

:math:`a = 2, r = 3`

.. rst-class:: solution

:math:`t_n = a \cdot r^{n-1} = 2(3)^{n-1}`

.. rst-class:: keepwithnext

b\) What is the value of :math:`t_9`?

.. rst-class:: solution

:math:`t_9 = 2(3)^{9-1} = 13\,122`

.. rst-class:: keepwithnext

**Example 5:** Determine a formula for the general term of the following
geometric sequence.

270, 90, 30, 10, ...

.. rst-class:: solution

:math:`a = 270, r = \dfrac{1}{3}`

.. rst-class:: solution

:math:`t_n = a \cdot r^{n-1} = 270\left(\dfrac{1}{3}\right)^{n-1}`

.. rst-class:: keepwithnext

b\) What is the value of :math:`t_9`?

.. rst-class:: solution

:math:`t_9 = 270\left(\dfrac{1}{3}\right)^{9-1} = 270\left(\dfrac{1}{6561}\right) = \dfrac{10}{243}`
