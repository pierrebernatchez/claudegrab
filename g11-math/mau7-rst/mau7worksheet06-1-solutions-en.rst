**3)** Expand completely.

.. list-table::
   :widths: 50 50
   :width: 100%

   * - .. rst-class:: keepwithnext

       a\) :math:`(2m-1)^4`

       .. rst-class:: solution

       :math:`= 1(2m)^4+4(2m)^3(-1)+6(2m)^2(-1)^2+4(2m)(-1)^3+1(-1)^4`

       .. rst-class:: solution

       :math:`= 16m^4-32m^3+24m^2-8m+1`
     - .. rst-class:: keepwithnext

       b\) :math:`(x-y)^3`

       .. rst-class:: solution

       :math:`= 1(x)^3+3(x)^2(-y)+3(x)(-y)^2+1(-y)^3`

       .. rst-class:: solution

       :math:`= x^3-3x^2y+3xy^2-y^3`
   * - .. rst-class:: keepwithnext

       c\) :math:`(x^4-y)^5`

       .. rst-class:: solution

       :math:`= 1(x^4)^5+5(x^4)^4(-y)+10(x^4)^3(-y)^2`

       .. rst-class:: solution

       :math:`+10(x^4)^2(-y)^3+5(x^4)(-y)^4+1(-y)^5`

       .. rst-class:: solution

       :math:`= x^{20}-5x^{16}y+10x^{12}y^2-10x^8y^3+5x^4y^4-y^5`
     - .. rst-class:: keepwithnext

       d\) :math:`(2x^3+1)^5`

       .. rst-class:: solution

       :math:`= 1(2x^3)^5+5(2x^3)^4(1)+10(2x^3)^3(1)^2`

       .. rst-class:: solution

       :math:`+10(2x^3)^2(1)^3+5(2x^3)(1)^4+1(1)^5`

       .. rst-class:: solution

       :math:`= 32x^{15}+80x^{12}+80x^9+40x^6+10x^3+1`
   * - .. rst-class:: keepwithnext

       e\) :math:`(y-x^2)^3`

       .. rst-class:: solution

       :math:`= 1(y)^3+3(y)^2(-x^2)+3(y)(-x^2)^2+1(-x^2)^3`

       .. rst-class:: solution

       :math:`= y^3-3x^2y^2+3x^4y-x^6`
     - .. rst-class:: keepwithnext

       f\) :math:`(y^3-4x)^3`

       .. rst-class:: solution

       :math:`= 1(y^3)^3+3(y^3)^2(-4x)+3(y^3)(-4x)^2+1(-4x)^3`

       .. rst-class:: solution

       :math:`= y^9-12xy^6+48x^2y^3-64x^3`
