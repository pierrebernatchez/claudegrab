Answer Key
================================================================================

1 a\) 3, 7, 11, 15, 19, 23, 27, ...

b\) -13, -11, -9, -7, -5, -3, -1, ...

c\) 22, 20, 18, 16, 14, 12, 10, ...

d\) -2, -5, -8, -11, -14, -17, -20, ...

2\) a\) 4, 8, 16, 32, 64, 128, ...

b\) 1, -6, 36, -216, 1296, -7776, ...

c\) 486, 162, 54, 27, 9, 3, ...

d\) 3, 15, 75, 375, 1875, 9375, ...

3\) a\) 4, 7, 9, 12, ... neither

b\) 15, 13, 11, 9, ... arithmetic :math:`t_n = 15 +(n-1)(-2)`

c\) 4, 12, 36, 108, ... geometric :math:`t_n = 4(3)^{n-1}`

d\) 5, 10, 15, 20, ... arithmetic :math:`t_n = 5 +(n-1)(5)`

e\) 7, 10, 13, 16, ... arithmetic :math:`t_n = 7 +(n-1)(3)`

f\) 120, -60, 30, -15, ... geometric :math:`t_n = 120(-1/2)^{n-1}`

g\) -6, -5, -3, -1, ... neither

h\) -13, -6, 1, 8, ... arithmetic :math:`t_n = -13 +(n-1)(7)`

i\) 625, 125, 25, 5, ... geometric :math:`t_n = 625(1/5)^{n-1}`

4\) a\) :math:`t_n = 115 +(n-1)(35)` b\) :math:`t_{30} = 1130`

5\) a\) :math:`t_n = 400(0.8)^{n-1}` b\) :math:`t_6=131.072`
