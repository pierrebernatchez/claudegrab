Part 1: Domain & Range Review
================================================================================

.. rst-class:: keepwithnext

a\) State the domain and range of the relation shown in the following graph:

.. image:: ../images/mau1lesson02-gpimage01.png
   :scale: 90

.. rst-class:: solution

:math:`D: \{x \in \mathbb{R} \mid -7 \leq x \leq 7\}`

.. rst-class:: solution

:math:`R: \{y \in \mathbb{R} \mid -2.5 \leq y \leq 3\}`

.. rst-class:: keepwithnext

b\) Is this a function?

.. rst-class:: solution

No, it does NOT pass the vertical line test.

.. rst-class:: keepwithnext

c\) What determines if a relation is a function or not?

.. rst-class:: solution

For each value of :math:`x`, there can only be one corresponding value of
:math:`y`.

.. rst-class:: keepwithnext

d\) How does the vertical line test help us determine if a relation is a
function?

.. rst-class:: solution

If any vertical line touches the graph of the relation in more than one
spot, it is NOT a function.

.. rst-class:: keepwithnext

e\) What is domain?

.. rst-class:: solution

The values :math:`x` may take.

.. rst-class:: keepwithnext

f\) What is range?

.. rst-class:: solution

The value :math:`y` may take.

Part 2: Find Values Using Function Notation
================================================================================

.. rst-class:: keepwithnext

What does a function do?

.. rst-class:: solution

Takes an input (x), performs operations on it and then gives an output (y).

.. image:: ../images/mau1lesson02-gpimage02.png
   :scale: 85
   :alt: function machine, INPUT x -> FUNCTION f: -> OUTPUT f(x)

.. rst-class:: keepwithnext

What does function notation look like?

.. rst-class:: solution

:math:`f(x) = \text{some operations applied to } x` |---| read as "f of x"
or "f at x", replaces "y"

Mapping Diagrams
================================================================================

A mapping diagram is a representation that can be used when the relation is
given as a set of ordered pairs. In a mapping diagram, the :sol:`domain`
values in one oval are joined to the :sol:`range` values in the other oval
using arrows.

A relation is a function if there is exactly :sol:`one` arrow leading from
each value in the domain. This indicates that each element in the domain
corresponds to exactly one element in the range.

.. image:: ../images/mau1lesson02-gpimage03.png
   :scale: 80
   :alt: mapping diagram, 1->1, 2->4, 3->9, 4->16, 5->25

**Example 4:** The temperature of the water at the surface of a lake is 22
degrees Celsius. As Geno scuba dives to the depths of the lake, he finds
that the temperature decreases by 1.5 degrees for every 8 meters he
descends.

*Notice it is a constant rate of change, making it a linear function of the
form* :math:`y = mx + b`

.. rst-class:: keepwithnext

a\) Model the water temperature at any depth using function notation.

.. rst-class:: solution

:math:`m = \dfrac{\Delta T}{\Delta d} = \dfrac{-1.5}{8} = \dfrac{-3}{16}`,
:math:`b = 22`

.. rst-class:: solution

:math:`T(d) = \dfrac{-3}{16}d + 22`

.. rst-class:: keepwithnext

b\) What is the water temperature at a depth of 40 meters?

.. rst-class:: solution

:math:`T(40) = \dfrac{-3}{16}(40) + 22`

.. rst-class:: solution

:math:`T(40) = 14.5°C`

.. rst-class:: keepwithnext

c\) At the bottom of the lake the temperature is 5.5 degrees Celsius. How
deep is the lake?

.. rst-class:: solution

:math:`5.5 = \dfrac{-3}{16}d + 22`

.. rst-class:: solution

:math:`(16)\ {-16.5} = \dfrac{-3}{16}d\ (16)`

.. rst-class:: solution

:math:`-264 = -3d`

.. rst-class:: solution

:math:`d = 88` meters deep
