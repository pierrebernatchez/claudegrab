Definitions
================================================================================

**Radicand:**

.. rst-class:: solution

a number or expression under a radical sign

**Entire Radical:**

.. rst-class:: solution

a radical in the form :math:`\sqrt{n}`, where :math:`n > 0`, such as
:math:`\sqrt{45}`

**Mixed Radical:**

.. rst-class:: solution

a radical in the form :math:`a\sqrt{b}`, where :math:`a \neq 1` or
:math:`-1` and :math:`b > 0`, such as :math:`3\sqrt{5}`

More About Radicals
================================================================================

Some numbers cannot be expressed as fractions. These are called
:sol:`irrational` numbers. One type of irrational number is of the form
:math:`\sqrt{n}` where :math:`n` is not a perfect square. These numbers
are sometimes called :sol:`radicals`.

An approximate value can be found for these irrational numbers using a
calculator but it is better to work with an exact value. Answers should
be left in radical form when an EXACT answer is needed. Sometimes entire
radicals can be simplified by removing perfect square factors. The
resulting expression is called a :sol:`mixed radical`.

Adding and Subtracting Radicals
================================================================================

Adding and subtracting radicals works in the same way as adding and
subtracting polynomials. You can only add :sol:`like` terms or, in this
case, :sol:`like radicals`.

**Example:**

:math:`2\sqrt{3}+5\sqrt{7}` cannot be added because they do not have the
same radical.

However, :math:`3\sqrt{5}+6\sqrt{5}` have a common radical, so they can be
added. :math:`3\sqrt{5}+6\sqrt{5} = 9\sqrt{5}`

Note, the radical stays the same when adding and subtracting expressions
with like radicals.

.. rst-class:: keepwithnext

**Example 2:** Simplify the following

.. rst-class:: keepwithnext

a\) :math:`9\sqrt{7}-3\sqrt{7}`

.. rst-class:: solution

b\) :math:`4\sqrt{3}-2\sqrt{27}`

.. rst-class:: solution

Multiplying Radicals
================================================================================

.. rst-class:: keepwithnext

**Example 3:** Simplify fully

.. rst-class:: keepwithnext

a\) :math:`(2\sqrt{3})(3\sqrt{6})`

*Multiply the coefficients together and then multiply the radicands
together. Then simplify!*

.. rst-class:: solution

:math:`= (2)(3)(\sqrt{3})(\sqrt{6}) = 6\sqrt{18} = 6(\sqrt{9})(\sqrt{2}) =
6(3)(\sqrt{2}) = 18\sqrt{2}`

.. rst-class:: keepwithnext

b\) :math:`2\sqrt{3}(4+5\sqrt{3})`

*Don't forget the distributive property:* :math:`a(x+y) = ax+ay`

.. rst-class:: solution

:math:`= 2\sqrt{3}(4)+2\sqrt{3}(5\sqrt{3}) = 8\sqrt{3}+10\sqrt{9} =
8\sqrt{3}+10(3) = 8\sqrt{3}+30`

.. rst-class:: keepwithnext

c\) :math:`-7\sqrt{2}(6\sqrt{8}-11)`

.. rst-class:: solution

:math:`= -7\sqrt{2}(6\sqrt{8})-7\sqrt{2}(-11) = -42\sqrt{16}+77\sqrt{2} =
-168+77\sqrt{2}`

.. rst-class:: keepwithnext

d\) :math:`(\sqrt{3}+5)(2-\sqrt{3})`

*Don't forget FOIL. Each term in the first binomial must be multiplied by
each term in the second binomial.*

.. rst-class:: solution

:math:`= \sqrt{3}(2)+\sqrt{3}(-\sqrt{3})+5(2)+5(-\sqrt{3}) =
2\sqrt{3}-\sqrt{9}+10-5\sqrt{3}`

.. rst-class:: solution

:math:`= 2\sqrt{3}-5\sqrt{3}-3+10 = -3\sqrt{3}+7`

.. rst-class:: keepwithnext

e\) :math:`(2\sqrt{2}+3\sqrt{3})(2\sqrt{2}-3\sqrt{3})`

*There is a shortcut! This is a difference of squares.*
:math:`(a+b)(a-b) = a^2-b^2`

.. rst-class:: solution

:math:`= (2\sqrt{2})^2-(3\sqrt{3})^2 = 4(2)-9(3) = 8-27 = -19`

Key Concepts
================================================================================

- .. rst-class:: solution

  :math:`\sqrt{a}\times\sqrt{b} = \sqrt{ab}` for :math:`a \geq 0` and
  :math:`b \geq 0`.
- .. rst-class:: solution

  An entire radical can be simplified to a mixed radical in simplest form
  by removing the largest perfect square from under the radical to form
  a mixed radical. For example, :math:`\sqrt{50} = \sqrt{25\times2} =
  5\sqrt{2}`.
- .. rst-class:: solution

  Like radicals can be combined through addition and subtraction. For
  example, :math:`3\sqrt{7}+2\sqrt{7} = 5\sqrt{7}`.
- .. rst-class:: solution

  Radicals can be multiplied using the distributive property. For
  example, :math:`4\sqrt{2}(5\sqrt{3}-3) = 20\sqrt{6}-12\sqrt{2}` and
  :math:`(\sqrt{2}-3)(\sqrt{2}+1) = \sqrt{4}+\sqrt{2}-3\sqrt{2}-3 =
  2-2\sqrt{2}-3 = -2\sqrt{2}-1`.
