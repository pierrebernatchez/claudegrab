Partie 1 : fais-le maintenant
================================================================================

.. rst-class:: keepwithnext

a\) Te souviens-tu de la formule quadratique ?

.. rst-class:: solution

:math:`x = \dfrac{-b\pm\sqrt{b^2-4ac}}{2a}`

.. rst-class:: keepwithnext

b\) Utilise la formule quadratique pour trouver les abscisses à l’origine de :

:math:`0 = 2x^2+7x-4`

.. rst-class:: solution

N’oublie pas que pour résoudre une quadratique, elle doit être égalée à
zéro, car à une abscisse à l’origine, la coordonnée y est nulle.

.. rst-class:: solution

:math:`x = \dfrac{-7\pm\sqrt{(7)^2-4(2)(-4)}}{2(2)}`

.. rst-class:: solution

:math:`x = \dfrac{-7\pm\sqrt{49+32}}{4} = \dfrac{-7\pm\sqrt{81}}{4} =
\dfrac{-7\pm9}{4}`

.. rst-class:: solution

:math:`x=\dfrac{-7+9}{4}=\dfrac{1}{2}` ou :math:`x=\dfrac{-7-9}{4}=-4`

Partie 2 : révision du discriminant
================================================================================

Est-ce que toutes les paraboles ont deux abscisses à l’origine ?

.. rst-class:: solution

Non.

Quels sont les trois scénarios possibles ?

.. rst-class:: solution

Une parabole peut avoir 0, 1 ou 2 solutions (abscisses à l’origine).

La façon de déterminer combien d’abscisses à l’origine une parabole peut
avoir consiste à évaluer la partie :math:`b^2-4ac` de la formule
quadratique (appelée le « **discriminant** »)

**Discriminant :** la valeur sous le radical

.. rst-class:: keepwithnext

Si :math:`b^2-4ac > 0`, il y a deux solutions

.. image:: ../images/mau1lesson06-gpimage01.png
   :scale: 100

.. rst-class:: keepwithnext

Si :math:`b^2-4ac = 0`, il y a une solution

.. image:: ../images/mau1lesson06-gpimage02.png
   :scale: 100

.. rst-class:: keepwithnext

Si :math:`b^2-4ac < 0`, il n’y a aucune solution

.. image:: ../images/mau1lesson06-gpimage03.png
   :scale: 100

Partie 3 : résoudre une quadratique à 2 racines
================================================================================

.. image:: ../images/mau1lesson06-gpimage04.png
   :scale: 100

**Objectif :** déterminer les racines d’une quadratique à l’aide de la
formule quadratique et laisser les réponses sous forme EXACTE

**Réponse exacte :** sous forme de radical ou de fraction. Les réponses
exactes ne contiennent pas de nombres décimaux.

.. rst-class:: keepwithnext

**Exemple 1 :** trouve les solutions exactes de :math:`3x^2-10x+5=0`

.. rst-class:: solution

:math:`x = \dfrac{10\pm\sqrt{(-10)^2-4(3)(5)}}{2(3)} =
\dfrac{10\pm\sqrt{40}}{6}`

.. rst-class:: solution

:math:`= \dfrac{10\pm\sqrt{4}\sqrt{10}}{6} = \dfrac{10\pm2\sqrt{10}}{6}`
(simplifier le radical)

.. rst-class:: solution

:math:`= \dfrac{2(5\pm\sqrt{10})}{6} = \dfrac{5\pm\sqrt{10}}{3}`
(facteur commun, réduire)

.. rst-class:: solution

:math:`x=\dfrac{5+\sqrt{10}}{3}` ou :math:`x=\dfrac{5-\sqrt{10}}{3}`

.. rst-class:: keepwithnext

**Exemple 2 :** trouve les solutions exactes de :math:`-2x^2+8x-5=0`

.. rst-class:: solution

:math:`x = \dfrac{-8\pm\sqrt{(8)^2-4(-2)(-5)}}{2(-2)} =
\dfrac{-8\pm\sqrt{24}}{-4}`

.. rst-class:: solution

:math:`= \dfrac{-8\pm\sqrt{4}\sqrt{6}}{-4} = \dfrac{-8\pm2\sqrt{6}}{-4}`
(simplifier le radical)

.. rst-class:: solution

:math:`= \dfrac{2(4\mp\sqrt{6})}{2(-2)} = \dfrac{4\mp\sqrt{6}}{-2} =
\dfrac{4\mp\sqrt{6}}{2}` (facteur commun, réduire)

.. rst-class:: solution

:math:`x=\dfrac{4-\sqrt{6}}{2}` ou :math:`x=\dfrac{4+\sqrt{6}}{2}`

Partie 4 : résoudre une quadratique à 1 racine
================================================================================

.. image:: ../images/mau1lesson06-gpimage05.png
   :scale: 100

**Remarque :** lorsqu’une quadratique n’a qu’une seule solution,
l’abscisse à l’origine correspond aussi au sommet

.. rst-class:: keepwithnext

**Exemple 3 :** trouve les racines exactes de :math:`4x^2+24x+36=0`

.. rst-class:: solution

Facteur commun 4 : :math:`4(x^2+6x+9)=0 \Rightarrow x^2+6x+9=0`

.. rst-class:: solution

:math:`x = \dfrac{-6\pm\sqrt{(6)^2-4(1)(9)}}{2(1)} = \dfrac{-6\pm\sqrt{0}}{2}`

.. rst-class:: solution

:math:`x = \dfrac{-6}{2} = -3`

Partie 5 : résoudre des quadratiques à 0 racine
================================================================================

.. image:: ../images/mau1lesson06-gpimage06.png
   :scale: 100

2 scénarios menant à 0 racine :

i\) le sommet est au-dessus de l’axe des x et la parabole s’ouvre vers le
haut

ii\) le sommet est au-dessous de l’axe des x et la parabole s’ouvre vers
le bas

.. rst-class:: keepwithnext

**Exemple 4 :** trouve les abscisses à l’origine de :math:`8x^2-11x+5=0`

.. rst-class:: solution

:math:`x = \dfrac{11\pm\sqrt{(-11)^2-4(8)(5)}}{2(8)} = \dfrac{11\pm\sqrt{-39}}{16}`

.. rst-class:: solution

Puisque la valeur sous le radical est négative, il n’y a aucune solution
réelle.

Partie 6 : utiliser le discriminant pour déterminer le nombre de racines
================================================================================

.. rst-class:: keepwithnext

**Exemple 5 :** pour chacune des quadratiques suivantes, utilise le
discriminant pour indiquer le nombre de racines qu’elle aura.

.. rst-class:: keepwithnext

a\) :math:`2x^2+5x-5=0`

.. rst-class:: solution

:math:`b^2-4ac = (5)^2-4(2)(-5) = 25+40 = 65`

.. rst-class:: solution

:math:`65>0`, donc 2 solutions

.. rst-class:: keepwithnext

b\) :math:`3x^2-7x+5=0`

.. rst-class:: solution

:math:`b^2-4ac = (-7)^2-4(3)(5) = 49-60 = -11`

.. rst-class:: solution

:math:`-11<0`, donc aucune solution

.. rst-class:: keepwithnext

c\) :math:`-4x^2+12x-9=0`

.. rst-class:: solution

:math:`b^2-4ac = (12)^2-4(-4)(-9) = 144-144 = 0`

.. rst-class:: solution

:math:`0=0`, donc 1 solution

Partie 7 : application
================================================================================

.. rst-class:: keepwithnext

**Exemple 6 :** on lance une balle, et l’équation ci-dessous modélise sa
trajectoire :

:math:`h = -0.25d^2+2d+1.5`

« h » est la hauteur en mètres au-dessus du sol et « d » est la distance
horizontale en mètres par rapport à la personne qui a lancé la balle.

.. rst-class:: keepwithnext

a\) À quelle hauteur la balle a-t-elle été lancée ?

.. rst-class:: solution

Isoler « h » lorsque :math:`d=0` :
:math:`h = -0.25(0)^2+2(0)+1.5 = 1.5` mètres

.. rst-class:: keepwithnext

b\) Quelle distance horizontale la balle a-t-elle parcourue lorsqu’elle
touche le sol ?

.. rst-class:: solution

Poser :math:`h=0` : :math:`0 = -0.25d^2+2d+1.5`

.. rst-class:: solution

Diviser par -0,25 : :math:`0 = d^2-8d-6`

.. rst-class:: solution

:math:`d = \dfrac{8\pm\sqrt{(-8)^2-4(1)(-6)}}{2(1)} = \dfrac{8\pm\sqrt{88}}{2}`

.. rst-class:: solution

:math:`d=\dfrac{8+\sqrt{88}}{2}\approx8.7` mètres, ou
:math:`d=\dfrac{8-\sqrt{88}}{2}\approx-0.7` mètres (rejetée, distance
négative)

.. rst-class:: solution

La balle parcourt environ 8,7 mètres horizontalement.
