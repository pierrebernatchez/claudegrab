**7)** Pam a 90 m de clôture pour enclore une aire dans un zoo pour enfants
avec deux séparateurs pour séparer trois types de jeunes animaux. Les trois
enclos doivent avoir la même aire.

.. image:: ../images/mau1worksheet01-gpimage26.png
   :scale: 90

.. rst-class:: keepwithnext

a\) Exprimez la fonction donnant l'aire totale clôturée par les trois
enclos ensemble, en fonction de :math:`x`.

.. rst-class:: solution

Les deux séparateurs plus les deux côtés extérieurs utilisent :math:`4x` de
clôture, laissant :math:`90 - 4x` pour les deux longueurs, donc chaque enclos
a une longueur de :math:`\dfrac{90-4x}{2}`.

.. math::
   :class: solution

   A = \left(\frac{90-4x}{2}\right)(x) = (45-2x)(x) = -2x^2 + 45x

.. rst-class:: keepwithnext

b\) Déterminez le domaine et l'image de la fonction d'aire.

.. rst-class:: solution

abscisses à l'origine : :math:`x = 0` ou :math:`45 - 2x = 0 \Rightarrow x = 22.5`

.. rst-class:: solution

sommet : :math:`x = \dfrac{-45}{2(-2)} = 11.25`,
:math:`y = -2(11.25)^2 + 45(11.25) = 253.125`

.. rst-class:: solution

:math:`D: \{x \in \mathbb{R} \mid 0 < x < 22.5\}`

.. rst-class:: solution

:math:`I: \{y \in \mathbb{R} \mid 0 < y \leq 253.125\}`
