More About Radicals
================================================================================

Some numbers cannot be expressed as fractions. These are called
``________________`` numbers. One type of irrational number is of the
form :math:`\sqrt{n}` where :math:`n` is not a perfect square. These
numbers are sometimes called ``________________``.

calculator but it is better to work with an exact value. Answers should
be left in radical form when an EXACT answer is needed. Sometimes entire
radicals can be simplified by removing perfect square factors. The

Adding and Subtracting Radicals
================================================================================

Adding and subtracting radicals works in the same way as adding and
subtracting polynomials. You can only add ``_________`` terms or, in this
case, ``_________`` ``_______________``.

**Example:**

:math:`2\sqrt{3}+5\sqrt{7}` cannot be added because they do not have the
same radical.

However, :math:`3\sqrt{5}+6\sqrt{5}` have a common radical, so they can be
added. :math:`3\sqrt{5}+6\sqrt{5} = 9\sqrt{5}`

Note, the radical stays the same when adding and subtracting expressions
with like radicals.
