.. rst-class:: keepwithnext

**1)** Utilise le discriminant pour déterminer le nombre de racines de
chaque équation quadratique.

.. rst-class:: keepwithnext

a\) :math:`x^2-10x+25=0`

.. rst-class:: solution

:math:`b^2-4ac = (-10)^2-4(1)(25) = 0`, donc 1 racine

.. rst-class:: keepwithnext

b\) :math:`3x^2+4x+\dfrac{4}{3}=0`

.. rst-class:: solution

:math:`b^2-4ac = (4)^2-4(3)\left(\dfrac{4}{3}\right) = 0`, donc 1 racine

.. rst-class:: keepwithnext

c\) :math:`2x^2-8x+9=0`

.. rst-class:: solution

:math:`b^2-4ac = (-8)^2-4(2)(9) = -8`, donc aucune racine

.. rst-class:: keepwithnext

d\) :math:`-2x^2+0.75x+5=0`

.. rst-class:: solution

:math:`b^2-4ac = (0.75)^2-4(-2)(5) = 40.5625`, donc 2 racines

.. rst-class:: keepwithnext

**2)** Résous chaque équation quadratique à l’aide de la formule
quadratique. Donne des réponses exactes.

:math:`x = \dfrac{-b\pm\sqrt{b^2-4ac}}{2a}`

.. rst-class:: keepwithnext

a\) :math:`x^2+4x-3=0`

.. rst-class:: solution

:math:`x = \dfrac{-4\pm\sqrt{(4)^2-4(1)(-3)}}{2(1)} = \dfrac{-4\pm\sqrt{28}}{2}
= \dfrac{2(-2\pm\sqrt{7})}{2}`; :math:`x=-2+\sqrt{7}` ou
:math:`x=-2-\sqrt{7}`

.. rst-class:: keepwithnext

b\) :math:`-x^2+12=9x`

.. rst-class:: solution

Réarranger : :math:`-x^2-9x+12=0 \Rightarrow x^2+9x-12=0`.
:math:`x = \dfrac{-9\pm\sqrt{(9)^2-4(1)(-12)}}{2(1)} =
\dfrac{-9\pm\sqrt{129}}{2}`; :math:`x_1=\dfrac{-9+\sqrt{129}}{2}` ou
:math:`x_2=\dfrac{-9-\sqrt{129}}{2}`

.. rst-class:: keepwithnext

c\) :math:`x^2=-5x+2`

.. rst-class:: solution

Réarranger : :math:`x^2+5x-2=0`.
:math:`x = \dfrac{-5\pm\sqrt{(5)^2-4(1)(-2)}}{2(1)} =
\dfrac{-5\pm\sqrt{33}}{2}`; :math:`x_1=\dfrac{-5+\sqrt{33}}{2}` ou
:math:`x_2=\dfrac{-5-\sqrt{33}}{2}`

.. rst-class:: keepwithnext

d\) :math:`x^2-3x+1=6`

.. rst-class:: solution

Réarranger : :math:`x^2-3x-5=0`.
:math:`x = \dfrac{3\pm\sqrt{(-3)^2-4(1)(-5)}}{2(1)} =
\dfrac{3\pm\sqrt{29}}{2}`; :math:`x_1=\dfrac{3+\sqrt{29}}{2}` ou
:math:`x_2=\dfrac{3-\sqrt{29}}{2}`

.. rst-class:: keepwithnext

e\) :math:`x^2+6x+9=0`

.. rst-class:: solution

:math:`x = \dfrac{-6\pm\sqrt{(6)^2-4(1)(9)}}{2(1)} = \dfrac{-6\pm\sqrt{0}}{2}
= -3`

.. rst-class:: keepwithnext

f\) :math:`4x^2-6x-1=0`

.. rst-class:: solution

:math:`x = \dfrac{6\pm\sqrt{(-6)^2-4(4)(-1)}}{2(4)} = \dfrac{6\pm\sqrt{52}}{8}
= \dfrac{6\pm2\sqrt{13}}{8} = \dfrac{3\pm\sqrt{13}}{4}`;
:math:`x_1=\dfrac{3+\sqrt{13}}{4}` ou :math:`x_2=\dfrac{3-\sqrt{13}}{4}`

.. rst-class:: keepwithnext

g\) :math:`5x^2-3x-1=0`

.. rst-class:: solution

:math:`x = \dfrac{3\pm\sqrt{(-3)^2-4(5)(-1)}}{2(5)} = \dfrac{3\pm\sqrt{29}}{10}`;
:math:`x_1=\dfrac{3+\sqrt{29}}{10}` ou :math:`x_2=\dfrac{3-\sqrt{29}}{10}`

.. rst-class:: keepwithnext

h\) :math:`-x^2+7x-18=0`

.. rst-class:: solution

:math:`x = \dfrac{-7\pm\sqrt{(7)^2-4(-1)(-18)}}{2(-1)} = \dfrac{-7\pm\sqrt{-23}}{-2}`;
aucune racine réelle (discriminant négatif)

.. rst-class:: keepwithnext

i\) :math:`4x^2-25=0`

.. rst-class:: solution

:math:`x = \dfrac{0\pm\sqrt{(0)^2-4(4)(-25)}}{2(4)} = \dfrac{\pm\sqrt{400}}{8}
= \dfrac{\pm20}{8}`; :math:`x=\dfrac{5}{2}` ou :math:`x=-\dfrac{5}{2}`

.. rst-class:: keepwithnext

j\) :math:`3x^2-7x-4=x^2-4x`

.. rst-class:: solution

Réarranger : :math:`2x^2-3x-4=0`.
:math:`x = \dfrac{3\pm\sqrt{(-3)^2-4(2)(-4)}}{2(2)} = \dfrac{3\pm\sqrt{41}}{4}`;
:math:`x_1=\dfrac{3+\sqrt{41}}{4}` ou :math:`x_2=\dfrac{3-\sqrt{41}}{4}`

.. rst-class:: keepwithnext

k\) :math:`8x^2+4x-5=0`

.. rst-class:: solution

:math:`x = \dfrac{-4\pm\sqrt{(4)^2-4(8)(-5)}}{2(8)} = \dfrac{-4\pm\sqrt{176}}{16}
= \dfrac{4(-1\pm\sqrt{11})}{16} = \dfrac{-1\pm\sqrt{11}}{4}`;
:math:`x_1=\dfrac{-1+\sqrt{11}}{4}` ou :math:`x_2=\dfrac{-1-\sqrt{11}}{4}`

.. rst-class:: keepwithnext

l\) :math:`4x^2-18x=0`

.. rst-class:: solution

:math:`x = \dfrac{18\pm\sqrt{(-18)^2-4(4)(0)}}{2(4)} = \dfrac{18\pm18}{8}`;
:math:`x=\dfrac{36}{8}=\dfrac{9}{2}` ou :math:`x=\dfrac{0}{8}=0`

.. rst-class:: keepwithnext

**3)** Résous chaque équation quadratique en utilisant n’importe quelle
méthode

.. rst-class:: keepwithnext

a\) :math:`3x^2-12x=0`

.. rst-class:: solution

:math:`3x(x-4)=0`; :math:`x=0` ou :math:`x=4`

.. rst-class:: keepwithnext

b\) :math:`2x^2+4x-6=0`

.. rst-class:: solution

Facteur commun 2 : :math:`x^2+2x-3=0`. Produit : -3, somme : 2, facteurs 3
et -1 : :math:`(x+3)(x-1)=0`; :math:`x=-3` ou :math:`x=1`

.. rst-class:: keepwithnext

c\) :math:`3x^2+5x-2=0`

.. rst-class:: solution

Produit : -6, somme : 5, facteurs 6 et -1 :
:math:`3x(x+2)-1(x+2)=0 \Rightarrow (3x-1)(x+2)=0`; :math:`x=\dfrac{1}{3}`
ou :math:`x=-2`

.. rst-class:: keepwithnext

d\) :math:`4x^2-11x-8=0`

.. rst-class:: solution

:math:`x = \dfrac{11\pm\sqrt{(-11)^2-4(4)(-8)}}{2(4)} = \dfrac{11\pm\sqrt{249}}{8}`

.. rst-class:: keepwithnext

**4)** Trois longueurs de tuyau mesurant 24 cm, 31 cm et 38 cm seront
utilisées pour former un triangle rectangle. La même longueur sera
coupée de chacun des trois tuyaux afin de former ce triangle rectangle.
Quelle est cette longueur ?

.. rst-class:: solution

Soit :math:`x` la longueur coupée de chaque tuyau. Selon le théorème de
Pythagore : :math:`(24-x)^2+(31-x)^2=(38-x)^2`

.. rst-class:: solution

:math:`576-48x+x^2+961-62x+x^2 = 1444-76x+x^2`

.. rst-class:: solution

:math:`x^2-34x+93 = 0 \Rightarrow (x-3)(x-31)=0`; :math:`x=3` ou
:math:`x=31`

.. rst-class:: solution

:math:`x=31` est rejeté puisqu’on ne peut pas couper 31 cm d’un tuyau de
24 cm, donc la longueur coupée de chaque tuyau est 3 cm.
