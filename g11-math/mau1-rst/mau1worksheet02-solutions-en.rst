**1)** For each function, determine :math:`f(4)`, :math:`f(-5)`, and
:math:`f\left(-\dfrac{2}{3}\right)`.

.. rst-class:: keepwithnext

a\) :math:`f(x) = \dfrac{2}{5}x + 11`

.. rst-class:: solution

:math:`f(4) = \dfrac{2}{5}(4) + 11 = \dfrac{8}{5} + \dfrac{55}{5} = \dfrac{63}{5}`

.. rst-class:: solution

:math:`f(-5) = \dfrac{2}{5}(-5) + 11 = -2 + 11 = 9`

.. rst-class:: solution

:math:`f\left(-\dfrac{2}{3}\right) = \dfrac{2}{5}\left(-\dfrac{2}{3}\right) + 11
= -\dfrac{4}{15} + \dfrac{165}{15} = \dfrac{161}{15}`

.. rst-class:: keepwithnext

b\) :math:`f(x) = 3x^2 + 2x + 1`

.. rst-class:: solution

:math:`f(4) = 3(4)^2 + 2(4) + 1 = 48 + 8 + 1 = 57`

.. rst-class:: solution

:math:`f(-5) = 3(-5)^2 + 2(-5) + 1 = 75 - 10 + 1 = 66`

.. rst-class:: solution

:math:`f\left(-\dfrac{2}{3}\right) = 3\left(-\dfrac{2}{3}\right)^2 + 2\left(-\dfrac{2}{3}\right) + 1
= \dfrac{12}{9} - \dfrac{4}{3} + 1 = 1`

.. rst-class:: keepwithnext

c\) :math:`f(x) = 2(x+4)^2`

.. rst-class:: solution

:math:`f(4) = 2(4+4)^2 = 2(64) = 128`

.. rst-class:: solution

:math:`f(-5) = 2(-5+4)^2 = 2(1) = 2`

.. rst-class:: solution

:math:`f\left(-\dfrac{2}{3}\right) = 2\left(-\dfrac{2}{3}+4\right)^2
= 2\left(\dfrac{10}{3}\right)^2 = \dfrac{200}{9}`

.. rst-class:: keepwithnext

d\) :math:`f(x) = -6`

.. rst-class:: solution

:math:`f(4) = -6`, :math:`f(-5) = -6`, :math:`f\left(-\dfrac{2}{3}\right) = -6`

.. rst-class:: keepwithnext

e\) :math:`f(x) = \dfrac{1}{x}`

.. rst-class:: solution

:math:`f(4) = \dfrac{1}{4}`, :math:`f(-5) = -\dfrac{1}{5}`

.. rst-class:: solution

:math:`f\left(-\dfrac{2}{3}\right) = \dfrac{1}{-2/3} = 1 \times \dfrac{3}{-2}
= -\dfrac{3}{2}`

.. rst-class:: keepwithnext

f\) :math:`f(x) = \sqrt{x+5}`

.. rst-class:: solution

:math:`f(4) = \sqrt{4+5} = 3`

.. rst-class:: solution

:math:`f(-5) = \sqrt{-5+5} = 0`

.. rst-class:: solution

:math:`f\left(-\dfrac{2}{3}\right) = \sqrt{-\dfrac{2}{3}+\dfrac{15}{3}}
= \sqrt{\dfrac{13}{3}}`
