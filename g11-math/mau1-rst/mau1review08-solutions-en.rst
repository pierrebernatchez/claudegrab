c\) :math:`f(x) = 3x^2-30x+73`

.. rst-class:: solution

Vertex is :math:`(5,-2)` |nbsp| |nbsp| **min**

.. rst-class:: keepwithnext

d\) :math:`f(x) = -2x^2-8x+7`

**3)** Use partial factoring to determine the vertex of each function.
State if the vertex is a max or min.

.. rst-class:: keepwithnext

a\) :math:`y = -x^2+4x+11`

.. rst-class:: solution

:math:`0=-x^2+4x \Rightarrow 0=-x(x-4) \Rightarrow x=0` or :math:`x=4`

.. rst-class:: solution

x-vertex :math:`=\dfrac{0+4}{2}=2`; y-vertex
:math:`=-(2)^2+4(2)+11=15`

.. rst-class:: solution

Vertex is :math:`(2,15)` |nbsp| |nbsp| **max**

.. rst-class:: keepwithnext

b\) :math:`y = 3x^2-18x+14`

.. rst-class:: solution

:math:`0=3x^2-18x \Rightarrow 0=3x(x-6) \Rightarrow x=0` or :math:`x=6`

.. rst-class:: solution

x-vertex :math:`=\dfrac{0+6}{2}=3`; y-vertex
:math:`=3(3)^2-18(3)+14=-13`

.. rst-class:: solution

Vertex is :math:`(3,-13)` |nbsp| |nbsp| **min**

.. rst-class:: keepwithnext

c\) :math:`y = 5x^2+14x-21`

.. rst-class:: solution

:math:`0=5x^2+14x \Rightarrow 0=x(5x+14) \Rightarrow x=0` or :math:`x=-\dfrac{14}{5}=-2.8`

.. rst-class:: solution

x-vertex :math:`=\dfrac{0+(-2.8)}{2}=-1.4`; y-vertex
:math:`=5(-1.4)^2+14(-1.4)-21=-30.8`

.. rst-class:: solution

Vertex is :math:`(-1.4,-30.8)` |nbsp| |nbsp| **min**

.. rst-class:: keepwithnext

d\) :math:`y = -2x^2-11x+1`

.. rst-class:: solution

:math:`0=-2x^2-11x \Rightarrow 0=-x(2x+11) \Rightarrow x=0` or
:math:`x=-\dfrac{11}{2}=-5.5`

.. rst-class:: solution

x-vertex :math:`=\dfrac{0+(-5.5)}{2}=-2.75`; y-vertex
:math:`=-2(-2.75)^2-11(-2.75)+1=16.125`

.. rst-class:: solution

Vertex is :math:`\left(-\dfrac{11}{4},\dfrac{129}{8}\right)` |nbsp| |nbsp|
**max**

**4)** A hall charges $30 per person for a sports banquet when 120
attend. For every 10 extra people that attend, the hall will decrease
the price by $1.50 per person. What number of people will maximize the
revenue for the hall?

.. rst-class:: solution

Revenue :math:`=(\text{cost})(\text{number of people})`:
:math:`0=(30-1.50x)(120+10x)`

.. rst-class:: solution

:math:`30-1.50x=0 \Rightarrow x=20`; :math:`120+10x=0 \Rightarrow x=-12`

.. rst-class:: solution

x-vertex :math:`=\dfrac{20+(-12)}{2}=4`; number of people
:math:`=120+10(4)=160`

.. rst-class:: solution

**160 people** will maximize the revenue.

.. rst-class:: keepwithnext

**5)** The power, P, in watts, produced by a solar panel is given by the
function :math:`P(I) = -5I^2+100I`, where I represents the current, in
amperes.

.. rst-class:: keepwithnext

a\) What value of the current will maximize the power?

.. rst-class:: solution

:math:`0=-5I^2+100I \Rightarrow 0=-5I(I-20) \Rightarrow I=0` or :math:`I=20`

.. rst-class:: solution

x-vertex :math:`=\dfrac{0+20}{2}=10`. A current of **10 A** maximizes the
power.

.. rst-class:: keepwithnext

b\) What is the maximum power?

.. rst-class:: solution

:math:`P(10) = -5(10)^2+100(10) = -500+1000 = 500`

.. rst-class:: solution

The maximum power is **500 W**.

Section 4: Solve Quadratics by Factoring
================================================================================

.. rst-class:: keepwithnext

**9)** Solve each of the following quadratic equations by factoring.

.. rst-class:: keepwithnext

a\) :math:`x^2+4x-21=0`

.. rst-class:: solution

:math:`(x+7)(x-3)=0`, so :math:`x=-7` or :math:`x=3`

.. rst-class:: keepwithnext

b\) :math:`5x^2-19x-4=0`

.. rst-class:: solution

Decompose: :math:`5x^2-20x+x-4=0 \Rightarrow 5x(x-4)+1(x-4)=0
\Rightarrow (x-4)(5x+1)=0`

.. rst-class:: solution

:math:`x=4` or :math:`x=-\dfrac{1}{5}`

.. rst-class:: keepwithnext

c\) :math:`4x^2+12x=-9`

.. rst-class:: solution

:math:`4x^2+12x+9=0` is a perfect square trinomial:
:math:`(2x+3)^2=0 \Rightarrow x=-\dfrac{3}{2}`

.. rst-class:: keepwithnext

a\) x-intercepts -2 and 5, containing the point (3, 5)

.. rst-class:: solution

.. rst-class:: solution

:math:`y=a\left(x-(-2+\sqrt{5})\right)\left(x-(-2-\sqrt{5})\right) =
a\left((x+2)^2-5\right) = a(x^2+4x-1)`

.. rst-class:: solution

Substitute :math:`(-4,5)`: :math:`5=a((-4)^2+4(-4)-1)=a(-1)
\Rightarrow a=-5`

.. rst-class:: solution

:math:`y=-5(x^2+4x-1) = -5x^2-20x+5`

**14)** A golf ball is hit, and it lands at a point on the same
horizontal plane 53 meters away. The path of the ball took it just over
a 9 meter tall tree that was 8 meters in front of the golfer.

.. rst-class:: keepwithnext

a\) Assume the ball is hit from the origin of a coordinate plane. Find a
quadratic function that describes the path of the ball.

.. rst-class:: solution

The ball lands at :math:`(0,0)` and :math:`(53,0)`, and passes through
:math:`(8,9)`: :math:`y=a\,x(x-53)`

.. rst-class:: solution

:math:`9=a(8)(8-53)=a(-360) \Rightarrow a=-\dfrac{1}{40}`

.. rst-class:: solution

:math:`y=-\dfrac{1}{40}x(x-53) = -\dfrac{1}{40}x^2+\dfrac{53}{40}x`

.. rst-class:: keepwithnext

b\) What is the maximum height of the ball?

.. rst-class:: solution

x-vertex :math:`=\dfrac{0+53}{2}=26.5`

.. rst-class:: solution

y-vertex :math:`=-\dfrac{1}{40}(26.5)^2+\dfrac{53}{40}(26.5) \approx
17.6` m

**15)** Determine the points of intersection of each pair of functions.

.. rst-class:: keepwithnext

a\) :math:`f(x) = 4x^2-15x+20` and :math:`g(x) = 5x-4`

.. rst-class:: solution

:math:`5x-4 = 4x^2-15x+20 \Rightarrow 0 = 4x^2-20x+24 \Rightarrow
0 = 4(x^2-5x+6) \Rightarrow 0 = (x-2)(x-3)`

.. rst-class:: solution

:math:`x=2` or :math:`x=3`

.. rst-class:: solution

POI #1: :math:`g(2)=5(2)-4=6`, giving :math:`(2,6)`.

.. rst-class:: solution

POI #2: :math:`g(3)=5(3)-4=11`, giving :math:`(3,11)`.

.. rst-class:: keepwithnext

b\) :math:`f(x) = -2x^2+9x+9` and :math:`g(x) = -3x-5`

.. rst-class:: solution

:math:`-3x-5 = -2x^2+9x+9 \Rightarrow 0 = -2x^2+12x+14 \Rightarrow
0 = x^2-6x-7 \Rightarrow 0 = (x-7)(x+1)`

.. rst-class:: solution

:math:`x=7` or :math:`x=-1`

.. rst-class:: solution

POI #1: :math:`g(7)=-3(7)-5=-26`, giving :math:`(7,-26)`.

.. rst-class:: solution

POI #2: :math:`g(-1)=-3(-1)-5=-2`, giving :math:`(-1,-2)`.
