.. rst-class:: keepwithnext

**1)** Détermine si chaque fonction quadratique croisera une fois, deux
fois, ou pas du tout la fonction linéaire donnée.

.. rst-class:: keepwithnext

a\) :math:`y = 2x^2-2x+1` et :math:`y = 3x-5`

.. rst-class:: solution

:math:`3x-5 = 2x^2-2x+1 \Rightarrow 0 = 2x^2-5x+6`

.. rst-class:: solution

:math:`b^2-4ac = (-5)^2-4(2)(6) = -23`

.. rst-class:: solution

Puisque le discriminant est négatif, **elles ne se croisent pas**.

.. rst-class:: keepwithnext

b\) :math:`y = -x^2+3x-5` et :math:`y = -x-1`

.. rst-class:: solution

:math:`-x-1 = -x^2+3x-5 \Rightarrow 0 = -x^2+4x-4`

.. rst-class:: solution

:math:`b^2-4ac = (4)^2-4(-1)(-4) = 0`

.. rst-class:: solution

Puisque le discriminant est 0, **1 PI**.

.. rst-class:: keepwithnext

c\) :math:`y = \dfrac{1}{2}x^2+4x-2` et :math:`y = x+3`

.. rst-class:: solution

:math:`x+3 = \dfrac{1}{2}x^2+4x-2 \Rightarrow 0 = \dfrac{1}{2}x^2+3x-5`

.. rst-class:: solution

:math:`b^2-4ac = (3)^2-4\left(\dfrac{1}{2}\right)(-5) = 19`

.. rst-class:: solution

Puisque le discriminant est positif, **2 PI**.

.. rst-class:: keepwithnext

d\) :math:`y = -\dfrac{2}{3}x^2+x+3` et :math:`y = x`

.. rst-class:: solution

:math:`x = -\dfrac{2}{3}x^2+x+3 \Rightarrow 0 = -\dfrac{2}{3}x^2+3`

.. rst-class:: solution

:math:`b^2-4ac = (0)^2-4\left(-\dfrac{2}{3}\right)(3) = 8`

.. rst-class:: solution

Puisque le discriminant est positif, **2 PI**.

.. rst-class:: keepwithnext

**2)** Détermine les coordonnées du ou des points d’intersection de
chaque système linéaire-quadratique.

.. rst-class:: keepwithnext

a\) :math:`y = x^2-7x+15` et :math:`y = 2x-5`

.. rst-class:: solution

:math:`2x-5 = x^2-7x+15 \Rightarrow 0 = x^2-9x+20 \Rightarrow 0 = (x-4)(x-5)`

.. rst-class:: solution

:math:`x=4` ou :math:`x=5`

.. rst-class:: solution

PI #1 : :math:`f(4) = 2(4)-5 = 3`, ce qui donne :math:`(4,3)`.

.. rst-class:: solution

PI #2 : :math:`f(5) = 2(5)-5 = 5`, ce qui donne :math:`(5,5)`.

.. rst-class:: keepwithnext

b\) :math:`y = 3x^2-16x+37` et :math:`y = 8x+1`

.. rst-class:: solution

:math:`8x+1 = 3x^2-16x+37 \Rightarrow 0 = 3x^2-24x+36 \Rightarrow
0 = 3(x^2-8x+12) \Rightarrow 0 = (x-2)(x-6)`

.. rst-class:: solution

:math:`x=2` ou :math:`x=6`

.. rst-class:: solution

PI #1 : :math:`f(2) = 8(2)+1 = 17`, ce qui donne :math:`(2,17)`.

.. rst-class:: solution

PI #2 : :math:`f(6) = 8(6)+1 = 49`, ce qui donne :math:`(6,49)`.

.. rst-class:: keepwithnext

c\) :math:`y = \dfrac{1}{2}x^2-2x-3` et :math:`y = -3x+1`

.. rst-class:: solution

:math:`-3x+1 = \dfrac{1}{2}x^2-2x-3 \Rightarrow 0 = \dfrac{1}{2}x^2+x-4
\Rightarrow 0 = x^2+2x-8 \Rightarrow 0 = (x+4)(x-2)`

.. rst-class:: solution

:math:`x=-4` ou :math:`x=2`

.. rst-class:: solution

PI #1 : :math:`f(-4) = -3(-4)+1 = 13`, ce qui donne :math:`(-4,13)`.

.. rst-class:: solution

PI #2 : :math:`f(2) = -3(2)+1 = -5`, ce qui donne :math:`(2,-5)`.

.. rst-class:: keepwithnext

**3)** Détermine la valeur de l’ordonnée à l’origine d’une droite, de
pente donnée, qui est tangente à la courbe donnée.

.. rst-class:: keepwithnext

a\) :math:`y = -2x^2+5x+4` et une droite de pente 1

.. rst-class:: solution

Soit la droite :math:`y=x+b`. :math:`x+b = -2x^2+5x+4 \Rightarrow
0 = -2x^2+4x+(4-b)`

.. rst-class:: solution

Pose :math:`b^2-4ac=0` : :math:`(4)^2-4(-2)(4-b) = 0`

.. rst-class:: solution

:math:`16-4(-8+2b) = 0 \Rightarrow 16+32-8b = 0 \Rightarrow -8b=-48
\Rightarrow b=6`

.. rst-class:: keepwithnext

b\) :math:`y = -x^2-5x-5` et une droite de pente -3

.. rst-class:: solution

Soit la droite :math:`y=-3x+b`. :math:`-3x+b = -x^2-5x-5 \Rightarrow
0 = -x^2-2x+(-5-b)`

.. rst-class:: solution

Pose :math:`b^2-4ac=0` : :math:`(-2)^2-4(-1)(-5-b) = 0`

.. rst-class:: solution

:math:`4-4(5+b) = 0 \Rightarrow 4-20-4b = 0 \Rightarrow -4b=16
\Rightarrow b=-4`

.. rst-class:: keepwithnext

**4)** Le tracé d’un ruisseau souterrain est donné par la fonction
:math:`y = 4x^2+17x-32`. Deux nouvelles maisons ont besoin de puits. Sur
le plan du terrain, ces maisons se trouvent sur une droite définie par
l’équation :math:`y = -15x+100`. Détermine les coordonnées où les deux
nouveaux puits doivent être creusés.

.. rst-class:: solution

:math:`-15x+100 = 4x^2+17x-32 \Rightarrow 0 = 4x^2+32x-132 \Rightarrow
0 = 4(x^2+8x-33) \Rightarrow 0 = (x+11)(x-3)`

.. rst-class:: solution

:math:`x=-11` ou :math:`x=3`

.. rst-class:: solution

PI #1 : :math:`f(-11) = -15(-11)+100 = 265`, ce qui donne
:math:`(-11,265)`.

.. rst-class:: solution

PI #2 : :math:`f(3) = -15(3)+100 = 55`, ce qui donne :math:`(3,55)`.
