Définitions
================================================================================

**Radicande :**

.. rst-class:: solution

un nombre ou une expression sous un signe radical

**Radical entier :**

.. rst-class:: solution

un radical de la forme :math:`\sqrt{n}`, où :math:`n > 0`, comme
:math:`\sqrt{45}`

**Radical mixte :**

.. rst-class:: solution

un radical de la forme :math:`a\sqrt{b}`, où :math:`a \neq 1` ou
:math:`-1` et :math:`b > 0`, comme :math:`3\sqrt{5}`

En savoir plus sur les radicaux
================================================================================

Certains nombres ne peuvent pas être exprimés sous forme de fractions. On
les appelle des nombres :sol:`irrationnels`. Un type de nombre irrationnel
est de la forme :math:`\sqrt{n}` où :math:`n` n’est pas un carré parfait.
Ces nombres sont parfois appelés :sol:`radicaux`.

On peut trouver une valeur approximative de ces nombres irrationnels à
l’aide d’une calculatrice, mais il est préférable de travailler avec une
valeur exacte. Les réponses doivent être laissées sous forme radicale
lorsqu’une réponse EXACTE est demandée. Parfois, un radical entier peut
être simplifié en retirant les facteurs carrés parfaits. L’expression
obtenue s’appelle un :sol:`radical mixte`.

Addition et soustraction de radicaux
================================================================================

L’addition et la soustraction de radicaux fonctionnent de la même façon
que l’addition et la soustraction de polynômes. On ne peut additionner
que des termes :sol:`semblables` ou, dans ce cas, des
:sol:`radicaux semblables`.

**Exemple :**

:math:`2\sqrt{3}+5\sqrt{7}` ne peuvent pas être additionnés, car ils
n’ont pas le même radical.

Par contre, :math:`3\sqrt{5}+6\sqrt{5}` ont un radical commun, donc ils
peuvent être additionnés. :math:`3\sqrt{5}+6\sqrt{5} = 9\sqrt{5}`

Remarque, le radical reste le même lors de l’addition et de la
soustraction d’expressions avec des radicaux semblables.

.. rst-class:: keepwithnext

**Exemple 2 :** Simplifie les expressions suivantes

.. rst-class:: keepwithnext

a\) :math:`9\sqrt{7}-3\sqrt{7}`

.. rst-class:: solution

:math:`= 6\sqrt{7}`

.. rst-class:: keepwithnext

b\) :math:`4\sqrt{3}-2\sqrt{27}`

.. rst-class:: solution

:math:`= 4\sqrt{3}-2(\sqrt{9})(\sqrt{3}) = 4\sqrt{3}-2(3)(\sqrt{3}) =
4\sqrt{3}-6\sqrt{3} = -2\sqrt{3}`

.. rst-class:: keepwithnext

c\) :math:`5\sqrt{8}+3\sqrt{18}`

.. rst-class:: solution

:math:`= 5(\sqrt{4})(\sqrt{2})+3(\sqrt{9})(\sqrt{2}) =
5(2)(\sqrt{2})+3(3)(\sqrt{2}) = 10\sqrt{2}+9\sqrt{2} = 19\sqrt{2}`

.. rst-class:: keepwithnext

d\) :math:`\dfrac{1}{4}\sqrt{28}-\dfrac{3}{4}\sqrt{63}+\dfrac{2}{3}\sqrt{50}`

.. rst-class:: solution

:math:`= \dfrac{1}{4}(\sqrt{4})(\sqrt{7})-\dfrac{3}{4}(\sqrt{9})(\sqrt{7})+
\dfrac{2}{3}(\sqrt{25})(\sqrt{2})`

.. rst-class:: solution

:math:`= \dfrac{2}{4}\sqrt{7}-\dfrac{9}{4}\sqrt{7}+\dfrac{10}{3}\sqrt{2}`

.. rst-class:: solution

:math:`= -\dfrac{7}{4}\sqrt{7}+\dfrac{10}{3}\sqrt{2}`

Multiplication de radicaux
================================================================================

.. rst-class:: keepwithnext

**Exemple 3 :** Simplifie complètement

.. rst-class:: keepwithnext

a\) :math:`(2\sqrt{3})(3\sqrt{6})`

*Multiplie les coefficients ensemble, puis multiplie les radicandes
ensemble. Simplifie ensuite!*

.. rst-class:: solution

:math:`= (2)(3)(\sqrt{3})(\sqrt{6}) = 6\sqrt{18} = 6(\sqrt{9})(\sqrt{2}) =
6(3)(\sqrt{2}) = 18\sqrt{2}`

.. rst-class:: keepwithnext

b\) :math:`2\sqrt{3}(4+5\sqrt{3})`

*N’oublie pas la propriété de distributivité :* :math:`a(x+y) = ax+ay`

.. rst-class:: solution

:math:`= 2\sqrt{3}(4)+2\sqrt{3}(5\sqrt{3}) = 8\sqrt{3}+10\sqrt{9} =
8\sqrt{3}+10(3) = 8\sqrt{3}+30`

.. rst-class:: keepwithnext

c\) :math:`-7\sqrt{2}(6\sqrt{8}-11)`

.. rst-class:: solution

:math:`= -7\sqrt{2}(6\sqrt{8})-7\sqrt{2}(-11) = -42\sqrt{16}+77\sqrt{2} =
-168+77\sqrt{2}`

.. rst-class:: keepwithnext

d\) :math:`(\sqrt{3}+5)(2-\sqrt{3})`

*N’oublie pas la méthode FOIL (double distribution). Chaque terme du
premier binôme doit être multiplié par chaque terme du second binôme.*

.. rst-class:: solution

:math:`= \sqrt{3}(2)+\sqrt{3}(-\sqrt{3})+5(2)+5(-\sqrt{3}) =
2\sqrt{3}-\sqrt{9}+10-5\sqrt{3}`

.. rst-class:: solution

:math:`= 2\sqrt{3}-5\sqrt{3}-3+10 = -3\sqrt{3}+7`

.. rst-class:: keepwithnext

e\) :math:`(2\sqrt{2}+3\sqrt{3})(2\sqrt{2}-3\sqrt{3})`

*Il existe un raccourci! C’est une différence de carrés.*
:math:`(a+b)(a-b) = a^2-b^2`

.. rst-class:: solution

:math:`= (2\sqrt{2})^2-(3\sqrt{3})^2 = 4(2)-9(3) = 8-27 = -19`

Concepts clés
================================================================================

- .. rst-class:: solution

  :math:`\sqrt{a}\times\sqrt{b} = \sqrt{ab}` pour :math:`a \geq 0` et
  :math:`b \geq 0`.
- .. rst-class:: solution

  Un radical entier peut être simplifié en un radical mixte sous sa forme
  la plus simple en retirant le plus grand carré parfait de sous le
  radical pour former un radical mixte. Par exemple,
  :math:`\sqrt{50} = \sqrt{25\times2} = 5\sqrt{2}`.
- .. rst-class:: solution

  Les radicaux semblables peuvent être combinés par addition et
  soustraction. Par exemple, :math:`3\sqrt{7}+2\sqrt{7} = 5\sqrt{7}`.
- .. rst-class:: solution

  Les radicaux peuvent être multipliés à l’aide de la propriété de
  distributivité. Par exemple,
  :math:`4\sqrt{2}(5\sqrt{3}-3) = 20\sqrt{6}-12\sqrt{2}` et
  :math:`(\sqrt{2}-3)(\sqrt{2}+1) = \sqrt{4}+\sqrt{2}-3\sqrt{2}-3 =
  2-2\sqrt{2}-3 = -2\sqrt{2}-1`.
