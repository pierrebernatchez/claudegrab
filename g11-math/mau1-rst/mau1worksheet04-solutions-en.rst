**4)** Add or subtract as indicated

.. rst-class:: keepwithnext

a\) :math:`8\sqrt{2}-4\sqrt{8}+\sqrt{32}`

.. rst-class:: solution

:math:`= 8\sqrt{2}-4(\sqrt{4})(\sqrt{2})+(\sqrt{16})(\sqrt{2}) =
8\sqrt{2}-8\sqrt{2}+4\sqrt{2} = 4\sqrt{2}`

.. rst-class:: keepwithnext

b\) :math:`\sqrt{20}-4\sqrt{12}-\sqrt{125}+2\sqrt{3}`

.. rst-class:: solution

:math:`= (\sqrt{4})(\sqrt{5})-4(\sqrt{4})(\sqrt{3})-(\sqrt{25})(\sqrt{5})+2\sqrt{3}`

.. rst-class:: solution

:math:`= 2\sqrt{5}-8\sqrt{3}-5\sqrt{5}+2\sqrt{3} = -3\sqrt{5}-6\sqrt{3}`

.. rst-class:: keepwithnext

c\) :math:`5\sqrt{3}-\sqrt{72}+\sqrt{243}+\sqrt{8}`

.. rst-class:: solution

:math:`= 5\sqrt{3}-(\sqrt{36})(\sqrt{2})+(\sqrt{81})(\sqrt{3})+(\sqrt{4})(\sqrt{2})`

.. rst-class:: solution

:math:`= 5\sqrt{3}-6\sqrt{2}+9\sqrt{3}+2\sqrt{2} = 14\sqrt{3}-4\sqrt{2}`

.. rst-class:: keepwithnext

d\) :math:`\sqrt{44}+\sqrt{88}+\sqrt{99}+\sqrt{198}`

.. rst-class:: solution

:math:`= (\sqrt{4})(\sqrt{11})+(\sqrt{4})(\sqrt{22})+(\sqrt{9})(\sqrt{11})+(\sqrt{9})(\sqrt{22})`

.. rst-class:: solution

:math:`= 2\sqrt{11}+2\sqrt{22}+3\sqrt{11}+3\sqrt{22} = 5\sqrt{11}+5\sqrt{22}`

.. rst-class:: keepwithnext

**7)** Expand and simplify where possible

.. rst-class:: keepwithnext

a\) :math:`(\sqrt{2}+5)(\sqrt{2}+5)`

.. rst-class:: solution

:math:`= \sqrt{4}+5\sqrt{2}+5\sqrt{2}+25 = 2+10\sqrt{2}+25 = 27+10\sqrt{2}`

.. rst-class:: keepwithnext

b\) :math:`(\sqrt{3}+2\sqrt{2})(5+5\sqrt{2})`

.. rst-class:: solution

:math:`= 5\sqrt{3}+5\sqrt{6}+10\sqrt{2}+10\sqrt{4} =
5\sqrt{3}+5\sqrt{6}+10\sqrt{2}+20`

.. rst-class:: keepwithnext

c\) :math:`(1+\sqrt{5})(1-\sqrt{5})`

.. rst-class:: solution

Difference of squares: :math:`= (1)^2-(\sqrt{5})^2 = 1-5 = -4`

.. rst-class:: keepwithnext

d\) :math:`(4-3\sqrt{7})(\sqrt{7}+1)`

.. rst-class:: solution

:math:`= 4\sqrt{7}+4-3\sqrt{49}-3\sqrt{7} = 4\sqrt{7}+4-21-3\sqrt{7} =
\sqrt{7}-17`

**8)** Simplify

.. rst-class:: keepwithnext

a\) :math:`\dfrac{1}{4}\sqrt{54}-\dfrac{1}{4}\sqrt{150}`

.. rst-class:: solution

:math:`= \dfrac{1}{4}(\sqrt{9})(\sqrt{6})-\dfrac{1}{4}(\sqrt{25})(\sqrt{6})
= \dfrac{3}{4}\sqrt{6}-\dfrac{5}{4}\sqrt{6} = -\dfrac{1}{2}\sqrt{6}`

.. rst-class:: keepwithnext

b\) :math:`\dfrac{1}{2}\sqrt{8}+\dfrac{3}{5}\sqrt{50}-\dfrac{2}{3}\sqrt{18}`

.. rst-class:: solution

:math:`= \dfrac{1}{2}(\sqrt{4})(\sqrt{2})+\dfrac{3}{5}(\sqrt{25})(\sqrt{2})-
\dfrac{2}{3}(\sqrt{9})(\sqrt{2})`

.. rst-class:: solution

:math:`= 1\sqrt{2}+3\sqrt{2}-2\sqrt{2} = 2\sqrt{2}`

answer in simplified radical form.

**11)** Simplify each of the following

.. rst-class:: keepwithnext

a\) :math:`\dfrac{21-7\sqrt{6}}{7}`

.. rst-class:: solution

:math:`= \dfrac{7(3-\sqrt{6})}{7} = 3-\sqrt{6}`

.. rst-class:: solution

:math:`= \dfrac{12-(\sqrt{16})(\sqrt{3})}{4} = \dfrac{12-4\sqrt{3}}{4} =
\dfrac{4(3-\sqrt{3})}{4} = 3-\sqrt{3}`
