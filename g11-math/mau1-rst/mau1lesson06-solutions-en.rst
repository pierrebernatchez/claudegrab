Part 1: Do It Now
================================================================================

a\) Do you remember the quadratic formula?

.. rst-class:: solution

:math:`x = \dfrac{-b\pm\sqrt{b^2-4ac}}{2a}`

.. rst-class:: keepwithnext

b\) Use the quadratic formula to find the x-intercepts of:

:math:`0 = 2x^2+7x-4`

.. rst-class:: solution

Don't forget that to solve a quadratic, it must be set equal to zero
because at an x-intercept, the y-coordinate will be zero.

.. rst-class:: solution

:math:`x = \dfrac{-7\pm\sqrt{(7)^2-4(2)(-4)}}{2(2)}`

.. rst-class:: solution

:math:`x = \dfrac{-7\pm\sqrt{49+32}}{4} = \dfrac{-7\pm\sqrt{81}}{4} =
\dfrac{-7\pm9}{4}`

.. rst-class:: solution

:math:`x=\dfrac{-7+9}{4}=\dfrac{1}{2}` or :math:`x=\dfrac{-7-9}{4}=-4`

Part 2: Discriminant Review
================================================================================

Do all parabolas have two x-intercepts?

.. rst-class:: solution

No.

What are the three different scenarios?

.. rst-class:: solution

A parabola can have 0, 1, or 2 solutions (x-intercepts).

The way to determine how many x-intercepts a parabola might have is by
evaluating the :math:`b^2-4ac` part of the quadratic formula (called the
"**discriminant**")

**Discriminant:** the value under the square root

.. rst-class:: keepwithnext

If :math:`b^2-4ac > 0`, there are two solutions

.. image:: ../images/mau1lesson06-gpimage01.png
   :scale: 100

.. rst-class:: keepwithnext

If :math:`b^2-4ac = 0`, there is one solution

.. image:: ../images/mau1lesson06-gpimage02.png
   :scale: 100

.. rst-class:: keepwithnext

If :math:`b^2-4ac < 0`, there are no solutions

.. image:: ../images/mau1lesson06-gpimage03.png
   :scale: 100

Part 3: Solve a Quadratic With 2 Roots
================================================================================

.. image:: ../images/mau1lesson06-gpimage04.png
   :scale: 100

**Objective:** Determine the roots of a quadratic using the quadratic
formula and leave as EXACT answers

**Exact answer:** as a radical or fraction. Exact answers do not have
decimals.

.. rst-class:: keepwithnext

**Example 1:** Find the exact solutions of :math:`3x^2-10x+5=0`

.. rst-class:: solution

:math:`x = \dfrac{10\pm\sqrt{(-10)^2-4(3)(5)}}{2(3)} =
\dfrac{10\pm\sqrt{40}}{6}`

.. rst-class:: solution

:math:`= \dfrac{10\pm\sqrt{4}\sqrt{10}}{6} = \dfrac{10\pm2\sqrt{10}}{6}`
(simplify the radical)

.. rst-class:: solution

:math:`= \dfrac{2(5\pm\sqrt{10})}{6} = \dfrac{5\pm\sqrt{10}}{3}`
(common factor, reduce)

.. rst-class:: solution

:math:`x=\dfrac{5+\sqrt{10}}{3}` or :math:`x=\dfrac{5-\sqrt{10}}{3}`

.. rst-class:: keepwithnext

**Example 2:** Find the exact solutions of :math:`-2x^2+8x-5=0`

.. rst-class:: solution

:math:`x = \dfrac{-8\pm\sqrt{(8)^2-4(-2)(-5)}}{2(-2)} =
\dfrac{-8\pm\sqrt{24}}{-4}`

.. rst-class:: solution

:math:`= \dfrac{-8\pm\sqrt{4}\sqrt{6}}{-4} = \dfrac{-8\pm2\sqrt{6}}{-4}`
(simplify the radical)

.. rst-class:: solution

:math:`= \dfrac{2(4\mp\sqrt{6})}{2(-2)} = \dfrac{4\mp\sqrt{6}}{-2} =
\dfrac{4\mp\sqrt{6}}{2}` (common factor, reduce)

.. rst-class:: solution

:math:`x=\dfrac{4-\sqrt{6}}{2}` or :math:`x=\dfrac{4+\sqrt{6}}{2}`

Part 4: Solving a Quadratic With 1 Root
================================================================================

.. image:: ../images/mau1lesson06-gpimage05.png
   :scale: 100

**Note:** when a quadratic only has 1 solution, the x-intercept is also
the vertex

.. rst-class:: keepwithnext

**Example 3:** Find the exact roots of :math:`4x^2+24x+36=0`

.. rst-class:: solution

Common factor 4: :math:`4(x^2+6x+9)=0 \Rightarrow x^2+6x+9=0`

.. rst-class:: solution

:math:`x = \dfrac{-6\pm\sqrt{(6)^2-4(1)(9)}}{2(1)} = \dfrac{-6\pm\sqrt{0}}{2}`

.. rst-class:: solution

:math:`x = \dfrac{-6}{2} = -3`

Part 5: Solving Quadratics With 0 Roots
================================================================================

.. image:: ../images/mau1lesson06-gpimage06.png
   :scale: 100

2 Scenarios causing 0 roots:

i\) vertex is above the x-axis and opens up

ii\) vertex is below the x-axis and opens down

.. rst-class:: keepwithnext

**Example 4:** Find the x-intercepts of :math:`8x^2-11x+5=0`

.. rst-class:: solution

:math:`x = \dfrac{11\pm\sqrt{(-11)^2-4(8)(5)}}{2(8)} = \dfrac{11\pm\sqrt{-39}}{16}`

.. rst-class:: solution

Since the value under the square root is negative, there are no real
solutions.

Part 6: Use the Discriminant to Determine the Number of Roots
================================================================================

.. rst-class:: keepwithnext

**Example 5:** For each of the following quadratics, use the discriminant
to state the number of roots it will have.

.. rst-class:: keepwithnext

a\) :math:`2x^2+5x-5=0`

.. rst-class:: solution

:math:`b^2-4ac = (5)^2-4(2)(-5) = 25+40 = 65`

.. rst-class:: solution

:math:`65>0`, so 2 solutions

.. rst-class:: keepwithnext

b\) :math:`3x^2-7x+5=0`

.. rst-class:: solution

:math:`b^2-4ac = (-7)^2-4(3)(5) = 49-60 = -11`

.. rst-class:: solution

:math:`-11<0`, so no solutions

.. rst-class:: keepwithnext

c\) :math:`-4x^2+12x-9=0`

.. rst-class:: solution

:math:`b^2-4ac = (12)^2-4(-4)(-9) = 144-144 = 0`

.. rst-class:: solution

:math:`0=0`, so 1 solution

Part 7: Application
================================================================================

.. rst-class:: keepwithnext

**Example 6:** A ball is thrown and the equation below models its path:

:math:`h = -0.25d^2+2d+1.5`

'h' is the height in meters above the ground and 'd' is the horizontal
distance in meters from the person who threw the ball.

.. rst-class:: keepwithnext

a\) At what height was the ball thrown from?

.. rst-class:: solution

Solve for 'h' when :math:`d=0`:
:math:`h = -0.25(0)^2+2(0)+1.5 = 1.5` meters

.. rst-class:: keepwithnext

b\) How far has the ball travelled horizontally when it lands on the
ground?

.. rst-class:: solution

Set :math:`h=0`: :math:`0 = -0.25d^2+2d+1.5`

.. rst-class:: solution

Divide by -0.25: :math:`0 = d^2-8d-6`

.. rst-class:: solution

:math:`d = \dfrac{8\pm\sqrt{(-8)^2-4(1)(-6)}}{2(1)} = \dfrac{8\pm\sqrt{88}}{2}`

.. rst-class:: solution

:math:`d=\dfrac{8+\sqrt{88}}{2}\approx8.7` meters, or
:math:`d=\dfrac{8-\sqrt{88}}{2}\approx-0.7` meters (rejected, negative
distance)

.. rst-class:: solution

The ball travels approximately 8.7 meters horizontally.
