Lesson Outline
================================================================================

**Section 1:** Solve a quadratic with an 'a' value of 1 or that can be
factored out

**Section 2:** Solve a quadratic with an 'a' value of not 1 that can't be
factored out.

In all cases we will start with an equation in Standard Form and we will
set it equal to 0:

:math:`ax^2+bx+c = 0`

**NOTE:** If it's not in standard form, you must rearrange before
factoring.

How to Solve Quadratics
================================================================================

Solving a quadratic means to find the x-intercepts or roots.

To solve a quadratic equation:

1) It must be set to equal 0. Before factoring, it must be in the form
   :math:`ax^2+bx+c = 0`
2) Factor the left side of the equation
3) Set each factor to equal zero and solve for :math:`x`.

**zero product rule:** if two factors have a product of zero; one or both
of the factors must equal zero.

.. rst-class:: keepwithnext

**Example 1:** Solve the following quadratics by factoring

When factoring :math:`ax^2+bx+c=0` when 'a' is 1 or can be factored out,
steps to follow:

1) Check if there is a common factor that can be divided out
2) Look at the 'c' value and the 'b' value
3) Determine what factors multiply to give 'c' and add to give 'b'
4) Put those factors into :math:`(x+r)(x+s)` for 'r' and 's'.
5) Make sure nothing else can be factored

.. rst-class:: keepwithnext

a\) :math:`0 = x^2-15x+56`

.. rst-class:: solution

Product: 56, sum: -15, so the factors are -8 and -7:
:math:`0 = (x-8)(x-7)`

.. rst-class:: solution

:math:`x-8=0` or :math:`x-7=0`, so :math:`x=8` or :math:`x=7`

.. rst-class:: keepwithnext

b\) :math:`-6 = x^2-5x`

.. rst-class:: solution

Rearrange to standard form: :math:`0 = x^2-5x+6`. Product: 6, sum: -5,
so the factors are -2 and -3: :math:`0 = (x-2)(x-3)`

.. rst-class:: solution

:math:`x-2=0` or :math:`x-3=0`, so :math:`x=2` or :math:`x=3`

.. rst-class:: keepwithnext

c\) :math:`0 = 2x^2-8x-42`

.. rst-class:: solution

Common factor 2: :math:`0 = 2(x^2-4x-21)`. Product: -21, sum: -4, so the
factors are -7 and 3: :math:`0 = 2(x-7)(x+3)`

.. rst-class:: solution

:math:`x-7=0` or :math:`x+3=0`, so :math:`x=7` or :math:`x=-3`

.. rst-class:: keepwithnext

**Example 2:** Solve by factoring

Steps to factoring :math:`ax^2+bx+c` when 'a' cannot be factored out and
is not 1:

1) Look to see if there is a common factor that can be divided out
2) Take the 'a' value and multiply it to the 'c' value
3) Determine what factors of THIS number add together to get the 'b'
   value
4) Break the 'b' value up into THOSE factors!
5) Put parenthesis around the first two variables and the last two
6) Factor by grouping

.. rst-class:: keepwithnext

a\) :math:`8x^2+2x-15=0`

.. rst-class:: solution

Product: :math:`8\times(-15)=-120`, sum: 2, so the factors are 12 and
-10: :math:`8x^2+12x-10x-15=0`

.. rst-class:: solution

:math:`(8x^2+12x)+(-10x-15)=0` (factor by grouping)

.. rst-class:: solution

:math:`4x(2x+3)-5(2x+3)=0` (common factor each group)

.. rst-class:: solution

:math:`(2x+3)(4x-5)=0` (binomial common factor, zero product rule)

.. rst-class:: solution

:math:`2x+3=0` or :math:`4x-5=0`, so :math:`x=-\dfrac{3}{2}` or
:math:`x=\dfrac{5}{4}`

.. rst-class:: keepwithnext

b\) :math:`2x^2-11x = -15`

.. rst-class:: solution

Rearrange: :math:`2x^2-11x+15=0`. Product: :math:`2\times15=30`, sum:
-11, so the factors are -6 and -5: :math:`2x^2-6x-5x+15=0`

.. rst-class:: solution

:math:`(2x^2-6x)+(-5x+15)=0`

.. rst-class:: solution

:math:`2x(x-3)-5(x-3)=0`

.. rst-class:: solution

:math:`(x-3)(2x-5)=0`

.. rst-class:: solution

:math:`x-3=0` or :math:`2x-5=0`, so :math:`x=3` or :math:`x=\dfrac{5}{2}`

.. rst-class:: keepwithnext

**Example 3:** For the quadratic :math:`y = 2x^2-4x-16`

.. rst-class:: keepwithnext

a\) Find the roots of the quadratic by factoring

.. rst-class:: solution

:math:`0 = 2(x^2-2x-8)`. Product: -8, sum: -2, so the factors are -4 and
2: :math:`0 = 2(x-4)(x+2)`

.. rst-class:: solution

:math:`x-4=0` or :math:`x+2=0`, so :math:`x=4` or :math:`x=-2`

.. rst-class:: keepwithnext

b\) Find the axis of symmetry (average of x-intercepts)

.. rst-class:: solution

:math:`\text{a.o.s} = \dfrac{r+s}{2} = \dfrac{4+(-2)}{2} = \dfrac{2}{2} = 1`

.. rst-class:: keepwithnext

c\) Find the coordinates of the vertex and state if it is a max or min
value

.. rst-class:: solution

:math:`x_{vertex} = 1`

.. rst-class:: solution

:math:`y_{vertex} = 2(1)^2-4(1)-16 = 2-4-16 = -18`

.. rst-class:: solution

So the vertex is :math:`(1,-18)`. This is a minimum value because the
parabola opens up (:math:`a>0`).
