Partie 1 : Révision du domaine et de l'image
================================================================================

.. rst-class:: keepwithnext

a\) Déterminez le domaine et l'image de la relation illustrée dans le
graphique suivant :

.. image:: ../images/mau1lesson02-gpimage01.png
   :scale: 90

.. rst-class:: solution

:math:`D: \{x \in \mathbb{R} \mid -7 \leq x \leq 7\}`

.. rst-class:: solution

:math:`I: \{y \in \mathbb{R} \mid -2.5 \leq y \leq 3\}`

.. rst-class:: keepwithnext

b\) Est-ce une fonction?

.. rst-class:: solution

Non, elle ne réussit pas le test de la droite verticale.

.. rst-class:: keepwithnext

c\) Qu'est-ce qui détermine si une relation est une fonction ou non?

.. rst-class:: solution

Pour chaque valeur de :math:`x`, il ne peut y avoir qu'une seule valeur
correspondante de :math:`y`.

.. rst-class:: keepwithnext

d\) Comment le test de la droite verticale nous aide-t-il à déterminer si
une relation est une fonction?

.. rst-class:: solution

Si une droite verticale touche le graphique de la relation en plus d'un
point, ce n'est PAS une fonction.

.. rst-class:: keepwithnext

e\) Qu'est-ce que le domaine?

.. rst-class:: solution

Les valeurs que :math:`x` peut prendre.

.. rst-class:: keepwithnext

f\) Qu'est-ce que l'image?

.. rst-class:: solution

Les valeurs que :math:`y` peut prendre.

Partie 2 : Déterminer des valeurs à l'aide de la notation fonctionnelle
================================================================================

.. container:: keeptogether

   Que fait une fonction?

   .. rst-class:: solution

   Elle prend une entrée (x), lui applique des opérations, puis produit une
   sortie (y).

   .. image:: ../images/mau1lesson02-gpimage02-fr.png
      :scale: 85
      :alt: machine à fonction, ENTRÉE x -> FONCTION f : -> SORTIE f(x)

   À quoi ressemble la notation fonctionnelle?

   .. rst-class:: solution

   :math:`f(x) = \text{des opérations appliquées à } x` |---| se lit « f de
   x » ou « f en x », remplace « y »

.. rst-class:: keepwithnext

**Exemple 1 :** Pour chacune des fonctions suivantes, déterminez
:math:`f(2)`, :math:`f(-5)` et :math:`f(1/2)`

.. rst-class:: keepwithnext

a\) :math:`f(x) = 2x - 4`

.. rst-class:: solution

:math:`f(2) = 2(2) - 4 = 0` |---| :math:`(2, 0)`

.. rst-class:: solution

:math:`f(-5) = 2(-5) - 4 = -14` |---| :math:`(-5, -14)`

.. rst-class:: solution

:math:`f(1/2) = 2(1/2) - 4 = -3` |---| :math:`(1/2, -3)`

.. rst-class:: keepwithnext

b\) :math:`f(x) = 3x^2 - x + 7`

.. rst-class:: solution

:math:`f(2) = 3(2)^2 - 2 + 7 = 17` |---| :math:`(2, 17)`

.. rst-class:: solution

:math:`f(-5) = 3(-5)^2 - (-5) + 7 = 75 + 5 + 7 = 87` |---| :math:`(-5, 87)`

.. rst-class:: solution

:math:`f(1/2) = 3(1/2)^2 - 1/2 + 7 = 3/4 - 2/4 + 28/4 = 29/4` |---|
:math:`(1/2, 29/4)`

.. rst-class:: keepwithnext

c\) :math:`f(x) = 87`

.. rst-class:: solution

:math:`f(2) = 87` |---| :math:`(2, 87)`

.. rst-class:: solution

:math:`f(-5) = 87` |---| :math:`(-5, 87)`

.. rst-class:: solution

:math:`f(1/2) = 87` |---| :math:`(1/2, 87)`

.. rst-class:: keepwithnext

d\) :math:`f(x) = \dfrac{2x}{x^2 - 3}`

.. rst-class:: solution

:math:`f(2) = \dfrac{2(2)}{(2)^2 - 3} = 4` |---| :math:`(2, 4)`

.. rst-class:: solution

:math:`f(-5) = \dfrac{2(-5)}{(-5)^2 - 3} = \dfrac{-10}{22} = \dfrac{-5}{11}`
|---| :math:`(-5, -5/11)`

.. rst-class:: solution

:math:`f(1/2) = \dfrac{2(1/2)}{(1/2)^2 - 3} = \dfrac{1}{1/4 - 12/4} =
\dfrac{1}{-11/4} = \dfrac{-4}{11}` |---| :math:`(1/2, -4/11)`

Diagrammes sagittaux
================================================================================

Un diagramme sagittal est une représentation qu'on peut utiliser lorsque la
relation est donnée sous forme d'un ensemble de couples. Dans un diagramme
sagittal, les valeurs du :sol:`domaine` dans une ellipse sont reliées aux
valeurs de l':sol:`image` dans l'autre ellipse à l'aide de flèches.

Une relation est une fonction s'il y a exactement :sol:`une` flèche partant
de chaque valeur du domaine. Cela indique que chaque élément du domaine
correspond à exactement un élément de l'image.

.. image:: ../images/mau1lesson02-gpimage03-fr.png
   :scale: 80
   :alt: diagramme sagittal, 1->1, 2->4, 3->9, 4->16, 5->25

**Exemple 4 :** La température de l'eau à la surface d'un lac est de 22
degrés Celsius. Lorsque Geno plonge en scaphandre autonome vers les
profondeurs du lac, il constate que la température diminue de 1,5 degré
pour chaque 8 mètres de descente.

*Remarquez qu'il s'agit d'un taux de variation constant, ce qui en fait une
fonction linéaire de la forme* :math:`y = mx + b`

.. rst-class:: keepwithnext

a\) Modélisez la température de l'eau à n'importe quelle profondeur à
l'aide de la notation fonctionnelle.

.. rst-class:: solution

:math:`m = \dfrac{\Delta T}{\Delta d} = \dfrac{-1.5}{8} = \dfrac{-3}{16}`,
:math:`b = 22`

.. rst-class:: solution

:math:`T(d) = \dfrac{-3}{16}d + 22`

.. rst-class:: keepwithnext

b\) Quelle est la température de l'eau à une profondeur de 40 mètres?

.. rst-class:: solution

:math:`T(40) = \dfrac{-3}{16}(40) + 22`

.. rst-class:: solution

:math:`T(40) = 14.5°C`

.. rst-class:: keepwithnext

c\) Au fond du lac, la température est de 5,5 degrés Celsius. Quelle est la
profondeur du lac?

.. rst-class:: solution

:math:`5.5 = \dfrac{-3}{16}d + 22`

.. rst-class:: solution

:math:`(16)\ {-16.5} = \dfrac{-3}{16}d\ (16)`

.. rst-class:: solution

:math:`-264 = -3d`

.. rst-class:: solution

:math:`d = 88` mètres de profondeur
