**1)** Determine the vertex for each quadratic function by completing
the square. State if the vertex is a maximum or a minimum.

.. rst-class:: keepwithnext

a\) :math:`f(x) = x^2+14x-14`

.. rst-class:: solution

:math:`= (x^2+14x)-14 = (x^2+14x+49-49)-14 = (x+7)^2-63`

.. rst-class:: solution

Vertex is :math:`(-7,-63)` and is a minimum.

.. rst-class:: keepwithnext

b\) :math:`f(x) = x^2-6x+17`

.. rst-class:: solution

:math:`= (x^2-6x)+17 = (x^2-6x+9-9)+17 = (x-3)^2+8`

.. rst-class:: solution

Vertex is :math:`(3,8)` and is a minimum.

.. rst-class:: keepwithnext

c\) :math:`f(x) = x^2+7x+11`

.. rst-class:: solution

:math:`= \left(x^2+7x+\dfrac{49}{4}-\dfrac{49}{4}\right)+11 =
\left(x+\dfrac{7}{2}\right)^2-\dfrac{5}{4}`

.. rst-class:: solution

Vertex is :math:`\left(-\dfrac{7}{2},-\dfrac{5}{4}\right)` and is a minimum.

.. rst-class:: keepwithnext

d\) :math:`f(x) = 2x^2+12x+16`

.. rst-class:: solution

:math:`= 2(x^2+6x+9-9)+16 = 2(x+3)^2-2`

.. rst-class:: solution

Vertex is :math:`(-3,-2)` and is a minimum.

.. rst-class:: keepwithnext

e\) :math:`f(x) = -3x^2+6x+1`

.. rst-class:: solution

:math:`= -3(x^2-2x+1-1)+1 = -3(x-1)^2+4`

.. rst-class:: solution

Vertex is :math:`(1,4)` and is a maximum.

.. rst-class:: keepwithnext

f\) :math:`f(x) = -\dfrac{1}{2}x^2-x+\dfrac{3}{2}`

.. rst-class:: solution

:math:`= -\dfrac{1}{2}(x^2+2x+1-1)+\dfrac{3}{2} =
-\dfrac{1}{2}(x+1)^2+2`

.. rst-class:: solution

Vertex is :math:`(-1,2)` and is a maximum.

**2)** Use partial factoring to determine the vertex of each function.
State if the vertex is a max or min.

.. rst-class:: keepwithnext

a\) :math:`f(x) = 3x^2-6x+11`

.. rst-class:: solution

:math:`11 = 3x^2-6x+11 \Rightarrow 0 = 3x^2-6x \Rightarrow 0 = 3x(x-2)`,
giving :math:`x=0,\ x=2`

.. rst-class:: solution

x-vertex :math:`= \dfrac{0+2}{2} = 1`; y-vertex :math:`= 3(1)^2-6(1)+11 = 8`

.. rst-class:: solution

Vertex is :math:`(1,8)` and is a minimum.

.. rst-class:: keepwithnext

b\) :math:`f(x) = -2x^2+8x-3`

.. rst-class:: solution

:math:`-3 = -2x^2+8x-3 \Rightarrow 0 = -2x^2+8x \Rightarrow 0 = -2x(x-4)`,
giving :math:`x=0,\ x=4`

.. rst-class:: solution

x-vertex :math:`= \dfrac{0+4}{2} = 2`; y-vertex
:math:`= -2(2)^2+8(2)-3 = 5`

.. rst-class:: solution

Vertex is :math:`(2,5)` and is a maximum.

.. rst-class:: keepwithnext

c\) :math:`h(x) = -x^2+2x+4`

.. rst-class:: solution

:math:`4 = -x^2+2x+4 \Rightarrow 0 = -x^2+2x \Rightarrow 0 = -x(x-2)`,
giving :math:`x=0,\ x=2`

.. rst-class:: solution

x-vertex :math:`= \dfrac{0+2}{2} = 1`; y-vertex :math:`= -(1)^2+2(1)+4 = 5`

.. rst-class:: solution

Vertex is :math:`(1,5)` and is a maximum.

.. rst-class:: keepwithnext

d\) :math:`f(x) = 2x^2+12x+17`

.. rst-class:: solution

:math:`17 = 2x^2+12x+17 \Rightarrow 0 = 2x^2+12x \Rightarrow 0 = 2x(x+6)`,
giving :math:`x=0,\ x=-6`

.. rst-class:: solution

x-vertex :math:`= \dfrac{0+(-6)}{2} = -3`; y-vertex
:math:`= 2(-3)^2+12(-3)+17 = -1`

.. rst-class:: solution

Vertex is :math:`(-3,-1)` and is a minimum.

.. rst-class:: keepwithnext

e\) :math:`f(x) = 4x^2+64x+156`

.. rst-class:: solution

:math:`156 = 4x^2+64x+156 \Rightarrow 0 = 4x^2+64x \Rightarrow
0 = 4x(x+16)`, giving :math:`x=0,\ x=-16`

.. rst-class:: solution

x-vertex :math:`= \dfrac{0+(-16)}{2} = -8`; y-vertex
:math:`= 4(-8)^2+64(-8)+156 = -100`

.. rst-class:: solution

Vertex is :math:`(-8,-100)` and is a minimum.

.. rst-class:: keepwithnext

f\) :math:`f(x) = \dfrac{1}{2}x^2-3x+8`

.. rst-class:: solution

:math:`8 = \dfrac{1}{2}x^2-3x+8 \Rightarrow 0 = \dfrac{1}{2}x^2-3x
\Rightarrow 0 = \dfrac{1}{2}x(x-6)`, giving :math:`x=0,\ x=6`

.. rst-class:: solution

x-vertex :math:`= \dfrac{0+6}{2} = 3`; y-vertex
:math:`= \dfrac{1}{2}(3)^2-3(3)+8 = \dfrac{7}{2}`

.. rst-class:: solution

Vertex is :math:`\left(3,\dfrac{7}{2}\right)` and is a minimum.

**3)** An electronics store sells an average of 60 entertainment systems
per month at an average of $800 more than the cost price. For every $20
increase in the selling price, the store sells one fewer system. What
amount over the cost price will maximize revenue?

.. rst-class:: solution

Revenue :math:`= (\text{cost})(\text{number sold})`:
:math:`0 = (800+20x)(60-x)`

.. rst-class:: solution

:math:`800+20x=0 \Rightarrow x=-40`; :math:`60-x=0 \Rightarrow x=60`

.. rst-class:: solution

x-vertex :math:`= \dfrac{-40+60}{2} = 10`

.. rst-class:: solution

:math:`\text{cost} = 800+20(10) = 1000`

.. rst-class:: solution

A price of $1000 over the cost price will maximize revenue.

**4)** Last year, a banquet hall charged $30 per person, and 60 people
attended the hockey banquet dinner. This year, the hall's manager has
said that for every 10 extra people that attend the banquet, they will
decrease the price by $1.50 per person. What size group would maximize
the profit for the hall this year and what would the maximum profit be?

.. rst-class:: solution

Profit :math:`= (\text{cost})(\text{number of people})`:
:math:`0 = (30-1.50x)(60+10x)`

.. rst-class:: solution

:math:`30-1.50x=0 \Rightarrow x=20`; :math:`60+10x=0 \Rightarrow x=-6`

.. rst-class:: solution

x-vertex :math:`= \dfrac{20+(-6)}{2} = 7`

.. rst-class:: solution

cost :math:`= 30-1.50(7) = 19.50`; people :math:`= 60+10(7) = 130`

.. rst-class:: solution

profit :math:`= (19.50)(130) = 2535`

.. rst-class:: solution

A group of 130 would give a max profit of $2535 (cost $19.50 per person).

**5)** The path of a rocket is given by the function,
:math:`h(t) = -3t^2+30t+73`, where 'h' is the height in meters and 't' is
the time in seconds.

.. rst-class:: keepwithnext

a\) What is the maximum height of the rocket?

.. rst-class:: solution

:math:`h(t) = -3(t^2-10t)+73 = -3(t^2-10t+25-25)+73 = -3(t-5)^2+148`

.. rst-class:: solution

Vertex is :math:`(5,148)`. Max height is 148 m.

.. rst-class:: keepwithnext

b\) At what time does the rocket reach its maximum height?

.. rst-class:: solution

5 seconds.
