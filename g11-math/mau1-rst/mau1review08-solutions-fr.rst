Section 2 : maximum ou minimum d’une fonction quadratique
================================================================================

.. rst-class:: keepwithnext

**2)** Détermine le sommet de chaque fonction quadratique en complétant
le carré. Indique si le sommet est un maximum ou un minimum.

.. rst-class:: keepwithnext

a\) :math:`f(x) = x^2-10x+7`

.. rst-class:: solution

:math:`= (x^2-10x+25-25)+7 = (x-5)^2-18`

.. rst-class:: solution

Sommet :math:`(5,-18)` |nbsp| |nbsp| **minimum**

.. rst-class:: keepwithnext

b\) :math:`f(x) = x^2+2x+6`

.. rst-class:: solution

:math:`= (x^2+2x+1-1)+6 = (x+1)^2+5`

.. rst-class:: solution

Sommet :math:`(-1,5)` |nbsp| |nbsp| **minimum**

.. rst-class:: keepwithnext

c\) :math:`f(x) = 3x^2-30x+73`

.. rst-class:: solution

:math:`= 3(x^2-10x)+73 = 3(x^2-10x+25-25)+73 = 3(x-5)^2-2`

.. rst-class:: solution

Sommet :math:`(5,-2)` |nbsp| |nbsp| **minimum**

.. rst-class:: keepwithnext

d\) :math:`f(x) = -2x^2-8x+7`

.. rst-class:: solution

:math:`= -2(x^2+4x)+7 = -2(x^2+4x+4-4)+7 = -2(x+2)^2+15`

.. rst-class:: solution

**3)** Utilise la factorisation partielle pour déterminer le sommet de
chaque fonction. Indique si le sommet est un maximum ou un minimum.

.. rst-class:: keepwithnext

a\) :math:`y = -x^2+4x+11`

.. rst-class:: solution

:math:`0=-x^2+4x \Rightarrow 0=-x(x-4) \Rightarrow x=0` ou :math:`x=4`

.. rst-class:: solution

sommet-x :math:`=\dfrac{0+4}{2}=2`; sommet-y
:math:`=-(2)^2+4(2)+11=15`

.. rst-class:: solution

Sommet :math:`(2,15)` |nbsp| |nbsp| **maximum**

.. rst-class:: keepwithnext

b\) :math:`y = 3x^2-18x+14`

.. rst-class:: solution

:math:`0=3x^2-18x \Rightarrow 0=3x(x-6) \Rightarrow x=0` ou :math:`x=6`

.. rst-class:: solution

sommet-x :math:`=\dfrac{0+6}{2}=3`; sommet-y
:math:`=3(3)^2-18(3)+14=-13`

.. rst-class:: solution

Sommet :math:`(3,-13)` |nbsp| |nbsp| **minimum**

.. rst-class:: keepwithnext

c\) :math:`y = 5x^2+14x-21`

.. rst-class:: solution

:math:`0=5x^2+14x \Rightarrow 0=x(5x+14) \Rightarrow x=0` ou :math:`x=-\dfrac{14}{5}=-2.8`

.. rst-class:: solution

sommet-x :math:`=\dfrac{0+(-2.8)}{2}=-1.4`; sommet-y
:math:`=5(-1.4)^2+14(-1.4)-21=-30.8`

.. rst-class:: solution

Sommet :math:`(-1.4,-30.8)` |nbsp| |nbsp| **minimum**

.. rst-class:: keepwithnext

d\) :math:`y = -2x^2-11x+1`

.. rst-class:: solution

:math:`0=-2x^2-11x \Rightarrow 0=-x(2x+11) \Rightarrow x=0` ou
:math:`x=-\dfrac{11}{2}=-5.5`

.. rst-class:: solution

sommet-x :math:`=\dfrac{0+(-5.5)}{2}=-2.75`; sommet-y
:math:`=-2(-2.75)^2-11(-2.75)+1=16.125`

.. rst-class:: solution

Sommet :math:`\left(-\dfrac{11}{4},\dfrac{129}{8}\right)` |nbsp| |nbsp|
**maximum**

.. rst-class:: keepwithnext

**4)** Une salle facture 30 $ par personne pour un banquet sportif
lorsque 120 personnes y assistent. Pour chaque tranche de 10 personnes
supplémentaires, la salle diminuera le prix de 1,50 $ par personne. Quel
nombre de personnes maximisera les revenus de la salle ?

.. rst-class:: solution

Revenu :math:`=(\text{coût})(\text{nombre de personnes})`:
:math:`0=(30-1.50x)(120+10x)`

.. rst-class:: solution

:math:`30-1.50x=0 \Rightarrow x=20`; :math:`120+10x=0 \Rightarrow x=-12`

.. rst-class:: solution

sommet-x :math:`=\dfrac{20+(-12)}{2}=4`; nombre de personnes
:math:`=120+10(4)=160`

.. rst-class:: solution

**160 personnes** maximiseront les revenus.

.. rst-class:: keepwithnext

**5)** La puissance, P, en watts, produite par un panneau solaire est
donnée par la fonction :math:`P(I) = -5I^2+100I`, où I représente le
courant, en ampères.

.. rst-class:: keepwithnext

a\) Quelle valeur du courant maximisera la puissance ?

.. rst-class:: solution

:math:`0=-5I^2+100I \Rightarrow 0=-5I(I-20) \Rightarrow I=0` ou :math:`I=20`

.. rst-class:: solution

sommet-x :math:`=\dfrac{0+20}{2}=10`. Un courant de **10 A** maximise la
puissance.

.. rst-class:: keepwithnext

b\) Quelle est la puissance maximale ?

.. rst-class:: solution

:math:`P(10) = -5(10)^2+100(10) = -500+1000 = 500`

.. rst-class:: solution

La puissance maximale est de **500 W**.

Section 4 : résoudre des quadratiques par factorisation
================================================================================

.. rst-class:: keepwithnext

**9)** Résous chacune des équations quadratiques suivantes par
factorisation.

.. rst-class:: keepwithnext

a\) :math:`x^2+4x-21=0`

.. rst-class:: solution

:math:`(x+7)(x-3)=0`, donc :math:`x=-7` ou :math:`x=3`

.. rst-class:: keepwithnext

b\) :math:`5x^2-19x-4=0`

.. rst-class:: solution

Décompose : :math:`5x^2-20x+x-4=0 \Rightarrow 5x(x-4)+1(x-4)=0
\Rightarrow (x-4)(5x+1)=0`

.. rst-class:: solution

:math:`x=4` ou :math:`x=-\dfrac{1}{5}`

.. rst-class:: keepwithnext

c\) :math:`4x^2+12x=-9`

.. rst-class:: solution

:math:`4x^2+12x+9=0` est un trinôme carré parfait :
:math:`(2x+3)^2=0 \Rightarrow x=-\dfrac{3}{2}`

Section 5 : résoudre des quadratiques à l’aide de la formule quadratique

.. rst-class:: keepwithnext

**10)** Résous chaque équation quadratique. Donne des réponses exactes.

.. rst-class:: keepwithnext

a\) :math:`f(x) = 2x^2-9x-1`

.. rst-class:: solution

:math:`x = \dfrac{9\pm\sqrt{(-9)^2-4(2)(-1)}}{2(2)} = \dfrac{9\pm\sqrt{89}}{4}`

.. rst-class:: solution

:math:`x=\dfrac{9+\sqrt{89}}{4}` ou :math:`x=\dfrac{9-\sqrt{89}}{4}`

.. rst-class:: keepwithnext

b\) :math:`g(x) = -3x^2+4x+2`

.. rst-class:: solution

:math:`x = \dfrac{-4\pm\sqrt{(4)^2-4(-3)(2)}}{2(-3)} =
\dfrac{-4\pm\sqrt{40}}{-6} = \dfrac{-4\pm2\sqrt{10}}{-6}`

.. rst-class:: solution

:math:`x=\dfrac{2-\sqrt{10}}{3}` ou :math:`x=\dfrac{2+\sqrt{10}}{3}`

.. rst-class:: keepwithnext

**11)** Résous chaque équation quadratique en utilisant n’importe
quelle méthode.

.. rst-class:: keepwithnext

a\) :math:`3x^2-15x=42`

.. rst-class:: solution

:math:`3x^2-15x-42=0 \Rightarrow 3(x^2-5x-14)=0 \Rightarrow x^2-5x-14=0`

.. rst-class:: solution

:math:`(x-7)(x+2)=0`, donc :math:`x=7` ou :math:`x=-2`

.. rst-class:: keepwithnext

b\) :math:`5x^2+11x+1=0`

.. rst-class:: solution

:math:`x = \dfrac{-11\pm\sqrt{(11)^2-4(5)(1)}}{2(5)} =
\dfrac{-11\pm\sqrt{101}}{10}`

**12)** Utilise le discriminant pour prédire le nombre de racines
réelles de...

.. rst-class:: keepwithnext

a\) :math:`f(x) = x^2+3x+3`

.. rst-class:: solution

.. rst-class:: solution

Section 6 : déterminer une équation quadratique à partir de ses racines
================================================================================

.. rst-class:: keepwithnext

**13)** Détermine l’équation sous forme générale de chaque fonction
quadratique...

.. rst-class:: keepwithnext

a\) abscisses à l’origine -2 et 5, passant par le point (3, 5)

.. rst-class:: solution

:math:`y=a(x+2)(x-5)`. Substitue :math:`(3,5)` :
:math:`5=a(3+2)(3-5)=a(5)(-2)=-10a \Rightarrow a=-\dfrac{1}{2}`

.. rst-class:: solution

:math:`y=-\dfrac{1}{2}(x+2)(x-5) = -\dfrac{1}{2}x^2+\dfrac{3}{2}x+5`

.. rst-class:: keepwithnext

b\) abscisses à l’origine :math:`-2\pm\sqrt{5}`, passant par le point
(-4, 5)

.. rst-class:: solution

:math:`y=a\left(x-(-2+\sqrt{5})\right)\left(x-(-2-\sqrt{5})\right) =
a\left((x+2)^2-5\right) = a(x^2+4x-1)`

.. rst-class:: solution

Substitue :math:`(-4,5)` : :math:`5=a((-4)^2+4(-4)-1)=a(-1)
\Rightarrow a=-5`

.. rst-class:: solution

:math:`y=-5(x^2+4x-1) = -5x^2-20x+5`

.. container:: keeptogether

   **14)** Une balle de golf est frappée et atterrit à un point situé
   sur le même plan horizontal, à 53 mètres de distance. La trajectoire
   de la balle l’a fait passer tout juste au-dessus d’un arbre de 9
   mètres de hauteur situé à 8 mètres devant le golfeur.

   a\) Suppose que la balle est frappée à partir de l’origine d’un plan
   cartésien. Trouve une fonction quadratique qui décrit la trajectoire
   de la balle.

   .. rst-class:: solution

   La balle atterrit en :math:`(0,0)` et :math:`(53,0)`, et passe par
   :math:`(8,9)` : :math:`y=a\,x(x-53)`

   .. rst-class:: solution

   :math:`9=a(8)(8-53)=a(-360) \Rightarrow a=-\dfrac{1}{40}`

   .. rst-class:: solution

   :math:`y=-\dfrac{1}{40}x(x-53) = -\dfrac{1}{40}x^2+\dfrac{53}{40}x`

.. rst-class:: keepwithnext

b\) Quelle est la hauteur maximale de la balle ?

.. rst-class:: solution

sommet-x :math:`=\dfrac{0+53}{2}=26.5`

.. rst-class:: solution

sommet-y :math:`=-\dfrac{1}{40}(26.5)^2+\dfrac{53}{40}(26.5) \approx
17.6` m

Section 7 : systèmes linéaires-quadratiques
================================================================================

.. rst-class:: keepwithnext

**15)** Détermine les points d’intersection de chaque paire de
fonctions.

.. rst-class:: keepwithnext

a\) :math:`f(x) = 4x^2-15x+20` et :math:`g(x) = 5x-4`

.. rst-class:: solution

:math:`5x-4 = 4x^2-15x+20 \Rightarrow 0 = 4x^2-20x+24 \Rightarrow
0 = 4(x^2-5x+6) \Rightarrow 0 = (x-2)(x-3)`

.. rst-class:: solution

:math:`x=2` ou :math:`x=3`

.. rst-class:: solution

PI #1 : :math:`g(2)=5(2)-4=6`, ce qui donne :math:`(2,6)`.

.. rst-class:: solution

PI #2 : :math:`g(3)=5(3)-4=11`, ce qui donne :math:`(3,11)`.

.. rst-class:: keepwithnext

b\) :math:`f(x) = -2x^2+9x+9` et :math:`g(x) = -3x-5`

.. rst-class:: solution

:math:`-3x-5 = -2x^2+9x+9 \Rightarrow 0 = -2x^2+12x+14 \Rightarrow
0 = x^2-6x-7 \Rightarrow 0 = (x-7)(x+1)`

.. rst-class:: solution

:math:`x=7` ou :math:`x=-1`

.. rst-class:: solution

PI #1 : :math:`g(7)=-3(7)-5=-26`, ce qui donne :math:`(7,-26)`.

.. rst-class:: solution

PI #2 : :math:`g(-1)=-3(-1)-5=-2`, ce qui donne :math:`(-1,-2)`.

**16)** Pour quelle valeur de b la droite :math:`y = -2x+b` sera-t-elle
tangente à la parabole :math:`y = 3x^2+4x-1` ?

.. rst-class:: solution

:math:`-2x+b = 3x^2+4x-1 \Rightarrow 0 = 3x^2+6x+(-1-b)`

.. rst-class:: solution

Pose :math:`b^2-4ac=0` : :math:`(6)^2-4(3)(-1-b) = 0`

.. rst-class:: solution

:math:`36+12+12b=0 \Rightarrow 12b=-48 \Rightarrow b=-4`
