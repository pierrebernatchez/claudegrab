**1)** Détermine le sommet de chaque fonction quadratique en complétant le
carré. Indique si le sommet est un maximum ou un minimum.

.. rst-class:: keepwithnext

a\) :math:`f(x) = x^2+14x-14`

.. rst-class:: solution

:math:`= (x^2+14x)-14 = (x^2+14x+49-49)-14 = (x+7)^2-63`

.. rst-class:: solution

Le sommet est :math:`(-7,-63)` et c'est un minimum.

.. rst-class:: keepwithnext

b\) :math:`f(x) = x^2-6x+17`

.. rst-class:: solution

:math:`= (x^2-6x)+17 = (x^2-6x+9-9)+17 = (x-3)^2+8`

.. rst-class:: solution

Le sommet est :math:`(3,8)` et c'est un minimum.

.. rst-class:: keepwithnext

c\) :math:`f(x) = x^2+7x+11`

.. rst-class:: solution

:math:`= \left(x^2+7x+\dfrac{49}{4}-\dfrac{49}{4}\right)+11 =
\left(x+\dfrac{7}{2}\right)^2-\dfrac{5}{4}`

.. rst-class:: solution

Le sommet est :math:`\left(-\dfrac{7}{2},-\dfrac{5}{4}\right)` et c'est un
minimum.

.. rst-class:: keepwithnext

d\) :math:`f(x) = 2x^2+12x+16`

.. rst-class:: solution

:math:`= 2(x^2+6x+9-9)+16 = 2(x+3)^2-2`

.. rst-class:: solution

Le sommet est :math:`(-3,-2)` et c'est un minimum.

.. rst-class:: keepwithnext

e\) :math:`f(x) = -3x^2+6x+1`

.. rst-class:: solution

:math:`= -3(x^2-2x+1-1)+1 = -3(x-1)^2+4`

.. rst-class:: solution

Le sommet est :math:`(1,4)` et c'est un maximum.

.. rst-class:: keepwithnext

f\) :math:`f(x) = -\dfrac{1}{2}x^2-x+\dfrac{3}{2}`

.. rst-class:: solution

:math:`= -\dfrac{1}{2}(x^2+2x+1-1)+\dfrac{3}{2} =
-\dfrac{1}{2}(x+1)^2+2`

.. rst-class:: solution

Le sommet est :math:`(-1,2)` et c'est un maximum.

**2)** Utilise la factorisation partielle pour déterminer le sommet de
chaque fonction. Indique si le sommet est un maximum ou un minimum.

.. rst-class:: keepwithnext

a\) :math:`f(x) = 3x^2-6x+11`

.. rst-class:: solution

:math:`11 = 3x^2-6x+11 \Rightarrow 0 = 3x^2-6x \Rightarrow 0 = 3x(x-2)`,
ce qui donne :math:`x=0,\ x=2`

.. rst-class:: solution

sommet-x :math:`= \dfrac{0+2}{2} = 1`; sommet-y
:math:`= 3(1)^2-6(1)+11 = 8`

.. rst-class:: solution

Le sommet est :math:`(1,8)` et c'est un minimum.

.. rst-class:: keepwithnext

b\) :math:`f(x) = -2x^2+8x-3`

.. rst-class:: solution

:math:`-3 = -2x^2+8x-3 \Rightarrow 0 = -2x^2+8x \Rightarrow 0 = -2x(x-4)`,
ce qui donne :math:`x=0,\ x=4`

.. rst-class:: solution

sommet-x :math:`= \dfrac{0+4}{2} = 2`; sommet-y
:math:`= -2(2)^2+8(2)-3 = 5`

.. rst-class:: solution

Le sommet est :math:`(2,5)` et c'est un maximum.

.. rst-class:: keepwithnext

c\) :math:`h(x) = -x^2+2x+4`

.. rst-class:: solution

:math:`4 = -x^2+2x+4 \Rightarrow 0 = -x^2+2x \Rightarrow 0 = -x(x-2)`,
ce qui donne :math:`x=0,\ x=2`

.. rst-class:: solution

sommet-x :math:`= \dfrac{0+2}{2} = 1`; sommet-y
:math:`= -(1)^2+2(1)+4 = 5`

.. rst-class:: solution

Le sommet est :math:`(1,5)` et c'est un maximum.

.. rst-class:: keepwithnext

d\) :math:`f(x) = 2x^2+12x+17`

.. rst-class:: solution

:math:`17 = 2x^2+12x+17 \Rightarrow 0 = 2x^2+12x \Rightarrow 0 = 2x(x+6)`,
ce qui donne :math:`x=0,\ x=-6`

.. rst-class:: solution

sommet-x :math:`= \dfrac{0+(-6)}{2} = -3`; sommet-y
:math:`= 2(-3)^2+12(-3)+17 = -1`

.. rst-class:: solution

Le sommet est :math:`(-3,-1)` et c'est un minimum.

.. rst-class:: keepwithnext

e\) :math:`f(x) = 4x^2+64x+156`

.. rst-class:: solution

:math:`156 = 4x^2+64x+156 \Rightarrow 0 = 4x^2+64x \Rightarrow
0 = 4x(x+16)`, ce qui donne :math:`x=0,\ x=-16`

.. rst-class:: solution

sommet-x :math:`= \dfrac{0+(-16)}{2} = -8`; sommet-y
:math:`= 4(-8)^2+64(-8)+156 = -100`

.. rst-class:: solution

Le sommet est :math:`(-8,-100)` et c'est un minimum.

.. rst-class:: keepwithnext

f\) :math:`f(x) = \dfrac{1}{2}x^2-3x+8`

.. rst-class:: solution

:math:`8 = \dfrac{1}{2}x^2-3x+8 \Rightarrow 0 = \dfrac{1}{2}x^2-3x
\Rightarrow 0 = \dfrac{1}{2}x(x-6)`, ce qui donne :math:`x=0,\ x=6`

.. rst-class:: solution

sommet-x :math:`= \dfrac{0+6}{2} = 3`; sommet-y
:math:`= \dfrac{1}{2}(3)^2-3(3)+8 = \dfrac{7}{2}`

.. rst-class:: solution

Le sommet est :math:`\left(3,\dfrac{7}{2}\right)` et c'est un minimum.

**3)** Un magasin d'électronique vend en moyenne 60 systèmes de
divertissement par mois à un prix moyen de 800 $ de plus que le prix
coûtant. Pour chaque augmentation de 20 $ du prix de vente, le magasin
vend un système de moins. Quel montant au-dessus du prix coûtant
maximisera le revenu ?

.. rst-class:: solution

Revenu :math:`= (\text{prix})(\text{nombre vendu})` :
:math:`0 = (800+20x)(60-x)`

.. rst-class:: solution

:math:`800+20x=0 \Rightarrow x=-40`; :math:`60-x=0 \Rightarrow x=60`

.. rst-class:: solution

sommet-x :math:`= \dfrac{-40+60}{2} = 10`

.. rst-class:: solution

:math:`\text{prix} = 800+20(10) = 1000`

.. rst-class:: solution

Un montant de 1000 $ au-dessus du prix coûtant maximisera le revenu.

**4)** L'an dernier, une salle de banquet facturait 30 $ par personne, et
60 personnes avaient assisté au banquet de hockey. Cette année, le
gérant de la salle a annoncé que pour chaque groupe de 10 personnes
supplémentaires présentes, le prix diminuera de 1,50 $ par personne.
Quelle taille de groupe maximiserait le profit de la salle cette année,
et quel serait ce profit maximal ?

.. rst-class:: solution

Profit :math:`= (\text{prix})(\text{nombre de personnes})` :
:math:`0 = (30-1.50x)(60+10x)`

.. rst-class:: solution

:math:`30-1.50x=0 \Rightarrow x=20`; :math:`60+10x=0 \Rightarrow x=-6`

.. rst-class:: solution

sommet-x :math:`= \dfrac{20+(-6)}{2} = 7`

.. rst-class:: solution

prix :math:`= 30-1.50(7) = 19.50`; personnes :math:`= 60+10(7) = 130`

.. rst-class:: solution

profit :math:`= (19.50)(130) = 2535`

.. rst-class:: solution

Un groupe de 130 personnes donnerait un profit maximal de 2535 $ (prix de
19,50 $ par personne).

**5)** La trajectoire d'une fusée est donnée par la fonction
:math:`h(t) = -3t^2+30t+73`, où « h » est la hauteur en mètres et « t » est
le temps en secondes.

.. rst-class:: keepwithnext

a\) Quelle est la hauteur maximale de la fusée ?

.. rst-class:: solution

:math:`h(t) = -3(t^2-10t)+73 = -3(t^2-10t+25-25)+73 = -3(t-5)^2+148`

.. rst-class:: solution

Le sommet est :math:`(5,148)`. La hauteur maximale est 148 m.

.. rst-class:: keepwithnext

b\) À quel moment la fusée atteint-elle sa hauteur maximale ?

.. rst-class:: solution

5 secondes.
