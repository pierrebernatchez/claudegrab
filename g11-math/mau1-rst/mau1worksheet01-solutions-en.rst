**7)** Pam has 90 m of fencing to enclose an area in a petting zoo with two
dividers to separate three types of young animals. The three pens are to
have the same area.

.. image:: ../images/mau1worksheet01-gpimage26.png
   :scale: 90

.. rst-class:: keepwithnext

a\) Express the function for the total area enclosed by all three pens
together, in terms of :math:`x`.

.. rst-class:: solution

The two dividers plus the two outer sides use :math:`4x` of fencing, leaving
:math:`90 - 4x` for the two lengths, so each pen has length
:math:`\dfrac{90-4x}{2}`.

.. math::
   :class: solution

   A = \left(\frac{90-4x}{2}\right)(x) = (45-2x)(x) = -2x^2 + 45x

.. rst-class:: keepwithnext

b\) Determine the domain and range for the area function.

.. rst-class:: solution

:math:`x`-intercepts: :math:`x = 0` or :math:`45 - 2x = 0 \Rightarrow x = 22.5`

.. rst-class:: solution

vertex: :math:`x = \dfrac{-45}{2(-2)} = 11.25`,
:math:`y = -2(11.25)^2 + 45(11.25) = 253.125`

.. rst-class:: solution

:math:`D: \{x \in \mathbb{R} \mid 0 < x < 22.5\}`

.. rst-class:: solution

:math:`R: \{y \in \mathbb{R} \mid 0 < y \leq 253.125\}`
