**2)** Determine the equation of the inverse of each function.

.. rst-class:: keepwithnext

a\) :math:`f(x) = 2x`

.. rst-class:: solution

:math:`y = 2x \Rightarrow x = 2y \Rightarrow \dfrac{x}{2} = y`

.. rst-class:: solution

:math:`f^{-1}(x) = \dfrac{x}{2}`

.. rst-class:: keepwithnext

b\) :math:`f(x) = 6x - 5`

.. rst-class:: solution

:math:`y = 6x-5 \Rightarrow x = 6y-5 \Rightarrow x+5 = 6y \Rightarrow
\dfrac{x+5}{6} = y`

.. rst-class:: solution

:math:`f^{-1}(x) = \dfrac{x+5}{6}`

.. rst-class:: keepwithnext

c\) :math:`f(x) = \dfrac{2x+4}{5}`

.. rst-class:: solution

:math:`y = \dfrac{2x+4}{5} \Rightarrow x = \dfrac{2y+4}{5} \Rightarrow
5x = 2y+4 \Rightarrow 5x-4 = 2y`

.. rst-class:: solution

:math:`f^{-1}(x) = \dfrac{5x-4}{2}`

.. rst-class:: keepwithnext

**3)** Determine the equation of the inverse of each function

.. rst-class:: keepwithnext

a\) :math:`f(x) = x^2 + 6`

.. rst-class:: solution

:math:`y = x^2+6 \Rightarrow x = y^2+6 \Rightarrow x-6 = y^2 \Rightarrow
\pm\sqrt{x-6} = y`

.. rst-class:: solution

:math:`f^{-1}(x) = \pm\sqrt{x-6}`

.. rst-class:: keepwithnext

b\) :math:`f(x) = (x+8)^2`

.. rst-class:: solution

:math:`y = (x+8)^2 \Rightarrow x = (y+8)^2 \Rightarrow \pm\sqrt{x} = y+8`

.. rst-class:: solution

:math:`f^{-1}(x) = \pm\sqrt{x} - 8`

.. rst-class:: keepwithnext

**4)** For each quadratic function, complete the square and then
determine the equation of the inverse.

.. rst-class:: keepwithnext

a\) :math:`f(x) = x^2 + 6x + 15`

.. rst-class:: solution

:math:`f(x) = (x^2+6x+9-9)+15 = (x+3)^2+6`

.. rst-class:: solution

:math:`x = (y+3)^2+6 \Rightarrow x-6 = (y+3)^2 \Rightarrow
\pm\sqrt{x-6} = y+3`

.. rst-class:: solution

:math:`f^{-1}(x) = \pm\sqrt{x-6} - 3`

.. rst-class:: keepwithnext

b\) :math:`f(x) = 2x^2 + 24x - 3`

.. rst-class:: solution

:math:`f(x) = 2(x^2+12x+36)-72-3 = 2(x+6)^2-75`

.. rst-class:: solution

:math:`x = 2(y+6)^2-75 \Rightarrow \dfrac{x+75}{2} = (y+6)^2 \Rightarrow
\pm\sqrt{\dfrac{x+75}{2}} = y+6`

.. rst-class:: solution

:math:`f^{-1}(x) = \pm\sqrt{\dfrac{x+75}{2}} - 6`

**8)** Determine the equation of the inverse for the given functions and
state the domain and range.

.. rst-class:: keepwithnext

a\) :math:`f(x) = \sqrt{x+3}`

.. rst-class:: solution

:math:`x = \sqrt{y+3} \Rightarrow x^2 = y+3 \Rightarrow x^2-3 = y`

.. rst-class:: solution

:math:`f^{-1}(x) = x^2 - 3`

.. rst-class:: solution

:math:`D` for :math:`f(x)`: :math:`\{x \in \mathbb{R} \mid x \geq -3\}`,
:math:`R` for :math:`f(x)`: :math:`\{y \in \mathbb{R} \mid y \geq 0\}`

.. rst-class:: solution

:math:`D` for :math:`f^{-1}(x)`: :math:`\{x \in \mathbb{R} \mid x \geq
0\}`, :math:`R` for :math:`f^{-1}(x)`: :math:`\{y \in \mathbb{R} \mid
y \geq -3\}`

.. rst-class:: keepwithnext

b\) :math:`f(x) = \dfrac{3}{x-2} + 2`

.. rst-class:: solution

:math:`x = \dfrac{3}{y-2}+2 \Rightarrow x-2 = \dfrac{3}{y-2} \Rightarrow
y-2 = \dfrac{3}{x-2} \Rightarrow y = \dfrac{3}{x-2}+2`

.. rst-class:: solution

:math:`f^{-1}(x) = \dfrac{3}{x-2} + 2`

.. rst-class:: solution

:math:`D` for :math:`f(x)`: :math:`\{x \in \mathbb{R} \mid x \neq 2\}`,
:math:`R` for :math:`f(x)`: :math:`\{y \in \mathbb{R} \mid y \neq 2\}`

.. rst-class:: solution

:math:`D` for :math:`f^{-1}(x)`: :math:`\{x \in \mathbb{R} \mid x \neq
2\}`, :math:`R` for :math:`f^{-1}(x)`: :math:`\{y \in \mathbb{R} \mid
y \neq 2\}`
