Réponses
================================================================================

**1)** a) la réciproque n'est PAS une fonction b) la réciproque n'est PAS
une fonction

**2)** a) :math:`f^{-1}(x) = \dfrac{x}{2}` b)
:math:`f^{-1}(x) = \dfrac{x+5}{6}` c)
:math:`f^{-1}(x) = \dfrac{5x-4}{2}`

**3)** a) :math:`f^{-1}(x) = \pm\sqrt{x-6}` b)
:math:`f^{-1}(x) = \pm\sqrt{x} - 8`

**4)** a) :math:`f^{-1}(x) = \pm\sqrt{x-6} - 3` b)
:math:`f^{-1}(x) = \pm\sqrt{\dfrac{x+75}{2}} - 6`

**5)** a) oui b) non

**6)** a) :math:`f^{-1}(x) = \dfrac{-x+6}{5}`

**7)** :math:`f^{-1}(x) = 2 \pm \sqrt{\dfrac{x-1}{2}}`

**8)** a) :math:`f^{-1}(x) = x^2 - 3`; :math:`D` pour :math:`f(x)` :
:math:`\{x \in \mathbb{R} \mid x \geq -3\}`, :math:`I` pour :math:`f(x)` :
:math:`\{y \in \mathbb{R} \mid y \geq 0\}`; :math:`D` pour
:math:`f^{-1}(x)` : :math:`\{x \in \mathbb{R} \mid x \geq 0\}`, :math:`I`
pour :math:`f^{-1}(x)` : :math:`\{y \in \mathbb{R} \mid y \geq -3\}`

b) :math:`f^{-1}(x) = \dfrac{3}{x-2} + 2`; :math:`D` pour :math:`f(x)` :
:math:`\{x \in \mathbb{R} \mid x \neq 2\}`, :math:`I` pour :math:`f(x)` :
:math:`\{y \in \mathbb{R} \mid y \neq 2\}`; :math:`D` pour
:math:`f^{-1}(x)` : :math:`\{x \in \mathbb{R} \mid x \neq 2\}`, :math:`I`
pour :math:`f^{-1}(x)` : :math:`\{y \in \mathbb{R} \mid y \neq 2\}`
