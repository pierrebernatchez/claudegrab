**Example 1:** Using the parent function :math:`f(x) = \sqrt{x}`, describe
the transformations and write the equation of the transformed function
:math:`g(x)`.

:math:`g(x) = -2f\left[-\dfrac{1}{3}(x+6)\right] - 5`
