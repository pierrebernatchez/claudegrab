Order of Transformations
================================================================================

**1.** stretches, compressions, reflections

**2.** translations

.. rst-class:: solution

:math:`a \to k \to d \to c`

.. rst-class:: keepwithnext

**Example 1:** If :math:`f(x) = x^2`, describe the changes and write the
transformed function:

.. container:: keeptogether

   a\) :math:`g(x) = 2f(x)`

   .. rst-class:: solution

   vertical stretch by a factor of 2

   .. rst-class:: solution

   :math:`g(x) = 2x^2`

.. container:: keeptogether

   b\) :math:`g(x) = f(2x)`

   .. rst-class:: solution

   horizontal compression by a factor of :math:`\dfrac{1}{2}`

   .. rst-class:: solution

   :math:`g(x) = (2x)^2`

.. container:: keeptogether

   c\) :math:`g(x) = f(x) + 4`

   .. rst-class:: solution

   shift up 4 units

   .. rst-class:: solution

   :math:`g(x) = x^2 + 4`

.. container:: keeptogether

   d\) :math:`g(x) = f(x+3)`

   .. rst-class:: solution

   shift left 3 units

   .. rst-class:: solution

   :math:`g(x) = (x+3)^2`

.. container:: keeptogether

   e\) :math:`g(x) = -f(x)`

   .. rst-class:: solution

   vertical reflection (flip over x-axis)

   .. rst-class:: solution

   :math:`g(x) = -x^2`

.. container:: keeptogether

   f\) :math:`g(x) = f(-x)`

   .. rst-class:: solution

   horizontal reflection (flip over y-axis)

   .. rst-class:: solution

   :math:`g(x) = (-x)^2`

.. rst-class:: keepwithnext

**Example 2:** For each of the following functions, describe the
transformations to :math:`f(x) = x^2` in order and write the transformed
equation.

.. container:: keeptogether

   a\) :math:`g(x) = -2f[-3(x+3)] - 1`

   .. rst-class:: solution

   vertical stretch by a factor of 2; vertical reflection; horizontal
   compression by a factor of :math:`\dfrac{1}{3}`; horizontal reflection;
   shift left 3 units and down 1 unit

   .. rst-class:: solution

   :math:`g(x) = -2[-3(x+3)]^2 - 1`

.. container:: keeptogether

   b\) :math:`y = \dfrac{1}{2}f[-3(x-2)] + 5`

   .. rst-class:: solution

   vertical compression by a factor of :math:`\dfrac{1}{2}`; horizontal
   compression by a factor of :math:`\dfrac{1}{3}`; horizontal reflection;
   shift right 2 units and up 5 units

   .. rst-class:: solution

   :math:`g(x) = \dfrac{1}{2}[-3(x-2)]^2 + 5`
