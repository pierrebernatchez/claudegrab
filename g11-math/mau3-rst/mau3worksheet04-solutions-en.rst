**1)** State the transformations to the parent function :math:`f(x) =
\dfrac{1}{x}` in the order that you would do them.

.. container:: keeptogether

   a\) :math:`g(x) = \dfrac{2}{3(x-1)}`

   .. rst-class:: solution

   vertical stretch by a factor of 2; horizontal compression by a factor
   of :math:`\dfrac{1}{3}`

   .. rst-class:: solution

   shift right 1 unit

.. container:: keeptogether

   b\) :math:`g(x) = \dfrac{-1}{x+2} - 1`

   .. rst-class:: solution

   vertical reflection

   .. rst-class:: solution

   shift left 2 units; shift down 1 unit

.. container:: keeptogether

   c\) :math:`g(x) = \dfrac{1}{\frac{1}{2}(x+1)} - 0.5`

   .. rst-class:: solution

   horizontal stretch by a factor of 2

   .. rst-class:: solution

   shift left 1 unit; shift down 0.5 units

.. rst-class:: keepwithnext

**3)** Use the description to write the transformed function,
:math:`g(x)`.

.. container:: keeptogether

   a\) The parent function, :math:`f(x) = \dfrac{1}{x}`, is compressed
   vertically by a factor of :math:`\dfrac{1}{3}` and then translated
   (shifted) 3 units left.

   .. rst-class:: solution

   :math:`a = \dfrac{1}{3}`, :math:`d = -3`

   .. rst-class:: solution

   :math:`g(x) = \dfrac{1}{3(x+3)}` or :math:`g(x) = \dfrac{1}{3} \cdot
   \dfrac{1}{x+3}`

.. container:: keeptogether

   b\) The parent function, :math:`f(x) = \dfrac{1}{x}`, is reflected over
   the x-axis, stretch horizontally by a factor of 3 and then translated 1
   unit left and 4 units down.

   .. rst-class:: solution

   :math:`a = -1`, :math:`k = \dfrac{1}{3}`, :math:`d = -1`, :math:`c = -4`

   .. rst-class:: solution

   :math:`g(x) = \dfrac{-1}{\frac{1}{3}(x+1)} - 4` or :math:`g(x) =
   \dfrac{-3}{x+1} - 4`
