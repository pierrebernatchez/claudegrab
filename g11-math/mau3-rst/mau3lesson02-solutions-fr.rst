Ordre des transformations
================================================================================

**1.** étirements, compressions, réflexions

**2.** translations

.. rst-class:: solution

:math:`a \to k \to d \to c`

.. rst-class:: keepwithnext

**Exemple 1 :** Si :math:`f(x) = x^2`, décris les changements et écris la
fonction transformée :

.. container:: keeptogether

   a\) :math:`g(x) = 2f(x)`

   .. rst-class:: solution

   étirement vertical d'un facteur de 2

   .. rst-class:: solution

   :math:`g(x) = 2x^2`

.. container:: keeptogether

   b\) :math:`g(x) = f(2x)`

   .. rst-class:: solution

   compression horizontale d'un facteur de :math:`\dfrac{1}{2}`

   .. rst-class:: solution

   :math:`g(x) = (2x)^2`

.. container:: keeptogether

   c\) :math:`g(x) = f(x) + 4`

   .. rst-class:: solution

   décalage de 4 unités vers le haut

   .. rst-class:: solution

   :math:`g(x) = x^2 + 4`

.. container:: keeptogether

   d\) :math:`g(x) = f(x+3)`

   .. rst-class:: solution

   décalage de 3 unités vers la gauche

   .. rst-class:: solution

   :math:`g(x) = (x+3)^2`

.. container:: keeptogether

   e\) :math:`g(x) = -f(x)`

   .. rst-class:: solution

   réflexion verticale (basculer par rapport à l'axe des x)

   .. rst-class:: solution

   :math:`g(x) = -x^2`

.. container:: keeptogether

   f\) :math:`g(x) = f(-x)`

   .. rst-class:: solution

   réflexion horizontale (basculer par rapport à l'axe des y)

   .. rst-class:: solution

   :math:`g(x) = (-x)^2`

   le haut
