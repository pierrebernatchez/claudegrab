.. rst-class:: keepwithnext

**Example 1:** Using the parent function :math:`f(x) = \sqrt{x}`, describe
the transformations and write the equation of the transformed function
:math:`g(x)`.

.. rst-class:: solution

:math:`g(x) = -2f\left[-\dfrac{1}{3}(x+6)\right] - 5`

.. rst-class:: solution

Vertical stretch by a factor of 2; vertical reflection (reflection across
the x-axis)

.. rst-class:: solution

Horizontal stretch by a factor of 3; horizontal reflection (reflection
across the y-axis)

.. rst-class:: solution

Phase shift 6 units left; translate 5 units down

.. rst-class:: solution

:math:`g(x) = -2\sqrt{-\dfrac{1}{3}(x+6)} - 5`

.. rst-class:: keepwithnext

**Example 2:** for each of the following functions...

**i)** make a table of values for the parent function

**ii)** graph the parent function :math:`f(x) = \sqrt{x}`

**iii)** describe the transformations

**iv)** make a table of values of image points

**v)** graph the transformed function and write its equation
