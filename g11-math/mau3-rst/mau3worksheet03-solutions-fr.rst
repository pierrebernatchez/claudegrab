**1)** Énonce les transformations de la fonction mère :math:`f(x) =
\sqrt{x}` dans l'ordre où tu les effectuerais.

.. container:: keeptogether

   a\) :math:`g(x) = 2\sqrt{x+1} - 3`

   .. rst-class:: solution

   étirement vertical d'un facteur de 2

   .. rst-class:: solution

   décalage de 1 unité vers la gauche; décalage de 3 unités vers le bas

.. container:: keeptogether

   b\) :math:`g(x) = 3\sqrt{\dfrac{1}{2}(x-5)} + 4`

   .. rst-class:: solution

   étirement vertical d'un facteur de 3; étirement horizontal d'un
   facteur de 2

   .. rst-class:: solution

   décalage de 5 unités vers la droite; décalage de 4 unités vers le
   haut

.. container:: keeptogether

   c\) :math:`g(x) = -\dfrac{1}{2}\sqrt{-3(x)} - 6`

   .. rst-class:: solution

   compression verticale d'un facteur de :math:`\dfrac{1}{2}`; réflexion
   verticale

   .. rst-class:: solution

   compression horizontale d'un facteur de :math:`\dfrac{1}{3}`;
   réflexion horizontale

   .. rst-class:: solution

   décalage de 6 unités vers le bas

.. rst-class:: keepwithnext

**3)** Utilise la description pour écrire la fonction transformée,
:math:`g(x)`.

.. container:: keeptogether

   a\) La fonction mère :math:`f(x) = \sqrt{x}` est comprimée
   verticalement d'un facteur de :math:`\dfrac{1}{3}`, puis translatée
   (décalée) de 3 unités vers la gauche.

   .. rst-class:: solution

   :math:`a = \dfrac{1}{3}`, :math:`d = -3`

   .. rst-class:: solution

   :math:`g(x) = \dfrac{1}{3}\sqrt{x+3}` ou
   :math:`g(x) = \sqrt{\dfrac{1}{9}(x+3)}`

.. container:: keeptogether

   b\) La fonction mère :math:`f(x) = \sqrt{x}` est réfléchie par rapport
   à l'axe des x, étirée horizontalement d'un facteur de 3, puis
   translatée de 1 unité vers la gauche et de 4 unités vers le bas.

   .. rst-class:: solution

   :math:`a = -1`, :math:`k = \dfrac{1}{3}`, :math:`d = -1`, :math:`c = -4`

   .. rst-class:: solution

   :math:`g(x) = -\sqrt{\dfrac{1}{3}(x+1)} - 4`
