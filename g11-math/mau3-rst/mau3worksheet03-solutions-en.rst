.. rst-class:: keepwithnext

**1)** State the transformations to the parent function :math:`f(x) =
\sqrt{x}` in the order that you would do them.

.. container:: keeptogether

   a\) :math:`g(x) = 2\sqrt{x+1} - 3`

   .. rst-class:: solution

   vertical stretch by a factor of 2

   .. rst-class:: solution

   shift left 1 unit; shift down 3 units

.. container:: keeptogether

   b\) :math:`g(x) = 3\sqrt{\dfrac{1}{2}(x-5)} + 4`

   .. rst-class:: solution

   vertical stretch by a factor of 3; horizontal stretch by a factor of 2

   .. rst-class:: solution

   shift right 5 units; shift up 4 units

.. container:: keeptogether

   c\) :math:`g(x) = -\dfrac{1}{2}\sqrt{-3(x)} - 6`

   .. rst-class:: solution

   vertical compression by a factor of :math:`\dfrac{1}{2}`; vertical
   reflection

   .. rst-class:: solution

   horizontal compression by a factor of :math:`\dfrac{1}{3}`; horizontal
   reflection

   .. rst-class:: solution

   shift down 6 units

**3)** Use the description to write the transformed function, :math:`g(x)`.

.. container:: keeptogether

   a\) The parent function :math:`f(x) = \sqrt{x}` is compressed
   vertically by a factor of :math:`\dfrac{1}{3}` and then translated
   (shifted) 3 units left.

   .. rst-class:: solution

   :math:`a = \dfrac{1}{3}`, :math:`d = -3`

   .. rst-class:: solution

   :math:`g(x) = \dfrac{1}{3}\sqrt{x+3}` or
   :math:`g(x) = \sqrt{\dfrac{1}{9}(x+3)}`

.. container:: keeptogether

   b\) The parent function :math:`f(x) = \sqrt{x}` is reflected over the
   x-axis, stretch horizontally by a factor of 3 and then translated 1
   unit left and 4 units down.

   .. rst-class:: solution

   :math:`a = -1`, :math:`k = \dfrac{1}{3}`, :math:`d = -1`, :math:`c = -4`

   .. rst-class:: solution

   :math:`g(x) = -\sqrt{\dfrac{1}{3}(x+1)} - 4`
