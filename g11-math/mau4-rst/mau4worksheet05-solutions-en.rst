**8) a)** Rewrite :math:`y = 9^x` using a base of 3. Describe how you can
graph this function by transforming the graph of :math:`y = 3^x`.

.. rst-class:: solution

:math:`y = 9^x = (3^2)^x = 3^{2x}`

.. rst-class:: solution

horizontal compression of the graph of :math:`y = 3^x` BAFO :math:`\dfrac{1}{2}`

.. rst-class:: keepwithnext

**b)** Rewrite :math:`y = 9^x` using a base of 81. Describe how you can
graph this function by transforming the graph of :math:`y = 81^x`.

.. rst-class:: solution

:math:`y = 9^x = (81^{\frac{1}{2}})^x = 81^{\frac{1}{2}x}`

.. rst-class:: solution

horizontal stretch of the graph of :math:`y = 81^x` by a factor of 2

Answers
================================================================================

**1)** a) translate 2 units down  b) translate 3 units left  c)
horizontal compression by a factor of :math:`\dfrac{1}{2}`
d) vertical stretch by a factor of 3, a translation 1 unit to the right
and 1 unit up

**2)** a) :math:`y = 2^x - 2`  b) :math:`y = 2^{x+3}`  c) :math:`y = 4^x`
d) :math:`y = 3(2^{x-1}) + 1`

**3)** a) :math:`y = 5^x - 3`  b) :math:`y = 5^{x-2}`  c)
:math:`5^{x+\frac{1}{2}}`  d) :math:`y = 5^{x+2.5} + 1`

**4)** a) vertical compression by a factor of :math:`\dfrac{1}{2}`  b)
horizontal compression by a factor of :math:`\dfrac{1}{4}`
c) vertical reflection (reflection in the x-axis)
d) horizontal reflection (reflection in the y-axis) and horizontal
compression by a factor of :math:`\dfrac{1}{2}`

**5)** a) :math:`y = -7^x`  b) :math:`y = 3(7^x)`  c)
:math:`y = 7^{\frac{x}{2.4}}`  d) :math:`y = 7(7^{-x})`

**6)** trace point :math:`(2, -4)` confirms the graph

**7)** trace point :math:`(-3, -3.267948)` confirms the graph

**8)** a) :math:`y = 3^{2x}`; horizontal compression of the graph of
:math:`y = 3^x` by a factor of :math:`\dfrac{1}{2}`

b) :math:`y = 81^{\frac{1}{2}x}`; horizontal stretch of the graph of
:math:`y = 81^x` by a factor of 2
