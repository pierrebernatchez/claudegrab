**1)** Marvin deposits $100 into an account that pays interest at 5% per
year, compounded annually.

.. rst-class:: keepwithnext

a\) Write an equation that can be used to calculate the amount in his
account in the form :math:`A = P(1+i)^n`.

.. rst-class:: solution

:math:`A = 100(1.05)^n`

**2)** Elaine deposits a $2000 inheritance into an account that earns 4%
per year, compounded annually. Find the amount in the account after each
time.

.. rst-class:: keepwithnext

a\) 3 years

.. rst-class:: solution

:math:`A = 2000(1.04)^n = 2000(1.04)^3`

.. rst-class:: solution

:math:`A = 2249.73`, so :math:`\$2249.73`

.. rst-class:: keepwithnext

b\) 8 years

.. rst-class:: solution

:math:`A = 2000(1.04)^8`

.. rst-class:: solution

:math:`A = 2737.14`, so :math:`\$2737.14`

.. rst-class:: keepwithnext

**3)** Soda invests $500 in an account that earns 7% per year, compounded
annually. How long does Soda need to leave her investment in the account
in order to double her money?

.. rst-class:: solution

:math:`A = 500(1.07)^n`, :math:`1000 = 500(1.07)^n`

.. rst-class:: solution

:math:`\log 2 = \log 1.07^n \Rightarrow \log 2 = n \cdot \log 1.07`

.. rst-class:: solution

:math:`n = \dfrac{\log 2}{\log 1.07} \approx 10.24` years

.. rst-class:: keepwithnext

**4)** Art Vandelay deposited some money into an account that pays 3% per
year, compounded annually. Today the account balance is $660. How much
was in the account...

.. rst-class:: keepwithnext

a\) 1 year ago

.. rst-class:: solution

:math:`660 = P(1.03)^1 \Rightarrow P = \dfrac{660}{1.03}`

.. rst-class:: solution

:math:`P \approx 640.78`, so :math:`\$640.78`

.. rst-class:: keepwithnext

b\) 5 years ago?

.. rst-class:: solution

:math:`660 = P(1.03)^5 \Rightarrow P = \dfrac{660}{1.03^5}`

.. rst-class:: solution

:math:`P \approx 569.32`, so :math:`\$569.32`

.. rst-class:: keepwithnext

**5)** Elaine wants to invest some money that will grow to $1000 in 6
years. If her account pays 4.5% interest, compounded annually, how much
should Elaine invest today?

.. rst-class:: solution

:math:`1000 = P(1.045)^6 \Rightarrow P = \dfrac{1000}{1.045^6}`

.. rst-class:: solution

:math:`P \approx 767.90`, so :math:`\$767.90`

.. rst-class:: keepwithnext

**6)** To buy a new guitar, Phoebe borrows $650, which she plans to repay
in 5 years. The bank charges 12% per annum, compounded annually.

.. rst-class:: keepwithnext

a\) Determine the amount that Phoebe must repay.

.. rst-class:: solution

:math:`A = 650(1.12)^5`

.. rst-class:: solution

:math:`A \approx 1145.52`, so :math:`\$1145.52`

.. rst-class:: keepwithnext

b\) How much would she have to pay if the interest was compounded
semi-annually instead of annually? (Hint: twice as many compounding
periods but the interest rate will need to be cut in half)

.. rst-class:: solution

:math:`P = 650`, :math:`i = 0.12 \div 2 = 0.06`, :math:`n = 5\times2 = 10`

.. rst-class:: solution

:math:`A = 650(1.06)^{10} \approx 1164.05`, so :math:`\$1164.05`

.. rst-class:: keepwithnext

c\) How much would she have to pay if the interest was compounded
monthly?

.. rst-class:: solution

:math:`P = 650`, :math:`i = 0.12 \div 12 = 0.01`, :math:`n = 5\times12 = 60`

.. rst-class:: solution

:math:`A = 650(1.01)^{60} \approx 1180.85`, so :math:`\$1180.85`
