**1)** Marvin dépose 100 \$ dans un compte qui rapporte un intérêt de 5 %
par année, composé annuellement.

.. rst-class:: keepwithnext

a\) Écris une équation qui peut servir à calculer le montant dans son
compte, de la forme :math:`A = P(1+i)^n`.

.. rst-class:: solution

:math:`A = 100(1,05)^n`

**2)** Elaine dépose un héritage de 2000 \$ dans un compte qui rapporte
4 % par année, composé annuellement. Trouve le montant dans le compte
après chaque durée.

.. rst-class:: keepwithnext

a\) 3 ans

.. rst-class:: solution

:math:`A = 2000(1,04)^n = 2000(1,04)^3`

.. rst-class:: solution

:math:`A = 2249,73`, donc :math:`2249,73` \$

.. rst-class:: keepwithnext

b\) 8 ans

.. rst-class:: solution

:math:`A = 2000(1,04)^8`

.. rst-class:: solution

:math:`A = 2737,14`, donc :math:`2737,14` \$

.. rst-class:: keepwithnext

**3)** Soda investit 500 \$ dans un compte qui rapporte 7 % par année,
composé annuellement. Combien de temps Soda doit-elle laisser son
placement dans le compte pour doubler son argent ?

.. rst-class:: solution

:math:`A = 500(1,07)^n`, :math:`1000 = 500(1,07)^n`

.. rst-class:: solution

:math:`\log 2 = \log 1,07^n \Rightarrow \log 2 = n \cdot \log 1,07`

.. rst-class:: solution

:math:`n = \dfrac{\log 2}{\log 1,07} \approx 10,24` ans

.. rst-class:: keepwithnext

**4)** Art Vandelay a déposé de l'argent dans un compte qui rapporte 3 %
par année, composé annuellement. Aujourd'hui, le solde du compte est de
660 \$. Combien y avait-il dans le compte...

.. rst-class:: keepwithnext

a\) il y a 1 an

.. rst-class:: solution

:math:`660 = P(1,03)^1 \Rightarrow P = \dfrac{660}{1,03}`

.. rst-class:: solution

:math:`P \approx 640,78`, donc :math:`640,78` \$

.. rst-class:: keepwithnext

b\) il y a 5 ans ?

.. rst-class:: solution

:math:`660 = P(1,03)^5 \Rightarrow P = \dfrac{660}{1,03^5}`

.. rst-class:: solution

:math:`P \approx 569,32`, donc :math:`569,32` \$

.. rst-class:: keepwithnext

**5)** Elaine veut investir de l'argent qui atteindra 1000 \$ en 6 ans.
Si son compte rapporte 4,5 % d'intérêt, composé annuellement, combien
Elaine devrait-elle investir aujourd'hui ?

.. rst-class:: solution

:math:`1000 = P(1,045)^6 \Rightarrow P = \dfrac{1000}{1,045^6}`

.. rst-class:: solution

:math:`P \approx 767,90`, donc :math:`767,90` \$

.. container:: keeptogether

   **6)** Pour acheter une nouvelle guitare, Phoebe emprunte 650 \$,
   qu'elle prévoit remettre dans 5 ans. La banque charge 12 % par année,
   composé annuellement.

   a\) Détermine le montant que Phoebe doit remettre.

.. rst-class:: solution

:math:`A = 650(1,12)^5`

.. rst-class:: solution

:math:`A \approx 1145,52`, donc :math:`1145,52` \$

.. rst-class:: keepwithnext

b\) Combien devrait-elle payer si l'intérêt était composé
semestriellement plutôt qu'annuellement ? (Indice : deux fois plus de
périodes de composition, mais le taux d'intérêt devra être réduit de
moitié)

.. rst-class:: solution

:math:`P = 650`, :math:`i = 0,12 \div 2 = 0,06`, :math:`n = 5\times2 = 10`

.. rst-class:: solution

:math:`A = 650(1,06)^{10} \approx 1164,05`, donc :math:`1164,05` \$

.. rst-class:: keepwithnext

c\) Combien devrait-elle payer si l'intérêt était composé mensuellement ?

.. rst-class:: solution

:math:`P = 650`, :math:`i = 0,12 \div 12 = 0,01`, :math:`n = 5\times12 = 60`

.. rst-class:: solution

:math:`A = 650(1,01)^{60} \approx 1180,85`, donc :math:`1180,85` \$
