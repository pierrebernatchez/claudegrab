Fractions Review
================================================================================

Adding and Subtracting Fractions
--------------------------------------------------------------------------------

*Always find a common denominator when adding or subtracting fractions!*

.. rst-class:: keepwithnext

a\) :math:`\dfrac{1}{2}+\dfrac{1}{8}`

.. rst-class:: solution

:math:`= \dfrac{4}{8}+\dfrac{1}{8} = \dfrac{5}{8}`

.. rst-class:: keepwithnext

b\) :math:`\dfrac{2x}{3y}-\dfrac{y}{2}`

.. rst-class:: solution

Common denominator: :math:`3y(2) = 6y`

.. rst-class:: solution

:math:`= \dfrac{4x}{6y}-\dfrac{3y^2}{6y} = \dfrac{4x-3y^2}{6y}`

Multiplying and Dividing Fractions
--------------------------------------------------------------------------------

*You do NOT need a common denominator when multiplying or dividing
fractions!*

.. rst-class:: keepwithnext

a\) :math:`\dfrac{3}{2}\cdot\dfrac{4}{5}`

.. rst-class:: solution

:math:`= \dfrac{(3)(4)}{(2)(5)} = \dfrac{12}{10} = \dfrac{6}{5}`

.. rst-class:: keepwithnext

b\) :math:`\dfrac{2}{3}\div\dfrac{4}{3}`

.. rst-class:: solution

Flip the second fraction and multiply: :math:`= \dfrac{2}{3}\times\dfrac{3}{4}
= \dfrac{6}{12} = \dfrac{1}{2}`

**Rule:** We can NEVER have a fraction with a denominator of 0. Why?

.. rst-class:: solution

:math:`\dfrac{6}{2}=3` because :math:`2\times3=6`. But
:math:`\dfrac{6}{0}=?` would mean :math:`0\times?=6`, which is
impossible.

**Rule:** Cross multiplication of fractions only happens when there is an
:math:`=` sign between two fractions.

.. rst-class:: solution

eg. :math:`\dfrac{2}{3}=\dfrac{x}{5}` :math:`\Rightarrow 5(2)=3x
\Rightarrow 10=3x \Rightarrow x=\dfrac{10}{3}`

**Rule:** We can cancel out ONLY when multiplying fractions

.. rst-class:: solution

You can cancel factors. eg. :math:`\dfrac{x(x+1)}{x} = x+1`; eg.
:math:`\dfrac{3x(x+3)}{2x} = \dfrac{3x+9}{2}`

**Rule:** We can NOT cancel out when adding or subtracting fractions

.. rst-class:: solution

eg. :math:`\dfrac{x+8}{x}` |---| no cancelling! eg.
:math:`\dfrac{2x+3}{4x}` |---| no cancelling!

Exponent Rules
================================================================================

.. list-table::
   :widths: 30 30 40
   :header-rows: 1
   :width: 100%

   * - Name
     - Rule
     - Example
   * - Adding and Subtracting Monomials
     - COMBINE LIKE TERMS! (do not change common variables and exponents)
     - :math:`3x^2y+2x^2y`

       .. rst-class:: solution

       :math:`=5x^2y`
   * - Product Rule
     - :math:`x^a\cdot x^b = x^{a+b}`
     - :math:`(-2x^2y)(3x^3y^2)`

       .. rst-class:: solution

       :math:`=-6x^5y^3`
   * - Quotient Rule
     - :math:`\dfrac{x^a}{x^b} = x^{a-b}`
     - :math:`\dfrac{28x^5}{42x}`

       .. rst-class:: solution

       :math:`=\dfrac{2x^4}{3}`
   * - Power of a Power Rule
     - :math:`(x^a)^b = x^{ab}`
     - :math:`(-2x^3)^2`

       .. rst-class:: solution

       :math:`=4x^6`
   * - Negative Exponent Rule
     - :math:`x^{-a} = \dfrac{1}{x^a}`
     - :math:`\dfrac{4x^2}{8x^5}`

       .. rst-class:: solution

       :math:`=\dfrac{1}{2x^3}`
   * - Exponent of Zero
     - :math:`x^0 = 1`
     - :math:`87^0`

       .. rst-class:: solution

       :math:`=1`

Simplify the following rational expressions using exponent laws.

.. rst-class:: keepwithnext

a\) :math:`\dfrac{12k^2m^8}{4k^5m^5}`

.. rst-class:: solution

:math:`= 3k^{-3}m^3 = \dfrac{3m^3}{k^3}`

.. rst-class:: keepwithnext

b\) :math:`\dfrac{5c^3d\cdot4c^2d^2}{(2c^2d)^2}`

.. rst-class:: solution

:math:`= \dfrac{20c^5d^3}{4c^4d^2} = 5cd`

.. rst-class:: keepwithnext

c\) :math:`\dfrac{(3xy)^3}{9x^4y^4}`

.. rst-class:: solution

:math:`= \dfrac{27x^3y^3}{9x^4y^4} = 3x^{-1}y^{-1} = \dfrac{3}{xy}`

.. rst-class:: keepwithnext

d\) :math:`\dfrac{(2z^3)^{-2}}{w^5z^2}`

.. rst-class:: solution

:math:`= \dfrac{2^{-2}z^{-6}}{w^5z^2} = \dfrac{1}{2^2w^5z^2z^6} =
\dfrac{1}{4w^5z^8}`

.. rst-class:: keepwithnext

e\) :math:`\dfrac{(x^{-4})^5x^3}{3x^{-1}}`

.. rst-class:: solution

:math:`= \dfrac{x^{-20}x^3}{3x^{-1}} = \dfrac{x^{-17}}{3x^{-1}} =
\dfrac{1}{3x^{-1}x^{17}} = \dfrac{1}{3x^{16}}`

Combining Fractions and Exponents
================================================================================

.. rst-class:: keepwithnext

Ex. :math:`\dfrac{3x^3}{2x^2}+\dfrac{4y^4}{3y}`

.. rst-class:: solution

Simplify each term first: :math:`= \dfrac{3x}{2}+\dfrac{4y^3}{3}`

.. rst-class:: solution

Common denominator 6: :math:`= \dfrac{9x}{6}+\dfrac{8y^3}{6} =
\dfrac{9x+8y^3}{6}`
