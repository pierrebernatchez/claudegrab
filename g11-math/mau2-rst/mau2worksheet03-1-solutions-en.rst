**2)** Simplify each expression and state all restrictions on :math:`x`.

.. list-table::
   :widths: 33 33 34
   :width: 100%

   * - a\) :math:`\dfrac{x-8}{x^2-13x+40}`

       .. rst-class:: solution

       :math:`= \dfrac{x-8}{(x-5)(x-8)} = \dfrac{1}{x-5}` ;
       :math:`x \neq 5, 8`
     - b\) :math:`\dfrac{x^2-3x-18}{x^2+x-42}`

       .. rst-class:: solution

       :math:`= \dfrac{(x-6)(x+3)}{(x+7)(x-6)} = \dfrac{x+3}{x+7}` ;
       :math:`x \neq -7, 6`
     - c\) :math:`\dfrac{x+8}{x^2+6x-16}`

       .. rst-class:: solution

       :math:`= \dfrac{x+8}{(x+8)(x-2)} = \dfrac{1}{x-2}` ;
       :math:`x \neq -8, 2`

**3)** Simplify and state the restrictions on the variables.

.. list-table::
   :widths: 25 25 25 25
   :width: 100%

   * - a\) :math:`\dfrac{14y}{11x} \times \dfrac{121y}{7x}`

       .. rst-class:: solution

       :math:`= \dfrac{22y^2}{x^2}` ; :math:`x \neq 0`
     - b\) :math:`\dfrac{16b^3}{4b} \times \dfrac{20b}{30b^2}`

       .. rst-class:: solution

       :math:`= \dfrac{5b}{2}` ; :math:`b \neq 0`
     - c\) :math:`\dfrac{5x}{9y} \div \dfrac{5x}{18y^2}`

       .. rst-class:: solution

       :math:`= \dfrac{5x}{9y} \times \dfrac{18y^2}{5x} = 2y` ;
       :math:`x \neq 0`, :math:`y \neq 0`
     - d\) :math:`\dfrac{26ab}{4a} \div \dfrac{39a^4b^3}{12b^4}`

       .. rst-class:: solution

       :math:`= \dfrac{26ab}{4a} \times \dfrac{12b^4}{39a^4b^3} =
       \dfrac{2b^2}{a^4}` ; :math:`a \neq 0`, :math:`b \neq 0`

**4)** Simplify and state the restrictions on the variable.

.. list-table::
   :widths: 50 50
   :width: 100%

   * - a\) :math:`\dfrac{5}{x+10} \times \dfrac{x+10}{1}`

       .. rst-class:: solution

       :math:`= 5` ; :math:`x \neq -10`
     - b\) :math:`\dfrac{x+5}{x-3} \times \dfrac{x-3}{x+7}`

       .. rst-class:: solution

       :math:`= \dfrac{x+5}{x+7}` ; :math:`x \neq 3, -7`
   * - c\) :math:`\dfrac{x+1}{x} \div \dfrac{x+1}{2x}`

       .. rst-class:: solution

       :math:`= \dfrac{x+1}{x} \times \dfrac{2x}{x+1} = 2` ;
       :math:`x \neq 0, -1`
     - d\) :math:`\dfrac{x+12}{x+10} \div \dfrac{x+12}{x-5}`

       .. rst-class:: solution

       :math:`= \dfrac{x+12}{x+10} \times \dfrac{x-5}{x+12} =
       \dfrac{x-5}{x+10}` ; :math:`x \neq -10, -12, 5`

**5)** Simplify and state the restrictions on the variable.

.. list-table::
   :widths: 50 50
   :width: 100%

   * - a\) :math:`\dfrac{3x^2}{12x^2+18x} \times \dfrac{4x+6}{3x+30}`

       .. rst-class:: solution

       :math:`= \dfrac{3x^2}{6x(2x+3)} \times \dfrac{2(2x+3)}{3(x+10)}
       = \dfrac{x}{3(x+10)}` ; :math:`x \neq -10, -\dfrac{3}{2}, 0`
     - b\) :math:`\dfrac{4x+24}{x^2+8x} \times \dfrac{12x^2}{3x+18}`

       .. rst-class:: solution

       :math:`= \dfrac{4(x+6)}{x(x+8)} \times \dfrac{12x^2}{3(x+6)} =
       \dfrac{16x}{x+8}` ; :math:`x \neq -8, -6, 0`
   * - c\) :math:`\dfrac{x^2+10x+21}{x+3} \times \dfrac{x+2}{x^2+9x+14}`

       .. rst-class:: solution

       :math:`= \dfrac{(x+7)(x+3)}{x+3} \times
       \dfrac{x+2}{(x+7)(x+2)} = 1` ; :math:`x \neq -3, -2, -7`
     - d\) :math:`\dfrac{x^2+2x-15}{x^2-9x+18} \times \dfrac{x-6}{x+5}`

       .. rst-class:: solution

       :math:`= \dfrac{(x+5)(x-3)}{(x-6)(x-3)} \times \dfrac{x-6}{x+5}
       = 1` ; :math:`x \neq -5, 3, 6`

**6)** Simplify and state the restrictions on the variable.

.. list-table::
   :widths: 50 50
   :width: 100%

   * - a\) :math:`\dfrac{x^2+15x}{4x+24} \div \dfrac{3x}{3x+18}`

       .. rst-class:: solution

       :math:`= \dfrac{x(x+15)}{4(x+6)} \times \dfrac{3(x+6)}{3x} =
       \dfrac{x+15}{4}` ; :math:`x \neq -6, 0`
     - b\) :math:`\dfrac{6x}{8x-72} \div \dfrac{9x}{2x-18}`

       .. rst-class:: solution

       :math:`= \dfrac{6x}{8(x-9)} \times \dfrac{2(x-9)}{9x} =
       \dfrac{1}{6}` ; :math:`x \neq 0, 9`
   * - c\) :math:`\dfrac{x^2+15x+26}{6x^2} \div \dfrac{x^2-3x-10}{30x^3}`

       .. rst-class:: solution

       :math:`= \dfrac{(x+2)(x+13)}{6x^2} \times
       \dfrac{30x^3}{(x-5)(x+2)} = \dfrac{5x(x+13)}{x-5}` ;
       :math:`x \neq -2, 0, 5`
     - d\) :math:`\dfrac{x^2+11x+24}{x^2+2x-3} \div \dfrac{x-8}{x-1}`

       .. rst-class:: solution

       :math:`= \dfrac{(x+8)(x+3)}{(x+3)(x-1)} \times \dfrac{x-1}{x-8}
       = \dfrac{x+8}{x-8}` ; :math:`x \neq -3, 1, 8`

**7)** Simplify and state the restrictions on the variable.

.. list-table::
   :widths: 50 50
   :width: 100%

   * - a\) :math:`\dfrac{a^2-25}{a+2} \times \dfrac{a^2-4}{a^2-7a+10}`

       .. rst-class:: solution

       :math:`= \dfrac{(a-5)(a+5)}{a+2} \times
       \dfrac{(a-2)(a+2)}{(a-2)(a-5)} = a+5` ; :math:`a \neq 2, -2, 5`
     - b\) :math:`\dfrac{y^2-4y-21}{3y^2+6y} \times \dfrac{y^2+8y}{y^2+11y+24}`

       .. rst-class:: solution

       :math:`= \dfrac{(y-7)(y+3)}{3y(y+2)} \times
       \dfrac{y(y+8)}{(y+8)(y+3)} = \dfrac{y-7}{3(y+2)}` ;
       :math:`y \neq -8, -3, -2, 0`
   * - c\) :math:`\dfrac{p^2-2p+1}{p+1} \div \dfrac{p^2-1}{p+1}`

       .. rst-class:: solution

       :math:`= \dfrac{(p-1)^2}{p+1} \times \dfrac{p+1}{(p-1)(p+1)} =
       \dfrac{p-1}{p+1}` ; :math:`p \neq -1, 1`
     - d\) :math:`\dfrac{x^2+6x-27}{x^2+11x+18} \div \dfrac{x-3}{x^2+x-2}`

       .. rst-class:: solution

       :math:`= \dfrac{(x+9)(x-3)}{(x+9)(x+2)} \times
       \dfrac{(x+2)(x-1)}{x-3} = x-1` ; :math:`x \neq -9, -2, 1, 3`
