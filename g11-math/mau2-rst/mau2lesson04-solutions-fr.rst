a\) :math:`\dfrac{1}{6}+\dfrac{1}{5}`

*Note : le produit des dénominateurs donne un dénominateur commun (mais
pas toujours le plus petit dénominateur commun)*

.. rst-class:: solution

Dénominateur commun = 30

.. rst-class:: solution

:math:`= \dfrac{5}{30}+\dfrac{6}{30} = \dfrac{11}{30}`

b\) Simplifie et énonce les restrictions

.. rst-class:: keepwithnext

:math:`\dfrac{x^2-1}{x^2-4}\times\dfrac{x^2+3x-4}{x^2+5x+4}`

.. rst-class:: solution

:math:`= \dfrac{(x-1)(x+1)}{(x-2)(x+2)}\times\dfrac{(x+4)(x-1)}{(x+4)(x+1)}
= \dfrac{(x-1)^2}{(x-2)(x+2)}\; ; \; x \neq 2, -2, -4, -1`

.. rst-class:: keepwithnext

c\) :math:`\dfrac{2x}{3y}+\dfrac{y}{6x}`

.. rst-class:: solution

Dénominateur commun = 6xy

.. rst-class:: solution

:math:`= \dfrac{4x^2}{6xy}+\dfrac{y^2}{6xy} = \dfrac{4x^2+y^2}{6xy}\; ;
\; x \neq 0,\; y \neq 0`

Additionner et soustraire des expressions rationnelles avec des dénominateurs monômes
==========================================================================================

**Étapes :** 1. factorise les dénominateurs si possible 2. trouve un
dénominateur commun 3. réécris l'expression avec un dénominateur commun
4. additionne/soustrais le numérateur (garde le même dénominateur)
5. simplifie lorsque possible 6. énonce les restrictions (tout au long du
processus)

.. rst-class:: keepwithnext

a\) :math:`\dfrac{1}{5x}+\dfrac{1}{2x}`

.. rst-class:: solution

Dénominateur commun = 10x

.. rst-class:: solution

:math:`= \dfrac{2}{10x}+\dfrac{5}{10x} = \dfrac{7}{10x}\; ; \; x \neq 0`

.. rst-class:: keepwithnext

b\) :math:`\dfrac{ab^2+2}{2ab^2}-\dfrac{b+2}{2b}`

.. rst-class:: solution

Dénominateur commun = :math:`2ab^2`

.. rst-class:: solution

:math:`= \dfrac{ab^2+2}{2ab^2}-\dfrac{ab(b+2)}{2ab^2}\; ; \; a \neq 0,\;
b \neq 0`

.. rst-class:: solution

:math:`= \dfrac{ab^2+2-ab^2-2ab}{2ab^2}\; ; \; a \neq 0,\; b \neq 0`

.. rst-class:: solution

:math:`= \dfrac{2-2ab}{2ab^2}\; ; \; a \neq 0,\; b \neq 0`

.. rst-class:: solution

:math:`= \dfrac{2(1-ab)}{2ab^2} = \dfrac{1-ab}{ab^2}\; ; \; a \neq 0,\;
b \neq 0`

Additionner et soustraire des expressions rationnelles avec des dénominateurs polynômes
============================================================================================

**Étapes :** 1. factorise les dénominateurs si possible 2. trouve un
dénominateur commun 3. réécris l'expression avec un dénominateur commun
4. additionne/soustrais le numérateur (garde le même dénominateur)
5. simplifie lorsque possible 6. énonce les restrictions (tout au long du
processus)

.. rst-class:: keepwithnext

a\) :math:`\dfrac{x+5}{x-3}+\dfrac{x-7}{x+2}`

.. rst-class:: solution

Dénominateur commun : :math:`(x-3)(x+2)`

.. rst-class:: solution

:math:`= \dfrac{(x+2)(x+5)}{(x+2)(x-3)}+\dfrac{(x-7)(x-3)}{(x+2)(x-3)}\; ;
\; x \neq -2, 3`

.. rst-class:: solution

:math:`= \dfrac{x^2+7x+10}{(x+2)(x-3)}+\dfrac{x^2-10x+21}{(x+2)(x-3)}\; ;
\; x \neq -2, 3`

.. rst-class:: solution

:math:`= \dfrac{2x^2-3x+31}{(x+2)(x-3)}\; ; \; x \neq -2, 3`

.. rst-class:: keepwithnext

b\) :math:`\dfrac{x+9}{x^2+2x-48}-\dfrac{x-9}{x^2-x-30}`

.. rst-class:: solution

Dénominateur commun = :math:`(x-6)(x+8)(x+5)`

.. rst-class:: solution

:math:`= \dfrac{(x+5)(x+9)}{(x+5)(x+8)(x-6)}-\dfrac{(x-9)(x+8)}
{(x-6)(x+5)(x+8)}\; ; \; x \neq -5, -8, 6`

.. rst-class:: solution

:math:`= \dfrac{(x+5)(x+9)-(x-9)(x+8)}{(x+5)(x+8)(x-6)}\; ; \; x \neq
-5, -8, 6`

.. rst-class:: solution

:math:`= \dfrac{x^2+14x+45-(x^2-x-72)}{(x+5)(x+8)(x-6)}\; ; \; x \neq
-5, -8, 6`

.. rst-class:: solution

:math:`= \dfrac{15x+117}{(x+5)(x+8)(x-6)}\; ; \; x \neq -5, -8, 6`

.. rst-class:: keepwithnext

c\) :math:`\dfrac{x-2}{x+2}+\dfrac{x+10}{x^2+6x+8}`

.. rst-class:: solution

Dénominateur commun = :math:`(x+2)(x+4)`

.. rst-class:: solution

:math:`= \dfrac{(x+4)(x-2)}{(x+4)(x+2)}+\dfrac{x+10}{(x+4)(x+2)}\; ; \;
x \neq -4, -2`

.. rst-class:: solution

:math:`= \dfrac{x^2+2x-8+x+10}{(x+4)(x+2)}\; ; \; x \neq -4, -2`

.. rst-class:: solution

:math:`= \dfrac{x^2+3x+2}{(x+4)(x+2)}\; ; \; x \neq -4, -2`

.. rst-class:: solution

:math:`= \dfrac{(x+2)(x+1)}{(x+4)(x+2)} = \dfrac{x+1}{x+4}\; ; \; x \neq
-4, -2`

.. rst-class:: keepwithnext

d\) :math:`\dfrac{2x}{x-1}-\dfrac{x+2}{x^2+3x-4}`

.. rst-class:: solution

Dénominateur commun = :math:`(x+4)(x-1)`

.. rst-class:: solution

:math:`= \dfrac{2x(x+4)}{(x+4)(x-1)}-\dfrac{x+2}{(x+4)(x-1)}\; ; \; x
\neq -4, 1`

.. rst-class:: solution

:math:`= \dfrac{2x^2+8x-x-2}{(x+4)(x-1)}\; ; \; x \neq -4, 1`

.. rst-class:: solution

:math:`= \dfrac{2x^2+7x-2}{(x+4)(x-1)}\; ; \; x \neq -4, 1`

.. rst-class:: keepwithnext

e\) :math:`\dfrac{a+1}{5-2a}-\dfrac{a-4}{2a-5}`

*Deux expressions binomiales peuvent différer par un facteur de -1.
Factorise -1 d'un des dénominateurs pour trouver le dénominateur commun.
Simplifie ensuite chaque expression et énonce les restrictions.*

.. rst-class:: solution

:math:`= \dfrac{a+1}{-1(-5+2a)}-\dfrac{a-4}{2a-5} = \dfrac{-1(a+1)}{2a-5}
-\dfrac{a-4}{2a-5}`

.. rst-class:: solution

:math:`= \dfrac{-1(a+1)-(a-4)}{2a-5}\; ; \; a \neq \dfrac{5}{2}`

.. rst-class:: solution

:math:`= \dfrac{-a-1-a+4}{2a-5} = \dfrac{-2a+3}{2a-5}\; ; \; a \neq
\dfrac{5}{2}`
