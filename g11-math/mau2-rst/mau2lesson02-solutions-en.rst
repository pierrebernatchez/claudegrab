Intro to Rational Exponents (fraction exponents)
================================================================================

:math:`\sqrt[2]{x^1}` |---| the small raised number to the left is the
**index** (also called the bottom), the number under the root is the
**radicand**, and the small raised number on the radicand is the top:
:math:`\sqrt[2]{x^1} = x^{\frac{1}{2}}`

Powers with a Rational Exponent of the Form :math:`\dfrac{1}{n}`
--------------------------------------------------------------------------------

A power involving a rational exponent with numerator 1 and denominator
:math:`n` can be interpreted as the :math:`n`\th root of the base:

:math:`b^{\frac{1}{n}} = \sqrt[n]{b}`

In particular, when :math:`n = 2`: :math:`x^{\frac{1}{2}} = \sqrt{x}`, the
simple root of :math:`x`.

.. rst-class:: keepwithnext

**Example 1:** Evaluate each of the following

.. list-table::
   :widths: 33 33 34
   :width: 100%

   * - a\) :math:`8^{\frac{1}{3}}`

       .. rst-class:: solution

       :math:`=2` (verified with a calculator)
     - b\) :math:`\sqrt[5]{-32}`

       .. rst-class:: solution

       :math:`=(-32)^{\frac{1}{5}}=-2`
     - c\) :math:`-16^{\frac{1}{4}}`

       .. rst-class:: solution

       :math:`=-2`
   * - d\) :math:`\sqrt[4]{\dfrac{16}{81}}`

       .. rst-class:: solution

       :math:`=\left(\dfrac{16}{81}\right)^{\frac{1}{4}}=\dfrac{16^{\frac{1}{4}}}{81^{\frac{1}{4}}}=\dfrac{2}{3}`
     - e\) :math:`(-27)^{-\frac{1}{3}}`

       .. rst-class:: solution

       :math:`=\dfrac{1}{(-27)^{\frac{1}{3}}}=\dfrac{1}{-3}=-\dfrac{1}{3}`
     - |nbsp|

Powers with a Rational Exponent of the Form :math:`\dfrac{m}{n}`
--------------------------------------------------------------------------------

You can evaluate a power involving a rational exponent with numerator
:math:`m` and denominator :math:`n` by taking the :math:`n`\th root of
the base raised to the exponent :math:`m`:

.. rst-class:: solution

:math:`b^{\frac{m}{n}} = \left(\sqrt[n]{b}\right)^m = \sqrt[n]{b^m}`

.. rst-class:: keepwithnext

**Example 2:** Simplify each of the following powers

.. list-table::
   :widths: 33 33 34
   :width: 100%

   * - a\) :math:`\sqrt[5]{y^2}`

       .. rst-class:: solution

       :math:`=y^{\frac{2}{5}}`
     - b\) :math:`\sqrt[3]{x}`

       .. rst-class:: solution

       :math:`=x^{\frac{1}{3}}`
     - c\) :math:`\sqrt{a^{-3}b^{\frac{4}{3}}}`

       .. rst-class:: solution

       :math:`=(a^{-3}b^{\frac{4}{3}})^{\frac{1}{2}}=a^{-\frac{3}{2}}b^{\frac{2}{3}}=\dfrac{b^{\frac{2}{3}}}{a^{\frac{3}{2}}}`
   * - d\) :math:`\sqrt[4]{x^3y^2}`

       .. rst-class:: solution

       :math:`=(x^3y^2)^{\frac{1}{4}}=x^{\frac{3}{4}}y^{\frac{1}{2}}`
     - e\) :math:`\dfrac{\sqrt[3]{x^2y}\cdot y^2}{x^3}`

       .. rst-class:: solution

       :math:`=\dfrac{(x^2y)^{\frac{1}{3}}y^2}{x^3}=\dfrac{x^{\frac{2}{3}}y^{\frac{1}{3}}y^2}{x^3}=x^{-\frac{7}{3}}y^{\frac{7}{3}}=\dfrac{y^{\frac{7}{3}}}{x^{\frac{7}{3}}}`
     - |nbsp|

.. rst-class:: keepwithnext

**Example 3:** Evaluate each of the following

*If you have a power with a negative exponent and a rational base, just
flip the base and make the exponent positive.*

.. list-table::
   :widths: 33 33 34
   :width: 100%

   * - a\) :math:`8^{\frac{2}{3}}`

       .. rst-class:: solution

       :math:`=(8^{\frac{1}{3}})^2=(2)^2=4` (verified with a calculator)
     - b\) :math:`81^{\frac{5}{4}}`

       .. rst-class:: solution

       :math:`=(81^{\frac{1}{4}})^5=(3)^5=243`
     - c\) :math:`\left(\dfrac{49}{81}\right)^{-\frac{3}{2}}`

       .. rst-class:: solution

       :math:`=\left(\dfrac{81}{49}\right)^{\frac{3}{2}}=\dfrac{81^{\frac{3}{2}}}{49^{\frac{3}{2}}}=\dfrac{729}{343}`

Apply Exponent Rules
================================================================================

.. rst-class:: keepwithnext

**Example 4:** Simplify and express answer using only positive exponents

.. list-table::
   :widths: 33 33 34
   :width: 100%

   * - a\) :math:`\dfrac{(x^{\frac{2}{3}})(x^{\frac{2}{3}})}{(x^{\frac{1}{3}})}`

       .. rst-class:: solution

       :math:`=\dfrac{x^{\frac{4}{3}}}{x^{\frac{1}{3}}}=x^{\frac{3}{3}}=x`
     - b\) :math:`\left(y^{\frac{1}{4}}\right)^2\times\left(y^{-\frac{1}{3}}\right)^2`

       .. rst-class:: solution

       :math:`=y^{\frac{1}{2}}\times y^{-\frac{2}{3}}=y^{\frac{3}{6}}\times y^{-\frac{4}{6}}=y^{-\frac{1}{6}}=\dfrac{1}{y^{\frac{1}{6}}}`
     - c\) :math:`\left(5x^{\frac{1}{2}}\right)^2\times4x^{-\frac{1}{2}}`

       .. rst-class:: solution

       :math:`=25x\cdot4x^{-\frac{1}{2}}=100x^{\frac{1}{2}}`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - d\) :math:`\dfrac{(m^{-2})^3\sqrt{m^4}}{m\sqrt{pq^{-3}}}`

       .. rst-class:: solution

       :math:`=\dfrac{m^{-6}\cdot m^2}{mp^{\frac{1}{2}}q^{-\frac{3}{2}}}=\dfrac{m^{-4}}{mp^{\frac{1}{2}}q^{-\frac{3}{2}}}`

       .. rst-class:: solution

       :math:`=\dfrac{m^{-5}}{p^{\frac{1}{2}}q^{-\frac{3}{2}}}=\dfrac{q^{\frac{3}{2}}}{m^5p^{\frac{1}{2}}}`
     - e\) :math:`\dfrac{(x^2)^{-4}\sqrt[5]{y^3}}{y\sqrt{x^{-2}y}}`

       .. rst-class:: solution

       :math:`=\dfrac{x^{-8}y^{\frac{3}{5}}}{yx^{-1}y^{\frac{1}{2}}}=\dfrac{x^{-7}y^{\frac{3}{5}}}{y^{\frac{3}{2}}}`

       .. rst-class:: solution

       :math:`=x^{-7}y^{\frac{6}{10}-\frac{15}{10}}=x^{-7}y^{-\frac{9}{10}}=\dfrac{1}{x^7y^{\frac{9}{10}}}`
