**1)** Add or subtract the following fractions.

   :widths: 25 25 25 25

   * - a\) :math:`\dfrac{2}{3}+\dfrac{3}{4}`

       .. rst-class:: solution

       :math:`=\dfrac{8}{12}+\dfrac{9}{12}=\dfrac{17}{12}`
     - b\) :math:`\dfrac{3}{5}-\dfrac{1}{3}`

       .. rst-class:: solution

       :math:`=\dfrac{9}{15}-\dfrac{5}{15}=\dfrac{4}{15}`
     - c\) :math:`\dfrac{x}{3}+\dfrac{y}{2}`

       .. rst-class:: solution

       :math:`=\dfrac{2x}{6}+\dfrac{3y}{6}=\dfrac{2x+3y}{6}`
     - d\) :math:`\dfrac{3x}{5}-\dfrac{2y}{7}`

       .. rst-class:: solution

       :math:`=\dfrac{21x}{35}-\dfrac{10y}{35}=\dfrac{21x-10y}{35}`

**4)** Simplify (exponents)

.. list-table::
   :widths: 25 25 25 25
   :width: 100%

   * - a\) :math:`(x^6)(x^4)`

       .. rst-class:: solution

       :math:`=x^{10}`
     - b\) :math:`(y^3)(y^7)(y^9)`

       .. rst-class:: solution

       :math:`=y^{19}`
     - c\) :math:`m^5\div m^4`

       .. rst-class:: solution

       :math:`=m`
     - d\) :math:`h^6\div h^8`

       .. rst-class:: solution

       :math:`=h^{-2}=\dfrac{1}{h^2}`
   * - e\) :math:`\sqrt{h^6}\div\sqrt{h^8}`

       .. rst-class:: solution

       :math:`=h^3\div h^4=\dfrac{1}{h}`
     - f\) :math:`\dfrac{x^{10}}{x^5}`

       .. rst-class:: solution

       :math:`=x^5`
     - g\) :math:`(yz^2)^3`

       .. rst-class:: solution

       :math:`=y^3z^6`
     - h\) :math:`\left[-(x)^2\right]^2`

       .. rst-class:: solution

       :math:`=x^4`
   * - i\) :math:`(x^2)^3(y^3)^2`

       .. rst-class:: solution

       :math:`=x^6y^6`
     - j\) :math:`\dfrac{(-x)^2}{(-x)}`

       .. rst-class:: solution

       :math:`=\dfrac{x^2}{-x}=-x`
     - |nbsp|

**5)** Simplify fractions and exponents

.. list-table::
   :widths: 50 50
   :width: 100%

   * - a\) :math:`\dfrac{7x}{3y}\cdot\dfrac{12y}{5x^2}+\dfrac{2}{3}`

       .. rst-class:: solution

       :math:`=\dfrac{28xy}{5x^2y}+\dfrac{2}{3} = \dfrac{28}{5x}+\dfrac{2}{3}`

       .. rst-class:: solution

       :math:`=\dfrac{84}{15x}+\dfrac{10x}{15x} = \dfrac{84+10x}{15x}`
     - b\) :math:`\dfrac{25x^3}{3x}\cdot\dfrac{7y^2}{5yx^2}`

       .. rst-class:: solution

       :math:`=\dfrac{175x^3y^2}{15x^3y} = \dfrac{35y}{3}`

**6)** Simplify. Your answer should contain only positive exponents.

.. list-table::
   :widths: 33 33 34
   :width: 100%

   * - a\) :math:`(x^{-2}x^{-3})^4`

       .. rst-class:: solution

       :math:`=(x^{-5})^4=x^{-20}=\dfrac{1}{x^{20}}`
     - b\) :math:`(x^4)^{-3}\cdot2x^4`

       .. rst-class:: solution

       :math:`=x^{-12}\cdot2x^4=2x^{-8}=\dfrac{2}{x^8}`
     - c\) :math:`(n^3)^3\cdot2n^{-1}`

       .. rst-class:: solution

       :math:`=n^9\cdot2n^{-1}=2n^8`
   * - d\) :math:`(2v)^2\cdot2v^2`

       .. rst-class:: solution

       :math:`=4v^2\cdot2v^2=8v^4`
     - e\) :math:`\dfrac{2x^2y^4\cdot4x^2y^4\cdot3x}{3x^{-3}y^2}`

       .. rst-class:: solution

       :math:`=\dfrac{24x^5y^8}{3x^{-3}y^2}=8x^8y^6`
     - f\) :math:`\dfrac{2y^3\cdot3xy^3}{3x^2y^4}`

       .. rst-class:: solution

       :math:`=\dfrac{6xy^6}{3x^2y^4}=\dfrac{2y^2}{x}`
   * - g\) :math:`\dfrac{x^3y^3\cdot x^3}{4x^2}`

       .. rst-class:: solution

       :math:`=\dfrac{x^6y^3}{4x^2}=\dfrac{x^4y^3}{4}`
     - h\) :math:`\dfrac{3x^2y^2}{2x^{-1}\cdot4yx^2}`

       .. rst-class:: solution

       :math:`=\dfrac{3x^2y^2}{8xy}=\dfrac{3xy}{8}`
     - i\) :math:`\dfrac{x}{(2x^0)^2}`

       .. rst-class:: solution

       :math:`=\dfrac{x}{4}`
   * - j\) :math:`\dfrac{2m^{-4}}{(2m^{-4})^3}`

       .. rst-class:: solution

       :math:`=\dfrac{2m^{-4}}{8m^{-12}}=\dfrac{m^8}{4}`
     - |nbsp|
     - |nbsp|
