**1)** Multiply the following rational expressions. Simplify and state
restrictions.

.. list-table::
   :widths: 50 50
   :width: 100%

   * - a\) :math:`\dfrac{x+4}{x} \cdot \dfrac{x^2}{x^2+5x+4}`

       .. rst-class:: solution

       :math:`= \dfrac{x+4}{x} \cdot \dfrac{x^2}{(x+4)(x+1)} =
       \dfrac{x}{x+1}` ; :math:`x \neq -4, -1, 0`
     - b\) :math:`\dfrac{x^2+10x+16}{5x-10} \cdot \dfrac{x-2}{x^2+9x+8}`

       .. rst-class:: solution

       :math:`= \dfrac{(x+2)(x+8)}{5(x-2)} \cdot
       \dfrac{x-2}{(x+8)(x+1)} = \dfrac{x+2}{5(x+1)}` ;
       :math:`x \neq -8, -1, 2`
   * - c\) :math:`\dfrac{2x^2-10x}{x^2-9x+20} \cdot \dfrac{x^2-8x+16}{4x^2}`

       .. rst-class:: solution

       :math:`= \dfrac{2x(x-5)}{(x-4)(x-5)} \cdot
       \dfrac{(x-4)^2}{4x^2} = \dfrac{x-4}{2x}` ; :math:`x \neq 0, 4, 5`
     - d\) :math:`\dfrac{2x+4}{x+4} \cdot \dfrac{5x^2+21x+4}{10x+2}`

       .. rst-class:: solution

       :math:`= \dfrac{2(x+2)}{x+4} \cdot
       \dfrac{(5x+1)(x+4)}{2(5x+1)} = x+2` ; :math:`x \neq -4,
       -\dfrac{1}{5}`

.. rst-class:: keepwithnext

**2)** Divide the following rational expressions. Simplify and state
restrictions.

.. list-table::
   :widths: 50 50
   :width: 100%

   * - a\) :math:`\dfrac{x^2-5x+6}{5} \div \dfrac{x-3}{15}`

       .. rst-class:: solution

       :math:`= \dfrac{(x-2)(x-3)}{5} \cdot \dfrac{15}{x-3} =
       3(x-2)` ; :math:`x \neq 3`
     - b\) :math:`\dfrac{x^2-5x+6}{8x^2+24x} \div \dfrac{x-2}{4x+12}`

       .. rst-class:: solution

       :math:`= \dfrac{(x-2)(x-3)}{8x(x+3)} \cdot
       \dfrac{4(x+3)}{x-2} = \dfrac{x-3}{2x}` ; :math:`x \neq -3, 0, 2`
   * - c\) :math:`\dfrac{x^2-2x+1}{x+1} \div \dfrac{x^2-1}{x+1}`

       .. rst-class:: solution

       :math:`= \dfrac{(x-1)^2}{x+1} \cdot \dfrac{x+1}{(x-1)(x+1)} =
       \dfrac{x-1}{x+1}` ; :math:`x \neq -1, 1`
     - d\) :math:`\dfrac{x^2+7x+12}{x^2+3x-10} \div \dfrac{x^2-x-20}{x^2-25}`

       .. rst-class:: solution

       :math:`= \dfrac{(x+3)(x+4)}{(x+5)(x-2)} \cdot
       \dfrac{(x-5)(x+5)}{(x-5)(x+4)} = \dfrac{x+3}{x-2}` ;
       :math:`x \neq -5, -4, 2, 5`

Answers
================================================================================

.. rst-class:: solution

**1)** a) :math:`\dfrac{x}{x+1}`, :math:`x \neq -4, -1, 0`
b) :math:`\dfrac{x+2}{5(x+1)}`, :math:`x \neq -8, -1, 2`
c) :math:`\dfrac{x-4}{2x}`, :math:`x \neq 0, 4, 5`
d) :math:`x+2`, :math:`x \neq -4, -\dfrac{1}{5}`

.. rst-class:: solution

**2)** a) :math:`3x-6`, :math:`x \neq 3`
b) :math:`\dfrac{x-3}{2x}`, :math:`x \neq -3, 0, 2`
c) :math:`\dfrac{x-1}{x+1}`, :math:`x \neq -1, 1`
d) :math:`\dfrac{x+3}{x-2}`, :math:`x \neq -5, -4, 2, 5`
