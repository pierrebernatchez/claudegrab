Section 1: Negative and Rational Exponents
================================================================================

.. rst-class:: keepwithnext

**1)** Evaluate. Express as a fraction in lowest terms.

.. rst-class:: keepwithnext

a\) :math:`10^{-1}`

.. rst-class:: solution

:math:`= \dfrac{1}{10}`

.. rst-class:: keepwithnext

b\) :math:`4^{-2}`

.. rst-class:: solution

:math:`= \dfrac{1}{16}`

.. rst-class:: keepwithnext

c\) :math:`3^{-2}+9^{-1}`

.. rst-class:: solution

:math:`= \dfrac{1}{9}+\dfrac{1}{9} = \dfrac{2}{9}`

.. rst-class:: keepwithnext

d\) :math:`5^{-3}+5^0`

.. rst-class:: solution

:math:`= \dfrac{1}{125}+1 = \dfrac{126}{125}`

.. rst-class:: keepwithnext

e\) :math:`\left(\dfrac{1}{5}\right)^{-1}`

.. rst-class:: solution

:math:`= 5`

.. rst-class:: keepwithnext

f\) :math:`\left(\dfrac{3}{4}\right)^{-3}`

.. rst-class:: solution

:math:`= \left(\dfrac{4}{3}\right)^3 = \dfrac{64}{27}`

.. rst-class:: keepwithnext

**2)** Simplify. Express your answers using only positive exponents.

.. rst-class:: keepwithnext

a\) :math:`(x^{-2})(x^{-1})(x^0)`

.. rst-class:: solution

:math:`= x^{-3} = \dfrac{1}{x^3}`

.. rst-class:: keepwithnext

b\) :math:`(3km^2)(2k^{-2}m^{-2})`

.. rst-class:: solution

:math:`= 6k^{-1}m^0 = \dfrac{6}{k}`

.. rst-class:: keepwithnext

c\) :math:`w^{-3} \div w^{-2}`

.. rst-class:: solution

:math:`= w^{-1} = \dfrac{1}{w}`

.. rst-class:: keepwithnext

d\) :math:`\dfrac{u^{-2}v^3}{u^{-3}v^{-2}}`

.. rst-class:: solution

:math:`= uv^5`

.. rst-class:: keepwithnext

e\) :math:`(z^{-3})^{-2}`

.. rst-class:: solution

:math:`= z^6`

.. rst-class:: keepwithnext

f\) :math:`(2ab^{-1})^{-2}`

.. rst-class:: solution

:math:`= \dfrac{1}{(2ab^{-1})^2} = \dfrac{1}{4a^2b^{-2}} = \dfrac{b^2}{4a^2}`

.. rst-class:: keepwithnext

**3)** Simplify. Express your answers using only positive exponents.

.. rst-class:: keepwithnext

a\) :math:`(4a^{-2})(-2a^{-3})`

.. rst-class:: solution

:math:`= -8a^{-5} = -\dfrac{8}{a^5}`

.. rst-class:: keepwithnext

b\) :math:`\dfrac{(2x^2y)^{-2}(3xy)^{-1}}{(6x^2y^2)^{-2}}`

.. rst-class:: solution

:math:`= \dfrac{(6x^2y^2)^2}{(2x^2y)^2(3xy)} = \dfrac{36x^4y^4}{4x^4y^2
(3xy)} = \dfrac{36x^4y^4}{12x^5y^3} = \dfrac{3y}{x}`

.. rst-class:: keepwithnext

c\) :math:`\left(\dfrac{1}{4x^2}\right)^{-2}`

.. rst-class:: solution

:math:`= (4x^2)^2 = 16x^4`

.. rst-class:: keepwithnext

d\) :math:`\left(\dfrac{6a^3}{4b^4}\right)^{-2}`

.. rst-class:: solution

:math:`= \left(\dfrac{4b^4}{6a^3}\right)^2 = \dfrac{16b^8}{36a^6}
= \dfrac{4b^8}{9a^6}`

.. rst-class:: keepwithnext

**5)** Simplify. Express answers using only positive exponents.

.. rst-class:: keepwithnext

a\) :math:`n^{\frac{1}{2}} \times n^{\frac{1}{3}} \times n^{\frac{1}{4}}`

.. rst-class:: solution

:math:`= n^{6/12} \cdot n^{4/12} \cdot n^{3/12} = n^{13/12}`

.. rst-class:: keepwithnext

b\) :math:`(27y^3)^{\frac{1}{3}} \times \left(\dfrac{1}{16y^4}\right)
^{-\frac{3}{4}}`

:math:`= 3y \times (16y^4)^{3/4} = 3y(8y^3) = 24y^4`

.. rst-class:: keepwithnext

c\) :math:`(27x^6)^{\frac{2}{3}} \div (9x^4)^{\frac{1}{2}}`

.. rst-class:: solution

:math:`= 9x^4 \div 3x^2 = 3x^2`

.. rst-class:: keepwithnext

d\) :math:`\dfrac{x^{-\frac{2}{3}}}{x^{-\frac{4}{5}}}`

.. rst-class:: solution

:math:`= x^{4/5} \cdot x^{-2/3} = x^{12/15-10/15} = x^{2/15}`

Section 2: Rational Expressions
================================================================================

.. rst-class:: keepwithnext

**6)** Simplify each expression and state all restrictions on :math:`x`.

.. rst-class:: keepwithnext

a\) :math:`\dfrac{x+7}{x^2+10x+21}`

.. rst-class:: solution

:math:`= \dfrac{x+7}{(x+7)(x+3)} = \dfrac{1}{x+3}\; ; \; x \neq -7, -3`

.. rst-class:: keepwithnext

b\) :math:`\dfrac{x^2-64}{x-8}`

.. rst-class:: solution

:math:`= \dfrac{(x-8)(x+8)}{x-8} = x+8\; ; \; x \neq 8`

.. rst-class:: keepwithnext

c\) :math:`\dfrac{x^2-9}{x^2-8x+15}`

.. rst-class:: solution

:math:`= \dfrac{(x-3)(x+3)}{(x-3)(x-5)} = \dfrac{x+3}{x-5}\; ; \; x \neq
3, 5`

.. rst-class:: keepwithnext

**7)** Simplify each expression and state the restrictions.

.. rst-class:: keepwithnext

a\) :math:`\dfrac{3x^2}{5xy} \times \dfrac{20xy^3}{12xy}`

.. rst-class:: solution

:math:`= \dfrac{60x^3y^3}{60x^2y^2} = xy\; ; \; x \neq 0,\; y \neq 0`

.. rst-class:: keepwithnext

b\) :math:`\dfrac{150a^3b^4}{20a^2b} \div \dfrac{6b}{8ab^2}`

.. rst-class:: solution

:math:`= \dfrac{150a^3b^4}{20a^2b} \times \dfrac{8ab^2}{6b}
= \dfrac{60a^4b^6}{6a^2b^2} = 10a^2b^4\; ; \; a \neq 0,\; b \neq 0`

.. rst-class:: keepwithnext

c\) :math:`\dfrac{1}{3x}+\dfrac{5}{2x^2}`

.. rst-class:: solution

:math:`= \dfrac{2x}{6x^2}+\dfrac{15}{6x^2} = \dfrac{2x+15}{6x^2}\; ; \; x
\neq 0`

.. rst-class:: keepwithnext

d\) :math:`\dfrac{4}{x-6}-\dfrac{3}{x-4}`

.. rst-class:: solution

:math:`= \dfrac{4(x-4)}{(x-6)(x-4)}-\dfrac{3(x-6)}{(x-6)(x-4)}
= \dfrac{4x-16-3x+18}{(x-6)(x-4)} = \dfrac{x+2}{(x-6)(x-4)}\; ; \; x \neq
6, 4`

.. rst-class:: keepwithnext

**8)** Simplify each expression and state restrictions.

.. rst-class:: keepwithnext

a\) :math:`\dfrac{x^2+7x}{3x+21} \times \dfrac{x^2+3x+2}{x+2}`

.. rst-class:: solution

:math:`= \dfrac{x(x+7)}{3(x+7)} \times \dfrac{(x+2)(x+1)}{x+2}
= \dfrac{x(x+1)}{3}\; ; \; x \neq -7, -2`

.. rst-class:: keepwithnext

b\) :math:`\dfrac{x^2+4x-60}{3x+30} \div \dfrac{x^2-8x+12}{6x-12}`

.. rst-class:: solution

:math:`= \dfrac{(x+10)(x-6)}{3(x+10)} \times \dfrac{6(x-2)}{(x-6)(x-2)}
= \dfrac{6}{3} = 2\; ; \; x \neq -10, 2, 6`

.. rst-class:: keepwithnext

c\) :math:`\dfrac{3}{x^2+7x+10}-\dfrac{5x}{x^2-4}`

.. rst-class:: solution

:math:`= \dfrac{3(x-2)}{(x+2)(x+5)(x-2)}-\dfrac{5x(x+5)}
{(x+2)(x+5)(x-2)} = \dfrac{3x-6-5x^2-25x}{(x+2)(x+5)(x-2)}
= \dfrac{-5x^2-22x-6}{(x+2)(x+5)(x-2)}\; ; \; x \neq -5, -2, 2`

.. rst-class:: keepwithnext

d\) :math:`\dfrac{-10x}{x^2+18x+32}+\dfrac{12x}{x^2+6x-160}`

.. rst-class:: solution

:math:`= \dfrac{-10x(x-10)}{(x+16)(x+2)(x-10)}+\dfrac{12x(x+2)}
{(x+16)(x+2)(x-10)} = \dfrac{-10x^2+100x+12x^2+24x}{(x+16)(x+2)(x-10)}`

.. rst-class:: solution

:math:`= \dfrac{2x^2+124x}{(x+16)(x+2)(x-10)} = \dfrac{2x(x+62)}
{(x+16)(x+2)(x-10)}\; ; \; x \neq -16, -2, 10`

.. rst-class:: keepwithnext

**9)** Simplify each expression and state any restrictions

.. rst-class:: keepwithnext

a\) :math:`\dfrac{x-8}{x+7} \times \dfrac{x+15}{x^2+12x-45}`

.. rst-class:: solution

:math:`= \dfrac{x-8}{x+7} \times \dfrac{x+15}{(x+15)(x-3)}
= \dfrac{x-8}{(x+7)(x-3)}\; ; \; x \neq -15, -7, 3`

.. rst-class:: keepwithnext

b\) :math:`\dfrac{x^2+12x+20}{x+5} \div \dfrac{x^2+7x-30}{x+10}`

.. rst-class:: solution

:math:`= \dfrac{(x+10)(x+2)}{x+5} \times \dfrac{x+10}{(x+10)(x-3)}
= \dfrac{(x+10)(x+2)}{(x+5)(x-3)}\; ; \; x \neq -10, -5, 3`

.. rst-class:: keepwithnext

c\) :math:`\dfrac{x+3}{x-7}-\dfrac{x+9}{x-2}`

.. rst-class:: solution

:math:`= \dfrac{(x+3)(x-2)}{(x-7)(x-2)}-\dfrac{(x+9)(x-7)}{(x-7)(x-2)}
= \dfrac{x^2+x-6-(x^2+2x-63)}{(x-7)(x-2)} = \dfrac{-x+57}{(x-7)(x-2)}\; ;
\; x \neq 2, 7`

.. rst-class:: keepwithnext

d\) :math:`\dfrac{x+8}{x+3}+\dfrac{x-6}{x^2+9x+18}`

.. rst-class:: solution

:math:`= \dfrac{(x+6)(x+8)}{(x+3)(x+6)}+\dfrac{x-6}{(x+3)(x+6)}
= \dfrac{x^2+14x+48+x-6}{(x+3)(x+6)} = \dfrac{x^2+15x+42}{(x+3)(x+6)}\; ;
\; x \neq -3, -6`

.. rst-class:: keepwithnext

e\) :math:`\dfrac{5x+1}{2x-1}-\dfrac{3x-3}{1-2x}`

.. rst-class:: solution

:math:`= \dfrac{5x+1}{2x-1}-\dfrac{-1(3x-3)}{-1(1-2x)} = \dfrac{5x+1}
{2x-1}+\dfrac{3x-3}{2x-1} = \dfrac{8x-2}{2x-1}\; ; \; x \neq
\dfrac{1}{2}`
