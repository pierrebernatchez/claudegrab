Add and Subtract Rational Expressions With Monomial Denominators
================================================================================

**Steps:** 1. factor denominators if possible 2. get a common denominator
3. re-write expression with a common denominator 4. add/subtract the
numerator (keep denominator the same) 5. simplify where possible 6. state
restrictions (throughout process)

.. rst-class:: keepwithnext

a\) :math:`\dfrac{1}{5x}+\dfrac{1}{2x}`
