What is a Rational Expression?
================================================================================

.. rst-class:: solution

**Rational expression:** the quotient of two polynomials,
:math:`\dfrac{p(x)}{q(x)}`, where :math:`q(x) \neq 0`.

.. rst-class:: keepwithnext

**Example of a graph of a rational expression:**

.. rst-class:: keepwithnext

.. image:: ../images/mau2lesson03-gpimage01.png
   :scale: 85
   :alt: f(x) = (x^2-2x)/(x-2), a line y = x with an open circle (hole) at x = 2

The open circle is used to represent a hole in the graph. This
corresponds to any restrictions on the variable (denominator can't be
0).

Stating Restrictions
================================================================================

**Note:** rational expressions must be checked for restrictions by
determining where the denominator is equal to :sol:`zero`. These
restrictions must be stated when the expression is simplified.

.. list-table::
   :width: 100%

   * - .. rst-class:: solution

       *bottom of a fraction can NOT = 0.*

.. rst-class:: keepwithnext

**Example 1:** State the restrictions for the following rational
expressions

.. list-table::
   :widths: 33 33 34
   :width: 100%

   * - a\) :math:`\dfrac{x+2}{x-2}`

       .. rst-class:: solution

       :math:`x-2 \neq 0 \Rightarrow x \neq 2`
     - b\) :math:`\dfrac{x+2}{(x-3)(x+4)}`

       .. rst-class:: solution

       :math:`x-3 \neq 0 \Rightarrow x \neq 3`;
       :math:`x+4 \neq 0 \Rightarrow x \neq -4`
     - c\) :math:`\dfrac{5}{x(x+3)}`

       .. rst-class:: solution

       :math:`x \neq 0`; :math:`x+3 \neq 0 \Rightarrow x \neq -3`

.. rst-class:: keepwithnext

**Rule:** We can cancel out ONLY when multiplying fractions.

.. rst-class:: solution

You can cancel factors.

.. rst-class:: solution

:math:`\text{e.g. } \dfrac{\cancel{x}(x+1)}{\cancel{x}} = x+1`
is an example of when cancelling is allowed.

.. rst-class:: solution

:math:`\text{e.g. } \dfrac{\cancel{3}\cancel{x}(x+3)}{2\cancel{4}\cancel{x}}
= \dfrac{3x+9}{2}` is an example of when cancelling is allowed.

.. rst-class:: keepwithnext

**Rule:** We can **NOT** cancel out when adding or subtracting
fractions.

.. rst-class:: solution

:math:`\text{e.g. } \dfrac{x+8}{x}` |---| NO! Don't do this!

.. rst-class:: solution

:math:`\text{e.g. } \dfrac{2x+3}{4x}` |---| no cancelling!

Simplifying Rational Expressions
================================================================================

.. rst-class:: keepwithnext

**Example 2:** Simplify each expression and determine any restrictions
on the variable.

**Note:** factor where possible and then state restrictions before
cancelling factors.

.. list-table::
   :widths: 50 50
   :width: 100%

   * - a\) :math:`\dfrac{3x^2}{yx}`

       .. rst-class:: solution

       :math:`= \dfrac{3x}{y}` ; :math:`y \neq 0`, :math:`x \neq 0`
     - b\) :math:`\dfrac{x-3}{x^2+3x-18}`

       .. rst-class:: solution

       :math:`= \dfrac{\cancel{x-3}}{(x+6)\cancel{(x-3)}}` ;
       :math:`x \neq -6, 3`

       .. rst-class:: solution

       :math:`= \dfrac{1}{x+6}` ; :math:`x \neq -6, 3`
   * - c\) :math:`\dfrac{x^2+10x+21}{x+3}`

       .. rst-class:: solution

       :math:`= \dfrac{(x+7)\cancel{(x+3)}}{\cancel{x+3}}` ;
       :math:`x \neq -3`

       .. rst-class:: solution

       :math:`= x+7` ; :math:`x \neq -3`
     - d\) :math:`\dfrac{x+1}{x^2+3x+2}`

       .. rst-class:: solution

       :math:`= \dfrac{\cancel{x+1}}{(x+2)\cancel{(x+1)}}` ;
       :math:`x \neq -2, -1`

       .. rst-class:: solution

       :math:`= \dfrac{1}{x+2}`
   * - e\) :math:`\dfrac{x^2-9}{x^2+7x+12}`

       .. rst-class:: solution

       difference of squares: :math:`a^2-b^2 = (a-b)(a+b)`

       .. rst-class:: solution

       :math:`= \dfrac{(x-3)\cancel{(x+3)}}{(x+4)\cancel{(x+3)}}` ;
       :math:`x \neq -4, -3`

       .. rst-class:: solution

       :math:`= \dfrac{x-3}{x+4}` ; :math:`x \neq -4, -3`
     - f\) :math:`\dfrac{6x^2-7x-5}{3x^2+x-10}`

       .. rst-class:: solution

       Factor numerator: :math:`6x^2-10x+3x-5 = 2x(3x-5)+1(3x-5) =
       (2x+1)(3x-5)`

       .. rst-class:: solution

       Factor denominator: :math:`3x^2+6x-5x-10 = 3x(x+2)-5(x+2) =
       (x+2)(3x-5)`

       .. rst-class:: solution

       :math:`= \dfrac{(2x+1)\cancel{(3x-5)}}{(x+2)\cancel{(3x-5)}}` ;
       :math:`x \neq -2, \dfrac{5}{3}`

       .. rst-class:: solution

       :math:`= \dfrac{2x+1}{x+2}` ; :math:`x \neq -2, \dfrac{5}{3}`

Multiplying Rational Expressions
================================================================================

.. list-table::
   :width: 100%

   * - **1.** factor where possible

       **2.** cancel common factors

       **3.** multiply numerators and denominators

       **4.** state restrictions (throughout process)

.. list-table::
   :widths: 50 50
   :width: 100%

   * - a\) :math:`\dfrac{4x^2}{3x} \cdot \dfrac{12x^3}{2x}`

       .. rst-class:: solution

       :math:`x \neq 0`

       .. rst-class:: solution

       :math:`= 8x^3` ; :math:`x \neq 0`
     - b\) :math:`\dfrac{4x+24}{x^2+8x} \cdot \dfrac{12x^2}{3x+18}`

       .. rst-class:: solution

       :math:`= \dfrac{4(x+6)}{x(x+8)} \cdot \dfrac{12x^2}{3(x+6)}` ;
       :math:`x \neq 0, -8, -6`

       .. rst-class:: solution

       :math:`= \dfrac{16x}{x+8}` ; :math:`x \neq 0, -8, -6`
   * - c\) :math:`\dfrac{x+1}{2x} \cdot \dfrac{3x}{x^2+4x+3}`

       .. rst-class:: solution

       :math:`x \neq 0`

       .. rst-class:: solution

       :math:`= \dfrac{x+1}{2x} \cdot \dfrac{3x}{(x+1)(x+3)}` ;
       :math:`x \neq 0, -1, -3`

       .. rst-class:: solution

       :math:`= \dfrac{3}{2(x+3)}` ; :math:`x \neq 0, -1, -3`
     - d\) :math:`\dfrac{5x^2-13x+8}{x-7} \cdot \dfrac{1}{5x-8}`

       .. rst-class:: solution

       Factor: :math:`5x^2-13x+8 = 5x^2-8x-5x+8 = x(5x-8)-1(5x-8) =
       (5x-8)(x-1)`

       .. rst-class:: solution

       :math:`= \dfrac{(5x-8)(x-1)}{x-7} \cdot \dfrac{1}{5x-8}` ;
       :math:`x \neq 7, \dfrac{8}{5}`

       .. rst-class:: solution

       :math:`= \dfrac{x-1}{x-7}` ; :math:`x \neq 7, \dfrac{8}{5}`

Dividing Rational Expressions
================================================================================

.. list-table::
   :width: 100%

   * - **1.** flip second fraction and change to multiplication

       **2.** factor where possible

       **3.** cancel common factors

       **4.** multiply numerators and denominators

       **5.** state restrictions (throughout process)

.. list-table::
   :widths: 50 50
   :width: 100%

   * - a\) :math:`\dfrac{10ab^2}{4a} \div \dfrac{15a^2}{12b^2}`

       .. rst-class:: solution

       *no cross cancelling until after second fraction has been
       flipped*

       .. rst-class:: solution

       :math:`= \dfrac{10ab^2}{4a} \times \dfrac{12b^2}{15a^2}` ;
       :math:`a \neq 0`, :math:`b \neq 0`

       .. rst-class:: solution

       :math:`= \dfrac{2b^4}{a^2}` ; :math:`a \neq 0`, :math:`b \neq 0`
     - b\) :math:`\dfrac{a^2+2a}{3a} \div \dfrac{5a^2+10a}{20a^2}`

       .. rst-class:: solution

       :math:`= \dfrac{a^2+2a}{3a} \times \dfrac{20a^2}{5a^2+10a}` ;
       :math:`a \neq 0`

       .. rst-class:: solution

       :math:`= \dfrac{a(a+2)}{3a} \times \dfrac{20a^2}{5a(a+2)}` ;
       :math:`a \neq 0, -2`

       .. rst-class:: solution

       :math:`= \dfrac{4a}{3}` ; :math:`a \neq 0, -2`
   * - c\) :math:`\dfrac{2x^2-8x}{x^2-3x-10} \div \dfrac{4x^2}{x^2-9x+20}`

       .. rst-class:: solution

       :math:`= \dfrac{2x^2-8x}{x^2-3x-10} \times
       \dfrac{x^2-9x+20}{4x^2}`

       .. rst-class:: solution

       :math:`= \dfrac{2x(x-4)}{(x-5)(x+2)} \times
       \dfrac{(x-5)(x-4)}{4x^2}` ; :math:`x \neq -2, 0, 4, 5`

       .. rst-class:: solution

       :math:`= \dfrac{(x-4)^2}{2x(x+2)}` ; :math:`x \neq -2, 0, 4, 5`
     - |nbsp|
