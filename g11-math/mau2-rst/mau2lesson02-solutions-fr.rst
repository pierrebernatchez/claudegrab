Introduction aux exposants rationnels (exposants fractionnaires)
================================================================================

:math:`\sqrt[2]{x^1}` |---| le petit nombre surélevé à gauche est
l'**indice** (aussi appelé le dénominateur), le nombre sous la racine est
le **radicande**, et le petit nombre surélevé sur le radicande est le
numérateur : :math:`\sqrt[2]{x^1} = x^{\frac{1}{2}}`

Puissances avec un exposant rationnel de la forme :math:`\dfrac{1}{n}`
--------------------------------------------------------------------------------

Une puissance avec un exposant rationnel dont le numérateur est 1 et le
dénominateur est :math:`n` peut être interprétée comme la racine
:math:`n`-ième de la base :

:math:`b^{\frac{1}{n}} = \sqrt[n]{b}`

En particulier, lorsque :math:`n = 2` : :math:`x^{\frac{1}{2}} = \sqrt{x}`,
la racine simple de :math:`x`.

.. rst-class:: keepwithnext

**Exemple 1 :** Évalue chacune des expressions suivantes

.. list-table::
   :widths: 33 33 34
   :width: 100%

   * - a\) :math:`8^{\frac{1}{3}}`

       .. rst-class:: solution

       :math:`=2` (vérifié à la calculatrice)
     - b\) :math:`\sqrt[5]{-32}`

       .. rst-class:: solution

       :math:`=(-32)^{\frac{1}{5}}=-2`
     - c\) :math:`-16^{\frac{1}{4}}`

       .. rst-class:: solution

       :math:`=-2`
   * - d\) :math:`\sqrt[4]{\dfrac{16}{81}}`

       .. rst-class:: solution

       :math:`=\left(\dfrac{16}{81}\right)^{\frac{1}{4}}=\dfrac{16^{\frac{1}{4}}}{81^{\frac{1}{4}}}=\dfrac{2}{3}`
     - e\) :math:`(-27)^{-\frac{1}{3}}`

       .. rst-class:: solution

       :math:`=\dfrac{1}{(-27)^{\frac{1}{3}}}=\dfrac{1}{-3}=-\dfrac{1}{3}`
     - |nbsp|

Puissances avec un exposant rationnel de la forme :math:`\dfrac{m}{n}`
--------------------------------------------------------------------------------

Tu peux évaluer une puissance avec un exposant rationnel dont le
numérateur est :math:`m` et le dénominateur est :math:`n` en prenant la
racine :math:`n`-ième de la base élevée à l'exposant :math:`m` :

.. rst-class:: solution

:math:`b^{\frac{m}{n}} = \left(\sqrt[n]{b}\right)^m = \sqrt[n]{b^m}`

.. rst-class:: keepwithnext

**Exemple 2 :** Simplifie chacune des puissances suivantes

.. list-table::
   :widths: 33 33 34
   :width: 100%

   * - a\) :math:`\sqrt[5]{y^2}`

       .. rst-class:: solution

       :math:`=y^{\frac{2}{5}}`
     - b\) :math:`\sqrt[3]{x}`

       .. rst-class:: solution

       :math:`=x^{\frac{1}{3}}`
     - c\) :math:`\sqrt{a^{-3}b^{\frac{4}{3}}}`

       .. rst-class:: solution

       :math:`=(a^{-3}b^{\frac{4}{3}})^{\frac{1}{2}}=a^{-\frac{3}{2}}b^{\frac{2}{3}}=\dfrac{b^{\frac{2}{3}}}{a^{\frac{3}{2}}}`
   * - d\) :math:`\sqrt[4]{x^3y^2}`

       .. rst-class:: solution

       :math:`=(x^3y^2)^{\frac{1}{4}}=x^{\frac{3}{4}}y^{\frac{1}{2}}`
     - e\) :math:`\dfrac{\sqrt[3]{x^2y}\cdot y^2}{x^3}`

       .. rst-class:: solution

       :math:`=\dfrac{(x^2y)^{\frac{1}{3}}y^2}{x^3}=\dfrac{x^{\frac{2}{3}}y^{\frac{1}{3}}y^2}{x^3}=x^{-\frac{7}{3}}y^{\frac{7}{3}}=\dfrac{y^{\frac{7}{3}}}{x^{\frac{7}{3}}}`
     - |nbsp|

.. rst-class:: keepwithnext

**Exemple 3 :** Évalue chacune des expressions suivantes

*Si tu as une puissance avec un exposant négatif et une base rationnelle,
renverse simplement la base et rends l'exposant positif.*

.. list-table::
   :widths: 33 33 34
   :width: 100%

   * - a\) :math:`8^{\frac{2}{3}}`

       .. rst-class:: solution

       :math:`=(8^{\frac{1}{3}})^2=(2)^2=4` (vérifié à la calculatrice)
     - b\) :math:`81^{\frac{5}{4}}`

       .. rst-class:: solution

       :math:`=(81^{\frac{1}{4}})^5=(3)^5=243`
     - c\) :math:`\left(\dfrac{49}{81}\right)^{-\frac{3}{2}}`

       .. rst-class:: solution

       :math:`=\left(\dfrac{81}{49}\right)^{\frac{3}{2}}=\dfrac{81^{\frac{3}{2}}}{49^{\frac{3}{2}}}=\dfrac{729}{343}`

Applique les lois des exposants
================================================================================

.. rst-class:: keepwithnext

**Exemple 4 :** Simplifie et exprime ta réponse en utilisant seulement des
exposants positifs

.. list-table::
   :widths: 33 33 34
   :width: 100%

   * - a\) :math:`\dfrac{(x^{\frac{2}{3}})(x^{\frac{2}{3}})}{(x^{\frac{1}{3}})}`

       .. rst-class:: solution

       :math:`=\dfrac{x^{\frac{4}{3}}}{x^{\frac{1}{3}}}=x^{\frac{3}{3}}=x`
     - b\) :math:`\left(y^{\frac{1}{4}}\right)^2\times\left(y^{-\frac{1}{3}}\right)^2`

       .. rst-class:: solution

       :math:`=y^{\frac{1}{2}}\times y^{-\frac{2}{3}}=y^{\frac{3}{6}}\times y^{-\frac{4}{6}}=y^{-\frac{1}{6}}=\dfrac{1}{y^{\frac{1}{6}}}`
     - c\) :math:`\left(5x^{\frac{1}{2}}\right)^2\times4x^{-\frac{1}{2}}`

       .. rst-class:: solution

       :math:`=25x\cdot4x^{-\frac{1}{2}}=100x^{\frac{1}{2}}`

.. list-table::
   :widths: 50 50
   :width: 100%

   * - d\) :math:`\dfrac{(m^{-2})^3\sqrt{m^4}}{m\sqrt{pq^{-3}}}`

       .. rst-class:: solution

       :math:`=\dfrac{m^{-6}\cdot m^2}{mp^{\frac{1}{2}}q^{-\frac{3}{2}}}=\dfrac{m^{-4}}{mp^{\frac{1}{2}}q^{-\frac{3}{2}}}`

       .. rst-class:: solution

       :math:`=\dfrac{m^{-5}}{p^{\frac{1}{2}}q^{-\frac{3}{2}}}=\dfrac{q^{\frac{3}{2}}}{m^5p^{\frac{1}{2}}}`
     - e\) :math:`\dfrac{(x^2)^{-4}\sqrt[5]{y^3}}{y\sqrt{x^{-2}y}}`

       .. rst-class:: solution

       :math:`=\dfrac{x^{-8}y^{\frac{3}{5}}}{yx^{-1}y^{\frac{1}{2}}}=\dfrac{x^{-7}y^{\frac{3}{5}}}{y^{\frac{3}{2}}}`

       .. rst-class:: solution

       :math:`=x^{-7}y^{\frac{6}{10}-\frac{15}{10}}=x^{-7}y^{-\frac{9}{10}}=\dfrac{1}{x^7y^{\frac{9}{10}}}`
