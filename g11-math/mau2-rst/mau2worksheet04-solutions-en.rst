.. rst-class:: keepwithnext

**1)** Simplify and state any restrictions

.. rst-class:: keepwithnext

a\) :math:`\dfrac{x+1}{18}+\dfrac{x-1}{45}`

.. rst-class:: solution

:math:`= \dfrac{5(x+1)}{90}+\dfrac{2(x-1)}{90} = \dfrac{5x+5+2x-2}{90}
= \dfrac{7x+3}{90}`, no restrictions

.. rst-class:: keepwithnext

b\) :math:`\dfrac{2}{3x}-\dfrac{1}{4x}`

.. rst-class:: solution

:math:`= \dfrac{8}{12x}-\dfrac{3}{12x} = \dfrac{5}{12x}\; ; \; x \neq 0`

.. rst-class:: keepwithnext

c\) :math:`\dfrac{3}{ab}+\dfrac{5}{4b}`

.. rst-class:: solution

:math:`= \dfrac{12}{4ab}+\dfrac{5a}{4ab} = \dfrac{12+5a}{4ab}\; ; \; a
\neq 0,\; b \neq 0`

.. rst-class:: keepwithnext

d\) :math:`\dfrac{2+a}{a^2b}+\dfrac{4-a}{3ab^2}`

.. rst-class:: solution

:math:`= \dfrac{3b(2+a)}{3a^2b^2}+\dfrac{a(4-a)}{3a^2b^2} = \dfrac{6b+3ab
+4a-a^2}{3a^2b^2}\; ; \; a \neq 0,\; b \neq 0`

.. rst-class:: keepwithnext

**2)** Simplify and state the restrictions.

.. rst-class:: keepwithnext

a\) :math:`\dfrac{1}{x-6}-\dfrac{1}{x+6}`

.. rst-class:: solution

:math:`= \dfrac{1(x+6)}{(x-6)(x+6)}-\dfrac{1(x-6)}{(x-6)(x+6)}
= \dfrac{x+6-x+6}{(x-6)(x+6)} = \dfrac{12}{(x-6)(x+6)}\; ; \; x \neq
-6, 6`

.. rst-class:: keepwithnext

b\) :math:`\dfrac{12}{x+8}+\dfrac{3}{x-9}`

.. rst-class:: solution

:math:`= \dfrac{12(x-9)}{(x+8)(x-9)}+\dfrac{3(x+8)}{(x+8)(x-9)}
= \dfrac{12x-108+3x+24}{(x+8)(x-9)} = \dfrac{15x-84}{(x+8)(x-9)}\; ; \; x
\neq -8, 9`

.. rst-class:: keepwithnext

c\) :math:`\dfrac{x+10}{x-6}-\dfrac{x-3}{x+4}`

.. rst-class:: solution

:math:`= \dfrac{(x+4)(x+10)}{(x+4)(x-6)}-\dfrac{(x-6)(x-3)}{(x+4)(x-6)}
= \dfrac{x^2+14x+40-(x^2-9x+18)}{(x+4)(x-6)} = \dfrac{23x+22}{(x+4)(x-6)}
\; ; \; x \neq -4, 6`

.. rst-class:: keepwithnext

d\) :math:`\dfrac{x+5}{x+1}+\dfrac{x+2}{x-2}`

.. rst-class:: solution

:math:`= \dfrac{(x+5)(x-2)}{(x+1)(x-2)}+\dfrac{(x+1)(x+2)}{(x+1)(x-2)}
= \dfrac{x^2+3x-10+x^2+3x+2}{(x+1)(x-2)} = \dfrac{2x^2+6x-8}{(x+1)(x-2)}`

.. rst-class:: solution

:math:`= \dfrac{2(x+4)(x-1)}{(x+1)(x-2)}\; ; \; x \neq -1, 2`

.. rst-class:: keepwithnext

**3)** Simplify and state the restrictions.

.. rst-class:: keepwithnext

a\) :math:`\dfrac{x}{x^2-9x+8}+\dfrac{2}{x-8}`

.. rst-class:: solution

:math:`= \dfrac{x}{(x-8)(x-1)}+\dfrac{2(x-1)}{(x-8)(x-1)}
= \dfrac{x+2x-2}{(x-8)(x-1)} = \dfrac{3x-2}{(x-8)(x-1)}\; ; \; x \neq
8, 1`

.. rst-class:: keepwithnext

b\) :math:`\dfrac{x+3}{x+5}+\dfrac{x+2}{x^2+3x-10}`

.. rst-class:: solution

:math:`= \dfrac{(x+3)(x-2)}{(x+5)(x-2)}+\dfrac{x+2}{(x+5)(x-2)}
= \dfrac{x^2+x-6+x+2}{(x+5)(x-2)} = \dfrac{x^2+2x-4}{(x+5)(x-2)}\; ; \; x
\neq -5, 2`

.. rst-class:: keepwithnext

c\) :math:`\dfrac{x}{x^2+3x+2}-\dfrac{3x-2}{x^2+8x+7}`

.. rst-class:: solution

:math:`= \dfrac{x(x+7)}{(x+2)(x+1)(x+7)}-\dfrac{(3x-2)(x+2)}
{(x+2)(x+1)(x+7)} = \dfrac{x^2+7x-(3x^2+4x-4)}{(x+2)(x+1)(x+7)}
= \dfrac{-2x^2+3x+4}{(x+2)(x+1)(x+7)}\; ; \; x \neq -2, -1, -7`

.. rst-class:: keepwithnext

d\) :math:`\dfrac{x+4}{x^2-121}-\dfrac{2x-1}{x^2+8x-33}`

.. rst-class:: solution

:math:`= \dfrac{(x+4)(x-3)}{(x-11)(x+11)(x-3)}-\dfrac{(2x-1)(x-11)}
{(x-11)(x+11)(x-3)} = \dfrac{x^2+x-12-(2x^2-23x+11)}{(x-11)(x+11)(x-3)}
= \dfrac{-x^2+24x-23}{(x-11)(x+11)(x-3)}`

.. rst-class:: solution

:math:`= \dfrac{-(x-23)(x-1)}{(x+11)(x-11)(x-3)}\; ; \; x \neq -11, 3, 11`

.. rst-class:: keepwithnext

**4)** Binomial expressions can differ by a factor of -1. Factor -1 from
one of the denominators to identify the common denominator. Then,
simplify each expression and state the restrictions.

.. rst-class:: keepwithnext

a\) :math:`\dfrac{1}{x-2}-\dfrac{1}{2-x}`

.. rst-class:: solution

:math:`= \dfrac{1}{x-2}-\dfrac{-1(1)}{-1(x-2)} = \dfrac{1}{x-2}
-\dfrac{-1}{x-2} = \dfrac{2}{x-2}\; ; \; x \neq 2`

.. rst-class:: keepwithnext

b\) :math:`\dfrac{2b+3}{4b-1}+\dfrac{b+6}{1-4b}`

.. rst-class:: solution

:math:`= \dfrac{2b+3}{4b-1}+\dfrac{-1(b+6)}{-1(1-4b)} = \dfrac{2b+3}
{4b-1}+\dfrac{-b-6}{4b-1} = \dfrac{2b+3-b-6}{4b-1} = \dfrac{b-3}{4b-1}\; ;
\; b \neq \dfrac{1}{4}`

Answers
================================================================================

**1)** a) :math:`\dfrac{7x+3}{90}`, no restrictions
b) :math:`\dfrac{5}{12x}`, :math:`x \neq 0`
c) :math:`\dfrac{12+5a}{4ab}`, :math:`a \neq 0,\; b \neq 0`
d) :math:`\dfrac{6b+3ab+4a-a^2}{3a^2b^2}`, :math:`a \neq 0,\; b \neq 0`

**2)** a) :math:`\dfrac{12}{(x-6)(x+6)}`, :math:`x \neq -6, 6`
b) :math:`\dfrac{15x-84}{(x+8)(x-9)}`, :math:`x \neq -8, 9`
c) :math:`\dfrac{23x+22}{(x-6)(x+4)}`, :math:`x \neq -4, 6`
d) :math:`\dfrac{2(x+4)(x-1)}{(x+1)(x-2)}`, :math:`x \neq -1, 2`

**3)** a) :math:`\dfrac{3x-2}{(x-1)(x-8)}`, :math:`x \neq 1, 8`
b) :math:`\dfrac{x^2+2x-4}{(x+5)(x-2)}`, :math:`x \neq -5, 2`
c) :math:`\dfrac{-2x^2+3x+4}{(x+1)(x+2)(x+7)}`, :math:`x \neq -7, -2, -1`
d) :math:`\dfrac{-(x-23)(x-1)}{(x+11)(x-11)(x-3)}`, :math:`x \neq -11, 3, 11`

**4)** a) :math:`\dfrac{2}{x-2}`, :math:`x \neq 2`
b) :math:`\dfrac{b-3}{4b-1}`, :math:`b \neq \dfrac{1}{4}`
