Corrigé
================================================================================

1-2\) voir graphiques ci-dessus (points clés à 0°, 90°, 180°, 270°, 360°)

3\) a) décalage de phase droite 50°, décalage vertical vers le haut de 3
unités b) décalage de phase gauche 45°, décalage vertical vers le bas
d'une unité

4\) a) décalage de phase gauche 120°, décalage vertical vers le bas de 5
unités b) décalage de phase droite 150°, décalage vertical vers le haut
de 7 unités

5\) a) amplitude 5, période 90°, décalage de phase gauche 60°, décalage
vertical vers le bas de 2, max 3, min -7

b) amplitude 2, période 180°, décalage de phase gauche 150°, décalage
vertical vers le bas de 5, max -3, min -7

c) amplitude 0.5, période 720°, décalage de phase droite 60°, décalage
vertical vers le haut de 1, max 1.5, min 0.5

d) amplitude 0.8, période 100°, décalage de phase droite 40°, décalage
vertical vers le bas de 0.4, max 0.4, min -1.2
