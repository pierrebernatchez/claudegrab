Section 2: Properties of Sine and Cosine Functions
================================================================================

.. rst-class:: solution

**Domain:** :math:`x \in \mathbb{R}`

.. rst-class:: solution

**Range:** :math:`-1 \le y \le 1`

.. rst-class:: solution

**Period:** :math:`360\degree`

.. rst-class:: solution

**Amplitude:** :math:`1`

Section 3: Transformations of the Sine and Cosine Functions
================================================================================

:math:`y = a\sin[k(x-d)]+c`

.. list-table::
   :header-rows: 1
   :width: 100%

   * - :math:`a`
     - :math:`k`
     - :math:`d`
     - :math:`c`
   * - Vertical stretch or compression by a factor of :math:`a`.

       Vertical reflection if :math:`a<0`

       :math:`|a| = \text{amplitude}`
     - Horizontal stretch or compression by a factor of :math:`\frac{1}{k}`.

       Horizontal reflection if :math:`k<0`.

       :math:`\dfrac{360}{|k|} = \text{period}`
     - Phase shift

       :math:`d>0`; shift right

       :math:`d<0`; shift left
     - Vertical shift

       :math:`c>0`; shift up

       :math:`c<0`; shift down

.. rst-class:: keepwithnext

**Example 3:** For the function :math:`y = 3\sin[2(x+60\degree)]-1`, state
the...

.. list-table::
   :widths: 50 50
   :width: 100%

   * - Amplitude:

       .. rst-class:: solution

       :math:`|a| = 3`
     - Period:

       .. rst-class:: solution

       :math:`\dfrac{360}{|k|} = \dfrac{360}{2} = 180\degree`

   * - Phase shift:

       .. rst-class:: solution

       :math:`d=-60\degree`, left :math:`60\degree`
     - Vertical shift:

       .. rst-class:: solution

       :math:`c=-1`, down :math:`1`

   * - Max:

       .. rst-class:: solution

       :math:`c+|a| = -1+3 = 2`
     - Min:

       .. rst-class:: solution

       :math:`c-|a| = -1-3 = -4`
