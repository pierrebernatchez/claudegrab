**Instructions:** For each of the following start with two cycles of the
parent graph (-360 to 360). Transform key points to produce the new
graph.

.. rst-class:: keepwithnext

**1)** Using transformations, graph two cycles of the following
trigonometric functions. State the period, phase shift, amplitude, and
vertical displacement.

.. rst-class:: keepwithnext

a\) :math:`y = 4\cos(\theta+180\degree)+2`

.. image:: ../images/mau6worksheet03-gpimage01.png
   :scale: 100

.. rst-class:: solution

period = :math:`360\degree`, phase shift = left :math:`180\degree`,
amplitude = 4, vertical shift = up 2

.. rst-class:: keepwithnext

b\) :math:`y = \sin[2(\theta+30\degree)]+3`

.. image:: ../images/mau6worksheet03-gpimage02.png
   :scale: 100

.. rst-class:: solution

period = :math:`180\degree`, phase shift = left :math:`30\degree`,
amplitude = 1, vertical shift = up 3

.. rst-class:: keepwithnext

c\) :math:`y = 2\sin[3(\theta-180\degree)]`

.. image:: ../images/mau6worksheet03-gpimage03.png
   :scale: 100

.. rst-class:: solution

period = :math:`120\degree`, phase shift = right :math:`180\degree`,
amplitude = 2, vertical shift = none

.. rst-class:: keepwithnext

d\) :math:`y = -3\cos(2\theta)+4`

.. image:: ../images/mau6worksheet03-gpimage04.png
   :scale: 100

.. rst-class:: solution

period = :math:`180\degree`, phase shift = none, amplitude = 3, vertical
shift = up 4

.. rst-class:: keepwithnext

e\) :math:`y = \dfrac{1}{2}\sin(\theta+45\degree)-3`

.. image:: ../images/mau6worksheet03-gpimage05.png
   :scale: 100

.. rst-class:: solution

period = :math:`360\degree`, phase shift = left :math:`45\degree`,
amplitude = :math:`\dfrac{1}{2}`, vertical shift = down 3

.. rst-class:: keepwithnext

f\) :math:`y = 3\cos[2(\theta-60\degree)]+4`

.. image:: ../images/mau6worksheet03-gpimage06.png
   :scale: 100

.. rst-class:: solution

period = :math:`180\degree`, phase shift = right :math:`60\degree`,
amplitude = 3, vertical shift = up 4
