**Consignes :** Pour chacune des suivantes, commence avec deux cycles de
la fonction mère (-360 à 360). Transforme les points clés pour produire
le nouveau graphique.

.. rst-class:: keepwithnext

**1)** À l'aide de transformations, trace deux cycles des fonctions
trigonométriques suivantes. Indique la période, le décalage de phase,
l'amplitude, et le déplacement vertical.

.. rst-class:: keepwithnext

a\) :math:`y = 4\cos(\theta+180\degree)+2`

.. image:: ../images/mau6worksheet03-gpimage01.png
   :scale: 100

.. rst-class:: solution

période = :math:`360\degree`, décalage de phase = gauche
:math:`180\degree`, amplitude = 4, décalage vertical = haut 2

.. rst-class:: keepwithnext

b\) :math:`y = \sin[2(\theta+30\degree)]+3`

.. image:: ../images/mau6worksheet03-gpimage02.png
   :scale: 100

.. rst-class:: solution

:math:`30\degree`, amplitude = 1, décalage vertical = haut 3
