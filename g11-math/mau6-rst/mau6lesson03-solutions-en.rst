Section 1: Review of Sine and Cosine Functions
================================================================================

:math:`y = a\sin[k(x-d)]+c` OR :math:`y = a\cos[k(x-d)]+c`

.. list-table::
   :header-rows: 1
   :width: 100%

   * - :math:`a`
     - :math:`k`
     - :math:`d`
     - :math:`c`
   * - Vertical stretch or compression by a factor of :math:`a`.

       Vertical reflection if :math:`a<0`

       :math:`|a| = \text{amplitude}`
     - Horizontal stretch or compression by a factor of :math:`\frac{1}{k}`.

       Horizontal reflection if :math:`k<0`.

       :math:`\dfrac{360}{|k|} = \text{period}`
     - Phase shift

       :math:`d>0`; shift right

       :math:`d<0`; shift left
     - Vertical shift

       :math:`c>0`; shift up

       :math:`c<0`; shift down

Section 2: Graphing Transformed Sinusoidal Functions
================================================================================

.. rst-class:: keepwithnext

**Example 1:** Graph :math:`y = 2\sin x + 1` using transformations. Then
state the amplitude, period, and number of cycles between 0° and 360°.

.. image:: ../images/mau6lesson03-gpimage03.png
   :scale: 100

.. rst-class:: solution

Amplitude: :math:`|a|=2`

.. rst-class:: solution

Period: :math:`\dfrac{360}{|k|} = \dfrac{360}{1} = 360\degree`

.. rst-class:: solution

Number of cycles between 0° and 360°: :math:`1`
