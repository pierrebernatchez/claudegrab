**1)** A sinusoidal function has an amplitude of 5 units, a period of
120°, and a maximum at (0, 3).

.. rst-class:: keepwithnext

a\) Represent the function with an equation using a sine function

.. rst-class:: solution

:math:`y = 5\sin[3(x+30\degree)]-2`

.. rst-class:: keepwithnext

b\) Represent the function with an equation using a cosine function

.. rst-class:: solution

:math:`y = 5\cos 3x - 2`

.. rst-class:: keepwithnext

**2)** A sinusoidal function has an amplitude of :math:`\frac{1}{2}`
units, a period of 720°, and a maximum at :math:`\left(0,
\frac{3}{2}\right)`.

.. rst-class:: keepwithnext

a\) Represent the function with an equation using a sine function

.. rst-class:: solution

:math:`y = \dfrac{1}{2}\sin\left[\dfrac{1}{2}(x+180\degree)\right]+1`

.. rst-class:: keepwithnext

b\) Represent the function with an equation using a cosine function

.. rst-class:: solution

:math:`y = \dfrac{1}{2}\cos\dfrac{1}{2}x+1`

.. rst-class:: keepwithnext

**4)** The relationship between the stress on the shaft of an electric
motor and time can be modelled with a sinusoidal function. Determine an
equation of a function that describes stress in terms of time.

.. image:: ../images/mau6worksheet04-gpimage02.png
   :scale: 100

.. rst-class:: solution

:math:`y = 3\sin(9000x)+8` OR :math:`y = 3\cos[9000(x-0.01)]+8`
