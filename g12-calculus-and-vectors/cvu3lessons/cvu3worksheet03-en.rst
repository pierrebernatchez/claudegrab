Answer Key
================================================================================

**1)** a) :math:`g'(x) = 4^x(\ln 4)`  b) :math:`f'(x) = 11^x(\ln 11)`
c) :math:`y' = \left(\dfrac{1}{2}\right)^x\left[\ln\dfrac{1}{2}\right]`
d) :math:`N'(x) = -3e^x`  e) :math:`h'(x) = e^x`
f) :math:`y' = \pi^x(\ln\pi)`

**2)** :math:`f'(x) = f''(x) = f'''(x) = e^x`

**3)** :math:`40.2`

**4)** :math:`27.3`

**5)** :math:`y = 6\sqrt{2}(\ln 2)x + \sqrt{2}(2 - 3\ln 2)`

**6)** a) :math:`N(t) = 10(2)^t`  b) :math:`1280`  c) :math:`887` flies/day
d) :math:`5.64` days  e) :math:`346` flies/day

**7)** i) :math:`1.53` days  ii) :math:`8.17` days

**8)** :math:`y = -\dfrac{2}{3}x + \dfrac{2}{3}\ln 3 + \dfrac{3}{2}`
