**3\)** Find the equation of the line that is tangent to the curve
:math:`y = 2\sin\theta + 4\cos\theta` at :math:`\theta = \dfrac{\pi}{4}`.

.. rst-class:: solution

Point:

.. math::
   :class: solution

   y\left(\frac{\pi}{4}\right) = 2\sin\left(\frac{\pi}{4}\right) + 4\cos\left(\frac{\pi}{4}\right)

.. math::
   :class: solution

   y\left(\frac{\pi}{4}\right) = 2\left(\frac{\sqrt{2}}{2}\right) + 4\left(\frac{\sqrt{2}}{2}\right)

.. math::
   :class: solution

   y\left(\frac{\pi}{4}\right) = \sqrt{2} + 2\sqrt{2}

.. math::
   :class: solution

   y\left(\frac{\pi}{4}\right) = 3\sqrt{2}

.. math::
   :class: solution

   \left(\frac{\pi}{4}, 3\sqrt{2}\right)

.. rst-class:: solution

Slope:

.. math::
   :class: solution

   y' = 2\cos\theta - 4\sin\theta

.. math::
   :class: solution

   y'\left(\frac{\pi}{4}\right) = 2\cos\left(\frac{\pi}{4}\right) - 4\sin\left(\frac{\pi}{4}\right)

.. math::
   :class: solution

   y'\left(\frac{\pi}{4}\right) = 2\left(\frac{\sqrt{2}}{2}\right) - 4\left(\frac{\sqrt{2}}{2}\right)

.. math::
   :class: solution

   y'\left(\frac{\pi}{4}\right) = \sqrt{2} - 2\sqrt{2}

.. math::
   :class: solution

   y'\left(\frac{\pi}{4}\right) = -\sqrt{2}

.. math::
   :class: solution

   m = -\sqrt{2}

.. rst-class:: solution

Equation:

.. math::
   :class: solution

   y = m\theta + b

.. math::
   :class: solution

   :class: solution

Section 6: 3.6 -- Applications: Piston Motion

.. rst-class:: keepwithnext

**7\)** The movement of an engine piston can be modelled by
:math:`h = 4\sin t` where :math:`h` is the height of the piston, in
cm, above the neutral position and :math:`t` is time, in seconds.

.. rst-class:: keepwithnext

a\) Determine the velocity of the piston when :math:`t = 5`.

.. math::
   :class: solution

   v(t) = h'(t) = 4\cos t

.. math::
   :class: solution

   v(5) = 4\cos(5)

.. math::
   :class: solution

   v(5) \cong 1.13 \text{ cm/s}

.. rst-class:: keepwithnext

b\) Determine the acceleration of the piston when :math:`t = 5`

.. math::
   :class: solution

   a(t) = v'(t) = -4\sin t

.. math::
   :class: solution

   a(5) = -4\sin(5)

.. math::
   :class: solution

   a(5) \cong 3.8 \text{ cm/s}^2

**16\)** Continuous growth or decay follows the formula
:math:`A = ce^{kt}`, where :math:`c` is the initial amount, and
:math:`k` is a rate factor. The mass of a radioactive substance is
1000 g on day 1, and only 100 g after 100 days. Find...

.. rst-class:: keepwithnext

a\) :math:`k`

.. math::
   :class: solution

   100 = 1000e^{100k}

.. math::
   :class: solution

   0.1 = e^{100k}

.. math::
   :class: solution

.. math::
   :class: solution

.. math::
   :class: solution

b\) the half-life

.. math::
   :class: solution

   500 = 1000e^{-0.023t}

.. math::
   :class: solution

   0.5 = e^{-0.023t}

   \ln(0.5) = -0.023t

.. math::
   :class: solution

   t \cong 30.1 \text{ days}

.. rst-class:: keepwithnext

.. math::
   :class: solution

.. math::
   :class: solution

   A(300) \cong 1.01 \text{ grams}

.. rst-class:: keepwithnext

Section 14: 3.5 -- Implicit Differentiation
================================================================================

.. rst-class:: keepwithnext

**17\)** Find :math:`\dfrac{dy}{dx}` by implicit differentiation

.. rst-class:: keepwithnext

a\) :math:`x^2 + y^2 = 36`

.. math::
   :class: solution

   2x + 2y\left(\frac{dy}{dx}\right) = 0

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{-2x}{2y}

.. math::
   :class: solution

   \frac{dy}{dx} = -\frac{x}{y}

.. rst-class:: keepwithnext

b\) :math:`x^3 - xy + y^2 = 4`

.. math::
   :class: solution

   3x^2 - \left[1y + \frac{dy}{dx}(x)\right] + 2y\left(\frac{dy}{dx}\right) = 0

.. math::
   :class: solution

   3x^2 - y - x\left(\frac{dy}{dx}\right) + 2y\left(\frac{dy}{dx}\right) = 0

.. math::
   :class: solution

   -x\left(\frac{dy}{dx}\right) + 2y\left(\frac{dy}{dx}\right) = y - 3x^2

.. math::
   :class: solution

   \frac{dy}{dx}(-x + 2y) = y - 3x^2

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{y - 3x^2}{-x + 2y}

.. rst-class:: keepwithnext

c\) :math:`2\sin x\cos y = 1`

.. math::
   :class: solution

   2\cos x\cos y + (-\sin y)\left(\frac{dy}{dx}\right)(2)\sin x = 0

.. math::
   :class: solution

   2\cos x\cos y = 2\sin x\sin y\left(\frac{dy}{dx}\right)

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{\cos x\cos y}{\sin x\sin y}

.. rst-class:: keepwithnext

d\) :math:`(4 - x)y^2 = x^3`

.. math::
   :class: solution

   -1y^2 + 2y\left(\frac{dy}{dx}\right)(4 - x) = 3x^2

.. math::
   :class: solution

   \frac{dy}{dx}(2y)(4 - x) = 3x^2 + y^2

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{3x^2 + y^2}{2y(4 - x)}

**18\)** Use implicit differentiation to find an equation of the

.. rst-class:: solution

   :class: solution

   :class: solution

**19\)** Find the slope of the tangent at :math:`(2, 1)` for the curve
:math:`y = 2^{x-2y}`

.. math::
   :class: solution

   y' = 2^{x-2y}(\ln 2)\left(1 - 2y'\right)

.. math::
   :class: solution

   y' = 2^{x-2y}(\ln 2) - 2^{x-2y}(\ln 2)(2y')

.. math::
   :class: solution

   y' + 2y'(2)^{x-2y}(\ln 2) = 2^{x-2y}(\ln 2)

.. math::
   :class: solution

   y'\left[1 + 2(2)^{x-2y}\ln 2\right] = 2^{x-2y}(\ln 2)

.. math::
   :class: solution

   y' = \frac{2^{x-2y}(\ln 2)}{1 + 2(2)^{x-2y}\ln 2}

.. math::
   :class: solution

   y'(2, 1) = \frac{2^0(\ln 2)}{1 + 2\ln 2}

.. math::
   :class: solution

   m = \frac{\ln(2)}{1 + 2\ln(2)}
