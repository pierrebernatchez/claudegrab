Corrigé
================================================================================

**1)** a) :math:`\dfrac{dy}{dx} = -\sin x`  b) :math:`f'(x) = -2\cos x`
c) :math:`y' = -\sin x - \cos x`

**2)** :math:`2`

**3)** :math:`y = -\sqrt{2}\theta + \dfrac{\sqrt{2}}{4}\pi + 3\sqrt{2}`

**4)** a) :math:`y' = \sin(2x)`  b) :math:`y' = 2\cos(2\theta) + 4\sin(2\theta)`
c) :math:`f'(\theta) = -\pi\cos(2\theta - \pi)`
d) :math:`f'(x) = [\cos(\sin x)](\cos x)`  e) :math:`f'(x) = [\sin(\cos x)](\sin x)`

**f)** :math:`f'(\theta) = -7\sin(7\theta) + 5\sin(5\theta)`
**g)** :math:`y' = 3x\cos x + 3\sin x`
**h)** :math:`f'(t) = -4t^2\sin(2t) + 4t\cos(2t)`
**i)** :math:`y' = \pi^2 t[\cos(\pi t - 6)] + \pi\sin(\pi t - 6)`
**j)** :math:`y' = -\sin(\sin\theta)(\cos\theta) - \cos(\cos\theta)(\sin\theta)`
**k)** :math:`f'(x) = -2\cos x[\sin(\sin x)][\cos(\sin x)]`
**l)** :math:`f'(\theta) = -7\sin(7\theta) + 10\cos(5\theta)[\sin(5\theta)]`
**m)** :math:`y' = 6\cos(2x) + 8\sin(2x)`  **n)** :math:`y' = 3\sec^2(3x)`
**o)** :math:`y' = \dfrac{-\sin x}{(2 - \cos x)^2}`

**p)** :math:`y' = 2x\sec^2(2x) + \tan(2x)`
**q)** :math:`y' = e^{3x}[3\sin(2x) + 2\cos(2x)]`
**r)** :math:`y' = -4\cos(2x)\sin(2x)`

**5)** :math:`y = 6x - 3\pi` (les réponses peuvent varier)

**6)** a) tension max : 148 V au temps :math:`t = \dfrac{(4k+1)\pi}{10}, k \in \mathbb{Z}, k \geq 0`

tension min : :math:`-112` V au temps :math:`t = \dfrac{(4k+3)\pi}{10}, k \in \mathbb{Z}, k \geq 0`

b) période : :math:`T = \dfrac{2\pi}{5}` secondes; fréquence :
:math:`f = \dfrac{5}{2\pi}` Hz; amplitude : :math:`A = 130` V

**7)** a) 1,13 cm/s  b) 3,8 cm/s\ :sup:`2`

**8)** a) :math:`h(t) = 8\cos(7t)`  b) :math:`v(t) = -56\sin(7t)`
c) vitesse max de 56 cm/s lorsque :math:`t = \dfrac{3 + 4k}{14}\pi, k \in \mathbb{Z}, k \geq 0`

**9)** a) :math:`f'(x) = \left(\dfrac{1}{2}\right)^x\ln\left(\dfrac{1}{2}\right)`
b) :math:`g'(x) = -2e^x`  c) :math:`y' = 5^x\ln(5)`
d) :math:`y' = 5(2)^x\ln(2)`  e) :math:`y' = 2(52)^{2x}\ln(52)`

**f)** :math:`y = -6(10)^{3x}\ln(10)`
**g)** :math:`y' = (e^{3x^2-2x+1})(6x - 2)`
**h)** :math:`f'(x) = e^{2x}(2x - 1)`  **i)** :math:`y' = 3 - e^{-x}`
**j)** :math:`y' = e^x[-2\sin(2x) + \cos(2x)]`

**k)** :math:`g'(x) = \left[4\ln\left(\dfrac{1}{3}\right)\right]\left(\dfrac{1}{3}\right)^{4x} - (2e^{\sin x})(\cos x)`

**10)** :math:`y = 6x\ln(3) - 6\ln(3) + 6`

**11)** :math:`y = -6x + 6\ln(2) - 6`

**12)** :math:`y = 3x - e^2`

**13)** :math:`y = 2`

**14)** :math:`y' = 2xe^{2x}(1 + x)`; minimum en :math:`(0, 0)`, maximum en

**15)** :math:`(-0.48, -0.18)` est un minimum local
