**3\)** Trouve l'équation de la droite tangente à la courbe
:math:`y = 2\sin\theta + 4\cos\theta` en :math:`\theta = \dfrac{\pi}{4}`.

.. rst-class:: solution

Point :

.. math::
   :class: solution

   y\left(\frac{\pi}{4}\right) = 2\sin\left(\frac{\pi}{4}\right) + 4\cos\left(\frac{\pi}{4}\right)

.. math::
   :class: solution

   y\left(\frac{\pi}{4}\right) = 2\left(\frac{\sqrt{2}}{2}\right) + 4\left(\frac{\sqrt{2}}{2}\right)

.. math::
   :class: solution

   y\left(\frac{\pi}{4}\right) = \sqrt{2} + 2\sqrt{2}

.. math::
   :class: solution

   y\left(\frac{\pi}{4}\right) = 3\sqrt{2}

.. math::
   :class: solution

   \left(\frac{\pi}{4}, 3\sqrt{2}\right)

.. rst-class:: solution

Pente :

.. math::
   :class: solution

   y' = 2\cos\theta - 4\sin\theta

.. math::
   :class: solution

   y'\left(\frac{\pi}{4}\right) = 2\cos\left(\frac{\pi}{4}\right) - 4\sin\left(\frac{\pi}{4}\right)

.. math::
   :class: solution

   y'\left(\frac{\pi}{4}\right) = 2\left(\frac{\sqrt{2}}{2}\right) - 4\left(\frac{\sqrt{2}}{2}\right)

.. math::
   :class: solution

   y'\left(\frac{\pi}{4}\right) = \sqrt{2} - 2\sqrt{2}

.. math::
   :class: solution

   y'\left(\frac{\pi}{4}\right) = -\sqrt{2}

.. math::
   :class: solution

   m = -\sqrt{2}

.. rst-class:: solution

Équation :

.. math::
   :class: solution

   y = m\theta + b

.. math::
   :class: solution

   3\sqrt{2} = -\sqrt{2}\left(\frac{\pi}{4}\right) + b

.. math::
   :class: solution

   b = 3\sqrt{2} + \frac{\pi}{4}\sqrt{2}

.. math::
   :class: solution

   y = -\sqrt{2}\theta + 3\sqrt{2} + \frac{\pi}{4}\sqrt{2}

Section 5 : 3.6 - Applications : signal de tension CA
================================================================================

.. rst-class:: keepwithnext

**6\)** Une tension de l'alimentation dans un circuit couplé CA-CC est
donnée par la fonction :math:`V(t) = 130\sin(5t) + 18`, où :math:`t`
est le temps, en secondes, et :math:`V` est la tension, en volts, au
temps :math:`t`.

.. rst-class:: keepwithnext

a\) Trouve les tensions maximale et minimale et les moments où elles
se produisent.

.. math::
   :class: solution

   \text{Max} = 18 + 130 = 148

.. math::
   :class: solution

   148 = 130\sin(5t) + 18

.. math::
   :class: solution

   1 = \sin(5t)

.. math::
   :class: solution

   5t = \frac{\pi}{2}, \frac{5\pi}{2}, \frac{9\pi}{2}, \ldots

.. math::
   :class: solution

   t = \frac{\pi}{10}, \frac{5\pi}{10}, \frac{9\pi}{10}, \ldots

.. rst-class:: solution

Max de 148 V lorsque :math:`t = \dfrac{\pi + 4\pi k}{10}, k \in \mathbb{Z}, k \geq 0`

.. math::
   :class: solution

   \text{Min} = 18 - 130 = -112 \text{ V}

.. math::
   :class: solution

   -112 = 130\sin(5t) + 18

.. math::
   :class: solution

   -1 = \sin(5t)

.. math::
   :class: solution

   5t = \frac{3\pi}{2}, \frac{7\pi}{2}, \frac{11\pi}{2}, \ldots

.. math::
   :class: solution

   t = \frac{3\pi}{10}, \frac{7\pi}{10}, \frac{11\pi}{10}, \ldots

.. rst-class:: solution

Min de :math:`-112` V lorsque :math:`t = \dfrac{3\pi + 4\pi k}{10}, k \in \mathbb{Z}, k \geq 0`

.. rst-class:: keepwithnext

b\) Détermine la période, :math:`T`, en secondes, la fréquence,
:math:`f`, en hertz, et l'amplitude, :math:`A`, en volts, pour ce
signal.

.. math::
   :class: solution

   T = \frac{2\pi}{5} \text{ secondes}

.. math::
   :class: solution

   f = \frac{5}{2\pi} \text{ Hz}

.. math::
   :class: solution

   A = 130 \text{ V}

Section 6 : 3.6 - Applications : mouvement d'un piston
================================================================================

.. rst-class:: keepwithnext

**7\)** Le mouvement d'un piston de moteur peut être modélisé par
:math:`h = 4\sin t` où :math:`h` est la hauteur du piston, en cm,
au-dessus de la position neutre et :math:`t` est le temps, en
secondes.

.. rst-class:: keepwithnext

a\) Détermine la vitesse du piston lorsque :math:`t = 5`.

.. math::
   :class: solution

   v(t) = h'(t) = 4\cos t

.. math::
   :class: solution

   v(5) = 4\cos(5)

.. math::
   :class: solution

   v(5) \cong 1.13 \text{ cm/s}

.. rst-class:: keepwithnext

b\) Détermine l'accélération du piston lorsque :math:`t = 5`

.. math::
   :class: solution

   a(t) = v'(t) = -4\sin t

.. math::
   :class: solution

   a(5) = -4\sin(5)

.. math::
   :class: solution

   a(5) \cong 3.8 \text{ cm/s}^2

Section 13 : 3.6 - Applications : décroissance radioactive
================================================================================

.. rst-class:: keepwithnext

**16\)** La croissance ou la décroissance continue suit la formule
:math:`A = ce^{kt}`, où :math:`c` est la quantité initiale, et
:math:`k` est un facteur de taux. La masse d'une substance radioactive
est de 1000 g au jour 1, et seulement 100 g après 100 jours. Trouve...

.. rst-class:: keepwithnext

a\) :math:`k`

.. math::
   :class: solution

   100 = 1000e^{100k}

.. math::
   :class: solution

   0.1 = e^{100k}

.. math::
   :class: solution

   \ln(0.1) = 100k

.. math::
   :class: solution

   k = \frac{\ln(0.1)}{100}

.. math::
   :class: solution

   k \cong -0.023

.. rst-class:: keepwithnext

b\) la demi-vie

.. math::
   :class: solution

   500 = 1000e^{-0.023t}

.. math::
   :class: solution

   0.5 = e^{-0.023t}

.. math::
   :class: solution

   \ln(0.5) = -0.023t

.. math::
   :class: solution

   t \cong 30.1 \text{ jours}

.. rst-class:: keepwithnext

c\) la quantité qui reste après 300 jours

.. math::
   :class: solution

   A(300) = 1000e^{-0.023(300)}

.. math::
   :class: solution

   A(300) \cong 1.01 \text{ grammes}

.. rst-class:: keepwithnext

d\) le taux de décroissance après 50 jours

.. math::
   :class: solution

   A(t) = 1000e^{-0.023t}

.. math::
   :class: solution

.. math::
   :class: solution

.. math::
   :class: solution

   A'(50) = -23e^{-0.023(50)}

   :class: solution

Section 14 : 3.5 - Dérivation implicite
================================================================================

.. rst-class:: keepwithnext

**17\)** Trouve :math:`\dfrac{dy}{dx}` par dérivation implicite

.. rst-class:: keepwithnext

a\) :math:`x^2 + y^2 = 36`

.. math::
   :class: solution

   2x + 2y\left(\frac{dy}{dx}\right) = 0

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{-2x}{2y}

.. math::
   :class: solution

   \frac{dy}{dx} = -\frac{x}{y}

.. rst-class:: keepwithnext

b\) :math:`x^3 - xy + y^2 = 4`

.. math::
   :class: solution

   3x^2 - \left[1y + \frac{dy}{dx}(x)\right] + 2y\left(\frac{dy}{dx}\right) = 0

.. math::
   :class: solution

   3x^2 - y - x\left(\frac{dy}{dx}\right) + 2y\left(\frac{dy}{dx}\right) = 0

.. math::
   :class: solution

   -x\left(\frac{dy}{dx}\right) + 2y\left(\frac{dy}{dx}\right) = y - 3x^2

.. math::
   :class: solution

   \frac{dy}{dx}(-x + 2y) = y - 3x^2

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{y - 3x^2}{-x + 2y}

.. rst-class:: keepwithnext

c\) :math:`2\sin x\cos y = 1`

.. math::
   :class: solution

   2\cos x\cos y + (-\sin y)\left(\frac{dy}{dx}\right)(2)\sin x = 0

.. math::
   :class: solution

   2\cos x\cos y = 2\sin x\sin y\left(\frac{dy}{dx}\right)

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{\cos x\cos y}{\sin x\sin y}

.. rst-class:: keepwithnext

d\) :math:`(4 - x)y^2 = x^3`

.. math::
   :class: solution

   -1y^2 + 2y\left(\frac{dy}{dx}\right)(4 - x) = 3x^2

.. math::
   :class: solution

   \frac{dy}{dx}(2y)(4 - x) = 3x^2 + y^2

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{3x^2 + y^2}{2y(4 - x)}
