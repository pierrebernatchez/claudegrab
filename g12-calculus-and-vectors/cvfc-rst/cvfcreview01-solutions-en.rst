**2)** Determine :math:`f''(-1)` for the function :math:`f(x) = \dfrac{3}{(2x-3)^2}`.

.. rst-class:: solution

:math:`f(x) = 3(2x-3)^{-2}`

:solmath:`f'(x) = -6(2x-3)^{-3}(2) = -12(2x-3)^{-3}`

:solmath:`f''(x) = 36(2x-3)^{-4}(2) = \dfrac{72}{(2x-3)^4}`

.. rst-class:: solution

:math:`f''(-1) = \dfrac{72}{[2(-1)-3]^4} = \dfrac{72}{625}`

.. rst-class:: keepwithnext

**3)** Determine the equation of the tangent to the curve :math:`y = (2x^2-3)(x+1)^2` at the point where :math:`x = 1`.

.. rst-class:: solution

Point: :math:`y(1) = [2(1)^2-3](1+1)^2 = -4`, so the point is :math:`(1,-4)`.

:solmath:`y' = 4x(x+1)^2 + 2(x+1)(2x^2-3)`

.. rst-class:: solution

:math:`y'(1) = 4(1)(2)^2 + 2(2)[2(1)^2-3] = 16 + 4(-1) = 12`

.. rst-class:: solution

Using :math:`y = mx+b`: :math:`-4 = 12(1) + b \Rightarrow b = -16`

.. rst-class:: solution

:math:`y = 12x - 16`

.. rst-class:: keepwithnext

**4)** For what values of :math:`x` does the curve :math:`y = -x^3+6x^2` have a tangent with a slope of 12?

.. rst-class:: solution

:math:`y' = -3x^2+12x`

:solmath:`12 = -3x^2+12x`

:solmath:`0 = -3x^2+12x-12 = -3(x-2)^2`

.. rst-class:: solution

:math:`x = 2`

.. rst-class:: keepwithnext

**5)** A tangent to the parabola :math:`y = 3x^2-7x+5` is perpendicular to :math:`x+5y-10=0`. Determine the equation of the tangent.

.. rst-class:: solution

The line :math:`x+5y-10=0` has slope :math:`y = -\tfrac{1}{5}x+2`, so :math:`m=-\tfrac{1}{5}`; the perpendicular slope is :math:`m_\perp = 5`.

:solmath:`y' = 6x-7 = 5 \Rightarrow x = 2`

.. rst-class:: solution

:math:`y(2) = 3(2)^2-7(2)+5 = 3`, so the point is :math:`(2,3)`.

:solmath:`3 = 5(2) + b \Rightarrow b = -7`

.. rst-class:: solution

:math:`y = 5x - 7`

.. rst-class:: keepwithnext

**6)** Water is being drained from the bottom of a tank. The equation that gives the volume :math:`V` of water, in liters, remaining in the tank after :math:`t` minutes is :math:`V(t) = 3000\left(1-\dfrac{t}{10}\right)^2`, :math:`0 \le t \le 10`.

.. rst-class:: keepwithnext

**a)** Find the volume of water in the tank after 5 min.

.. rst-class:: solution

:math:`V(5) = 3000\left(1-\tfrac{5}{10}\right)^2 = 750` L

.. rst-class:: keepwithnext

**b)** Find the rate at which the water is draining from the tank after **i)** 3 min **ii)** 8 min

.. rst-class:: solution

:solmath:`V'(t) = 6000\left(1-\dfrac{t}{10}\right)\left(-\dfrac{1}{10}\right) = -600\left(1-\dfrac{t}{10}\right)`

.. rst-class:: solution

**i)** :math:`V'(3) = -420` L/min

.. rst-class:: solution

**ii)** :math:`V'(8) = -120` L/min

.. rst-class:: keepwithnext

**7)** For the function :math:`f(x) = x^3-x^2-x+1`, determine the points where the tangent line is horizontal.

.. rst-class:: solution

:math:`f'(x) = 3x^2-2x-1`

:solmath:`0 = 3x^2-2x-1 = (x-1)(3x+1)`

.. rst-class:: solution

:math:`x = 1` or :math:`x = -\tfrac{1}{3}`

:solmath:`f(1) = 0,\quad f(-\tfrac{1}{3}) = \tfrac{32}{27}`

.. rst-class:: solution

The points are :math:`(1,0)` and :math:`\left(-\tfrac{1}{3},\tfrac{32}{27}\right)`.

**8)** The amount of pollution in a certain lake is :math:`P(t) = \left(t^{1/4}+3\right)^3`, where :math:`t` is measured in years and :math:`P` is measured in parts per million (ppm). At what rate is the amount of pollution changing after 16 years?

.. rst-class:: solution

:solmath:`P'(t) = 3\left(t^{1/4}+3\right)^2\left(\tfrac{1}{4}t^{-3/4}\right)`

.. rst-class:: solution

:math:`P'(16) = 3\left(16^{1/4}+3\right)^2\left[\tfrac{1}{4}(16)^{-3/4}\right] = \dfrac{75}{32} \approx 2.34` ppm/year

.. rst-class:: keepwithnext

**9)** An object moves in a straight line, and its position, :math:`s`, in metres after :math:`t` seconds is :math:`s(t) = 8-7t-t^2`.

.. rst-class:: keepwithnext

**a)** Determine the velocity when :math:`t=5`.

.. rst-class:: solution

:math:`v(t) = s'(t) = -7-2t \Rightarrow v(5) = -7-2(5) = -17` m/s

.. rst-class:: keepwithnext

**b)** Determine the acceleration when :math:`t=5`.

.. rst-class:: solution

:math:`a(t) = v'(t) = -2 \Rightarrow a(5) = -2` m/s :math:`^2`

.. rst-class:: keepwithnext

**10)** A store sells 250 pairs of Brand X running shoes each month when priced at $100 per pair. It has been determined that for every $5 decrease in price, an additional 20 pairs will be sold.

.. rst-class:: keepwithnext

**a)** Determine the demand or price function.

.. rst-class:: solution

Let :math:`x` = number sold, :math:`n` = number of $5 price decreases. :math:`x = 250+20n \Rightarrow n = \dfrac{x-250}{20}`

:solmath:`p(x) = 100-5\left(\dfrac{x-250}{20}\right) = 100 - \dfrac{x-250}{4}`

.. rst-class:: solution

:math:`p(x) = -0.25x + 162.5`

.. rst-class:: keepwithnext

**b)** Determine the revenue function.

.. rst-class:: solution

:math:`R(x) = x \cdot p(x) = x(-0.25x+162.5)`

:math:`R(x) = -0.25x^2 + 162.5x`

.. rst-class:: keepwithnext

**c)** Find the revenue when sales are 250 pairs and 290 pairs of shoes per month.

.. rst-class:: solution

:math:`R(250) = \$25\,000 \qquad R(290) = \$26\,100`

.. rst-class:: keepwithnext

**d)** Determine the marginal revenue when sales are 290 pairs of shoes per month.

.. rst-class:: solution

:math:`R'(x) = -0.5x+162.5 \Rightarrow R'(290) = \$17.50` per pair sold

.. rst-class:: keepwithnext

**11)** A theatre has found that if the price of a ticket is $24 then 400 tickets will be sold. For every $2 decrease in price, an additional 50 tickets will be sold.

.. rst-class:: keepwithnext

**a)** Determine the demand or price function based on the number of price decreases.

.. rst-class:: solution

Let :math:`x` = number of $2 price decreases: :math:`p(x) = 24-2x`

.. rst-class:: keepwithnext

**b)** Determine a revenue function based on the number of price decreases.

.. rst-class:: solution

Tickets sold :math:`= 400+50x`

:solmath:`R(x) = (24-2x)(400+50x)`

.. rst-class:: solution

:math:`R(x) = 9600+400x-100x^2`

.. rst-class:: keepwithnext

**c)** Determine the marginal revenue for the revenue function developed in part a).

.. rst-class:: solution

:math:`R'(x) = 400-200x`

.. rst-class:: keepwithnext

**d)** When is this marginal revenue function equal to zero? What is the total revenue at this time? How can the owners of the theatre use this information?

.. rst-class:: solution

:math:`400-200x=0 \Rightarrow x=2`, so the price is :math:`24-2(2)=\$20`.

:solmath:`R(2) = 9600+400(2)-100(2)^2 = \$10\,000`

.. rst-class:: solution

This is the price/revenue combination that maximizes total revenue — the owners should price tickets at $20 to generate the greatest possible revenue.

.. rst-class:: keepwithnext

**e)** If the theatre has a maximum capacity of 450, what price will maximize revenue?

.. rst-class:: solution

Capacity constraint: :math:`400+50x \le 450 \Rightarrow x \le 1`. Since :math:`R(x)` is a downward parabola with unconstrained maximum at :math:`x=2`, :math:`R` is still increasing on :math:`0 \le x \le 1`, so the constrained maximum occurs at :math:`x=1`.

.. rst-class:: solution

Price :math:`= 24-2(1) = \$22`

**12)** Given the revenue function :math:`R(x) = 30x-0.025x^2` and the cost function :math:`C(x) = 2x+5`, where :math:`x` is the number of items being sold, determine:

.. rst-class:: keepwithnext

**a)** the revenue and marginal revenue when 500 items are sold

.. rst-class:: solution

:math:`R(500) = 30(500)-0.025(500)^2 = \$8750`

:solmath:`R'(x) = 30-0.05x`

.. rst-class:: solution

:math:`R'(500) = \$5` per item sold

.. rst-class:: keepwithnext

**b)** the cost and marginal cost when 500 items are produced

.. rst-class:: solution

:math:`C(500) = 2(500)+5 = \$1005 \qquad C'(x) = 2 \Rightarrow C'(500) = \$2` per item sold

.. rst-class:: keepwithnext

**c)** the profit and marginal profit from sales of 500 items

.. rst-class:: solution

:math:`P(x) = R(x)-C(x) = 28x-0.025x^2-5`

:solmath:`P(500) = 28(500)-0.025(500)^2-5 = \$7745`

.. rst-class:: solution

:math:`P'(x) = 28-0.05x \Rightarrow P'(500) = \$3` per item sold

.. rst-class:: keepwithnext

**13)** Determine the equation of all tangent lines to the curve :math:`y = 2x-\dfrac{8}{x}` that have a slope of 4.

.. rst-class:: solution

:math:`y' = 2+8x^{-2} = 4 \Rightarrow \dfrac{8}{x^2}=2 \Rightarrow x^2=4 \Rightarrow x=\pm2`

:solmath:`y(2) = 0,\quad y(-2)=0`

.. rst-class:: solution

For :math:`(2,0)`: :math:`0=4(2)+b \Rightarrow b=-8 \Rightarrow y=4x-8`

.. rst-class:: solution

For :math:`(-2,0)`: :math:`0=4(-2)+b \Rightarrow b=8 \Rightarrow y=4x+8`

**17)** Find the absolute maximum and minimum values of :math:`f(x) = x^3+3x^2+1` on the interval :math:`-2 \le x \le 2`.

.. rst-class:: solution

:math:`f'(x) = 3x^2+6x = 3x(x+2) \Rightarrow x=0,\ x=-2`

Test critical numbers and endpoints:

:solmath:`f(-2) = 5,\quad f(0)=1,\quad f(2)=21`

.. rst-class:: solution

**18)** Consider the function defined by :math:`f(x) = -4x^3+6x^2+2`

.. rst-class:: keepwithnext

**a)** Find the critical points and classify them using the second derivative test.

.. rst-class:: solution

:math:`f'(x) = -12x^2+12x = -12x(x-1) \Rightarrow x=0,\ x=1`

:solmath:`f(0)=2,\quad f(1)=4`

.. rst-class:: solution

Critical points: :math:`(0,2)` and :math:`(1,4)`

:solmath:`f''(x) = -24x+12`

.. rst-class:: solution

:math:`f''(0)=12>0`: :math:`(0,2)` is a local min. :math:`\quad f''(1)=-12<0`: :math:`(1,4)` is a local max.

.. rst-class:: keepwithnext

**b)** Find the points of inflection and identify the intervals of concavity.

.. rst-class:: solution

:math:`0 = -24x+12 \Rightarrow x = \tfrac{1}{2} \Rightarrow f(\tfrac{1}{2}) = 3`, possible POI at :math:`(0.5,3)`

.. rst-class:: solution

Concave up: :math:`x<\tfrac{1}{2} \qquad` Concave down: :math:`x>\tfrac{1}{2} \qquad` POI at :math:`(0.5,3)`

**19)** Determine the local extrema for each function and classify them as local maxima or minima.

.. rst-class:: keepwithnext

**a)** :math:`y = 81-x^4`

.. rst-class:: solution

:math:`y' = -4x^3 = 0 \Rightarrow x=0,\quad y(0)=81`. First derivative test: :math:`y'>0` for :math:`x<0`, :math:`y'<0` for :math:`x>0`.

.. rst-class:: solution

Local max at :math:`(0,81)`

.. rst-class:: keepwithnext

**b)** :math:`f(x) = 3x^4+8x^3-6x^2-24x+9`

.. rst-class:: solution

:solmath:`f'(x) = 12x^3+24x^2-12x-24 = 12(x-1)(x+1)(x+2)`

.. rst-class:: solution

Critical points at :math:`x=1,-1,-2`: :math:`f(1)=-10,\ f(-1)=22,\ f(-2)=17`. First derivative test gives sign pattern :math:`-,+,-,+` across :math:`-2,-1,1`.

.. rst-class:: solution

Local min: :math:`(-2,17)` and :math:`(1,-10) \qquad` Local max: :math:`(-1,22)`

.. rst-class:: keepwithnext

**c)** :math:`f(x) = -3x^3+9x^2-8`

.. rst-class:: solution

:math:`f'(x) = -9x^2+18x = -9x(x-2) \Rightarrow x=0,2`

:solmath:`f(0)=-8,\quad f(2)=4`

.. rst-class:: solution

Second derivative test: :math:`f''(x)=-18x+18`. :math:`f''(0)=18>0` (local min at :math:`(0,-8)`); :math:`f''(2)=-18<0` (local max at :math:`(2,4)`).

**22)** Sketch each function using the algorithm for curve sketching.

.. rst-class:: keepwithnext

**a)** :math:`h(x) = x^3+6x^2+9x+4`

.. rst-class:: solution

No restrictions, no asymptotes. :math:`h(x)=(x+4)(x+1)^2`, so :math:`x`-ints: :math:`(-4,0),(-1,0)`; :math:`y`-int: :math:`(0,4)`.

.. rst-class:: solution

:math:`h(-3)=4,\ h(-1)=0`. Critical points: :math:`(-3,4)` (local max) and :math:`(-1,0)` (local min).

:solmath:`h''(x) = 6x+12 = 0 \Rightarrow x=-2,\quad h(-2)=2`

.. rst-class:: solution

Possible POI: :math:`(-2,2)`. Decreasing/concave-down to the left, through a max, min, and inflection, increasing/concave-up to the right (see graph).
