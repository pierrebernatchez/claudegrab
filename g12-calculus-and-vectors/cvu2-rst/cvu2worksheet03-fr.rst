Corrigé
================================================================================

**1)** a) A-nég, B-nég, C-pos, D-pos  b) A-nég, B-nég, C-pos, D-nég

**2)** a) concave vers le haut : :math:`x > -2`; concave vers le bas :
:math:`x < -2`
b) concave vers le haut : :math:`x < -2, x > 0`; concave vers le bas :
:math:`-2 < x < 0`

**3)** a) concave vers le haut : :math:`x > 2`; concave vers le bas :
:math:`x < 2`; PI en :math:`x = 2`
b) concave vers le haut : :math:`x > 2`; concave vers le bas :
:math:`x < -1` et :math:`-1 < x < 2`; PI en :math:`x = 2`

**4)** a) toujours concave vers le haut  b) concave vers le haut :
:math:`x < 2`; concave vers le bas : :math:`x > 2`; PI en
:math:`(2, 23)`.

**5)** a) :math:`(-5, -36)` est un point minimum local  b)
:math:`(-\sqrt{3}, 1)` et :math:`(\sqrt{3}, 1)` sont des minimums
locaux, :math:`(0, 10)` est un maximum local
