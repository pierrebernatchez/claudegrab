# Calculus and Vectors (MCV4U) — English/French terminology glossary

Started on day one of transcription (2026-10-05), per `REUSE-GUIDE.md`'s
recommendation — Advanced Functions didn't start one until partway through
and had to reconstruct earlier decisions by grepping already-translated
files. Update this incrementally, during each lesson/worksheet pair's
French-translation step, not as a separate retroactive pass.

Only non-obvious terms need an entry — a term whose French rendering is a
direct, unambiguous cognate doesn't need to be tracked here.

## How to use this file

- One entry per non-obvious term, grouped by the unit it was first
  encountered in.
- Record the *reasoning* when a choice was non-obvious (e.g. a term with
  multiple valid French renderings, a calque vs. a more idiomatic phrase,
  Québec French vs. France French, how a term is rendered in the
  `jensenmath.ca`-sourced upstream material if that's the convention being
  followed).
- Once a term is decided, reuse it consistently for the rest of the course
  — don't re-decide the same term in a later unit.

## Unit 1

Established during `cvu1lesson01`/`cvu1worksheet01` translation (2026-10-05):

- **derivative** → *dérivée*; **to differentiate** → *dériver* (e.g. "Differentiate
  each function" → "Dérivez chaque fonction").
- **tangent (line)** → *tangente*; **slope** → *pente*.
- **instantaneous rate of change** → *taux de variation instantané*.
- **Newton's Quotient** / **Newton Quotient Example** → *quotient de Newton* /
  *exemple du quotient de Newton* — lowercase common-noun style, matching the
  precedent already set for "Remainder Theorem" → "théorème du reste" in
  Advanced Functions (u2lesson01): named rules/theorems are NOT capitalized
  in French the way English title-cases them, even when named after a person.
- **Constant Rule** → *règle de la constante*; **Power Rule** → *règle de la
  puissance*; **Constant Multiple Rule** → *règle du multiple constant*;
  **Sum Rule** → *règle de la somme*; **Difference Rule** → *règle de la
  différence*.
- **Binomial Theorem** → *théorème du binôme* (same lowercase-common-noun
  convention as above).
- **proof** (of a rule/theorem) → *démonstration*, not the more literal
  *preuve* — matches standard French mathematical register.
- **Remember:** (tip callout) → *Rappel :* — confirmed precedent from
  Advanced Functions (u3lesson04, u4lesson01), space before the colon per
  French typography.
- **Product Rule** → *règle du produit* (lowercase, same convention).
- **revenue** → *revenu* (not *recette* — "revenu" is the standard term
  in Ontario French-curriculum math for a revenue function, e.g.
  "fonction de revenu", "revenu maximal").
- **manager** (generic, e.g. a venue/event context) → *gérant*; but
  **owner** (a specific business owner, e.g. the hair salon problem) →
  *propriétaire* — don't conflate the two even though English sometimes
  uses them loosely interchangeably in a word problem.
- **haircut and blow dry** → *coupe et brushing* ("brushing" is an
  established loanword in French for this specific hairdressing
  service, more idiomatic than a literal "séchage").

## Unit 1 (continued) — Velocity, Acceleration, and Second Derivatives

- **second derivative** → *dérivée seconde*.
- **velocity** (signed, has direction) → *vitesse*; **speed** (scalar
  magnitude only) → *vitesse scalaire* — the lesson's own "Important"
  note explicitly distinguishes these, so don't collapse both to plain
  *vitesse*.
- **acceleration** → *accélération*; **displacement** → *déplacement*.
- **speeding up** / **slowing down** → rendered as verbs, *accélère* /
  *ralentit* (e.g. "the particle is speeding up" → "la particule
  accélère"), not as noun phrases — more natural French register for
  this construction.
- **moving forward** / **moving in reverse** → *avance* / *recule*.
- **particle** → *particule*; **position function** → *fonction de
  position*.

## Unit 1 (continued) — The Quotient Rule

- **Quotient Rule** → *règle du quotient* (lowercase, same convention).
- **hole** (in a graph, from a removable discontinuity) → *trou* (e.g.
  "a hole in the graph when x = 1" → "un trou dans le graphique lorsque
  x = 1").
- **horizontal tangent** → *tangente horizontale*.

## Unit 1 (continued) — The Chain Rule

- **composite function** → *fonction composée* (confirmed precedent:
  Advanced Functions u7lessons already uses this).
- **outer function** / **inner function** → *fonction externe* /
  *fonction interne*.
- **Chain Rule** → *règle de chaîne* (lowercase, same convention;
  already used once in `cvu1lesson04`'s Example 1d note).
- **Power of a Function Rule** → *règle de la puissance d'une fonction*.
- **differentiable** → *dérivable*.

## Unit 1 (continued) — Applications of Rates of Change

- **linear density** → *densité linéique* (standard French physics term,
  not a literal *densité linéaire*).
- **marginal** (economics, e.g. marginal cost/revenue/profit) →
  *marginal(e)* — direct cognate, used as an adjective agreeing with the
  noun (*coût marginal*, *fonction de revenu marginal*).
- **demand function** / **price function** → *fonction de demande* /
  *fonction de prix*; **cost function** → *fonction de coût*;
  **profit function** → *fonction de profit* (all direct cognates,
  "revenue function" already covered above under "revenue").
- **hot tub** → *spa* (the common French term; not a literal
  *baignoire chaude*).
