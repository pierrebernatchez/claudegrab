Section 7 : 5.1 -- Vecteurs colinéaires
================================================================================

.. rst-class:: keepwithnext

**7\)** Quel vecteur est colinéaire avec :math:`\vec{a} = [6,-4]`?
Fournir une preuve.

:math:`\vec{b} = [-9,6]`, :math:`\vec{c} = [-6,-4]`

:solmath:`\text{A-t-on } \vec{a} = k\vec{b}?\quad 6 = k(-9) \Rightarrow
k = -\dfrac{2}{3}; \quad -4 = k(6) \Rightarrow k = -\dfrac{2}{3}`

:solmath:`\text{A-t-on } \vec{a} = k\vec{c}?\quad 6 = k(-6) \Rightarrow
k = -1; \quad -4 = k(-4) \Rightarrow k = 1`

Puisque les deux composantes donnent :math:`k=-\dfrac{2}{3}` pour
:math:`\vec{b}`, mais des valeurs incohérentes de :math:`k` pour
:math:`\vec{c}`,

.. rst-class:: solution

:math:`\vec{b}` est colinéaire avec :math:`\vec{a}`; :math:`\vec{b} =
-\dfrac{3}{2}\vec{a}`

**12\)** Soit :math:`\vec{u} = [3,-5]`, :math:`\vec{v} = [-6,1]`, et
:math:`\vec{w} = [4,7]`. Évaluer chacune des expressions suivantes si
possible. Si ce n'est pas possible, expliquer pourquoi.

.. list-table::
   :widths: 50 50
   :header-rows: 0
   :width: 100%

   * - a\) :math:`\vec{u} \cdot (\vec{v}+\vec{w})`

       :solmath:`= [3,-5]\cdot[-2,8] = 3(-2)+(-5)(8)`

       .. rst-class:: solution

       :math:`\vec{u} \cdot (\vec{v}+\vec{w}) = -46`
     - b\) :math:`(\vec{u}+\vec{v}) \cdot (\vec{u}-\vec{v})`

       :solmath:`= [-3,-4]\cdot[9,-6] = -3(9)+(-4)(-6)`

       .. rst-class:: solution

       :math:`(\vec{u}+\vec{v}) \cdot (\vec{u}-\vec{v}) = -3`
   * - c\) :math:`\vec{u} + \vec{v}\cdot\vec{w}`

       .. rst-class:: solution

       Ce n'est pas possible. C'est la somme d'un vecteur et d'un
       scalaire.
     - d\) :math:`-3\vec{v} \cdot (2\vec{w})`

       :solmath:`= [18,-3]\cdot[8,14] = 18(8)+(-3)(14)`

       .. rst-class:: solution

       :math:`-3\vec{v} \cdot (2\vec{w}) = 102`
   * - e\) :math:`(\vec{u}+2\vec{v}) \cdot (3\vec{w}-\vec{u})`

       :solmath:`= [-9,-3]\cdot[9,26] = -9(9)+(-3)(26)`

       .. rst-class:: solution

       :math:`(\vec{u}+2\vec{v}) \cdot (3\vec{w}-\vec{u}) = -159`
     - f\) :math:`\vec{v}\cdot\vec{v} + \vec{w}\cdot\vec{w}`

       :solmath:`= [37] + [65]`

       .. rst-class:: solution

       :math:`\vec{v}\cdot\vec{v} + \vec{w}\cdot\vec{w} = 102`

**31\)** Identifier le type de triangle ayant pour sommets
:math:`A(2,3,-5)`, :math:`B(-4,8,1)`, et :math:`C(6,-4,0)`.

:solmath:`\vec{AB} = [-6,5,6]`, :solmath:`|\vec{AB}| = \sqrt{97}`

:solmath:`\vec{AC} = [4,-7,5]`, :solmath:`|\vec{AC}| = \sqrt{90}`

:solmath:`\vec{BC} = [10,-12,-1]`, :solmath:`|\vec{BC}| = \sqrt{245}`

scalène.

Section 37 : 5.6 -- Travail dans l'espace à trois dimensions
================================================================================

.. rst-class:: keepwithnext

**37\)** Une force de :math:`\vec{F} = [3,5,12]`, en Newtons, est
appliquée pour soulever une boîte, avec un déplacement :math:`\vec{s}
= [2,1,6]`. Calculer le travail contre la gravité et le comparer au
travail dans la direction du déplacement.

:solmath:`\text{Travail contre la gravité : } W = [3,5,12]\cdot[0,0,6]
= 3(0)+5(0)+12(6)`

.. rst-class:: solution

:math:`W = 72\ J`

:solmath:`\text{Travail dans la direction du déplacement : } W =
[3,5,12]\cdot[2,1,6] = 3(2)+5(1)+12(6)`

.. rst-class:: solution

:math:`W = 83\ J`

Le travail effectué dans la direction du déplacement (83 J) est
supérieur au travail effectué contre la gravité seule (72 J), puisqu'une
partie de la force agit également dans la direction horizontale du
déplacement.

Section 38 : 5.6 -- Projection dans l'espace à trois dimensions
================================================================================

.. rst-class:: keepwithnext

**38\)** Déterminer la projection, et sa norme, de :math:`\vec{u} =
[3,1,4]` sur :math:`\vec{v} = [6,2,7]`.

:solmath:`|proj_{\vec{v}}\,\vec{u}| = \dfrac{\vec{u}\cdot\vec{v}}{|\vec{v}|}
= \dfrac{3(6)+1(2)+4(7)}{\sqrt{6^2+2^2+7^2}} = \dfrac{48}{\sqrt{89}}`

:solmath:`proj_{\vec{v}}\,\vec{u} = \dfrac{48}{\sqrt{89}}
\left(\dfrac{[6,2,7]}{\sqrt{89}}\right) = \dfrac{48}{89}[6,2,7]`

.. rst-class:: solution

:math:`proj_{\vec{v}}\,\vec{u} = \left[\dfrac{288}{89},
\dfrac{96}{89}, \dfrac{336}{89}\right]`

:math:`\vec{u}=[1,4,3]`, :math:`\vec{v}=[2,5,6]`, et

Section 41 : 5.6 -- Aire d'un triangle à l'aide du produit vectoriel
================================================================================

.. rst-class:: keepwithnext

**41\)** Un triangle a pour sommets :math:`A(-2,1,3)`, :math:`B(7,8,-4)`,
et :math:`C(5,0,2)`. Déterminer l'aire du triangle :math:`ABC`.

:solmath:`\vec{AB} = [9,7,-7]`, :solmath:`\vec{AC} = [7,-1,-1]`

:solmath:`\vec{AB}\times\vec{AC} = [7(-1)-(-7)(-1), -7(7)-9(-1),
9(-1)-7(7)]`

:solmath:`\vec{AB}\times\vec{AC} = [-14,-40,-58]`

:solmath:`\text{Aire} = \dfrac{1}{2}|\vec{AB}\times\vec{AC}| =
\dfrac{1}{2}\sqrt{(-14)^2+(-40)^2+(-58)^2} = \dfrac{1}{2}\sqrt{5160}`

.. rst-class:: solution

:math:`\text{Aire} = \sqrt{1290} \cong 35.9` unités\ :superscript:`2`
