**5\)** If :math:`\vec{u} = [-3, 5]` and :math:`\vec{v} = [2, 9]`.

.. list-table::
   :widths: 33 33 34
   :header-rows: 0
   :width: 100%

   * - a\) :math:`\vec{u} + \vec{v}`

       :solmath:`= [-3 + 2, 5 + 9]`

       .. rst-class:: solution

       :math:`= [-1, 14]`
     - b\) :math:`\hat{u}`

       :solmath:`= \dfrac{1}{|\vec{u}|}\vec{u} = \dfrac{1}{\sqrt{34}}[-3, 5]`

       .. rst-class:: solution

       :math:`= \left[\dfrac{-3}{\sqrt{34}}, \dfrac{5}{\sqrt{34}}\right]`
     - c\) :math:`-3\vec{u} + 4\vec{v}`

       :solmath:`= -3[-3, 5] + 4[2, 9]`

       :solmath:`= [9, -15] + [8, 36]`

       .. rst-class:: solution

       :math:`= [17, 21]`
   * - d\) :math:`7\vec{u} + 6\vec{i} - 8\vec{j} - 3\vec{v}`

       :solmath:`= 7(-3\vec{i} + 5\vec{j}) + 6\vec{i} - 8\vec{j} - 3(2\vec{i} + 9\vec{j})`

       :solmath:`= -21\vec{i} + 35\vec{j} + 6\vec{i} - 8\vec{j} - 6\vec{i} - 27\vec{j}`

       .. rst-class:: solution

       :math:`= -21\vec{i} + 0\vec{j} = [-21, 0]`
     - e\) :math:`|\vec{v}|`

       :solmath:`= \sqrt{(2)^2 + (9)^2}`

       .. rst-class:: solution

       :math:`= \sqrt{85}`
     - f\) :math:`|-3\vec{u} - 2\vec{v}|`

       :solmath:`-3\vec{u} - 2\vec{v} = -3[-3, 5] - 2[2, 9]`

       :solmath:`= [9, -15] - [4, 18] = [5, -33]`

       .. rst-class:: solution

       :math:`|-3\vec{u} - 2\vec{v}| = \sqrt{(5)^2 + (-33)^2} = \sqrt{1114}`

**11\)** Which vector is NOT collinear with :math:`\vec{a} = [6, -4]`?

:math:`\vec{b} = [3, -2]`, :math:`\vec{c} = [-6, -4]`, :math:`\vec{d}
= [-6, 4]`, or :math:`\vec{e} = [-9, 6]`

:solmath:`\dfrac{a_x}{b_x} = \dfrac{a_y}{b_y}:\ \dfrac{6}{3} =
\dfrac{-4}{-2} \Rightarrow 2 = 2,\ \vec{a} = 2\vec{b}`

:solmath:`\dfrac{a_x}{c_x} = \dfrac{a_y}{c_y}:\ \dfrac{6}{-6} =
\dfrac{-4}{-4} \Rightarrow -1 \neq 1,\ \vec{a}` and :math:`\vec{c}`
are NOT collinear

:solmath:`\dfrac{a_x}{d_x} = \dfrac{a_y}{d_y}:\ \dfrac{6}{-6} =
\dfrac{-4}{4} \Rightarrow -1 = -1,\ \vec{a} = -\vec{d}`

:solmath:`\dfrac{a_x}{e_x} = \dfrac{a_y}{e_y}:\ \dfrac{6}{-9} =
\dfrac{-4}{6} \Rightarrow -\dfrac{2}{3} = -\dfrac{2}{3},\ \vec{a} =
-\dfrac{2}{3}\vec{e}`

.. rst-class:: solution

:math:`\vec{c}` is NOT collinear with :math:`\vec{a}`.
