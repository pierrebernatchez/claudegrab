Answer Key
================================================================================

**1)** a) increasing: :math:`x < -2, x > 0`; decreasing: :math:`-2 < x < 0`
b) increasing: :math:`x < 0, x > 4`; decreasing: :math:`0 < x < 4`
c) increasing: :math:`-2 < x < 0, x > 1`; decreasing: :math:`x < -2, 0 < x < 1`
d) increasing: :math:`-2 < x < 0.5, x > 2.25`; decreasing: :math:`x < -2, 0.5 < x < 2.25`

**2)** a) increasing: :math:`-3 < x < -2, x > 1`; decreasing: :math:`x < -3, -2 < x < 1`
b) increasing: :math:`x < -1 - \sqrt{5}, x > -1 + \sqrt{5}`; decreasing: :math:`-1 - \sqrt{5} < x < -1 + \sqrt{5}`
c) increasing: :math:`-3 < x < -2, x > 2`; decreasing: :math:`x < -3, -2 < x < 2`

**3)** a) increasing: :math:`x > 3`; decreasing: :math:`x < 3`
b) increasing: :math:`x < -1, x > 2`; decreasing: :math:`-1 < x < 2`
c) increasing: :math:`-4 < x < 0, x > 2`; decreasing: :math:`x < -4, 0 < x < 2`
