**4\)** Pour chaque fonction, trouvez les intervalles de concavité et
les coordonnées de tout point d'inflexion.

.. rst-class:: keepwithnext

a\) :math:`y = 6x^2 - 7x + 5`

.. math::
   :class: solution

   y' = 12x - 7

.. math::
   :class: solution

   y'' = 12

.. rst-class:: solution

:math:`y` est toujours concave vers le haut; aucun PI.

   :class: solution

.. math::
   :class: solution

   g''(x) = -12x + 24

.. math::
   :class: solution

.. math::
   :class: solution

   x = 2

.. math::
   :class: solution

   g(2) = 23

**5\)** Pour chaque fonction, trouvez et classifiez tous les points
critiques à l'aide du critère de la dérivée seconde.

.. rst-class:: keepwithnext

a\) :math:`y = x^2 + 10x - 11`

.. math::
   :class: solution

   y' = 2x + 10

.. math::
   :class: solution

   0 = 2x + 10

.. math::
   :class: solution

   x = -5

.. math::
   :class: solution

   y(-5) = -36

.. rst-class:: solution

:math:`(-5, -36)` est un point critique

**Critère de la dérivée seconde :**

.. math::
   :class: solution

   y'' = 2

.. math::
   :class: solution

   y''(-5) = 2

.. rst-class:: solution

Donc :math:`y` est concave vers le haut lorsque :math:`x = -5`

:math:`(-5, -36)` est un MINIMUM local.

.. rst-class:: keepwithnext

b\) :math:`f(x) = x^4 - 6x^2 + 10`

.. math::
   :class: solution

   f'(x) = 4x^3 - 12x

.. math::
   :class: solution

   0 = 4x(x^2 - 3)

.. math::
   :class: solution

   x_1 = 0 \qquad x_2 = \sqrt{3} \qquad x_3 = -\sqrt{3}

.. math::
   :class: solution

   f(0) = 10 \qquad f(\sqrt{3}) = 1 \qquad f(-\sqrt{3}) = 1

.. rst-class:: solution

Points critiques : :math:`(0, 10)`, :math:`(\sqrt{3}, 1)`, et
:math:`(-\sqrt{3}, 1)`

**Critère de la dérivée seconde :**

.. math::
   :class: solution

   f''(x) = 12x^2 - 12

.. math::
   :class: solution

   f''(0) = -12

.. rst-class:: solution

concave vers le bas; :math:`(0, 10)` est un MAXIMUM local

.. math::
   :class: solution

   f''(\sqrt{3}) = 24

.. rst-class:: solution

concave vers le haut; :math:`(\sqrt{3}, 1)` est un MINIMUM local

.. math::
   :class: solution

   f''(-\sqrt{3}) = 24

.. rst-class:: solution

concave vers le haut; :math:`(-\sqrt{3}, 1)` est un MINIMUM local

Corrigé
================================================================================

**1)** a) A-nég, B-nég, C-pos, D-pos  b) A-nég, B-nég, C-pos, D-nég

**2)** a) concave vers le haut : :math:`x > -2`; concave vers le bas :
:math:`x < -2`
b) concave vers le haut : :math:`x < -2, x > 0`; concave vers le bas :
:math:`-2 < x < 0`

**3)** a) concave vers le haut : :math:`x > 2`; concave vers le bas :
:math:`x < 2`; PI en :math:`x = 2`
b) concave vers le haut : :math:`x > 2`; concave vers le bas :
:math:`x < -1` et :math:`-1 < x < 2`; PI en :math:`x = 2`

**4)** a) toujours concave vers le haut  b) concave vers le haut :
:math:`x < 2`; concave vers le bas : :math:`x > 2`; PI en
:math:`(2, 23)`.

**5)** a) :math:`(-5, -36)` est un point minimum local  b)
:math:`(-\sqrt{3}, 1)` et :math:`(\sqrt{3}, 1)` sont des minimums
locaux, :math:`(0, 10)` est un maximum local
