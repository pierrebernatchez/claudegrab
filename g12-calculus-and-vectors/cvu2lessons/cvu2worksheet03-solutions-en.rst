**5\)** For each function, find and classify all the critical points
using the second derivative test.

.. rst-class:: keepwithnext

a\) :math:`y = x^2 + 10x - 11`

.. math::
   :class: solution

   y' = 2x + 10

.. math::
   :class: solution

   0 = 2x + 10

.. math::
   :class: solution

   x = -5

.. math::
   :class: solution

   y(-5) = -36

.. rst-class:: solution

:math:`(-5, -36)` is a critical point

**2nd Derivative Test:**

.. math::
   :class: solution

   y'' = 2

.. math::
   :class: solution

   y''(-5) = 2

.. rst-class:: solution

So :math:`y` is concave up when :math:`x = -5`

:math:`(-5, -36)` is a local MIN.

.. rst-class:: keepwithnext

b\) :math:`f(x) = x^4 - 6x^2 + 10`

.. math::
   :class: solution

   f'(x) = 4x^3 - 12x

.. math::
   :class: solution

   0 = 4x(x^2 - 3)

.. math::
   :class: solution

   x_1 = 0 \qquad x_2 = \sqrt{3} \qquad x_3 = -\sqrt{3}

.. math::
   :class: solution

   f(0) = 10 \qquad f(\sqrt{3}) = 1 \qquad f(-\sqrt{3}) = 1

.. rst-class:: solution

Critical points: :math:`(0, 10)`, :math:`(\sqrt{3}, 1)`, and
:math:`(-\sqrt{3}, 1)`

**2nd derivative test:**

.. math::
   :class: solution

   f''(x) = 12x^2 - 12

.. math::
   :class: solution

   f''(0) = -12

.. rst-class:: solution

concave down; :math:`(0, 10)` is a local MAX

.. math::
   :class: solution

   f''(\sqrt{3}) = 24

.. rst-class:: solution

concave up; :math:`(\sqrt{3}, 1)` is a local MIN

.. math::
   :class: solution

   f''(-\sqrt{3}) = 24

.. rst-class:: solution

concave up; :math:`(-\sqrt{3}, 1)` is a local MIN

Answer Key
================================================================================

**1)** a) A-neg, B-neg, C-pos, D-pos  b) A-neg, B-neg, C-pos, D-neg

**2)** a) concave up: :math:`x > -2`; concave down: :math:`x < -2`
b) concave up: :math:`x < -2, x > 0`; concave down: :math:`-2 < x < 0`

**3)** a) concave up: :math:`x > 2`; concave down: :math:`x < 2`; POI
when :math:`x = 2`
b) concave up: :math:`x > 2`; concave down: :math:`x < -1` and
:math:`-1 < x < 2`; POI when :math:`x = 2`

**4)** a) always concave up  b) concave up: :math:`x < 2`; concave
down: :math:`x > 2`; POI at :math:`(2, 23)`.

**5)** a) :math:`(-5, -36)` is a local min point  b) :math:`(-\sqrt{3}, 1)`
and :math:`(\sqrt{3}, 1)` are local mins, :math:`(0, 10)` is a local max

**6)** See figures above.
