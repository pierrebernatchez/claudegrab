**4\)** Determine the angle between the planes :math:`x + 2y - 3z - 4
= 0` and :math:`x + 2y - 1 = 0`. *(Hint: the angle between 2
intersecting planes should be equal to the angle between their
normals)*

.. rst-class:: solution

:math:`\vec{n_1} = [1,2,-3]`, :math:`\vec{n_2} = [1,2,0]`

:solmath:`\cos\theta = \dfrac{\vec{n_1}\cdot\vec{n_2}}{|\vec{n_1}||\vec{n_2}|}`

:solmath:`\cos\theta = \dfrac{5}{(\sqrt{14})(\sqrt{5})}`

.. rst-class:: solution

:math:`\theta \cong 53.3°`

**5\)** Write the vector equation and parametric equations of the
plane: :math:`3x - y + 2z - 4 = 0`

:solmath:`x\text{-int: } 3x=4,\ x=\frac{4}{3}`

:solmath:`y\text{-int: } -y=4,\ y=-4`

:solmath:`z\text{-int: } 2z=4,\ z=2`

.. rst-class:: solution

So :math:`X\left(\frac{4}{3},0,0\right)`, :math:`Y(0,-4,0)`,
:math:`Z(0,0,2)` are points on the plane.

:solmath:`\vec{m_1} = \vec{XY} = \left[-\frac{4}{3},-4,0\right],
\text{ reduces to } [1,3,0]`

:solmath:`\vec{m_2} = \vec{YZ} = [0,4,2], \text{ reduces to }
[0,2,1]`

.. rst-class:: solution

:math:`[x,y,z] = [0,0,2] + t[1,3,0] + s[0,2,1]`

.. rst-class:: solution

:math:`\pi: \begin{cases} x = t \\ y = 3t+2s \\ z = 2+s \end{cases}`

**7\)** Consider the plane :math:`-x + 4y + 2z + 6 = 0`

.. rst-class:: keepwithnext

**a)** Determine a normal vector, :math:`\vec{n}`, to the plane.

.. rst-class:: solution

:math:`\vec{n} = [-1,4,2]`

.. rst-class:: keepwithnext

**b)** Determine the coordinates of two points, :math:`S` and
:math:`T`, on the plane.

:solmath:`\text{Let } y=z=0\text{: } -x+6=0,\ x=6`

.. rst-class:: solution

:math:`S(6,0,0)`

:solmath:`\text{Let } x=y=0\text{: } 2z+6=0,\ z=-3`

.. rst-class:: solution

:math:`T(0,0,-3)`

.. rst-class:: keepwithnext

**c)** Determine :math:`\vec{ST}`

:solmath:`\vec{ST} = [0-6,0-0,-3-0]`

.. rst-class:: solution

:math:`\vec{ST} = [-6,0,-3]`

.. rst-class:: keepwithnext

**d)** Show that :math:`\vec{ST}` is perpendicular to :math:`\vec{n}`.

:solmath:`\vec{ST} \cdot \vec{n} = [-6,0,-3] \cdot [-1,4,2]`

:solmath:`\vec{ST} \cdot \vec{n} = 6 + 0 - 6`

.. rst-class:: solution

:math:`\vec{ST} \cdot \vec{n} = 0`, so :math:`\vec{ST}` is
perpendicular to :math:`\vec{n}`.
