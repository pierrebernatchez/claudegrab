Section 7: 5.1 -- Collinear Vectors
================================================================================

.. rst-class:: keepwithnext

**7\)** Which vector is collinear with :math:`\vec{a} = [6,-4]`? Give
proof.

:math:`\vec{b} = [-9,6]`, :math:`\vec{c} = [-6,-4]`

:solmath:`\text{Does } \vec{a} = k\vec{b}?\quad 6 = k(-9) \Rightarrow
k = -\dfrac{2}{3}; \quad -4 = k(6) \Rightarrow k = -\dfrac{2}{3}`

:solmath:`\text{Does } \vec{a} = k\vec{c}?\quad 6 = k(-6) \Rightarrow
k = -1; \quad -4 = k(-4) \Rightarrow k = 1`

Since both components give :math:`k=-\dfrac{2}{3}` for :math:`\vec{b}`
but inconsistent values of :math:`k` for :math:`\vec{c}`,

.. rst-class:: solution

:math:`\vec{b}` is collinear with :math:`\vec{a}`; :math:`\vec{b} =
-\dfrac{3}{2}\vec{a}`

.. list-table::
   :widths: 50 50
   :header-rows: 0
   :width: 100%

   * - a\) :math:`\vec{u} \cdot (\vec{v}+\vec{w})`

       :solmath:`= [3,-5]\cdot[-2,8] = 3(-2)+(-5)(8)`

       .. rst-class:: solution

       :math:`\vec{u} \cdot (\vec{v}+\vec{w}) = -46`
     - b\) :math:`(\vec{u}+\vec{v}) \cdot (\vec{u}-\vec{v})`

       :solmath:`= [-3,-4]\cdot[9,-6] = -3(9)+(-4)(-6)`

       .. rst-class:: solution

   * - c\) :math:`\vec{u} + \vec{v}\cdot\vec{w}`

       .. rst-class:: solution

       This is not possible. It is the sum of a vector and a scalar.
     - d\) :math:`-3\vec{v} \cdot (2\vec{w})`

       :solmath:`= [18,-3]\cdot[8,14] = 18(8)+(-3)(14)`

       .. rst-class:: solution

       :math:`-3\vec{v} \cdot (2\vec{w}) = 102`

Section 41: 5.6 -- Area of a Triangle Using the Cross Product
================================================================================

.. rst-class:: keepwithnext

**41\)** A triangle has vertices :math:`A(-2,1,3)`, :math:`B(7,8,-4)`,

:solmath:`\vec{AB} = [9,7,-7]`, :solmath:`\vec{AC} = [7,-1,-1]`

.. rst-class:: solution

:math:`\text{Area} = \sqrt{1290} \cong 35.9` units\ :superscript:`2`
