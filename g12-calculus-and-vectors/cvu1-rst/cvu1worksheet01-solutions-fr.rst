.. rst-class:: keepwithnext

**1)** Encerclez les fonctions dont la dérivée est zéro :

A\) :math:`y = 8.7`   B) :math:`y = -4 + x`   C) :math:`y = \dfrac{5}{9}x`   D) :math:`y = \sqrt{7}`   E) :math:`y = -7.1\pi`

.. rst-class:: solution

A, D et E ont une dérivée de zéro (chacune est une fonction constante).

.. rst-class:: keepwithnext

**2)** Pour chaque fonction, déterminez :math:`\dfrac{dy}{dx}`

.. rst-class:: keepwithnext

a\) :math:`y = x`

.. math::
   :class: solution

   \frac{dy}{dx} = 1

.. rst-class:: keepwithnext

b\) :math:`y = \dfrac{1}{4}x^2`

.. math::
   :class: solution

   \frac{dy}{dx} = 2\left(\frac{1}{4}\right)x

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{1}{2}x

.. rst-class:: keepwithnext

c\) :math:`y = -3x^4`

.. math::
   :class: solution

   \frac{dy}{dx} = 4(-3)x^3

.. math::
   :class: solution

   \frac{dy}{dx} = -12x^3

.. rst-class:: keepwithnext

d\) :math:`y = \sqrt[5]{x^3}`

.. math::
   :class: solution

   y = x^{\frac{3}{5}}

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{3}{5}x^{\frac{3}{5}-1}

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{3}{5}x^{-\frac{2}{5}}

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{3}{5\sqrt[5]{x^2}}

.. rst-class:: keepwithnext

e\) :math:`y = \dfrac{5}{x}`

.. math::
   :class: solution

   y = 5x^{-1}

.. math::
   :class: solution

   \frac{dy}{dx} = -5x^{-2}

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{-5}{x^2}

.. rst-class:: keepwithnext

f\) :math:`y = \dfrac{4}{\sqrt{x}}`

.. math::
   :class: solution

   y = 4x^{-\frac{1}{2}}

.. math::
   :class: solution

   \frac{dy}{dx} = -\frac{1}{2}(4)x^{-\frac{1}{2}-1}

.. math::
   :class: solution

   \frac{dy}{dx} = -2x^{-\frac{3}{2}}

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{-2}{\sqrt{x^3}}

.. rst-class:: keepwithnext

**3)** Déterminez la pente de la tangente au graphique de chaque fonction à
la valeur indiquée.

.. rst-class:: keepwithnext

a\) :math:`y = 6` en :math:`x = 12`

.. math::
   :class: solution

   \frac{dy}{dx} = 0

.. math::
   :class: solution

   \left.\frac{dy}{dx}\right|_{x=12} = 0

.. rst-class:: keepwithnext

b\) :math:`f(x) = 2x^5` en :math:`x = \sqrt{3}`

.. math::
   :class: solution

   f'(x) = 10x^4

.. math::
   :class: solution

   f'(\sqrt{3}) = 10(\sqrt{3})^4

.. math::
   :class: solution

   f'(\sqrt{3}) = 10(3)^2

.. math::
   :class: solution

   f'(\sqrt{3}) = 90

.. rst-class:: keepwithnext

c\) :math:`y = \dfrac{1}{3x}` en :math:`x = -2`

.. math::
   :class: solution

   y = \frac{1}{3}x^{-1}

.. math::
   :class: solution

   \frac{dy}{dx} = -\frac{1}{3}x^{-2}

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{-1}{3x^2}

.. math::
   :class: solution

   \left.\frac{dy}{dx}\right|_{x=-2} = \frac{-1}{3(-2)^2}

.. math::
   :class: solution

   \left.\frac{dy}{dx}\right|_{x=-2} = \frac{-1}{12}

.. rst-class:: keepwithnext

d\) :math:`p(a) = \dfrac{a^5}{15} - 2\sqrt{a}`

.. math::
   :class: solution

**5)a)** Déterminez le point où la pente de la tangente à chaque parabole
est zéro.

.. rst-class:: keepwithnext

i\) :math:`y = 6x^2 - 3x + 4`

.. math::
   :class: solution

   y' = 12x - 3

.. math::
   :class: solution

   0 = 12x - 3

.. math::
   :class: solution

   x = \frac{1}{4}

.. math::
   :class: solution

   y = 6\left(\frac{1}{4}\right)^2 - 3\left(\frac{1}{4}\right) + 4

.. math::
   :class: solution

   y = \frac{29}{8}

.. math::
   :class: solution

   \left(\frac{1}{4}, \frac{29}{8}\right)

.. rst-class:: keepwithnext

ii\) :math:`y = \dfrac{3}{4}x^2 + 2x + 3`

.. math::
   :class: solution

   y' = \frac{3}{2}x + 2

.. math::
   :class: solution

   0 = \frac{3}{2}x + 2

.. math::
   :class: solution

   x = -\frac{4}{3}

.. math::
   :class: solution

   y = \frac{3}{4}\left(-\frac{4}{3}\right)^2 + 2\left(-\frac{4}{3}\right) + 3

.. math::
   :class: solution

   y = \frac{5}{3}

.. math::
   :class: solution

   \left(-\frac{4}{3}, \frac{5}{3}\right)

**7)** Un parachutiste saute d'un avion volant à 2500 mètres au-dessus du
sol. La hauteur du parachutiste, :math:`h`, en mètres, au-dessus du sol
après :math:`t` secondes est :math:`h(t) = 2500 - 4.9t^2`.

.. rst-class:: keepwithnext

a\) Déterminez le taux de variation de la hauteur du parachutiste à
:math:`t = 5\text{s}`

.. math::
   :class: solution

   h'(t) = -9.8t

.. math::
   :class: solution

   h'(5) = -9.8(5)

.. math::
   :class: solution

   h'(5) = -49 \text{ m/s}

.. rst-class:: keepwithnext

b\) Le parachute du parachutiste s'ouvre à 1000 m au-dessus du sol. Après
combien de secondes cela se produit-il?

.. math::
   :class: solution

   1000 = 2500 - 4.9t^2

.. math::
   :class: solution

   t^2 = \frac{1500}{4.9}

.. math::
   :class: solution

   t = \sqrt{\frac{1500}{4.9}}

.. math::
   :class: solution

   t \approx 17.5 \text{ secondes}

.. rst-class:: keepwithnext

c\) Quel est le taux de variation de la hauteur du parachutiste au moment
trouvé en b)?

.. math::
   :class: solution

   h'(17.5) \approx -9.8(17.5)

.. math::
   :class: solution

   h'(17.5) \approx -171.5 \text{ m/s}

.. rst-class:: keepwithnext

**8)** Déterminez l'équation de la tangente au graphique de
:math:`y = -6x^4 + 2x^3 + 5` au point :math:`(-1, -3)`.

.. math::
   :class: solution

   y' = -24x^3 + 6x^2

.. math::
   :class: solution

   y'(-1) = -24(-1)^3 + 6(-1)^2

.. math::
   :class: solution

   y'(-1) = 30

.. rst-class:: solution

.. math::

   y = mx + b

.. math::
   :class: solution

.. math::
   :class: solution

   b = 27

.. math::
   :class: solution

   y = 30x + 27

**10)** Une flèche enflammée est tirée dans les airs pour marquer le début
d'un festival. Sa hauteur, :math:`h`, en mètres, après :math:`t` secondes
peut être modélisée par la fonction :math:`h(t) = -4.9t^2 + 24.5t + 2`.

.. rst-class:: keepwithnext

a\) Déterminez la hauteur de la flèche à :math:`t = 2\text{s}`.

.. math::
   :class: solution

   h(2) = -4.9(2)^2 + 24.5(2) + 2

.. math::
   :class: solution

   h(2) = 31.4 \text{ m}

.. rst-class:: keepwithnext

b\) Combien de temps faut-il à la flèche pour atteindre le sol?

.. math::
   :class: solution

   0 = -4.9t^2 + 24.5t + 2

.. math::
   :class: solution

   t = \frac{-24.5 \pm \sqrt{(24.5)^2 - 4(-4.9)(2)}}{2(-4.9)}

.. rst-class:: solution

:math:`t_1 \approx -0.08` (rejeté, le temps ne peut pas être négatif)

.. math::
   :class: solution

   t_2 \approx 5.08 \text{ secondes}

.. rst-class:: keepwithnext

c\) À quelle vitesse la flèche voyage-t-elle lorsqu'elle touche le sol?

.. math::
   :class: solution

   h'(t) = -9.8t + 24.5

.. math::
   :class: solution

   h'(5.08) = -9.8(5.08) + 24.5

.. math::
   :class: solution

   h'(5.08) \approx -25.284 \text{ m/s}
