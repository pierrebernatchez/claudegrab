Consider :math:`-x^2(4x-1)` as the 1st function and :math:`x^3+2x+3` as the
2nd function.

.. math::
   :class: solution

   \frac{d}{dx}\left[-x^2(4x - 1)\right] = -2x(4x - 1) + 4(-x^2)

.. math::
   :class: solution

   \frac{d}{dx}\left[-x^2(4x - 1)\right] = -8x^2 + 2x - 4x^2

.. math::
   :class: solution

   \frac{d}{dx}\left[-x^2(4x - 1)\right] = -12x^2 + 2x

.. math::
   :class: solution

   \frac{dy}{dx} = (-12x^2 + 2x)(x^3 + 2x + 3) + (3x^2 + 2)(-x^2)(4x - 1)

   :class: solution

**6)** The owner of a local hair salon is planning to raise the price for a
haircut and blow dry. The current rate is $30 for this service, with the
salon averaging 550 clients a month. A survey indicates that the salon
will lose 5 clients for every incremental price increase of $2.50.

.. rst-class:: keepwithnext

a\) Write an equation to model the salon's monthly revenue, :math:`R`, in
dollars, as a function of :math:`x`, where :math:`x` represents the number
of $2.50 increases in the price.

.. math::
   :class: solution

   R(x) = (30 + 2.5x)(550 - 5x)

.. rst-class:: keepwithnext

b\) Use the product rule to determine :math:`R'(x)`

.. math::
   :class: solution

   R'(x) = 2.5(550 - 5x) + (-5)(30 + 2.5x)

.. math::
   :class: solution

   R'(x) = 1375 - 12.5x - 150 - 12.5x

.. math::
   :class: solution

   R'(x) = -25x + 1225

.. rst-class:: keepwithnext

c\) Evaluate :math:`R'(3)` and interpret it for this situation.

.. math::
   :class: solution

   R'(3) = -25(3) + 1225

.. math::
   :class: solution

   R'(3) = 1150

.. rst-class:: solution

At an increase of $7.50, the rate of change of revenue is $1150.

.. rst-class:: keepwithnext

d\) Solve :math:`R'(x) = 0`.

.. math::
   :class: solution

   0 = -25x + 1225

.. math::
   :class: solution

   x = 49

.. rst-class:: keepwithnext

e\) Explain how the owner can use the result of part d).

.. math::
   :class: solution

   R(49) = [30 + 2.5(49)][550 - 5(49)]

.. math::
   :class: solution

   R(49) = (152.50)(305)

.. math::
   :class: solution

   R(49) = 46\,512.50

.. rst-class:: solution

Increasing the price by $2.50, 49 times, results in a max revenue of
$46 512.50.
