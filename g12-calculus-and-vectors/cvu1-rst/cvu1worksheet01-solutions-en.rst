**1)** Circle the functions that have a derivative of zero:

A\) :math:`y = 8.7`   B) :math:`y = -4 + x`   C) :math:`y = \dfrac{5}{9}x`   D) :math:`y = \sqrt{7}`   E) :math:`y = -7.1\pi`

.. rst-class:: solution

A, D, and E have a derivative of zero (each is a constant function).

.. rst-class:: keepwithnext

**2)** For each function, determine :math:`\dfrac{dy}{dx}`

.. rst-class:: keepwithnext

a\) :math:`y = x`

.. math::
   :class: solution

   \frac{dy}{dx} = 1

.. rst-class:: keepwithnext

b\) :math:`y = \dfrac{1}{4}x^2`

.. math::
   :class: solution

   \frac{dy}{dx} = 2\left(\frac{1}{4}\right)x

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{1}{2}x

.. rst-class:: keepwithnext

c\) :math:`y = -3x^4`

.. math::
   :class: solution

   \frac{dy}{dx} = 4(-3)x^3

.. math::
   :class: solution

   \frac{dy}{dx} = -12x^3

.. rst-class:: keepwithnext

d\) :math:`y = \sqrt[5]{x^3}`

.. math::
   :class: solution

   y = x^{\frac{3}{5}}

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{3}{5}x^{\frac{3}{5}-1}

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{3}{5}x^{-\frac{2}{5}}

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{3}{5\sqrt[5]{x^2}}

.. rst-class:: keepwithnext

e\) :math:`y = \dfrac{5}{x}`

.. math::
   :class: solution

   y = 5x^{-1}

.. math::
   :class: solution

   \frac{dy}{dx} = -5x^{-2}

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{-5}{x^2}

.. rst-class:: keepwithnext

f\) :math:`y = \dfrac{4}{\sqrt{x}}`

.. math::
   :class: solution

   y = 4x^{-\frac{1}{2}}

.. math::
   :class: solution

   \frac{dy}{dx} = -\frac{1}{2}(4)x^{-\frac{1}{2}-1}

.. math::
   :class: solution

   \frac{dy}{dx} = -2x^{-\frac{3}{2}}

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{-2}{\sqrt{x^3}}

**3)** Determine the slope of the tangent to the graph of each function at
the indicated value.

.. rst-class:: keepwithnext

a\) :math:`y = 6` at :math:`x = 12`

.. rst-class:: keepwithnext

.. math::
   :class: solution

.. math::
   :class: solution

.. rst-class:: keepwithnext

.. math::
   :class: solution

.. math::
   :class: solution

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{-1}{3x^2}

.. math::
   :class: solution

**7)** A skydiver jumps out of a plane that is flying 2500 meters above the
ground. The skydiver's height, :math:`h`, in meters, above the ground after
:math:`t` seconds is :math:`h(t) = 2500 - 4.9t^2`.

.. rst-class:: keepwithnext

a\) Determine the rate of change of the height of the skydiver at :math:`t = 5\text{s}`

.. math::
   :class: solution

   h'(t) = -9.8t

.. math::
   :class: solution

   h'(5) = -9.8(5)

.. math::
   :class: solution

   h'(5) = -49 \text{ m/s}

.. rst-class:: keepwithnext

b\) The skydiver's parachute opens at 1000m above the ground. After how
many seconds does this happen?

.. math::
   :class: solution

   1000 = 2500 - 4.9t^2

.. math::
   :class: solution

   t^2 = \frac{1500}{4.9}

.. math::
   :class: solution

   t = \sqrt{\frac{1500}{4.9}}

.. math::
   :class: solution

   t \approx 17.5 \text{ seconds}

.. rst-class:: keepwithnext

c\) What is the rate of change of the height of the skydiver at the time
found in part b)?

.. math::
   :class: solution

   h'(17.5) \approx -9.8(17.5)

.. math::
   :class: solution

   h'(17.5) \approx -171.5 \text{ m/s}

.. rst-class:: keepwithnext

**10)** A flaming arrow is shot into the air to mark the beginning of a
festival. Its height, :math:`h`, in meters, after :math:`t` seconds can be
modelled by the function :math:`h(t) = -4.9t^2 + 24.5t + 2`.

.. rst-class:: keepwithnext

a\) Determine the height of the arrow at :math:`t = 2\text{s}`.

.. math::
   :class: solution

   h(2) = -4.9(2)^2 + 24.5(2) + 2

.. math::
   :class: solution

   h(2) = 31.4 \text{ m}

.. rst-class:: keepwithnext

b\) How long does it take the arrow to land on the ground?

.. math::
   :class: solution

   0 = -4.9t^2 + 24.5t + 2

.. math::
   :class: solution

   t = \frac{-24.5 \pm \sqrt{(24.5)^2 - 4(-4.9)(2)}}{2(-4.9)}

.. rst-class:: solution

:math:`t_1 \approx -0.08` (rejected, time cannot be negative)

.. math::
   :class: solution

   t_2 \approx 5.08 \text{ seconds}

.. rst-class:: keepwithnext

c\) How fast is the arrow travelling when it hits the ground?

.. math::
   :class: solution

   h'(t) = -9.8t + 24.5

.. math::
   :class: solution

   h'(5.08) = -9.8(5.08) + 24.5

.. math::
   :class: solution

   h'(5.08) \approx -25.284 \text{ m/s}
