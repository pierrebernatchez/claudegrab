   :class: solution

.. rst-class:: keepwithnext

a\) :math:`f(x) = (x^2 - 3)(x^2 + 1)` en :math:`x = -4`

Pente :

.. math::
   :class: solution

   f'(x) = 2x(x^2 + 1) + 2x(x^2 - 3)

.. math::
   :class: solution

   f'(x) = 2x^3 + 2x + 2x^3 - 6x

.. math::
   :class: solution

   f'(x) = 4x^3 - 4x

.. math::
   :class: solution

   f'(-4) = 4(-4)^3 - 4(-4)

.. math::
   :class: solution

   f'(-4) = -240

.. rst-class:: solution

:math:`m = -240`

Point :

.. math::
   :class: solution

   f(-4) = [(-4)^2 - 3][(-4)^2 + 1]

.. math::
   :class: solution

   f(-4) = 221

Équation :

.. math::

   y = mx + b

.. math::
   :class: solution

   221 = (-240)(-4) + b

.. math::
   :class: solution

   b = -739

.. math::
   :class: solution

   y = -240x - 739

.. rst-class:: keepwithnext

   :class: solution

   :class: solution

**4)** Déterminez le(s) point(s) sur chaque courbe correspondant à la
pente de tangente donnée.

.. rst-class:: keepwithnext

a\) :math:`y = (-4x + 3)(x + 3)`, :math:`m = 0`

.. math::
   :class: solution

   y' = -4(x + 3) + 1(-4x + 3)

.. math::
   :class: solution

   y' = -4x - 12 - 4x + 3

.. math::
   :class: solution

   y' = -8x - 9

.. math::
   :class: solution

   0 = -8x - 9

.. math::
   :class: solution

   x = -\frac{9}{8}

.. math::
   :class: solution

   y\left(-\frac{9}{8}\right) = \left[-4\left(-\frac{9}{8}\right) + 3\right]\left[-\frac{9}{8} + 3\right]

.. math::
   :class: solution

   y\left(-\frac{9}{8}\right) = \frac{225}{16}

.. math::
   :class: solution

   \left(-\frac{9}{8}, \frac{225}{16}\right)

.. rst-class:: keepwithnext

b\) :math:`y = (x^2 - 2)(2x + 1)`, :math:`m = -2`

.. math::
   :class: solution

   y' = 2x(2x + 1) + 2(x^2 - 2)

.. math::
   :class: solution

   y' = 4x^2 + 2x + 2x^2 - 4

.. math::
   :class: solution

   y' = 6x^2 + 2x - 4

.. math::
   :class: solution

   -2 = 6x^2 + 2x - 4

.. math::
   :class: solution

   0 = 6x^2 + 2x - 2

.. math::
   :class: solution

   0 = 3x^2 + x - 1

.. math::
   :class: solution

   x = \frac{-1 \pm \sqrt{(1)^2 - 4(3)(-1)}}{2(3)}

.. math::
   :class: solution

   x = \frac{-1 \pm \sqrt{13}}{6}

.. math::
   :class: solution

   x_1 \approx 0.43 \qquad x_2 \approx -0.77

.. rst-class:: solution

Point 1 : :math:`y(0.43) \approx -3.38`, donc :math:`(0.43, -3.38)`

a\) :math:`y = (5x^2 - x + 1)(x + 2)`

.. math::
   :class: solution

   \frac{dy}{dx} = (10x - 1)(x + 2) + 1(5x^2 - x + 1)

.. math::
   :class: solution

   \frac{dy}{dx} = 10x^2 + 19x - 2 + 5x^2 - x + 1

.. math::
   :class: solution

   \frac{dy}{dx} = 15x^2 + 18x - 1

.. rst-class:: keepwithnext

b\) :math:`y = -x^2(4x - 1)(x^3 + 2x + 3)`

Considérons :math:`-x^2(4x-1)` comme la 1re fonction et
:math:`x^3+2x+3` comme la 2e fonction.

.. math::
   :class: solution

   \frac{d}{dx}\left[-x^2(4x - 1)\right] = -2x(4x - 1) + 4(-x^2)

.. math::
   :class: solution

   \frac{d}{dx}\left[-x^2(4x - 1)\right] = -8x^2 + 2x - 4x^2

.. math::
   :class: solution

   \frac{d}{dx}\left[-x^2(4x - 1)\right] = -12x^2 + 2x

.. math::
   :class: solution

   \frac{dy}{dx} = (-12x^2 + 2x)(x^3 + 2x + 3) + (3x^2 + 2)(-x^2)(4x - 1)

.. math::
   :class: solution

   \frac{dy}{dx} = -12x^5 - 24x^3 - 36x^2 + 2x^4 + 4x^2 + 6x + (3x^2 + 2)(-4x^3 + x^2)

.. math::
   :class: solution

   \frac{dy}{dx} = -12x^5 + 2x^4 - 24x^3 - 32x^2 + 6x - 12x^5 + 3x^4 - 8x^3 + 2x^2

.. math::
   :class: solution

   \frac{dy}{dx} = -24x^5 + 5x^4 - 32x^3 - 30x^2 + 6x

**6)** La propriétaire d'un salon de coiffure local prévoit augmenter le
prix d'une coupe et brushing. Le tarif actuel est de 30 $ pour ce
service, et le salon reçoit en moyenne 550 clients par mois. Un sondage
indique que le salon perdra 5 clients pour chaque augmentation de prix de
2,50 $.

.. rst-class:: keepwithnext

a\) Écrivez une équation modélisant le revenu mensuel du salon, :math:`R`,
en dollars, en fonction de :math:`x`, où :math:`x` représente le nombre
d'augmentations de 2,50 $ sur le prix.

.. math::
   :class: solution

   R(x) = (30 + 2.5x)(550 - 5x)

.. rst-class:: keepwithnext

b\) Utilisez la règle du produit pour déterminer :math:`R'(x)`

.. math::
   :class: solution

   R'(x) = 2.5(550 - 5x) + (-5)(30 + 2.5x)

.. math::
   :class: solution

   R'(x) = 1375 - 12.5x - 150 - 12.5x

.. math::
   :class: solution

   R'(x) = -25x + 1225

.. rst-class:: keepwithnext

c\) Évaluez :math:`R'(3)` et interprétez-le dans ce contexte.

.. math::
   :class: solution

   R'(3) = -25(3) + 1225

.. math::
   :class: solution

   R'(3) = 1150

.. rst-class:: solution

À une augmentation de 7,50 $, le taux de variation du revenu est de
1150 $.

.. rst-class:: keepwithnext

d\) Résolvez :math:`R'(x) = 0`.

.. math::
   :class: solution

   0 = -25x + 1225

.. math::
   :class: solution

   x = 49

.. rst-class:: keepwithnext

e\) Expliquez comment la propriétaire peut utiliser le résultat de d).

.. math::
   :class: solution

   R(49) = [30 + 2.5(49)][550 - 5(49)]

.. math::
   :class: solution

   R(49) = (152.50)(305)

.. math::
   :class: solution

   R(49) = 46\,512.50

.. rst-class:: solution

En augmentant le prix de 2,50 $, 49 fois, on obtient un revenu maximal de
46 512,50 $.
