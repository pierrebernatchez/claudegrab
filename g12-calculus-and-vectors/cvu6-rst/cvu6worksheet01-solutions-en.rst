**4\)** Determine if each point :math:`P` is on the line :math:`[x,y]
= [3,1] + t[-2,5]`

.. list-table::
   :widths: 50 50
   :header-rows: 0
   :width: 100%

   * - a\) :math:`P(12,36)`

       :solmath:`12 = 3 - 2t` :solmath:`36 = 1 + 5t`

       .. rst-class:: solution

       :math:`t = -\dfrac{9}{2}` :math:`t = 7`

       .. rst-class:: solution

       :math:`t`-values are not equal, so :math:`P(12,36)` is NOT on
       the line.
     - b\) :math:`P(-7,26)`

       :solmath:`-7 = 3 - 2t` :solmath:`26 = 1 + 5t`

       .. rst-class:: solution

       :math:`t = 5` :math:`t = 5`

       .. rst-class:: solution

       :math:`t`-values are equal, so :math:`P(-7,26)` IS on the line.
   * - c\) :math:`P(1,6)`

       :solmath:`1 = 3 - 2t` :solmath:`6 = 1 + 5t`

       .. rst-class:: solution

       :math:`t = 1` :math:`t = 1`

       .. rst-class:: solution

       :math:`t`-values are equal, so :math:`P(1,6)` IS on the line.
     - d\) :math:`P(-3,15)`

       :solmath:`-3 = 3 - 2t` :solmath:`15 = 1 + 5t`

       .. rst-class:: solution

       :math:`t = 3` :math:`t = \dfrac{14}{5}`

       .. rst-class:: solution

       :math:`t`-values are not equal, so :math:`P(-3,15)` is NOT on
       the line.

**10\)** In each case, determine if :math:`\ell_1` and :math:`\ell_2`
are parallel, perpendicular, or neither. Explain.

.. rst-class:: keepwithnext

**a)** :math:`\ell_1: 4x - 6y = 9`

:math:`\ell_2: [x,y] = [6,3] + t[3,2]`

:solmath:`\vec{n_1} = [4,-6]`

:solmath:`\vec{m_1} = [6,4] = 2[3,2]`

:solmath:`\vec{m_2} = [3,2]`

.. rst-class:: solution

Since :math:`\vec{m_1} = 2\vec{m_2}`, :math:`\ell_1` and :math:`\ell_2`
are parallel.

.. rst-class:: keepwithnext

**b)** :math:`\ell_1: x + 9y = 2`

:math:`\ell_2: \begin{cases} x = t \\ y = 15 + 9t \end{cases}`

:solmath:`\vec{n_1} = [1,9]`

:solmath:`\vec{m_1} = [-9,1]`

:solmath:`\vec{m_2} = [1,9]`

:solmath:`\vec{m_1} \cdot \vec{m_2} = [-9,1] \cdot [1,9]`

:solmath:`= -9(1) + 1(9)`

:solmath:`= 0`

.. rst-class:: solution

Since :math:`\vec{m_1} \neq k\vec{m_2}` but :math:`\vec{m_1} \cdot
\vec{m_2} = 0`, :math:`\ell_1` and :math:`\ell_2` are perpendicular.
