Déterminer la ou les solutions de chaque système de plans. S'il n'y a
pas de solution cohérente, donner une preuve ou une explication du
pourquoi.

.. rst-class:: keepwithnext

**a)** :math:`\pi_1: 3x - 2y + z = 4`

:math:`\pi_2: 6x - 4y + 3z = 7`

.. rst-class:: solution

Les normales ne sont pas parallèles; elles se croisent selon une
droite.

:solmath:`2 \times ①: \quad 6x - 4y + 2z = 8`

:solmath:`②: \quad 6x - 4y + 3z = 7`

.. rst-class:: solution

:math:`-z = 1, \quad z = -1`

*Poser* :math:`x = t` :

:solmath:`3t - 2y + (-1) = 4`

:solmath:`3t - 1 - 4 = 2y`

:solmath:`3t - 5 = 2y`

.. rst-class:: solution

:math:`y = \dfrac{3}{2}t - \dfrac{5}{2}`

.. rst-class:: solution

:math:`\ell: \begin{cases} x = t \\ y = \dfrac{3}{2}t - \dfrac{5}{2} \\
z = -1 \end{cases}`

.. rst-class:: solution

:math:`[x,y,z] = \left[0, -\dfrac{5}{2}, -1\right] + t\left[1,
\dfrac{3}{2}, 0\right]`

.. rst-class:: keepwithnext

**b)** :math:`\pi_1: 2x - 8y - 6z - 2 = 0`

:math:`\pi_2: -x + 4y + 3z - 5 = 0`

.. rst-class:: solution

Les normales SONT parallèles; vérifier si confondus ou distincts.

:solmath:`①: \quad 2x - 8y - 6z - 2 = 0`

:solmath:`2 \times ②: \quad -2x + 8y + 6z - 10 = 0`

.. rst-class:: solution

:math:`-12 = 0`

.. rst-class:: solution

Aucune solution. Parallèles et distincts.

.. rst-class:: keepwithnext

**c)** :math:`\pi_1: x - 2y + 2.5z - 1 = 0`

:math:`\pi_2: 3x - 6y + 7.5z - 3 = 0`

.. rst-class:: solution

Les normales sont parallèles; vérifier si distincts ou confondus

:solmath:`3 \times ①: \quad 3x - 6y + 7.5z - 3 = 0`

:solmath:`②: \quad 3x - 6y + 7.5z - 3 = 0`

.. rst-class:: solution

:math:`0 = 0`

.. rst-class:: solution

Parallèles et confondus. Infinité de solutions.

.. rst-class:: keepwithnext

**d)** :math:`\pi_1: x + y + 2z = 5`

:math:`\pi_2: 4x - 3y + z = -8`

:math:`\pi_3: -5x - 2y + 3z = 7`

.. rst-class:: solution

Aucune normale n'est parallèle.

:solmath:`①: \quad x + y + 2z = 5`

:solmath:`2 \times ②: \quad 8x - 6y + 2z = -16`

.. rst-class:: solution

:math:`-7x + 7y = 21`

:solmath:`3 \times ①: \quad 3x + 3y + 6z = 15`

:solmath:`2 \times ③: \quad -10x - 4y + 6z = 14`

.. rst-class:: solution

:math:`13x + 7y = 1`

:solmath:`(-7x + 7y = 21) - (13x + 7y = 1):`

.. rst-class:: solution

:math:`-20x = 20, \quad x = -1`

:solmath:`13(-1) + 7y = 1`

.. rst-class:: solution

:math:`7y = 14, \quad y = 2`

:solmath:`x + y + 2z = 5: \quad -1 + 2 + 2z = 5`

.. rst-class:: solution

:math:`2z = 4, \quad z = 2`

.. rst-class:: solution

Les trois plans se croisent au point :math:`(-1,2,2)`.

.. rst-class:: keepwithnext

**e)** :math:`\pi_1: x + y + z = -3`

:math:`\pi_2: 2x + 2y - 3z = 4`

:math:`\pi_3: 3x + 3y - 2z = 1`

.. rst-class:: solution

Aucune normale n'est parallèle.

:solmath:`2 \times ①: \quad 2x + 2y + 2z = -6`

:solmath:`②: \quad 2x + 2y - 3z = 4`

.. rst-class:: solution

:math:`5z = -10, \quad z = -2`

:solmath:`3 \times ①: \quad 3x + 3y + 3z = -9`

:solmath:`③: \quad 3x + 3y - 2z = 1`

.. rst-class:: solution

:math:`5z = -10, \quad z = -2`

*Poser* :math:`x = t` :

:solmath:`t + y + (-2) = -3`

.. rst-class:: solution

:math:`y = -1 - t`

.. rst-class:: solution

:math:`\ell: \begin{cases} x = t \\ y = -1-t \\ z = -2 \end{cases}`

.. rst-class:: solution

:math:`[x,y,z] = [0,-1,-2] + t[1,-1,0]`

.. rst-class:: keepwithnext

**f)** :math:`\pi_1: -x + y + 3z = 2`

:math:`\pi_2: 2x - 2y - 6z = -4`

:math:`\pi_3: -3x + 3y + 9z = 6`

.. rst-class:: solution

:math:`-2\pi_1 = \pi_2`, :math:`3\pi_1 = \pi_3`

.. rst-class:: solution

Trois plans confondus. Infinité de solutions.

.. rst-class:: keepwithnext

**g)** :math:`\pi_1: x - 4y - 13z = 4`

:math:`\pi_2: x - 2y - 3z = 2`

:math:`\pi_3: -3x + 5y + 4z = 2`

.. rst-class:: solution

Aucune normale parallèle.

:solmath:`①: \quad x - 4y - 13z = 4`

:solmath:`②: \quad x - 2y - 3z = 2`

.. rst-class:: solution

:math:`-2y - 10z = 2`

:solmath:`3 \times ①: \quad 3x - 12y - 39z = 12`

:solmath:`③: \quad -3x + 5y + 4z = 2`

.. rst-class:: solution

:math:`-7y - 35z = 14`

:solmath:`7 \times (① - ②): \quad -14y - 70z = 14`

:solmath:`2 \times (3① + ③): \quad -14y - 70z = 28`

.. rst-class:: solution

:math:`0 = -14`

.. rst-class:: solution

Aucune solution. C'est un système incohérent; les plans se croisent
deux à deux.

.. rst-class:: keepwithnext

**h)** :math:`\pi_1: 3x - 2y + 5z = 1`

:math:`\pi_2: 5x + y - 3z = -4`

:math:`\pi_3: x - 5y + 13z = 6`

.. rst-class:: solution

Aucune normale parallèle.

:solmath:`5 \times ①: \quad 15x - 10y + 25z = 5`

:solmath:`3 \times ②: \quad 15x + 3y - 9z = -12`

.. rst-class:: solution

:math:`-13y + 34z = 17`

:solmath:`①: \quad 3x - 2y + 5z = 1`

:solmath:`3 \times ③: \quad 3x - 15y + 39z = 18`

.. rst-class:: solution

:math:`13y - 34z = -17`

*Les deux équations obtenues sont identiques (multipliées par -1), donc
les plans se croisent selon une droite.* Poser :math:`y = t` :

:solmath:`-13t + 34z = 17`

.. rst-class:: solution

:math:`z = \dfrac{17}{34} + \dfrac{13}{34}t`

:solmath:`③: \quad x - 5t + 13\left(\dfrac{17}{34} +
\dfrac{13}{34}t\right) = 6`

.. rst-class:: solution

:math:`x = -\dfrac{1}{2} + \dfrac{1}{34}t`

.. rst-class:: solution

:math:`\ell: \begin{cases} x = -\dfrac{1}{2} + \dfrac{1}{34}t \\ y = t
\\ z = \dfrac{17}{34} + \dfrac{13}{34}t \end{cases}`

.. rst-class:: solution

:math:`[x,y,z] = \left[-\dfrac{1}{2}, 0, \dfrac{17}{34}\right] +
t\left[\dfrac{1}{34}, 1, \dfrac{13}{34}\right]`

**i)** :math:`\pi_1: -x + y + 3z = 2`

:math:`\pi_2: -x + y + 3z = 4`

:math:`\pi_3: x - 3y + 5z = 6`

.. rst-class:: solution

:math:`\vec{n_1} = \vec{n_2}` mais :math:`\pi_1 \neq k\pi_2`; ils sont
parallèles et distincts.

.. rst-class:: solution

Système incohérent; deux plans parallèles et distincts croisés par un
troisième plan.

**j)** :math:`\pi_1: x + 4y + 3z = 5`

:math:`\pi_2: x + 3y + 2z + 4 = 0`

:math:`\pi_3: x + y - z = -1`

.. rst-class:: solution

Aucune normale parallèle.

:solmath:`①: \quad x + 4y + 3z = 5`

:solmath:`②: \quad x + 3y + 2z = -4`

.. rst-class:: solution

:math:`y + z = 9`

:solmath:`①: \quad x + 4y + 3z = 5`

:solmath:`③: \quad x + y - z = -1`

.. rst-class:: solution

:math:`3y + 4z = 6`

:solmath:`3 \times (y+z=9): \quad 3y + 3z = 27`

:solmath:`3y + 4z = 6`

.. rst-class:: solution

:math:`-z = 21, \quad z = -21`

:solmath:`y + (-21) = 9`

.. rst-class:: solution

:math:`y = 30`

:solmath:`x + 4(30) + 3(-21) = 5`

.. rst-class:: solution

:math:`x = -52`

.. rst-class:: solution

Ils se croisent au point :math:`(-52,30,-21)`.
