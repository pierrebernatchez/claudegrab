Corrigé
================================================================================

**1)** a) :math:`\dfrac{dy}{dx} = 4\cos(4x)`
b) :math:`f'(x) = 2\cos(2x + \pi)`
c) :math:`\dfrac{dy}{d\theta} = -6\cos(3\theta)`
d) :math:`\dfrac{dy}{dx} = 2\sin x\cos x`

**e)** :math:`f'(x) = -2\sin(2x)`
**f)** :math:`\dfrac{dy}{dx} = 12\sin(2t - 4)\cos(2t - 4) + 12\cos(3t + 1)\sin(3t + 1)`

**g)** :math:`f'(t) = -2\sin(\cos t)\cos(\cos t)\sin t`
**h)** :math:`f'(x) = -3x^2\cos(3x - \pi) - 2x\sin(3x - \pi)`

**i)** :math:`f'(\theta) = -2\sin^3\theta\cos\theta + 2\sin\theta\cos^3\theta`
**j)** :math:`\dfrac{dy}{dx} = \dfrac{-2}{x}\cos x\sin x - \dfrac{\cos^2 x}{x^2}`

**k)** :math:`y' = 2\sec^2 x - 2\sec^2(2x)`
**l)** :math:`y' = 2(\tan x + \cos x)(\sec^2 x - \sin x)`

**2)** :math:`0`

**3)** :math:`y = 2\pi^2 x + 2\pi^3`

**4)** :math:`\dfrac{d^2y}{dx^2} = -x^2\cos x - 4x\sin x + 2\cos x`

**5)** a) :math:`y = \dfrac{1}{\sin x}`  b) :math:`y = (\sin x)^{-1}`
c) :math:`\dfrac{dy}{dx} = -\csc x\cot x`
