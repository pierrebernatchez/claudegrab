**1\)** Find the derivative with respect to :math:`x` for each function.

.. rst-class:: keepwithnext

a\) :math:`y = 4\sin x`

.. math::
   :class: solution

   \frac{dy}{dx} = 4\cos x

.. rst-class:: keepwithnext

b\) :math:`f(x) = -3\cos x`

.. math::
   :class: solution

   f'(x) = -3(-\sin x)

.. math::
   :class: solution

   f'(x) = 3\sin x

.. rst-class:: keepwithnext

c\) :math:`y = \cos x - \sin x`

.. math::
   :class: solution

   \frac{dy}{dx} = -\sin x - \cos x

.. rst-class:: keepwithnext

d\) :math:`y = x^2 - 3\sin x`

.. math::
   :class: solution

   \frac{dy}{dx} = 2x - 3\cos x

.. rst-class:: keepwithnext

e\) :math:`y = \cos x + 7\pi\sin x - 3x`

.. math::
   :class: solution

   \frac{dy}{dx} = -\sin x + 7\pi\cos x - 3

.. rst-class:: keepwithnext

f\) :math:`f(x) = \dfrac{\pi}{4}\cos x - \dfrac{\pi}{3}\sin x`

.. math::
   :class: solution

   f'(x) = \frac{\pi}{4}(-\sin x) - \frac{\pi}{3}\cos x

.. math::
   :class: solution

   f'(x) = -\frac{\pi}{4}\sin x - \frac{\pi}{3}\cos x

.. rst-class:: keepwithnext

**2\)** Find the equation of the line that is tangent to the function
:math:`y = \cos x` and passes through the point
:math:`\left(\dfrac{\pi}{3}, \dfrac{1}{2}\right)`.

.. rst-class:: solution

Slope:

.. math::
   :class: solution

   y' = -\sin x

.. math::
   :class: solution

   y'\left(\frac{\pi}{3}\right) = -\sin\left(\frac{\pi}{3}\right)

.. math::
   :class: solution

   y'\left(\frac{\pi}{3}\right) = -\frac{\sqrt{3}}{2}

.. math::
   :class: solution

   m = -\frac{\sqrt{3}}{2}

.. rst-class:: solution

Equation:

.. math::
   :class: solution

   y = mx + b

.. math::
   :class: solution

   \frac{1}{2} = \left(-\frac{\sqrt{3}}{2}\right)\left(\frac{\pi}{3}\right) + b

.. math::
   :class: solution

   \frac{1}{2} = -\frac{\sqrt{3}\pi}{6} + b

.. math::
   :class: solution

   b = \frac{3}{6} + \frac{\sqrt{3}\pi}{6} = \frac{3 + \sqrt{3}\pi}{6}

.. math::
   :class: solution

   y = -\frac{\sqrt{3}}{2}x + \frac{3 + \sqrt{3}\pi}{6}

.. rst-class:: keepwithnext

**3\)** Find the equation of the line that is tangent to the function
:math:`y = -4\sin x` at :math:`x = \dfrac{\pi}{4}`.

.. rst-class:: solution

Point:

.. math::
   :class: solution

   y\left(\frac{\pi}{4}\right) = -4\sin\left(\frac{\pi}{4}\right)

.. math::
   :class: solution

   y\left(\frac{\pi}{4}\right) = -4\left(\frac{\sqrt{2}}{2}\right)

.. math::
   :class: solution

   y\left(\frac{\pi}{4}\right) = -2\sqrt{2}

.. math::
   :class: solution

   \left(\frac{\pi}{4}, -2\sqrt{2}\right)

.. rst-class:: solution

Slope:

.. math::
   :class: solution

   y' = -4\cos x

.. math::
   :class: solution

   y'\left(\frac{\pi}{4}\right) = -4\cos\left(\frac{\pi}{4}\right)

.. math::
   :class: solution

   y'\left(\frac{\pi}{4}\right) = -4\left(\frac{\sqrt{2}}{2}\right)

.. math::
   :class: solution

   y'\left(\frac{\pi}{4}\right) = -2\sqrt{2}

.. math::
   :class: solution

   m = -2\sqrt{2}

.. rst-class:: solution

Equation:

.. math::
   :class: solution

   y = mx + b

.. math::
   :class: solution

   -2\sqrt{2} = -2\sqrt{2}\left(\frac{\pi}{4}\right) + b

.. math::
   :class: solution

   -2\sqrt{2} = -\frac{\pi\sqrt{2}}{2} + b

.. math::
   :class: solution

   b = -2\sqrt{2} + \frac{\pi\sqrt{2}}{2}

.. math::
   :class: solution

   y = -2\sqrt{2}x + \frac{\pi\sqrt{2}}{2} - 2\sqrt{2}

.. rst-class:: keepwithnext

**4\)** Determine an equation for the tangent to the function
:math:`f(x) = \tan x` at :math:`x = \dfrac{\pi}{4}`.

.. rst-class:: solution

Point:

.. math::
   :class: solution

   f\left(\frac{\pi}{4}\right) = \tan\left(\frac{\pi}{4}\right)

.. math::
   :class: solution

   f\left(\frac{\pi}{4}\right) = 1

.. math::
   :class: solution

   \left(\frac{\pi}{4}, 1\right)

.. rst-class:: solution

Slope:

.. math::
   :class: solution

   f'(x) = \sec^2 x

.. math::
   :class: solution

   f'\left(\frac{\pi}{4}\right) = \sec^2\left(\frac{\pi}{4}\right)

.. math::
   :class: solution

   f'\left(\frac{\pi}{4}\right) = \frac{1}{\cos^2\left(\frac{\pi}{4}\right)}

.. math::
   :class: solution

   f'\left(\frac{\pi}{4}\right) = \frac{1}{\left(\frac{\sqrt{2}}{2}\right)^2}

.. math::
   :class: solution

   m = 2

.. rst-class:: solution

Equation:

.. math::
   :class: solution

   y = mx + b

.. math::
   :class: solution

   1 = 2\left(\frac{\pi}{4}\right) + b

.. math::
   :class: solution

   b = 1 - \frac{\pi}{2}

.. math::
   :class: solution

   y = 2x + 1 - \frac{\pi}{2}

**5\)** Find an equation of a line that is tangent to :math:`y = 2\sin x`
and whose slope is a max value.

.. rst-class:: solution

:math:`y = 2\sin x` has a max slope when :math:`y' = 2\cos x` is a max.

.. math::
   :class: solution

   2 = 2\cos x

.. math::
   :class: solution

   1 = \cos x

.. math::
   :class: solution

   x = 0, 2\pi, 4\pi, 6\pi, \ldots

.. rst-class:: solution

Max when :math:`x = 2k\pi, k \in \mathbb{Z}` (use any answer).

.. rst-class:: solution

Point (using :math:`x = 0`):

.. math::
   :class: solution

   y(0) = 2\sin(0)

.. math::
   :class: solution

   y(0) = 0

.. math::
   :class: solution

   (0, 0)

.. rst-class:: solution

Slope:

.. math::
   :class: solution

   y'(0) = 2\cos(0)

.. math::
   :class: solution

   y'(0) = 2(1)

.. math::
   :class: solution

   y'(0) = 2

.. rst-class:: solution

Equation:

.. math::
   :class: solution

   y = mx + b

.. math::
   :class: solution

   0 = 2(0) + b

.. math::
   :class: solution

   b = 0

.. math::
   :class: solution

   y = 2x

.. rst-class:: solution

Note: there are an infinite number of solutions. The slope is at a max
value at any :math:`x = 2k\pi` where :math:`k \in \mathbb{Z}`. Depending
on which :math:`x` value you choose, you will get a different
:math:`y`-intercept.
