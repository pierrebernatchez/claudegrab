**1\)** Determine the derivative of each function.

.. rst-class:: keepwithnext

a\) :math:`y = \sin(4x)`

.. math::
   :class: solution

   y' = \cos(4x)(4)

.. math::
   :class: solution

   y' = 4\cos(4x)

.. rst-class:: keepwithnext

b\) :math:`f(x) = \sin(2x + \pi)`

.. math::
   :class: solution

   f'(x) = \cos(2x + \pi)(2)

.. math::
   :class: solution

   f'(x) = 2\cos(2x + \pi)

.. rst-class:: keepwithnext

c\) :math:`y = -2\sin(3\theta)`

.. math::
   :class: solution

   y' = -2\cos(3\theta)(3)

.. math::
   :class: solution

   y' = -6\cos(3\theta)

.. rst-class:: keepwithnext

d\) :math:`y = \sin^2 x`

.. math::
   :class: solution

   y = (\sin x)^2

.. math::
   :class: solution

   y' = 2(\sin x)(\cos x)

.. math::
   :class: solution

   y' = 2\sin x\cos x

.. rst-class:: keepwithnext

e\) :math:`f(x) = \cos^2 x - \sin^2 x`

.. math::
   :class: solution

   f(x) = (\cos x)^2 - (\sin x)^2

.. math::
   :class: solution

   f'(x) = 2\cos x(-\sin x) - 2\sin x(\cos x)

.. math::
   :class: solution

   f'(x) = -2\cos x\sin x - 2\sin x\cos x

.. math::
   :class: solution

   f'(x) = -2(\cos x\sin x + \sin x\cos x)

.. math::
   :class: solution

   f'(x) = -2(2\sin x\cos x)

.. math::
   :class: solution

   f'(x) = -2\sin(2x)

.. rst-class:: keepwithnext

f\) :math:`y = 3\sin^2(2t - 4) - 2\cos^2(3t + 1)`

.. math::
   :class: solution

   y = 3[\sin(2t - 4)]^2 - 2[\cos(3t + 1)]^2

.. math::
   :class: solution

   y' = 3(2)[\sin(2t - 4)]\cos(2t - 4)(2) -
   2(2)[\cos(3t + 1)][-\sin(3t + 1)](3)

.. math::
   :class: solution

   y' = 12\sin(2t - 4)\cos(2t - 4) + 12\cos(3t + 1)\sin(3t + 1)

.. math::
   :class: solution

   y' = 6\sin[2(2t - 4)] + 6\sin[2(3t + 1)]

.. math::
   :class: solution

   y' = 6\sin(4t - 8) + 6\sin(6t + 2)

.. rst-class:: keepwithnext

g\) :math:`f(t) = \sin^2(\cos t)`

.. math::
   :class: solution

   f(t) = [\sin(\cos t)]^2

.. math::
   :class: solution

   f'(t) = 2[\sin(\cos t)][\cos(\cos t)](-\sin t)

.. math::
   :class: solution

   f'(t) = -2\sin(t)\sin(\cos t)\cos(\cos t)

.. rst-class:: keepwithnext

h\) :math:`f(x) = -x^2\sin(3x - \pi)`

.. math::
   :class: solution

   f'(x) = -2x\sin(3x - \pi) + [\cos(3x - \pi)](3)(-x^2)

.. math::
   :class: solution

   f'(x) = -2x\sin(3x - \pi) - 3x^2\cos(3x - \pi)

i\) :math:`f(\theta) = \sin^2\theta\cos^2\theta`

.. math::
   :class: solution

   f(\theta) = (\sin\theta)^2(\cos\theta)^2

.. math::
   :class: solution

   f'(\theta) = 2\sin\theta\cos\theta\cos^2\theta + 2\cos\theta(-\sin\theta)\sin^2\theta

.. math::
   :class: solution

   f'(\theta) = 2\sin\theta\cos^3\theta - 2\cos\theta\sin^3\theta

j\) :math:`y = x^{-1}\cos^2 x`

.. math::
   :class: solution

   y = x^{-1}(\cos x)^2

.. math::
   :class: solution

   y' = -1x^{-2}(\cos^2 x) + 2\cos x(-\sin x)x^{-1}

.. math::
   :class: solution

   y' = -\frac{\cos^2 x}{x^2} - \frac{2\cos x\sin x}{x}

   :class: solution

l\) :math:`y = (\tan x + \cos x)^2`

.. math::

**2\)** Find the slope of the function :math:`y = 2\cos x\sin(2x)` at
:math:`x = \dfrac{\pi}{2}`.

.. math::
   :class: solution

   y' = -2\sin x[\sin(2x)] + \cos(2x)(2)(2\cos x)

.. math::
   :class: solution

   y' = -2\sin x[\sin(2x)] + 4\cos(2x)\cos x

.. math::
   :class: solution

   y'\left(\frac{\pi}{2}\right) = -2\sin\left(\frac{\pi}{2}\right)[\sin(\pi)] + 4\cos(\pi)\cos\left(\frac{\pi}{2}\right)

.. math::
   :class: solution

   y'\left(\frac{\pi}{2}\right) = -2(1)(0) + 4(-1)(0)

.. math::
   :class: solution

   y'\left(\frac{\pi}{2}\right) = 0

:math:`m = 0`

**3\)** Find the equation of the line that is tangent to
:math:`y = x^2\sin(2x)` at :math:`x = -\pi`.

.. rst-class:: solution

Slope:

.. math::
   :class: solution

   y' = 2x\sin(2x) + \cos(2x)(2)x^2

.. math::
   :class: solution

   y' = 2x\sin(2x) + 2x^2\cos(2x)

.. math::
   :class: solution

   y'(-\pi) = 2(-\pi)\sin(-2\pi) + 2(-\pi)^2\cos(-2\pi)

.. math::
   :class: solution

   y'(-\pi) = -2\pi(0) + 2\pi^2(1)

.. math::
   :class: solution

   y'(-\pi) = 2\pi^2

.. rst-class:: solution

Point:

.. math::
   :class: solution

   y(-\pi) = (-\pi)^2\sin(-2\pi)

.. math::
   :class: solution

   y(-\pi) = 0

.. math::
   :class: solution

   (-\pi, 0)

.. rst-class:: solution

Equation:

.. math::
   :class: solution

   y = m x + b

.. math::
   :class: solution

   0 = 2\pi^2(-\pi) + b

.. math::
   :class: solution

   b = 2\pi^3

.. math::
   :class: solution

   y = 2\pi^2 x + 2\pi^3

**4\)** Determine :math:`\dfrac{d^2y}{dx^2}` for :math:`y = x^2\cos x`.

.. math::
   :class: solution

   \frac{dy}{dx} = 2x\cos x + (-\sin x)(x^2)

.. math::
   :class: solution

   \frac{dy}{dx} = 2x\cos x - x^2\sin x

.. math::
   :class: solution

   \frac{d^2y}{dx^2} = 2\cos x + (-\sin x)(2x) - \left[2x\sin x + \cos x(x^2)\right]

.. math::
   :class: solution

   \frac{d^2y}{dx^2} = 2\cos x - 2x\sin x - 2x\sin x - x^2\cos x

.. math::
   :class: solution

   \frac{d^2y}{dx^2} = 2\cos x - 4x\sin x - x^2\cos x
