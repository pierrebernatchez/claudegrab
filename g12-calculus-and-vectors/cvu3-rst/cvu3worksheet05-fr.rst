Corrigé
================================================================================

**1)** a) :math:`\dfrac{dy}{dx} = \dfrac{3x^2}{2y}`
b) :math:`\dfrac{dy}{dx} = \dfrac{6x^2}{10y+5}`
c) :math:`\dfrac{dy}{dx} = \dfrac{-y-5x^2}{x}`
d) :math:`\dfrac{dy}{dx} = \dfrac{-3y^2x-y+x^2}{3x^2y+x}`
e) :math:`\dfrac{dy}{dx} = \dfrac{6xy-3x^2-4y^2}{8xy-3x^2}`
f) :math:`\dfrac{dy}{dx} = \dfrac{\sin(2y)\sin x}{2\cos(2y)\cos x}`
g) :math:`\dfrac{dy}{dx} = \dfrac{8x}{y(x^2+4)^2}`

**2)** :math:`y = -x`

**3)** a) :math:`y' = \dfrac{2x+3-2x\ln x}{x(2x+3)^2}`
b) :math:`f'(x) = 7x^6 e^{x^7}`
c) :math:`f'(x) = \dfrac{2x}{x^2+1} - \dfrac{3x^2-1}{x^3-x}`
d) :math:`y' = \dfrac{2}{x\ln 2}`
