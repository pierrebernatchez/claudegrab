Answer Key
================================================================================

**1)** a) :math:`\dfrac{dy}{dx} = 4\cos x`  b) :math:`f'(x) = 3\sin x`
c) :math:`\dfrac{dy}{dx} = -\sin x - \cos x`  d) :math:`\dfrac{dy}{dx} = 2x - 3\cos x`
e) :math:`\dfrac{dy}{dx} = -\sin x + 7\pi\cos x - 3`
f) :math:`\dfrac{dy}{dx} = -\dfrac{\pi}{4}\sin x - \dfrac{\pi}{3}\cos x`

**2)** :math:`y = -\dfrac{\sqrt{3}}{2}x + \dfrac{\pi\sqrt{3} + 3}{6}`

**3)** :math:`y = -2\sqrt{2}x + \dfrac{\sqrt{2}\pi}{2} - 2\sqrt{2}`

**4)** :math:`y = 2x + 1 - \dfrac{\pi}{2}`

**5)** :math:`y = 2x`; note: there are an infinite number of solutions.
The slope is at a max value at any :math:`x = 2k\pi` where
:math:`k \in \mathbb{Z}`. Depending on which :math:`x` value you choose,
you will get a different :math:`y`-intercept.
