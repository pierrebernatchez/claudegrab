.. rst-class:: keepwithnext

**1)** Utilisez la règle du quotient pour dériver chaque fonction

.. rst-class:: keepwithnext

a\) :math:`h(x) = \dfrac{x}{x + 1}`

.. math::
   :class: solution

   h'(x) = \frac{1(x + 1) - 1(x)}{(x + 1)^2}

.. math::
   :class: solution

   h'(x) = \frac{x + 1 - x}{(x + 1)^2}

.. math::
   :class: solution

   h'(x) = \frac{1}{(x + 1)^2}

.. rst-class:: keepwithnext

b\) :math:`h(t) = \dfrac{2t - 3}{t + 5}`

.. math::
   :class: solution

   h'(t) = \frac{2(t + 5) - 1(2t - 3)}{(t + 5)^2}

.. math::
   :class: solution

   h'(t) = \frac{2t + 10 - 2t + 3}{(t + 5)^2}

.. math::
   :class: solution

   h'(t) = \frac{13}{(t + 5)^2}

.. rst-class:: keepwithnext

c\) :math:`h(x) = \dfrac{x^3}{2x^2 - 1}`

.. math::
   :class: solution

   h'(x) = \frac{3x^2(2x^2 - 1) - 4x(x^3)}{(2x^2 - 1)^2}

.. math::
   :class: solution

   h'(x) = \frac{6x^4 - 3x^2 - 4x^4}{(2x^2 - 1)^2}

.. math::
   :class: solution

   h'(x) = \frac{2x^4 - 3x^2}{(2x^2 - 1)^2}

.. rst-class:: keepwithnext

d\) :math:`h(x) = \dfrac{1}{x^2 + 3}`

.. math::
   :class: solution

   h'(x) = \frac{0(x^2 + 3) - 2x(1)}{(x^2 + 3)^2}

.. math::
   :class: solution

   h'(x) = \frac{-2x}{(x^2 + 3)^2}

.. rst-class:: keepwithnext

e\) :math:`y = \dfrac{x(3x + 5)}{1 - x^2}`

.. rst-class:: solution

:math:`y = \dfrac{3x^2 + 5x}{1 - x^2}`

.. math::
   :class: solution

   y' = \frac{(6x + 5)(1 - x^2) - (-2x)(3x^2 + 5x)}{(1 - x^2)^2}

.. math::
   :class: solution

   y' = \frac{6x - 6x^3 + 5 - 5x^2 + 6x^3 + 10x^2}{(1 - x^2)^2}

.. math::
   :class: solution

   y' = \frac{5x^2 + 6x + 5}{(1 - x^2)^2}

.. rst-class:: keepwithnext

f\) :math:`y = \dfrac{x^2 - x + 1}{x^2 + 3}`

.. math::
   :class: solution

   y' = \frac{(2x - 1)(x^2 + 3) - (2x)(x^2 - x + 1)}{(x^2 + 3)^2}

.. math::
   :class: solution

   y' = \frac{2x^3 + 6x - x^2 - 3 - 2x^3 + 2x^2 - 2x}{(x^2 + 3)^2}

.. math::
   :class: solution

   y' = \frac{x^2 + 4x - 3}{(x^2 + 3)^2}

.. rst-class:: keepwithnext

**2)** Déterminez :math:`\dfrac{dy}{dx}` pour chaque valeur donnée de :math:`x`.

.. rst-class:: keepwithnext

a\) :math:`y = \dfrac{3x + 2}{x + 5}` en :math:`x = -3`

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{3(x + 5) - 1(3x + 2)}{(x + 5)^2}

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{3x + 15 - 3x - 2}{(x + 5)^2}

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{13}{(x + 5)^2}

.. math::
   :class: solution

   \left.\frac{dy}{dx}\right|_{x=-3} = \frac{13}{(-3 + 5)^2} = \frac{13}{4}

.. rst-class:: keepwithnext

b\) :math:`y = \dfrac{x^3}{x^2 + 9}` en :math:`x = 1`

.. math::
   :class: solution

   \frac{dy}{dx} = \frac{3x^2(x^2 + 9) - 2x(x^3)}{(x^2 + 9)^2}

.. math::
   :class: solution

   \left.\frac{dy}{dx}\right|_{x=1} = \frac{3(1)^2[(1)^2 + 9] - 2(1)[(1)^3]}{[(1)^2 + 9]^2}

.. math::
   :class: solution

   \left.\frac{dy}{dx}\right|_{x=1} = \frac{30 - 2}{100}

.. math::
   :class: solution

   \left.\frac{dy}{dx}\right|_{x=1} = \frac{7}{25}

.. rst-class:: keepwithnext

**3)** Trouvez le(s) point(s) où la tangente à la courbe est horizontale.

.. rst-class:: keepwithnext

a\) :math:`y = \dfrac{2x^2}{x - 4}`

.. math::
   :class: solution

   y' = \frac{4x(x - 4) - 1(2x^2)}{(x - 4)^2}

.. math::
   :class: solution

   y' = \frac{4x^2 - 16x - 2x^2}{(x - 4)^2}

.. math::
   :class: solution

   y' = \frac{2x^2 - 16x}{(x - 4)^2}

.. math::
   :class: solution

   0 = 2x^2 - 16x

.. math::
   :class: solution

   0 = 2x(x - 8)

.. math::
   :class: solution

   x_1 = 0 \qquad x_2 = 8

.. math::
   :class: solution

   y_1 = \frac{2(0)^2}{0 - 4} = 0 \qquad y_2 = \frac{2(8)^2}{8 - 4} = 32

.. rst-class:: solution

:math:`(0, 0)` et :math:`(8, 32)`

.. rst-class:: keepwithnext

b\) :math:`y = \dfrac{x^2 - 1}{x^2 + x - 2}`

.. rst-class:: solution

Remarque : :math:`y = \dfrac{(x - 1)(x + 1)}{(x - 1)(x + 2)} = \dfrac{x + 1}{x + 2}`;
:math:`x \neq -2, 1` (un trou dans le graphique lorsque :math:`x = 1`)

.. math::
   :class: solution

   y' = \frac{2x(x^2 + x - 2) - (2x + 1)(x^2 - 1)}{(x^2 + x - 2)^2}

.. math::
   :class: solution

   y' = \frac{2x^3 + 2x^2 - 4x - (2x^3 - 2x + x^2 - 1)}{(x^2 + x - 2)^2}

.. math::
   :class: solution

   y' = \frac{x^2 - 2x + 1}{(x^2 + x - 2)^2}

.. math::
   :class: solution

   y' = \frac{(x - 1)^2}{(x + 2)^2(x - 1)^2}

.. rst-class:: solution

Pour :math:`x \neq 1` :

.. math::
   :class: solution

   y' = \frac{1}{(x + 2)^2}

.. math::
   :class: solution

   0 = \frac{1}{(x + 2)^2}

.. rst-class:: solution

Aucune solution -- il n'y a pas de tangente horizontale.

.. rst-class:: keepwithnext

**4)** Déterminez l'équation de la tangente à la courbe :math:`y = \dfrac{x^2 - 1}{3x}` en :math:`x = 2`.

.. math::
   :class: solution

   y' = \frac{2x(3x) - 3(x^2 - 1)}{(3x)^2}

.. math::
   :class: solution

   y' = \frac{6x^2 - 3x^2 + 3}{9x^2}

.. math::
   :class: solution

   y' = \frac{3x^2 + 3}{9x^2}

.. math::
   :class: solution

   y' = \frac{x^2 + 1}{3x^2}

Pente :

.. math::
   :class: solution

   y'(2) = \frac{(2)^2 + 1}{3(2)^2}

.. math::
   :class: solution

   y'(2) = \frac{5}{12}

Point :

.. math::
   :class: solution

   y(2) = \frac{(2)^2 - 1}{3(2)}

.. math::
   :class: solution

   y(2) = \frac{1}{2}

Équation :

.. math::

   y = mx + b

.. math::
   :class: solution

   \frac{1}{2} = \frac{5}{12}(2) + b

.. math::
   :class: solution

   \frac{3}{6} - \frac{5}{6} = b

.. math::
   :class: solution

   b = -\frac{1}{3}

.. math::
   :class: solution

   y = \frac{5}{12}x - \frac{1}{3}
