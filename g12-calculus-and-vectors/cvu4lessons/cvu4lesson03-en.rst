Part 1: Scalar Multiplication
================================================================================

In this section we will multiply a vector, :math:`\vec{a}`, by a
number :math:`k` to produce a new vector :math:`k\vec{a}`. The number
:math:`k` used for multiplication is called a
``________________`` and can be any real number.

Multiplying a vector by different values of a scalar :math:`k` can
affect the **magnitude** AND **direction** of the vector.

When two vectors are parallel, these vectors are described as being
``________________``. They are described this way because they can be
translated to be on the same straight line. Scalar multiples of
vectors are colinear.

.. image:: ../images/cvu4lesson03-gpimage01.png
   :scale: 85
   :alt: seven colinear scalar multiples of vector a at various lengths and directions

Rules:

1\) If :math:`k > 0`, then :math:`k\vec{a}` is in the same direction
as :math:`\vec{a}` with magnitude :math:`k|\vec{a}|`

.. rst-class:: keepwithnext

a\) If :math:`0 < k < 1`, :math:`\vec{a}` is shortened →
:math:`\left|\dfrac{1}{2}\vec{a}\right| = \dfrac{1}{2}|\vec{a}|`

.. rst-class:: keepwithnext

b\) If :math:`k > 1`, :math:`\vec{a}` is lengthened →
:math:`|2\vec{a}| = 2|\vec{a}|`

2\) If :math:`k < 0`, then :math:`k\vec{a}` is in the opposite
direction as :math:`\vec{a}` with magnitude :math:`|k||\vec{a}|`

.. rst-class:: keepwithnext

a\) If :math:`-1 < k < 0`, :math:`\vec{a}` is shortened and changes to
the opposite direction →
:math:`\left|-\dfrac{1}{2}\vec{a}\right| = \dfrac{1}{2}|\vec{a}|`

.. rst-class:: keepwithnext

b\) If :math:`k < -1`, :math:`\vec{a}` is lengthened and changes to
the opposite direction → :math:`|-2\vec{a}| = 2|\vec{a}|`

3\) If :math:`k = 0`, the result is the zero vector :math:`\vec{0}`

4\) The distributive property for vector multiplication is
:math:`k(\vec{u} + \vec{v}) = k\vec{u} + k\vec{v}`

.. rst-class:: keepwithnext

**Vector Properties for Scalar Multiplication**

**Distributive Property:** For any scalar :math:`k \in \mathbb{R}` and
any vectors :math:`\vec{u}` and :math:`\vec{v}`,
:math:`k(\vec{u} + \vec{v}) = k\vec{u} + k\vec{v}`

**Associative Property:** For any scalars :math:`a, b \in \mathbb{R}`
and any vector :math:`\vec{v}`, :math:`(ab)\vec{v} = a(b\vec{v})`

**Identity Property:** For any vector :math:`\vec{v}`,
:math:`1\vec{v} = \vec{v}`

Part 2: Creating Unit Vectors
================================================================================

It is sometimes useful to multiply the nonzero vector :math:`\vec{x}`
by the scalar :math:`\dfrac{1}{|\vec{x}|}`. When we multiply
:math:`\vec{x}` by :math:`\dfrac{1}{|\vec{x}|}`, we get the vector
:math:`\dfrac{1}{|\vec{x}|}\vec{x}`. This is a vector of length one
and is called a ``________________``, which points in the same
direction as :math:`\vec{x}`. The concept of unit vectors will prove
to be very useful when we discuss applications of vectors.
