**5\)** Le diagramme montre trois triangles équilatéraux congrus.
Exprime chaque différence comme un seul vecteur. Montre tes étapes de
simplification.

.. image:: ../images/cvu4worksheet02-gpimage19.png
   :scale: 85
   :alt: triangle ABC subdivisé en quatre triangles équilatéraux congrus avec les points milieux B, D, E

.. rst-class:: keepwithnext

a\) :math:`\vec{AB} - \vec{AE}`

.. math::
   :class: solution

   = \vec{EB}

.. rst-class:: keepwithnext

b\) :math:`-\vec{AB} + \vec{AE} + \vec{ED}`

.. math::
   :class: solution

   = \vec{BE} + \vec{ED}

.. math::
   :class: solution

   = \vec{BD}

.. rst-class:: keepwithnext

c\) :math:`\vec{BD} - \vec{BE}`

.. math::
   :class: solution

   = \vec{ED}

.. rst-class:: keepwithnext

d\) :math:`\vec{CD} - \vec{BD}`

.. math::
   :class: solution

   = \vec{CD} + (-\vec{BD})

.. math::
   :class: solution

   = \vec{CD} + \vec{DB}

.. math::
   :class: solution

   = \vec{CB}

**6\)** Un avion quitte l'aéroport en direction N30°O à 720 km/h.
Après 1 h, l'avion tourne vers le nord et vole encore 1.5 h à
850 km/h. Quel est le déplacement de l'avion après 2.5 h?

.. rst-class:: solution

.. image:: ../images/cvu4worksheet02-gpimage20.png
   :scale: 85
   :alt: triangle vectoriel pour les deux trajets de l'avion, 720 km puis 1275 km, avec le déplacement résultant

.. math::
   :class: solution

   |\vec{d}|^2 = 720^2 + 1275^2 - 2(720)(1275) \cos(150°)

.. math::
   :class: solution

   |\vec{d}| \approx 1932.4 \text{ km}

.. math::
   :class: solution

   \dfrac{\sin\theta}{1275} = \dfrac{\sin 150°}{1932.4}

.. math::
   :class: solution

   \theta \approx 19.26°

.. math::
   :class: solution

   \beta = 30° - 19.26°

.. math::
   :class: solution

   \beta \approx 10.74°

Réponse : 1932.4 km à :math:`N10.74°O`

   = \vec{AD}
