Part 1: Scalar Multiplication
================================================================================

In this section we will multiply a vector, :math:`\vec{a}`, by a
number :math:`k` to produce a new vector :math:`k\vec{a}`. The number
:math:`k` used for multiplication is called a :sol:`SCALAR` and can be
any real number.

Multiplying a vector by different values of a scalar :math:`k` can
affect the **magnitude** AND **direction** of the vector.

When two vectors are parallel, these vectors are described as being
:sol:`colinear`. They are described this way because they can be
translated to be on the same straight line. Scalar multiples of
vectors are colinear.

.. image:: ../images/cvu4lesson03-gpimage01.png
   :scale: 85
   :alt: seven colinear scalar multiples of vector a at various lengths and directions

Rules:

1\) If :math:`k > 0`, then :math:`k\vec{a}` is in the same direction
as :math:`\vec{a}` with magnitude :math:`k|\vec{a}|`

.. rst-class:: keepwithnext

a\) If :math:`0 < k < 1`, :math:`\vec{a}` is shortened →
:math:`\left|\dfrac{1}{2}\vec{a}\right| = \dfrac{1}{2}|\vec{a}|`

.. rst-class:: keepwithnext

b\) If :math:`k > 1`, :math:`\vec{a}` is lengthened →
:math:`|2\vec{a}| = 2|\vec{a}|`

2\) If :math:`k < 0`, then :math:`k\vec{a}` is in the opposite
direction as :math:`\vec{a}` with magnitude :math:`|k||\vec{a}|`

.. rst-class:: keepwithnext

a\) If :math:`-1 < k < 0`, :math:`\vec{a}` is shortened and changes to
the opposite direction →
:math:`\left|-\dfrac{1}{2}\vec{a}\right| = \dfrac{1}{2}|\vec{a}|`

.. rst-class:: keepwithnext

b\) If :math:`k < -1`, :math:`\vec{a}` is lengthened and changes to
the opposite direction → :math:`|-2\vec{a}| = 2|\vec{a}|`

3\) If :math:`k = 0`, the result is the zero vector :math:`\vec{0}`

4\) The distributive property for vector multiplication is
:math:`k(\vec{u} + \vec{v}) = k\vec{u} + k\vec{v}`

.. rst-class:: keepwithnext

**Vector Properties for Scalar Multiplication**

**Distributive Property:** For any scalar :math:`k \in \mathbb{R}` and
any vectors :math:`\vec{u}` and :math:`\vec{v}`,
:math:`k(\vec{u} + \vec{v}) = k\vec{u} + k\vec{v}`

**Associative Property:** For any scalars :math:`a, b \in \mathbb{R}`
and any vector :math:`\vec{v}`, :math:`(ab)\vec{v} = a(b\vec{v})`

**Identity Property:** For any vector :math:`\vec{v}`,
:math:`1\vec{v} = \vec{v}`

.. rst-class:: keepwithnext

**Example 3:** If :math:`\vec{x} = 3\vec{i} - 4\vec{j} + \vec{k}`,
:math:`\vec{y} = \vec{j} - 5\vec{k}`, and
:math:`\vec{z} = -\vec{i} - \vec{j} + 4\vec{k}`, determine each of the
following in terms of :math:`\vec{i}`, :math:`\vec{j}`, and
:math:`\vec{k}`.

.. rst-class:: keepwithnext

a\) :math:`\vec{x} + \vec{y}`

.. math::
   :class: solution

   = (3\vec{i} - 4\vec{j} + \vec{k}) + (\vec{j} - 5\vec{k})

.. math::
   :class: solution

   = 3\vec{i} - 4\vec{j} + \vec{k} + \vec{j} - 5\vec{k}

.. math::
   :class: solution

   = 3\vec{i} - 3\vec{j} - 4\vec{k}

.. rst-class:: keepwithnext

b\) :math:`\vec{x} - \vec{y}`

.. math::
   :class: solution

   = (3\vec{i} - 4\vec{j} + \vec{k}) - (\vec{j} - 5\vec{k})

.. math::
   :class: solution

   = 3\vec{i} - 4\vec{j} + \vec{k} - \vec{j} + 5\vec{k}

.. math::
   :class: solution

   = 3\vec{i} - 5\vec{j} + 6\vec{k}

.. rst-class:: keepwithnext

c\) :math:`\vec{x} - 2\vec{y} + 3\vec{z}`

.. math::
   :class: solution

   = (3\vec{i} - 4\vec{j} + \vec{k}) - 2(\vec{j} - 5\vec{k}) + 3(-\vec{i} - \vec{j} + 4\vec{k})

.. math::
   :class: solution

   = 3\vec{i} - 4\vec{j} + \vec{k} - 2\vec{j} + 10\vec{k} - 3\vec{i} - 3\vec{j} + 12\vec{k}

.. math::
   :class: solution

   = -9\vec{j} + 23\vec{k}

.. rst-class:: keepwithnext

**Example 4:** In trapezoid ABCD, :math:`BC \parallel AD` and
:math:`AD = 3BC`. Let :math:`\vec{AB} = \vec{u}` and
:math:`\vec{BC} = \vec{v}`. Express :math:`\vec{AD}`, :math:`\vec{BD}`,
and :math:`\vec{CD}` as linear combinations of :math:`\vec{u}` and
:math:`\vec{v}`.

.. image:: ../images/cvu4lesson03-gpimage07.png
   :scale: 85
   :alt: trapezoid ABCD with u=AB and v=BC labelled

.. rst-class:: solution

:math:`\vec{AD} = 3\vec{v}`

:math:`\vec{BD} = \vec{BA} + \vec{AD} = -\vec{u} + 3\vec{v}`

:math:`\vec{CD} = \vec{CB} + \vec{BA} + \vec{AD} = -\vec{v} + (-\vec{u}) + 3\vec{v} = 2\vec{v} - \vec{u}`

Part 2: Creating Unit Vectors
================================================================================

It is sometimes useful to multiply the nonzero vector :math:`\vec{x}`
by the scalar :math:`\dfrac{1}{|\vec{x}|}`. When we multiply
:math:`\vec{x}` by :math:`\dfrac{1}{|\vec{x}|}`, we get the vector
:math:`\dfrac{1}{|\vec{x}|}\vec{x}`. This is a vector of length one
and is called a :sol:`unit vector`, which points in the same direction
as :math:`\vec{x}`. The concept of unit vectors will prove to be very
useful when we discuss applications of vectors.

.. image:: ../images/cvu4lesson03-gpimage08.png
   :scale: 85
   :alt: vector x of length 3 and its unit vector one-third x

.. rst-class:: keepwithnext

**Example 5:** Given that :math:`|\vec{u}| = 4` and :math:`|\vec{v}| = 5`
and the angle between :math:`\vec{u}` and :math:`\vec{v}` is 120°,
determine the unit vector in the same direction as
:math:`\vec{u} + \vec{v}`.

.. image:: ../images/cvu4lesson03-gpimage09.png
   :scale: 85
   :alt: vectors u and v at 120 degrees with resultant u+v

.. math::
   :class: solution

   |\vec{u} + \vec{v}|^2 = |\vec{u}|^2 + |\vec{v}|^2 - 2|\vec{u}||\vec{v}| \cos(60)

.. math::
   :class: solution

   |\vec{u} + \vec{v}|^2 = (4)^2 + (5)^2 - 2(4)(5) \cos(60)

.. math::
   :class: solution

   |\vec{u} + \vec{v}|^2 = 41 - 40\left(\dfrac{1}{2}\right)

.. math::
   :class: solution

   |\vec{u} + \vec{v}|^2 = 21

.. math::
   :class: solution

   |\vec{u} + \vec{v}| = \sqrt{21}

To create a unit vector in the same direction as :math:`\vec{u} + \vec{v}`,
multiply by the scalar equal to :math:`\dfrac{1}{|\vec{u} + \vec{v}|}`

.. rst-class:: solution

Therefore, the unit vector is
:math:`\dfrac{1}{\sqrt{21}}(\vec{u} + \vec{v}) = \dfrac{1}{\sqrt{21}}\vec{u} + \dfrac{1}{\sqrt{21}}\vec{v}`
