**4\)** Nomme tous les vecteurs équivalents dans chaque diagramme.

.. rst-class:: solution

:math:`\vec{AB} = \vec{ED}, \vec{BC} = \vec{FE}, \vec{CD} = \vec{AF},
\vec{DE} = \vec{BA}, \vec{EF} = \vec{CB}, \vec{FA} = \vec{DC},
\vec{FB} = \vec{EC}, \vec{BF} = \vec{CE}`

.. image:: ../images/cvu4worksheet01-gpimage03.png

\vec{DA} = \vec{CB}, \vec{DE} = \vec{EB}, \vec{BE} = \vec{ED},
\vec{AE} = \vec{EC}, \vec{CE} = \vec{EA}`

**7\)** Indique si les quantités suivantes sont des vecteurs ou des
scalaires :

.. rst-class:: keepwithnext

a\) Une table pèse 80 N

.. rst-class:: solution

Vecteur |---| le poids est dû à la force gravitationnelle et a donc
une direction

.. rst-class:: keepwithnext

b\) L'âge d'une femme est 60 ans

.. rst-class:: solution

Scalaire |---| ceci n'a pas de direction

.. rst-class:: keepwithnext

c\) 300 km/h

.. rst-class:: solution

Scalaire |---| il n'y a pas de direction, c'est seulement une vitesse

.. rst-class:: keepwithnext

d\) Un ascenseur soulève une personne de 20 m

.. rst-class:: solution

Vecteur |---| il y a une norme et une direction (vers le haut)
