.. math::

   = -\vec{u} - 5\vec{v}

   :class: solution

**6\)** Étant donné que :math:`|\vec{u}| = 8` et :math:`|\vec{v}| = 10`
et que l'angle entre :math:`\vec{u}` et :math:`\vec{v}` est de 60°,
détermine :

.. rst-class:: keepwithnext

a\) :math:`|\vec{u} - \vec{v}|`

.. image:: ../images/cvu4worksheet03-gpimage13.png
   :scale: 85
   :alt: triangle pour u-v avec un angle de 60 degrés

.. math::
   :class: solution

   |\vec{u} - \vec{v}|^2 = 8^2 + 10^2 - 2(8)(10) \cos(60°)

.. math::
   :class: solution

   |\vec{u} - \vec{v}| = \sqrt{84}

.. math::
   :class: solution

   |\vec{u} - \vec{v}| = 2\sqrt{21}

.. rst-class:: keepwithnext

b\) la direction de :math:`\vec{u} - \vec{v}` par rapport à
:math:`\vec{u}`

.. image:: ../images/cvu4worksheet03-gpimage14.png
   :scale: 85
   :alt: triangle pour u-v avec l'angle theta par rapport à u

.. math::
   :class: solution

   \dfrac{\sin\theta}{10} = \dfrac{\sin 60°}{2\sqrt{21}}

.. math::
   :class: solution

   \theta \approx 70.9°

.. rst-class:: solution

70.9° entre :math:`\vec{u}` et :math:`\vec{u} - \vec{v}`

.. rst-class:: keepwithnext

c\) le vecteur unitaire dans la direction de
:math:`\vec{u} + \vec{v}`

.. image:: ../images/cvu4worksheet03-gpimage15.png
   :scale: 85
   :alt: triangle pour u+v avec un angle de 120 degrés

.. math::
   :class: solution

   |\vec{u} + \vec{v}|^2 = 8^2 + 10^2 - 2(8)(10) \cos(120°)

.. math::
   :class: solution

   |\vec{u} + \vec{v}| = \sqrt{244}

.. math::
   :class: solution

   |\vec{u} + \vec{v}| = 2\sqrt{61}

.. rst-class:: solution

vecteur unitaire : :math:`\dfrac{1}{2\sqrt{61}}(\vec{u} + \vec{v})`

.. rst-class:: keepwithnext

d\) :math:`|5\vec{u} + 2\vec{v}|`

.. math::
   :class: solution

   |5\vec{u}| = 40, \quad |2\vec{v}| = 20

.. math::
   :class: solution

   |5\vec{u} + 2\vec{v}|^2 = 40^2 + 20^2 - 2(40)(20) \cos(120°)

.. math::
   :class: solution

   |5\vec{u} + 2\vec{v}| = \sqrt{2800}

.. math::
   :class: solution

   |5\vec{u} + 2\vec{v}| = 20\sqrt{7}
