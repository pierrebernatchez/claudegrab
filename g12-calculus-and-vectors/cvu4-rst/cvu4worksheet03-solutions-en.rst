**2\)** Simplify each of the following algebraically.

.. rst-class:: keepwithnext

a\) :math:`\vec{a} + 2\vec{a} + 4\vec{a}`

.. rst-class:: solution

.. rst-class:: keepwithnext

b\) :math:`7\vec{u} + 5\vec{v} - 2\vec{u} + 8\vec{v}`

.. rst-class:: solution

:math:`= 5\vec{u} + 13\vec{v}`

.. rst-class:: keepwithnext

c\) :math:`2(\vec{u} + \vec{v}) - 3(\vec{u} - 2\vec{v})`

.. math::
   :class: solution

   = 2\vec{u} + 2\vec{v} - 3\vec{u} + 6\vec{v}

.. math::
   :class: solution

   = -\vec{u} + 8\vec{v}

.. rst-class:: keepwithnext

d\) :math:`7\vec{u} + 5\vec{v} - 2(\vec{u} - \vec{v}) + 2\vec{u}`

.. math::
   :class: solution

   = 7\vec{u} + 5\vec{v} - 2\vec{u} + 2\vec{v} + 2\vec{u}

.. math::
   :class: solution

   = 7\vec{u} + 7\vec{v}

.. rst-class:: keepwithnext

e\) :math:`-3(\vec{u} + \vec{v}) + 2(\vec{u} - \vec{v})`

.. math::
   :class: solution

   = -3\vec{u} - 3\vec{v} + 2\vec{u} - 2\vec{v}

.. math::
   :class: solution

   = -\vec{u} - 5\vec{v}

.. rst-class:: keepwithnext

f\) :math:`6(\vec{u} + 2\vec{v}) - 5(\vec{u} - 3\vec{v})`

.. math::
   :class: solution

   = 6\vec{u} + 12\vec{v} - 5\vec{u} + 15\vec{v}

.. math::
   :class: solution

   = \vec{u} + 27\vec{v}

**6\)** Given that :math:`|\vec{u}| = 8` and :math:`|\vec{v}| = 10`
and the angle between :math:`\vec{u}` and :math:`\vec{v}` is 60°,
determine:

.. rst-class:: keepwithnext

a\) :math:`|\vec{u} - \vec{v}|`

.. image:: ../images/cvu4worksheet03-gpimage13.png
   :scale: 85
   :alt: triangle for u-v with 60 degree angle

.. math::
   :class: solution

   |\vec{u} - \vec{v}|^2 = 8^2 + 10^2 - 2(8)(10) \cos(60°)

.. math::
   :class: solution

   |\vec{u} - \vec{v}| = \sqrt{84}

.. math::
   :class: solution

   |\vec{u} - \vec{v}| = 2\sqrt{21}

.. rst-class:: keepwithnext

b\) the direction of :math:`\vec{u} - \vec{v}` relative to
:math:`\vec{u}`

.. image:: ../images/cvu4worksheet03-gpimage14.png
   :scale: 85
   :alt: triangle for u-v with theta angle relative to u

.. math::
   :class: solution

   \dfrac{\sin\theta}{10} = \dfrac{\sin 60°}{2\sqrt{21}}

.. math::
   :class: solution

   \theta \approx 70.9°

.. rst-class:: solution

70.9° between :math:`\vec{u}` and :math:`\vec{u} - \vec{v}`

.. rst-class:: keepwithnext

c\) the unit vector in the direction of :math:`\vec{u} + \vec{v}`

.. image:: ../images/cvu4worksheet03-gpimage15.png
   :scale: 85
   :alt: triangle for u+v with 120 degree angle

.. math::
   :class: solution

   |\vec{u} + \vec{v}|^2 = 8^2 + 10^2 - 2(8)(10) \cos(120°)

.. math::
   :class: solution

   |\vec{u} + \vec{v}| = \sqrt{244}

.. math::
   :class: solution

   |\vec{u} + \vec{v}| = 2\sqrt{61}

.. rst-class:: solution

unit vector: :math:`\dfrac{1}{2\sqrt{61}}(\vec{u} + \vec{v})`

.. rst-class:: keepwithnext

d\) :math:`|5\vec{u} + 2\vec{v}|`

.. math::
   :class: solution

   |5\vec{u}| = 40, \quad |2\vec{v}| = 20

.. math::
   :class: solution

   |5\vec{u} + 2\vec{v}|^2 = 40^2 + 20^2 - 2(40)(20) \cos(120°)

.. math::
   :class: solution

   |5\vec{u} + 2\vec{v}| = \sqrt{2800}

.. math::
   :class: solution

   |5\vec{u} + 2\vec{v}| = 20\sqrt{7}
