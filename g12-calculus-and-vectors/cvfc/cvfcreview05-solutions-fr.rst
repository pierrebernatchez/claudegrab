**12)** Déterminer si le :math:`\triangle PQR` dont les sommets sont :math:`P(-5,3)`, :math:`Q(-7,8)` et
:math:`R(3,12)` est un triangle rectangle. Si oui, identifier l'angle droit.

.. image:: ../images/cvfcreview05-gpimage05.png
   :scale: 85
   :alt: triangle PQR dont les sommets sont P(-5,3), Q(-7,8), R(3,12)

.. rst-class:: solution

:solmath:`\vec{PQ} = [-2,5], |\vec{PQ}| = \sqrt{29}`

:solmath:`\vec{PR} = [8,9], |\vec{PR}| = \sqrt{145}`

:solmath:`\vec{RQ} = [-10,-4], |\vec{RQ}| = \sqrt{116}`

.. rst-class:: solution

Vérifier le théorème de Pythagore avec le côté le plus long, :math:`\vec{PR}` :

:solmath:`\left(\sqrt{29}\right)^2 + \left(\sqrt{116}\right)^2 \overset{?}{=} \left(\sqrt{145}\right)^2`

:solmath:`29 + 116 = 145`

.. rst-class:: solution

:math:`145 = 145` donc le :math:`\triangle PQR` est un triangle rectangle, avec l'angle droit en :math:`Q`.

.. list-table::
   :widths: 50 50
   :header-rows: 0
   :width: 100%

       :solmath:`10\vec{c}-10\vec{d} = [-60,40,0]-[0,-50,-70]`

       .. rst-class:: solution

     - **b)** :math:`2\vec{c} \cdot 3\vec{d} - 2\vec{c} \cdot 4\vec{e}`

       :solmath:`= 6(\vec{c}\cdot\vec{d}) - 8(\vec{c}\cdot\vec{e}) = 6(-20) - 8(-14)`

       .. rst-class:: solution

       :math:`= -8`
   * - **c)** :math:`(3\vec{d} - 4\vec{e}) \cdot 2\vec{c}`

       :solmath:`\text{par la propriété distributive, } = 3\vec{d}\cdot 2\vec{c} - 4\vec{e}\cdot 2\vec{c}`

       .. rst-class:: solution

       :math:`= -8` (même valeur qu'en b, le produit scalaire est commutatif)
     - **d)** :math:`\vec{c} \times \vec{d}`

       .. rst-class:: solution

       :math:`\vec{c} \times \vec{d} = [4(-7)-0(-5),\ 0(0)-(-6)(-7),\ (-6)(-5)-4(0)]`

       .. rst-class:: solution

       :math:`\vec{c} \times \vec{d} = [-28,-42,30]`
   * - **e)** :math:`\vec{d} \times \vec{e}`

       .. rst-class:: solution

       :math:`\vec{d} \times \vec{e} = [(-5)(2)-(-7)(1),\ (-7)(3)-0(2),\ 0(1)-(-5)(3)]`

       .. rst-class:: solution

       :math:`\vec{d} \times \vec{e} = [-3,-21,15]`
     - **f)** :math:`\vec{c} \times \vec{c}`

       .. rst-class:: solution

**24)** Une boîte de rangement est tirée sur :math:`7` m le long d'un plancher lisse et horizontal par une force
de :math:`43` N, appliquée à :math:`38°` par rapport au plancher. Elle est ensuite tirée sur :math:`3.5` m le
long d'une rampe inclinée à :math:`24°` par rapport à l'horizontale, en utilisant la même force. La boîte est
ensuite tirée sur encore :math:`6` m le long d'une plateforme horizontale en utilisant encore la même force.
Déterminer le travail total effectué pour déplacer la boîte.

.. rst-class:: solution

Sur le plancher horizontal et sur la plateforme horizontale, l'angle entre la force et la direction du
mouvement reste à :math:`38°`. Sur la rampe, l'angle entre la force et la direction du mouvement (le long de la
rampe) est de :math:`38° - 24° = 14°` :

:solmath:`W = 7(43)\cos(38°) + 3.5(43)\cos(14°) + 6(43)\cos(38°)`

.. rst-class:: solution

:math:`W \approx 586.5` J

:solmath:`W = \vec{F} \cdot \vec{d} = 5.2(21)\cos(11.2°)`

.. rst-class:: solution
