**2)** Déterminez :math:`f''(-1)` pour la fonction :math:`f(x) = \dfrac{3}{(2x-3)^2}`.

.. rst-class:: solution

:math:`f(x) = 3(2x-3)^{-2}`

:solmath:`f'(x) = -6(2x-3)^{-3}(2) = -12(2x-3)^{-3}`

:solmath:`f''(x) = 36(2x-3)^{-4}(2) = \dfrac{72}{(2x-3)^4}`

.. rst-class:: solution

:math:`f''(-1) = \dfrac{72}{[2(-1)-3]^4} = \dfrac{72}{625}`

**3)** Déterminez l'équation de la tangente à la courbe :math:`y = (2x^2-3)(x+1)^2` au point où :math:`x = 1`.

.. rst-class:: solution

Point : :math:`y(1) = [2(1)^2-3](1+1)^2 = -4`, donc le point est :math:`(1,-4)`.

:solmath:`y' = 4x(x+1)^2 + 2(x+1)(2x^2-3)`

.. rst-class:: solution

:math:`y'(1) = 4(1)(2)^2 + 2(2)[2(1)^2-3] = 16 + 4(-1) = 12`

.. rst-class:: solution

En utilisant :math:`y = mx+b` : :math:`-4 = 12(1) + b \Rightarrow b = -16`

.. rst-class:: solution

:math:`y = 12x - 16`

**4)** Pour quelles valeurs de :math:`x` la courbe :math:`y = -x^3+6x^2` a-t-elle une tangente de pente 12?

.. rst-class:: solution

:math:`y' = -3x^2+12x`

:solmath:`12 = -3x^2+12x`

:solmath:`0 = -3x^2+12x-12 = -3(x-2)^2`

.. rst-class:: solution

:math:`x = 2`

**5)** Une tangente à la parabole :math:`y = 3x^2-7x+5` est perpendiculaire à :math:`x+5y-10=0`. Déterminez l'équation de la tangente.

.. rst-class:: solution

La droite :math:`x+5y-10=0` a une pente :math:`y = -\tfrac{1}{5}x+2`, donc :math:`m=-\tfrac{1}{5}`; la pente perpendiculaire est :math:`m_\perp = 5`.

:solmath:`y' = 6x-7 = 5 \Rightarrow x = 2`

.. rst-class:: solution

:math:`y(2) = 3(2)^2-7(2)+5 = 3`, donc le point est :math:`(2,3)`.

:solmath:`3 = 5(2) + b \Rightarrow b = -7`

.. rst-class:: solution

:math:`y = 5x - 7`

**6)** On vide de l'eau par le bas d'un réservoir. L'équation donnant le volume :math:`V` d'eau, en litres, restant dans le réservoir après :math:`t` minutes est :math:`V(t) = 3000\left(1-\dfrac{t}{10}\right)^2`, :math:`0 \le t \le 10`.

.. rst-class:: keepwithnext

**a)** Déterminez le volume d'eau dans le réservoir après 5 min.

.. rst-class:: solution

:math:`V(5) = 3000\left(1-\tfrac{5}{10}\right)^2 = 750` L

.. rst-class:: keepwithnext

**b)** Déterminez le taux auquel l'eau s'écoule du réservoir après **i)** 3 min **ii)** 8 min

.. rst-class:: solution

:solmath:`V'(t) = 6000\left(1-\dfrac{t}{10}\right)\left(-\dfrac{1}{10}\right) = -600\left(1-\dfrac{t}{10}\right)`

.. rst-class:: solution

**i)** :math:`V'(3) = -420` L/min

.. rst-class:: solution

**ii)** :math:`V'(8) = -120` L/min

.. rst-class:: keepwithnext

**7)** Pour la fonction :math:`f(x) = x^3-x^2-x+1`, déterminez les points où la tangente est horizontale.

.. rst-class:: solution

:math:`f'(x) = 3x^2-2x-1`

:solmath:`0 = 3x^2-2x-1 = (x-1)(3x+1)`

.. rst-class:: solution

:math:`x = 1` ou :math:`x = -\tfrac{1}{3}`

:solmath:`f(1) = 0,\quad f(-\tfrac{1}{3}) = \tfrac{32}{27}`

.. rst-class:: solution

Les points sont :math:`(1,0)` et :math:`\left(-\tfrac{1}{3},\tfrac{32}{27}\right)`.

**8)** La quantité de pollution dans un certain lac est :math:`P(t) = \left(t^{1/4}+3\right)^3`, où :math:`t` est mesuré en années et :math:`P` est mesuré en parties par million (ppm). À quel taux la quantité de pollution change-t-elle après 16 ans?

.. rst-class:: solution

:solmath:`P'(t) = 3\left(t^{1/4}+3\right)^2\left(\tfrac{1}{4}t^{-3/4}\right)`

.. rst-class:: solution

:math:`P'(16) = 3\left(16^{1/4}+3\right)^2\left[\tfrac{1}{4}(16)^{-3/4}\right] = \dfrac{75}{32} \approx 2.34` ppm/année

.. rst-class:: keepwithnext

**9)** Un objet se déplace en ligne droite, et sa position, :math:`s`, en mètres après :math:`t` secondes, est :math:`s(t) = 8-7t-t^2`.

.. rst-class:: keepwithnext

**a)** Déterminez la vitesse lorsque :math:`t=5`.

.. rst-class:: solution

:math:`v(t) = s'(t) = -7-2t \Rightarrow v(5) = -7-2(5) = -17` m/s

.. rst-class:: keepwithnext

**b)** Déterminez l'accélération lorsque :math:`t=5`.

.. rst-class:: solution

:math:`a(t) = v'(t) = -2 \Rightarrow a(5) = -2` m/s :math:`^2`

.. rst-class:: keepwithnext

**10)** Un magasin vend 250 paires de chaussures de course de marque X chaque mois lorsqu'elles sont au prix de 100 $ la paire. On a déterminé que pour chaque baisse de prix de 5 $, 20 paires supplémentaires seront vendues.

.. rst-class:: keepwithnext

**a)** Déterminez la fonction de demande ou de prix.

.. rst-class:: solution

Soit :math:`x` = le nombre vendu, :math:`n` = le nombre de baisses de prix de 5 $. :math:`x = 250+20n \Rightarrow n = \dfrac{x-250}{20}`

:solmath:`p(x) = 100-5\left(\dfrac{x-250}{20}\right) = 100 - \dfrac{x-250}{4}`

.. rst-class:: solution

:math:`p(x) = -0.25x + 162.5`

.. rst-class:: keepwithnext

**b)** Déterminez la fonction de revenu.

.. rst-class:: solution

:math:`R(x) = x \cdot p(x) = x(-0.25x+162.5)`

:math:`R(x) = -0.25x^2 + 162.5x`

.. rst-class:: keepwithnext

**c)** Déterminez le revenu lorsque les ventes sont de 250 paires et de 290 paires de chaussures par mois.

.. rst-class:: solution

:math:`R(250) = \$25\,000 \qquad R(290) = \$26\,100`

.. rst-class:: keepwithnext

**d)** Déterminez le revenu marginal lorsque les ventes sont de 290 paires de chaussures par mois.

.. rst-class:: solution

:math:`R'(x) = -0.5x+162.5 \Rightarrow R'(290) = \$17.50` par paire vendue

.. rst-class:: keepwithnext

**11)** Un théâtre a constaté que si le prix d'un billet est de 24 $, 400 billets seront vendus. Pour chaque baisse de prix de 2 $, 50 billets supplémentaires seront vendus.

.. rst-class:: keepwithnext

**a)** Déterminez la fonction de demande ou de prix en fonction du nombre de baisses de prix.

.. rst-class:: solution

Soit :math:`x` = le nombre de baisses de prix de 2 $ : :math:`p(x) = 24-2x`

.. rst-class:: keepwithnext

**b)** Déterminez une fonction de revenu en fonction du nombre de baisses de prix.

.. rst-class:: solution

Billets vendus :math:`= 400+50x`

:solmath:`R(x) = (24-2x)(400+50x)`

.. rst-class:: solution

:math:`R(x) = 9600+400x-100x^2`

.. rst-class:: keepwithnext

**c)** Déterminez le revenu marginal pour la fonction de revenu élaborée à la partie a).

.. rst-class:: solution

:math:`R'(x) = 400-200x`

.. rst-class:: keepwithnext

**d)** Quand cette fonction de revenu marginal est-elle égale à zéro? Quel est le revenu total à ce moment? Comment les propriétaires du théâtre peuvent-ils utiliser cette information?

.. rst-class:: solution

:math:`400-200x=0 \Rightarrow x=2`, donc le prix est :math:`24-2(2)=\$20`.

:solmath:`R(2) = 9600+400(2)-100(2)^2 = \$10\,000`

.. rst-class:: solution

Il s'agit de la combinaison prix/revenu qui maximise le revenu total — les propriétaires devraient fixer le prix des billets à 20 $ pour générer le plus grand revenu possible.

.. rst-class:: keepwithnext

**e)** Si le théâtre a une capacité maximale de 450, quel prix maximisera le revenu?

.. rst-class:: solution

Contrainte de capacité : :math:`400+50x \le 450 \Rightarrow x \le 1`. Puisque :math:`R(x)` est une parabole ouverte vers le bas dont le maximum non contraint se trouve à :math:`x=2`, :math:`R` est encore croissante sur :math:`0 \le x \le 1`, donc le maximum contraint se produit à :math:`x=1`.

.. rst-class:: solution

Prix :math:`= 24-2(1) = \$22`

.. rst-class:: keepwithnext

**12)** Étant donné la fonction de revenu :math:`R(x) = 30x-0.025x^2` et la fonction de coût :math:`C(x) = 2x+5`, où :math:`x` est le nombre d'articles vendus, déterminez :

.. rst-class:: keepwithnext

**a)** le revenu et le revenu marginal lorsque 500 articles sont vendus

.. rst-class:: solution

:math:`R(500) = 30(500)-0.025(500)^2 = \$8750`

:solmath:`R'(x) = 30-0.05x`

.. rst-class:: solution

:math:`R'(500) = \$5` par article vendu

.. rst-class:: keepwithnext

**b)** le coût et le coût marginal lorsque 500 articles sont produits

.. rst-class:: solution

:math:`C(500) = 2(500)+5 = \$1005 \qquad C'(x) = 2 \Rightarrow C'(500) = \$2` par article vendu

.. rst-class:: keepwithnext

**c)** le profit et le profit marginal pour des ventes de 500 articles

.. rst-class:: solution

:math:`P(x) = R(x)-C(x) = 28x-0.025x^2-5`

:solmath:`P(500) = 28(500)-0.025(500)^2-5 = \$7745`

.. rst-class:: solution

:math:`P'(x) = 28-0.05x \Rightarrow P'(500) = \$3` par article vendu
